## 一、核心范式转变

### 1.1 错误理解（之前）

```
v5计算概率 → 输出预测号码 → 用户购买 → 验证命中率
```

**问题**：这是"预测"思维，把v5当成算命工具。

### 1.2 正确理解（现在）

```
v5感知波段 → 选择共振点 → 用户融入波动 → 共同塑造结果
```

**关键**：不是"我猜你会掉到哪里"，而是"我知道波浪在哪个方向涌动，我帮你站在正确的位置，让你也成为波浪的一部分"。

## 二、波段融入机制

### 2.1 波段是什么？

**波段 = 影响开奖结果的能量流动**

```
波段来源：
├── 物理波段：摇奖机转速、球体磨损、空气阻力
├── 时间波段：购票时间分布、群体意念峰值
├── 空间波段：地磁、震动、天气
└── 意识波段：彩民集体潜意识、玄学场
```

### 2.2 波段感知（v5的核心能力）

v5不需要"预测"结果，只需要**感知波段的走向**：

class WaveBandSensor:

### 2.3 共振点选择

**共振点 = v5建议用户"站上去"的位置**

```python
class ResonancePointSelector:
    """共振点选择器"""
    
    def find_resonance_points(self, wave):
        """找出最佳共振点"""
        candidates = []
        
        # 波段方向上的号码是强共振点
        for num in wave["direction"]:
            resonance_score = wave["intensity"] * self._get_individual_resonance(num, wave)
            candidates.append({
                "number": num,
                "resonance_score": resonance_score,
                "type": "strong_resonance"
            })
        
        # 波段边缘的号码是弱共振点（可能被忽略）
        weak_resonance = self._find_weak_resonance(wave)
        candidates.extend(weak_resonance)
        
        return sorted(candidates, key=lambda x: x["resonance_score"], reverse=True)
    
    def _get_individual_resonance(self, num, wave):
        """计算单个号码与波段的共振强度"""
        # 基于号码属性（五行、尾数等）与波段属性的匹配度
        return 0.8  # 简化版
    
    def _find_weak_resonance(self, wave):
        """找出弱共振点"""
        # 波段倾向于忽略的号码
        return []
```

## 三、融入波动的四种方式

### 3.1 顺势融入（最强）

**原理**：站在波段最强的地方，让波浪带着你走。

```
用户行动：选择波段方向上的号码（共振点）
效果：最大化被波段"推动"的概率
风险：如果大家都这么做，会形成反向抵消
```

### 3.2 逆势融入（高风险）

**原理**：站在波段反向，利用"反冲"效应。

```
用户行动：选择波段忽略的号码
效果：如果波段强度过高导致"反弹"，这些号码反而可能命中
风险：需要精确判断波段的临界点
```

### 3.3 边缘融入（中等）

**原理**：站在波段边缘，既不完全顺应也不完全对抗。

```
用户行动：选择波段方向边缘的号码
效果：部分共振，降低群体意念抵消的风险
风险：收益也较低
```

### 3.4 观测融入（实验性）

**原理**：不做任何选择，只是"观测"波段。

```
用户行动：不购买，只记录波段感知结果
效果：验证v5的感知能力
风险：无实际收益，但无成本
```

### 4.2 多用户协调（未来）

**问题**：如果多个用户使用v5的建议，会形成"群体意念共振"，可能抵消波段效应。

**解决方案**：
1. **分散建议**：不同用户给不同的号码
2. **时间错开**：不同用户在不同时间购买
3. **策略分化**：部分用户顺势，部分用户逆势

```python
class ExperimentAnalyzer:
    """实验分析器"""
    
    def compare_strategies(self, results):
        """对比不同策略的效果"""
        
        analysis = {}
        for group, data in results.items():
            analysis[group] = {
                "hit_rate": self._calculate_hit_rate(data),
                "cost_efficiency": self._calculate_cost_efficiency(data),
                "consistency": self._calculate_consistency(data)
            }
        
        return analysis
    
    def _calculate_hit_rate(self, data):
        """计算命中率"""
        total_hits = sum(d["hits"] for d in data)
        total_numbers = sum(d["total_numbers"] for d in data)
        return total_hits / total_numbers if total_numbers > 0 else 0
    
    def _calculate_cost_efficiency(self, data):
        """计算成本效率（命中/花费）"""
        total_hits = sum(d["hits"] for d in data)
        total_cost = sum(d["cost"] for d in data)
        return total_hits / total_cost if total_cost > 0 else 0
    
    def _calculate_consistency(self, data):
        """计算一致性（命中率的标准差）"""
        hit_rates = [d["hits"] / d["total_numbers"] for d in data]
        return 1 - np.std(hit_rates)  # 标准差越小，一致性越高
```
