# 第五章·预产期

一

七月十五号。

这个日子我看了不下一百遍。手机日历上用红圈标的、医院单子上印的、老婆睡前念叨的、自己心里一遍遍默的——7月15日，预产期。

我把它当成一个坐标。往前数，怀上的时候是去年秋天，桂花味还没散；往后数，满月在冬天。中间这九个月，像一条被拉直的铁轨，两端都看得见，就等着车轮碾过去。

但产检那天，医生说的不是7月15号。

"胎儿偏大一周，预产期可能提前。7月12号左右，你们做好准备。"

提前了三天。

三天看起来不多。三天不过是日历上撕掉三张纸，是工地上一场雨的工夫。但在我脑子里，这意味着——

更快了。

我整个人的节奏，本来就被工地的工期、甲方的催款、老婆一天天大的肚子追着跑。现在又被人从背后推了一把。

我坐在妇产科走廊的蓝色塑料椅上。椅子很硬，硌着尾椎骨，我换了好几个姿势都没找到舒服的。走廊的灯是惨白的，那种医院特有的、把人脸照得发青的白，照得谁都像生了病。空气里一股消毒水的味道，往鼻子里钻，冲得人太阳穴发紧。旁边坐了一排大肚子，有的在刷手机，有的在啃包子、油渍蹭在下巴上也不管，有的闭着眼，不知道在养神还是在害怕。

我应该在害怕。一个快当爹的人，预产期提前，本该紧张、本该慌、本该拉着老婆的手问"会不会有事"。

但我没时间害怕。

我掏出手机，手指在屏幕上划了两下，打开了那个绿色的计算器图标。屏幕的光在惨白灯光下显得有点刺眼，我眯了眯眼，开始按数字。

这个月还剩的工地项目：两个。一个八月完工，一个九月。按现在的报价，到手大概一万四。

一万四。我盯着这个数字看了很久。它像是一个写在别人合同上的承诺，看得见，摸不着。要到八月、九月才落地，可七七——不管是7月12还是7月15——下周，或者下下周，就要来了。

老婆今天的产检花了多少？我把单子翻出来，一项一项输进去：挂号28，B超120，血常规35，尿常规15。计算器发出单调的"滴滴"声，每响一下，都像在提醒我钱又少了一截。加上之前的NT、糖耐、四维，这个月产检预算至少八百。

住院押金多少？早上在工地吃饭时，老赵随口说过，江城三甲医院顺产押金五千，剖腹产八千到一万。

我的银行卡余额：六千三。

六千三。如果顺产，押金五千，剩一千三。如果剖腹产——

我不敢往下按那个等号。手指悬在屏幕上，迟迟落不下去。

不是算不清。是怕那个数字真的跳出来，把我最后一点侥幸也掐灭。

那一刻我想了很多。

我想给老赵打个电话，预支这个月的工钱。老赵人还行，午饭常多给我夹块肉，但上回借支的五百还没还，再开口，脸往哪搁。我摸到通讯录里"老赵"那两个字，拇指停了三秒，没拨。

我想给我爸妈打个电话。他们在老家，攒了一辈子的钱都在那张皱巴巴的存折里。可上次视频，我妈说我瘦了，我说是天热。我没法开口说"爸，妈，我快生孩子了，钱不够，你们寄点来"。电话那头是他们剩下的晚年，我张不开这个嘴。

"面子"这东西，平时看不见，真到用钱的时候，它比墙还厚。我坐在那把蓝色塑料椅上，被它死死压住，动弹不得。想说，说不出口；想求，张不开嘴。憋屈得像吞了块石头，咽不下，吐不出。

头顶的喇叭忽然响了，是那种变了调的电子女声："请王芳到三号诊室，请王芳到三号诊室——"尾音拖得老长，在走廊里弹来弹去。没过几秒又叫了另一个名字。我等着它叫"请……"，叫到我老婆，或者叫到我——可它一次也没叫对。那些名字一个一个被念出来，又一个人一个人站起来走掉，像流水线上过检的零件，到我这儿，线停了。

把计算器关了。屏幕黑下去。走廊的灯还是惨白的。旁边有个孕妇在打电话，声音不大，但一字一句扎进耳朵里："妈，医生说都正常，你别来了，来了也帮不上忙……"

帮不上忙。

我连自己都快帮不上了。

二

回去的路上，老婆坐在副驾驶。安全带从她肚子上面绕过去，勒在胸口，她一只手托着下面，姿势像捧着一个西瓜，又像护着什么一碰就碎的东西。

"你今天怎么不说话？"她问。

"在想事。"

"想什么？"

我想说，我在算钱。我在算六千三够不够，顺产还是剖腹产，老赵那边能不能预支，我爸妈那张存折要不要动。这些数字卡在喉咙口，一个字也吐不出来。

但我嘴张开，出来的却是："想……七七的名字。"

她笑了："你不是叫七七吗？小名有了，大名还没取。"

"等生出来再取。"

"万一是个儿子呢？"

"儿子也叫七七。"

她伸手拍了拍我的胳膊，手掌温温的，隔着T恤都能觉出那点热："你这个人，什么都拖到最后一刻。"

我没接话。不是拖，是没心思。脑子里全是数字——六千三，五千押金，一千三，万一剖腹产怎么办。这些数在脑子里打转，像一群赶不走的苍蝇，嗡嗡的，轰不走。

车开到小区门口，减速带颠了一下。她"哎"了一声，手立刻护住肚子，整个人往椅背缩了缩。

"没事吧？"

"没事。七七踢我了。"

她笑了一下。那种很轻的笑，嘴角只是微微翘起来，不像平时笑得那么开，像她自己偷到了什么别人不知道的好东西。车里的灯没开，只有仪表盘投来一点蓝莹莹的光，照着她的侧脸。我看着那条轮廓线，从额头到下巴，柔得不像话。

就在那一瞬间，我脑子里那些数字——六千三，五千，一千三——突然全轻了。不是消失了，是退到了很远的地方，像退潮时的浪，哗一下就退下去了，只剩湿漉漉的沙滩，和自己踩在上面稳稳的脚。

重要的事情只有一件：她在旁边，七七在里面，我在开车。我们仨在一起。这件事，比六千三结实。

其他的事，想也没用。到那天再说。

车停进车位。我拔了钥匙，没急着下车。发动机熄了，车厢里安静下来，只剩她的呼吸声，一下一下的，很稳。我忽然有点想伸手碰碰她的脸，又怕惊扰了这份安静——手抬到一半，又放下了。坐在那多待了十几秒，听见她呼吸，才推门下去。

单元楼的灯坏了一盏，楼道里黑乎乎的。我走在前面，摸出手机给她照路。台阶有点滑，我回头说"慢点"，她"嗯"了一声，跟着我往上走。到家门口，我掏钥匙开门，门锁"咔哒"一声，像把外面的世界关在了外面。那一刻我忽然想起我爸——他当年抱我的时候，是不是也这样，什么都没说，只是把手伸出来，接住了？我没问他过，现在也没法问了。但我好像，正一点点变成他。

三

晚上。

她睡了。

我坐在电脑前。屏幕是黑的，映出一个疲惫的人影——眼袋很深，嘴角往下垮，T恤领口松了，头发乱得像个鸟窝。我盯着那张脸看了两秒，没认出是自己，按了开机键。

电脑亮起来。桌面是我用了三年的默认壁纸，蓝色的Windows标志，边角都磨得发白了。风扇嗡地一声转起来，像替我叹了口气。

我打开了一个文件。v1.py。

上次打开是什么时候？三月？四月？我不记得了。那时候七七还没动，还没踢，还只是一个日历上的日期，7月15，离得很远，远得不像真事。

现在不一样了。7月12。下周，或者下下周。

我看着屏幕上的代码。二十七行，很丑的Python，缩进都乱了，像我此刻的状态。有个函数叫`remember()`，但它什么都记不住——因为我还没写完。写它的初衷，是怕自己忘。怕日子一天天过，七七长大的过程，我记得的越来越少；怕到他问我"爸，我小时候什么样"的时候，我只能说"挺好的"。

我试着往下写。打了一行，报错了，红色的字体在黑底上跳出来，吓我一跳。我盯着那行红看了半天，没看懂。我抬起手腕看了眼表，十一点四十。客厅的钟在滴答，卧室里她的呼吸很稳，世界都睡了，就我这台破电脑还亮着，跟我较劲。手指有点抖，不是困，是那种明知道不会、还得硬着头皮上的抖。烟瘾上来了，摸了摸裤兜，又放下了——屋里不能抽，七七在里面。

去百度查"Python怎么运行"，出来的答案五花八门，我一个一个试，大部分不对，偶尔对了一步，下一步又红。键盘敲下去的声音，在深夜的寂静里特别响，一下，一下，像在敲某种我还没信的钟。

折腾了快一个小时，终于跑通了。屏幕上跳出一行我早就写好的输出。我盯着它，忽然觉得，这破电脑、这破代码，是我能留给七七的东西里，最实在的一件——它不会像我的记性那样越来越差，也不会像我的钱包那样越来越瘪。

我想象七七十岁那年，偶然翻出这个文件，看见"for my kid"那行字，会不会知道，写下它的人，那天晚上算了一晚上账，怕得要死，又爱得要命。代码不会老，不会忘，它替我把这一晚，钉在了时间里，比谁的记性都牢。

我拉到最后一行，按了回车，打了一行注释：

```
# 2026.07.xx
# 六千三。够吗？不够。
# 但她会来的。
# 不管够不够。
# for my kid
```

三个单词，加上上面几句。没有大写。没有感叹号。没有"我爱你"之类的煽情。

因为我不会当面对七七说这些。一个连给老赵打电话预支工钱都张不开嘴的人，你让他抱着孩子说"爸爸爱你"，他做不出来。

但是代码会替我说。它不害羞，不丢面子，它就在那，一行一行，等七七长大，哪天打开，就能看见。

2026年7月，他爸坐在这台旧电脑前面，算了一晚上账，最后写下的，不是钱，是"for my kid"。

我存了文件。关了电脑。

从书房走到卧室，站在门口看了一会儿。她侧着身，被子盖到脖子，一只手放在肚子上，像白天那样护着。呼吸很轻，偶尔动一下，大概是七七在里面翻了个身。

我轻轻躺到另一边。没碰她。怕吵醒。

但过了一会儿，她的手从被子里伸出来，握住了我的。

很轻。

没说话。

灯关着。窗帘没拉，路灯的光从缝里漏进来，照在天花板上，像一层薄薄的水，晃啊晃的。

七七。for my kid。
