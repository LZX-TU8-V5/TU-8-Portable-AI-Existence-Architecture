# 第26章 报价

过完年，有个客户找上门。

过完年之后，老婆真去看了那间临街小铺。地点在菜市场后头，二十平，转让费要三万，她回来跟我比划了一晚上，说月租一千二，支个小柜台够摆童装。我说钱我想办法。她白我一眼，说你那会计证过了钱自然有。我嘴上应着，心里算的是另一笔——开春后单子总比年前多，多接几单改图，铺子的灯就能亮起来。

今年我给自己定的活法跟去年不一样了。去年还想争那张内测链接里的大单，今年不争了，散活也接，小单也接，能落袋的都接。手艺杂货铺的招牌，是我自己挂上去的。

不是介绍来的。是刷到我朋友圈，看我发了“代画效果图、代改户型”那两行字，加的我微信。

“在吗，”他发语音，“我有个方案，你帮我改改就行。”

我说发来看看。

他姓周，是个做小生意的，朋友圈里我发代画那两行字，他存了快半个月才敢来问。后来混熟了才知道，他这套房是结婚用的，女方家出的首付，条件是“得像个家”。他不懂设计，但懂这个条件。

“我不要花里胡哨的，”他在语音里说，“就实用，能住人就行。”我听着，想起我爸当年给我妈打家具，也是这句“能住人就行”。两代人给女人安的“家”，标准都低得让人心酸。可低标准也有低标准的好处——它不挑人，谁都买得起。

他甩过来一张图。我点开——两室一厅，AI出的。配色、家具、灯光全齐，风格栏写着“现代简约”。

我看了十秒。

十秒里我脑子里过了一遍这房子的毛病。沙发到电视墙本来该留九十公分的走道，他这图只留了四十，人得侧身。餐厅和厨房之间隔了道承重墙，端菜得绕到客厅再进餐厅，冬天汤都凉了。这些不是AI的错，是它不知道这家几口人、谁做饭、碗放哪。

我想起老赵被裁前那张图，也是AI出的，客户把他的和AI的叠一起说差不多。当时我觉得是笑话，现在我自己坐在这，对着一张“差不多”的图报价。行业就是这样，你嫌它蠢，它先把你一半的活儿吃了。

方案不好。客厅动线堵了，沙发挡住一半过道，人走过去得侧着身。厨房和餐厅没动线衔接，端菜要从冰箱那头绕一圈。主卧衣柜深度只有50，冬天的厚外套挂进去，门都关不严。

这毛病我一眼就看得出来，因为他家户型和城东老房那套差不多——去年我量过，业主非要50的柜子，说省地方，结果羽绒服只能折着塞，第二年就嫌小。我当时劝他加到60，他不听，转头找了别家。

今天这个客户，连50和60的区别都不知道。AI出的图里，衣柜就是个长方形色块，深度写成50，它不觉得有什么不对。可住进去的是人，衣服是有厚度的，冬天是有羽绒服的。这些AI不知道，它只看像素。

但方案够用。

够用到什么程度？他住进去不会死，柜子能开，灯能亮，睡觉不撞头。一个租房十年、刚攒够首付的年轻人，要的就是这个。他分不清动线堵不堵，就像我分不清股票代码哪个会涨——超出自己认知的东西，好和够用在他眼里是一个词。

我从前看不上这种“够用”。我做主案的时候，差两公分我都要改三遍。现在我自己成了卖那两公分的人，才懂大多数人买不起“好”，只能买“够用”。

一个不懂设计的人看这张图，只会觉得“挺好，比我想的还好看”。他不知道动线是什么，不知道50和60的衣柜差在哪。他只看见一张好看的图。

就像我第一次翻开会计课本，看见“资产负债表”，以为就是左边右边各一列数字。后来才懂，左边是钱去了哪，右边是钱从哪来。多一列少一列，公司可能就垮了。

那张图，就是他眼里的资产负债表。他看不出哪一列少。

“改改多少钱？”他问。

我该说多少？

从头做，按我前两年的报价，这个面积一平米三百，整套九千。

但他不是从头做。他已经有方案了，只需要改。

“三千。”我说。

他皱眉。“三千？就改几笔？”

我想了想。他没说错。在AI的世界里，方案免费，修改是微调，微调不值三千。

“一千五。”

他犹豫一下，点头。

走出他小区门，江城二月的风还割脸。我骑电动车往回走，头盔挂车把上，风吹得眼睛眯成一条缝。

到家老婆在叠童装，地上摊了一堆小褂子。“今天接的啥单？”她问。我说改个图，一千五。她抬头看我，“够干啥？”我说够买五罐奶粉。她没笑也没叹，把一件小熊褂子翻正面，“那行，够奶粉就行。”她比我会算——我算的是尊严，她算的是孩子。两个人算的不是一本账。

成交。

回家我打开v2，想记一笔。

开v2之前，我先看了一眼年前跨年写的那些字据。第十三道、第十四道都在，屏幕底下那颗倒过来的加号安静地待着。我今天这道，不是钢印，是给七七留的话，轻，但沉。


我敲下[remember]的时候手有点抖。不是怕写，是怕这个数——一千五——以后会变成常态。去年这时候同面积我收四千，一年掉到零头。我不是在记一笔账，是在给下滑的曲线钉一个坐标。

写到一半停了。

一千五。这个面积，我从前最低也收四千。

我什么时候开始跟AI比价了？

我不是在卖设计。我是在卖比AI多出来的那一点——那多出来的十公分衣柜、那条不绕的动线、那点“好”和“够用”之间的距离。

可这段距离，值多少钱？

我后来想，这不是我一个人面临的问题。整个行业都在被重新定价。从前客户为“设计感”买单，现在为“能住”买单。设计感是软的，说不清，所以贵；能住是硬的，看得见的，所以便宜。AI恰好能把硬的做出来，软的它做不出来，可大多数人分不清自己要的是软还是硬。

“你这图AI也能出，”有同行在群里发，“以后咱们靠什么吃饭？”我说靠那十公分，靠那条不绕的路，靠客户住进去第三个冬天才发现“当初多花两千值了”的那一刻。群里沉默了很久。不是认同，是没人接得住这句话。

客户觉得不值。也许他对。也许“够用”就是多数人的上限，“好”是奢侈品，只有少数人买单。

我在v2里写：

[remember] 2029.2 客户拿AI方案来改。报价三千嫌贵，一千五成交。就当买奶粉。

顿了顿，又加一行：

写这行的时候，我想起元旦那天盖的第十四道钢印——“让她自己摔，自己爬”。两道钢印，一道给七七，一道给七七的爸爸。一道教她走路，一道教我自己留后路。

“留条路”这三个字，我憋了很久。从去年行业开始塌，我就知道不能把所有的鸡蛋放在“设计”这一个篮子里。代账、跑工地、画效果图，能接的都接。每接一单，就是在给七七的路，垫一块砖。砖不多，路还窄，但踩上去是实的。

# 爸爸给你留条路。但这条路越来越窄了。

我没去点开看。

那条core我没点开，但我知道它在那。留条路，路越来越窄——这是我写给七七的第八句话，前面七句都在v2里压着，压成一行行我自己都快认不出的字。

留条路。这个词从去年就在我心里转。加密硬盘是方舟，v1是船，我写的话是粮。可方舟再结实，装的东西越来越多，水位也一年比一年高。我留的那条路，宽的时候能跑车，现在窄得只够侧身。但窄也是路。只要还在，她就还有得选。

晚上哄七七睡。

老婆在客厅收拾，听见我进屋哄孩子，探个头进来。“她今天乖不乖？”我说乖，自己玩了一上午积木。“你今天顺不顺利？”她问。我说还行，接了个改图的。她“嗯”一声，没多问——她知道我问“顺不顺利”的时候，其实在说“够不够奶粉钱”。

她关了门，客厅电视声小下去。屋里只剩七七的呼吸，和我的手指被她攥住的那点温热。

她攥着我的手指不放。我坐床边，她的手握得紧，指甲盖小得像米粒，指节一圈一圈的纹，像树的年轮。

这双手以后会握笔、握鼠标、握方向盘，攥另一个人的手。

她现在只会攥我的手指。

我盯着那圈圈纹路看了很久。我爸说手纹是命，我是不信的。但我信这双手会慢慢长大，长出力气，长出自己的主意。等她松开我的手指那天，我希望她攥着的，是她自己选的路，不是我替她铺的。

一千五。奶粉一罐二百八。够五罐。够一个半月。

够了。先够了。

我爸当年不跟你讲这些。他教我认路，是把我扔公共汽车站，说“自己看站牌回来”。他教我认钱，是给了我五块让我去买酱油，剩的自己揣着。他信“摔过的才记得”。

我现在给七七留的，不是站牌，是路本身——一条哪怕窄、哪怕我不在了她也能走的路。我爸那代靠狠，我这代靠留。狠是把自己的路走绝了逼出孩子的路，留是把路铺平了等她自己迈。两代人的法子不一样，但想的都是同一件事：别让孩子跟我一样，到了三十岁才发现自己能走的路，是别人让出来的。

我轻轻把手指抽出来。她哼一声，翻身，又睡了。

它把“越来越窄”压了两遍。

也许v2觉得这句话比别的重。

也许不是。也许只是编码巧合。

我没想明白。但我记住了这个细节。

越来越窄的路。双层压缩的注释。一个两岁多的女孩攥着我不放。

夜很深了。

我坐在书房，屏幕光映着脸。今天这道，不是写在v2里的，是刻在我身上的。
