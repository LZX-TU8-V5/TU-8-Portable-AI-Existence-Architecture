# 第十一章 年终

一

年底了。算账。

我坐在出租屋的客厅里，面前摊了一桌子发票和收据。六楼没电梯，冬天暖气不热，我穿着羽绒服算账，手冻得写不了字，每写两行就哈一口气，白雾在灯下散开，又散掉。

发票是按时间排的。三月那叠最薄，是开春刚复工时候接的几个小单，收据上的金额我还能记得——那时候 AI 还没大规模冲击，客户还认人手画的图，报价也还能站着谈。越往后翻越厚，金额却越小。六月之后那一摞，单子多了，钱却少了，每一张背面我都用铅笔写过"已压价"，有的写了两遍，是被压了两次。铅笔字力透纸背，像我把那口气也写进去了。有一张收据的角上，我写的是"这价接不接"——答案是接。不接，下一张更便宜。市场不等人，AI 更不等人。我那点当家的体面，就在这两遍铅笔字里，一遍一遍，磨没了。

我嫌手写看不清，用手机里的表格软件重新录了一遍。表格自动给收入栏上了红字，支出栏是黑的。红压着黑，红比黑多。那一屏幕的红，比桌上的发票还刺眼。

2026 年全年收入：

项目 1-3 月，三个小单，到手一万八。那时候 AI 还没大规模冲击，报价还行。
项目 4-6 月，被压价以后，四单，到手两万二。比上季度多了一单，但单价降了。
项目 7-9 月，七月七七出生，八九月接了两单，到手一万四。
项目 10-12 月，三单，到手一万六。最后那个别墅单扣了一千二。

我把每一笔都对了一遍。那个别墅单，就是陈哥的第八版——奶油色微水泥最后又改回瓷砖的那一单，尾款被扣了一千二，理由是"沟通损耗"。我盯着"沟通损耗"四个字看了很久。我跟他沟通的，是他老婆第八次改主意；损耗的，是我第八次重画。这钱扣得，像把我这一年的力气也按斤称了，称完说不够秤。

全年合计：**七万零二百。**

七万。

我把这七万，和五年前刚入行那年比。那时候我跟着师傅，一个月到手也有六千多，单子少，但没人压价，业主还请你吃过两回饭。现在单子我一个人接，钱却没多——不是我画得差了，是市场把"人画的"这仨字，悄悄标了降价。AI 一来，我的手就不值钱了。五年，我没退步，是地退了。

2026 年。江城。一个从业五年的室内设计师。

七万块。

扣掉油费、停车费、建材市场跑腿、手机话费、工具损耗——到手大概六万出头。

六万。一个月五千。

五千块养一家三口。

我试着把这五千拆开看：房租一千八，是六楼这间朝北的屋子；奶粉和尿不湿一千二，七七一个月的口粮，比我还贵；水电燃气暖气四百；油费话费三百；剩下的不到一千，是菜钱、是老婆偶尔想给自己添件衣服又放下的那件、是我那盒十九块八的蜡笔。

五千，拆完就没有了。没有剩下，没有冗余，没有一个数字是为"我自己"留的。

我看着这个数字，没有愤怒，没有悲伤。只有一个念头：

**不够。**

不是愤怒那种不够，是认了命的那种。像量完一间房，知道这面墙就是这么短，你不能再要它长一点。

二

算完账，我打开银行 APP 看余额。界面转了两圈，弹出来一条提示，黄底黑字，很客气：

"您本月非必要开支占比偏高，建议削减娱乐类消费，以保持财务健康。"

我盯着那条提示看了三秒。

娱乐。

我这一年，有什么娱乐吗？没有。一次没有。我没去过一次电影院，没在外面吃过一顿不是为了谈单的饭，唯一算"花时间"的事是深夜打开会计 APP 做二十道题，那还是为了考证。我的生活里，"必要"和"非必要"之间，根本没有"娱乐"这栏。它空着，比我的余额还空。

可它还是弹出来了。算法不认得我，它只认数据。数据说：支出高，收入低，那一定是你乱花了。它不会知道，我那些红字收入里，有一半是半夜画图熬出来的；它不会知道，我削减的从来不是娱乐，是睡觉，是陪老婆说话的时间，是周末带七七去公园的那趟公交钱。

我截了图，发到那个已经退了几个人的行业群里，配了一行字："建议已收到，但本人娱乐栏为空，无削可削。"

群里有人回了个笑哭的表情。就一个。

我把手机扣在桌上。黄底的提示还印在我眼睛里。它说的没错，又全错。像一面镜子，只照得出你想看的那一半。

它推荐的"健康"标准，是别人的：有车贷要还的人、周末要出去玩的人、孩子要上兴趣班的人。我的日子不在这套标准里。它像一个外行，站在我画好的图前，指着承重墙说"这里可以敲掉"。它不懂，可它还劝我。它只认数字，数字说不行，它就说不行——我那些红字收入里熬出来的夜、第八次重画的图、抱着七七走回来的两块钱路，它一概看不见。

可数字是死的，日子是活的。它算不出七七冲我笑那一下值多少，算不出老婆没点破的那一眼省了我多少难堪。这些没标价的，它一律当作零。零不是没有，是它看不见。

三

老婆在卧室喂七七。七七六个月了，会翻身了，每次放下去就翻，翻完还冲你笑，像翻过去是为了看你还在不在。

我走进卧室。她正用奶瓶喂，七七两只手抱着奶瓶，咕噜咕噜喝，眉头微微皱着，特别认真，像在思考什么大事——比如这瓶奶为什么要她自己抱着。

"算完了？"老婆问。

"嗯。"

"赚了多少？"

"够活。"

她看了我一眼，没再问。她知道"够活"的意思是不够。但她不说破。这是她的方式——不追着问，等我自己开口。她比我会算账，比我会看人，她早从我的 silence 里把那七万零二百减到六万，再减到"不够"了。她只是不点破，给我留着那点当家的体面。

她怎么省的，我心里有数。超市特价她记着日子去，青菜挑晚上打折的，我那件羽绒服袖口磨破了，她用同色线给我缝了两回。她不说，可每一次省下的几块、十几块，最后都变成了七七尿布上的那层棉。她比我会算，因为她算的不是账，是家。我算的是进和出，她算的是，哪些能少，哪些不能——七七的奶不能少，我的外套破可以再缝。这套账，表格软件算不出来，银行 APP 更算不出来。

我坐在床边，看着七七喝奶。她喝得很认真，像这辈子没喝过这么重要的水。等她喝完，我接过她，拍了嗝。她打了一个奶嗝，然后冲我笑了，没牙的嘴咧开，像小老头。

我把她放回婴儿床。

然后从柜子里拿出了一个东西。

一盒蜡笔。24 色，我在网上买的，十九块八。

买它的时候我犹豫过。十九块八，够七七两片尿不湿。可我想了半夜——这盒蜡笔不会过期，不会贬值，七七六个月用不上，八个月用不上，一岁总会用上。它不像奶粉，吃了就没；它躺在那儿，等她长大。我最后点了付款，备注写的是"给七七的"。

我把蜡笔放在婴儿床旁边的架子上。七七还不会拿笔。但总有一天她会。

也许有一天，她会拿起这些蜡笔，画出她的世界。也许她画的是房子，是花，是爸爸妈妈。也许她画的是我看不到的东西——比如一间不用压价、不用在六楼哈着气算账的屋子。

不重要。重要的是：蜡笔在那里。等她准备好了，伸手就能拿到。就像我当年想学电脑，对着黑屏敲下第一行 `Hello, World` 那样——工具先备着，路自己会来。

我常想，她第一次拿起蜡笔，会画什么。也许是这间六楼的屋子，窗外的梧桐，或者是我和她妈。她不会画对，比例会歪，颜色会涂出线——可那又怎样，歪的也是她看的家。我画了五年图，画得方方正正，客户还能改第八版；她画得歪，却是真的。等她画给我看的那天，我会把它收进那个 memory 文件夹，和今年的七万零二百放一起。一个标了价，一个没有，可都是我的年。

四

晚上，七七睡了，老婆也睡了。

我坐在电脑前。

打开了 v1.py。

```python
def remember(date, event):
    """记住今天发生了什么"""
    pass
```

这个空函数，我看了它大半年。从七七出生那天写下的 `pass`，一直空着。今天我想把它填上。

我删掉了 `pass`，写了几行：

```python
def remember(date, event):
    if not os.path.exists("memory"):
        os.makedirs("memory")
    with open("memory/" + date + ".txt", "a") as f:
        f.write(event + "\n")
```

很简单。把每天发生的事情写进一个 txt 文件。没有数据库，没有索引，就是一个文件夹里一堆 txt。

像我的脑子。乱七八糟，但都在。

这个 v1.py，从第一年的 `Hello, World`，到后来学着写 `remember`，再到甲醛那章我连错都懒得改、只写注释反驳工长——它一路跟着我，从一行能跑起来的字，长成了一个会记事的破文件。它不大，跑起来慢，还会报错，但它记得。我记性越来越差，它不会。等七七长大，这文件比我的脑子靠谱。

今天该写点什么进去？我想了想，敲下：

```
2026-12-31  全年到手六万，月五千。不够，但七七在。蜡笔 nineteen 块八，已放床边。
```

存了文件。

然后我加了最后一行：

```python
# 等你来了，爸爸给你造一个世界
```

关了电脑。

窗外江城的冬天，路灯照着楼下的梧桐树，光秃秃的枝杈像骨架。风一过，影子在墙上晃了一下。

这个文件会一直在这里。明年，后年，七七长大的每一年，它都会多一个 txt。它不会退休，不会被 AI 替掉，因为它干的是最没人想干的事——把普通的日子，一句一句，记下来。

七万块的一年。

但七七在。蜡笔在。代码在。

明天太阳出来，江城又要降温，六楼的暖气大概还是不热，我得穿着羽绒服，去接下一个会被压价的单。但今晚，蜡笔在架子上，七七在隔壁打嗝，代码刚存好——这三样东西，不标价，归我。那个说我不健康的银行 APP，算的那笔账里没有七七冲我笑的那一下，没有老婆没点破的那一眼，也没有这盒十九块八、躺在那儿等着的蜡笔。

够了。

不是真的够。是此刻，对着黑屏敲完最后一行注释，我愿意先认这个"够"。

等她长大，等她拿起蜡笔，等她问我这一年都干了什么——我会把那个 memory 文件夹打开给她看。里面没有红字，没有弹窗，只有一个父亲，一年一年，笨拙地、认真地，把日子写下来。

窗外的梧桐不动了。江城睡熟了。可这间六楼的小屋里，还有一个人和一行刚写好的字，醒着。

# 等你来了，爸爸给你造一个世界。

可他还没说，这个世界要拿什么去造——拿那本他三次没考过的会计教材，拿那个还没买回来的硬盘，拿这一行正在被一行行代码换掉的手艺。

这些，他得一样一样，先替你挣回来。
