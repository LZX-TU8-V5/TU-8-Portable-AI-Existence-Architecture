# 第十八章·v2

## 一

成绩出来以后的那几天，我说话很少。

经济法六十三，过了。实务五十六，差四分。两科得同一年过，有一科不过，另一科的成绩也不作数。等于白考。

老婆那几天不提这件事。她照常做饭、带孩子、问我明天去哪个工地。我照常起床、出门、量房、画图、回来。我们俩谁都没往那两个数字上碰。

可它就在那儿。看不见，摸不着，吃饭的时候在，画图的时候也在，我一停下来它就浮上来。

七七发烧那晚之后，她第二天下午又低烧了一次，37.9。我请了半天假在家守着，物理降温，喂水，到傍晚退了。第三天彻底干净。她又开始在爬行垫上扔摇铃，扔下去，弹起来，咯咯笑。

那两天我坐在她旁边，一直没怎么说话。

老婆说："你这两天怪怪的。"

"哪儿怪？"

"你不说话的时候，比说话的时候响。"

我没接。

那天下午我去了一趟建材市场，帮一个老客户挑踢脚线。老板报了三种价，我一个都没听进去，最后随手指了中间那款。回程骑电动车，等红灯的时候我才发现自己把车骑过了两个路口。

我在路边停了很久。旁边有个修手机的摊子，喇叭循环播放"换屏换电池"，播了得有五六遍。

那天晚上老婆问我，踢脚线定了没有。我说定了。她问多少钱一米，我张了张嘴，答不上来。

她看了我一眼，没再问，转身去厨房洗碗。水龙头开着，水声哗哗的，碗碰在池子里叮当响。我站在客厅中间，那声音听起来比骂我还难受。

## 二

六月十七号晚上，十一点。

七七睡了。老婆也睡了，睡前在门口站了一下，看我一眼，没劝，把门带上了。

我打开电脑，屏幕上还是 v1.py。

这个文件从第一年那行 `Hello, World` 开始，跟着我走了快两年。最初二十七行，后来我一点点往上加：remember()、日期记录、几个没写完的函数。到今年六月，它长到了八十三行。

那天我把它从头到尾读了一遍。

读到一半，我停住了。

**它没有容错。**

什么叫没有容错？

就是如果我给它一个它不认识的东西，它不会说"这个我不会"，也不会说"我先记着"。它会直接崩。屏幕上跳一屏红字，最后一行写着 Traceback，程序退出。

我当天下午就撞过一次。

七七退烧那天，我想把她的体温记进去。日期我顺手填成了"6月15"，少了年份。回车一按——红字，一整屏。

最上面一行是我写的那句调用，最下面一行是 Traceback，中间夹着七八行英文，我只认得 File 和 line 这两个词。文件名后面跟着一个行号：line 71。

我按提示翻到第 71 行。那行是我自己写的，一个把日期拆成年月日的处理。它默认所有日期都是"年-月-日"，我给它"6月15"，它不会拆，就报错。

我把那行改了，重启，再输一次。这次不报错了，可它也没存进去——因为路径是按"年-月-日"拼的，拼出来的文件夹根本不存在，写不进去。

我又改。改到第三遍的时候我放弃了，把电脑合上，去客厅坐着。

客厅没开灯。我在沙发上坐了大概十分钟，什么也没干。七七在婴儿房里翻了个身，哼了一声。老婆从卧室出来上厕所，看见我坐在黑里，吓了一跳。

"你坐这儿干什么？"

"坐一会儿。"

她没多问，去了趟卫生间，回来时顺手把客厅的灯拧亮了，又回去睡。

那十分钟里我想的不是代码。我想的是：一个程序遇到自己不认识的东西，为什么非得躺下不可？它就不能说一句"这个我不会，我先记着"？

这跟考会计是一样的。

第一次考，我差五分。第二次考，我差四分。为什么进步了一分？不是因为我变聪明了，也不是因为我把书多背了一遍。是因为第二次我换了策略：不会的题先跳过，做完会的，再回来猜。

第一年我卡在一道不会算的题上，死磕，磕了十五分钟，最后还是错。这十五分钟，够我做三道会的题。

**错了就记住，下次不再错。不会的就先放着，先做会的。**

这就是容错。

我的 v1.py 不会这个。遇到不认识的，它不跳过，也不记下来。它躺下，报错，什么都不干了。

跟第一年的我一模一样。

## 三

先把 v1.py 另存一份，名字叫 `v1.py.bak`。

另存的时候我犹豫了一下。按说新的出来了，旧的就该删掉——留着占地方，还容易以后改错文件。

可我没删。

那个文件里有七七出生之前的我。有我在炸鸡店门口蹲着写的注释，有甲醛那次我懒得改错、只在末尾写了一句反驳工长的话，有年终那天算完账我敲进去的六万出头。那些东西现在看很幼稚，甚至跑起来都费劲，可它们是我一路过来的痕迹。

删了，就等于说那个版本的我不算数。

所以留着。`.bak` 这个后缀，是我给它留的座。

然后新建文件：`v2.py`。

思路很简单，三条：

1. 出错了不崩，记下来
2. 记住了，下次不再错
3. 不会的先跳过，标成"待学"

核心是三个列表：

```python
errors = []    # 犯过的错
known = []     # 已经掌握的
pending = []   # 待学习
```

然后 remember() 升级了。以前它只干一件事——往 txt 里写一行字。现在它能分类：

```python
def remember(date, event, tag="daily"):
    # 出错了：存进 errors，不再犯第二次
    if tag == "error":
        errors.append({"date": date, "event": event, "count": 1})
    # 学会了：存进 known，下次直接用
    elif tag == "learned":
        known.append({"date": date, "event": event})
    # 其余的，还是老办法，写进txt
    else:
        with open("memory/" + date + ".txt", "a") as f:
            f.write(event + "\n")
```

很粗糙。没有数据库，没有索引，就是三个列表加上一堆 txt 文件。关掉电脑，数据就落到硬盘上，下次打开再读进来。

但逻辑是对的。

**错了就进 errors，学会了就进 known，日常的还是 txt。**

下次遇到同样的情况，先查 errors——这个我犯过没有？犯过，就不犯第二次。再查 known——这个我学过没有？学过，就直接用。都不在，就进 pending，先放着，哪天想起来再说。

就像我考会计。

不过这三个格子里，最难的是 pending。

errors 好办，错了就记。known 也好办，会了就记。可 pending 里放的是"见过但不认识"的东西，我一开始想得太复杂——我想给它排优先级，想按日期排序，想让它自动提醒我哪条该学了。

我写了两版，都写不下去。第二版写完我删了，重来。

最后我用了最笨的办法：**pending 只负责收，不负责排。** 它就是一个筐，见过不认识的，往里一扔。什么时候翻、先学哪条，我自己定。

它不管顺序，只管别丢。

写到这儿我停了一下，看了眼时间，十二点半。

## 四

写完的时候已经凌晨一点。

200 多行。我把 v1 那八十三行里还能用的搬过来，剩下的重写。

我运行了一下。先输一条测试数据：

```python
remember("2027-06-15", "实务最后一道大题长期股权投资不会做", tag="error")
```

运行成功。errors 里多了一条。

我又输一条：

```python
remember("2027-06-15", "借贷必相等，资产=负债+所有者权益", tag="learned")
```

运行成功。known 里多了一条。

然后我加了一条日常的：

```python
remember("2027-06-15", "七七发烧退了。我在婴儿床边坐了一夜。如果我死了她怎么办？")
```

这次没写 tag。默认是 daily。

运行成功。memory 文件夹里多出来一个 txt。

我打开那个 txt 看：

```
七七发烧退了。我在婴儿床边坐了一夜。如果我死了她怎么办？
```

就这一行。

v2 记住了。三种东西，分开放：错的、会的、日常的。不会搞混。

我把椅子往后推了推，伸了个懒腰。腰很酸——在地板上坐了一夜，两天了还没缓过来。肩膀也僵，抬手到一半能听见骨头响。

我盯着那个 txt 看了很久。

一行字，躺在一个文件夹里，文件名是日期。它不会问我这句话是什么意思，也不会安慰我。它就记着。

## 五

门响了一下。

老婆穿着睡衣站在门口，头发有点乱："你还不睡？"

"快了。"

她走过来，看了眼屏幕。屏幕上是一堆我看得懂、她看不懂的字。

"你这是……在干什么？"

"给它分了个类。"我说，"以前它什么都往一块儿记，记多了就乱。现在分三格：错的、会的、还不会的。"

她想了想："那'还不会的'怎么办？"

"先放着。"

"放着就不学了？"

"先做会的。"我说，"会的做完了，再回来啃那些不会的。"

她点点头，没再说什么，转身去厨房接了杯水，端回来放在我手边。杯子底磕在桌面上，响了一声。

"喝完早点睡。"她说，"你这两天眼睛都是红的。"

"嗯。"

她走到门口又停住，背对着我说了一句："成绩那事儿，我不是不问。我是不知道怎么问。"

"不用问。"

"那你自己别老搁心里盘。"她说，"盘久了会馊。"

她说完就出去了。我听见她躺下，床板轻轻响了一下。

我喝了一口水。水是凉的，顺着嗓子下去，人清醒了一点。

那句"盘久了会馊"，她大概是随口说的。可我听进去了。我确实在盘——盘那四分，盘明年还要不要考，盘考不过的话我这五年算什么。盘了两天，越盘越沉。

我把杯子里的水喝完，转回屏幕。

## 六

我又看了一遍那三个列表。

errors 里一条：长投不会做。

known 里一条：借贷必相等。

pending 里空着。

我忽然觉得这三个列表挺眼熟。

errors 里躺着的东西，是疼的。known 里躺着的东西，是稳的。pending 里躺着的东西，是等的。

疼的东西和会的东西，住的地方不一样。中间隔着一堵墙，那堵墙叫时间。

我今年考了第二次，实务差四分。那四分进 errors 了。我明年再考，它们会不会进 known？

我不知道。但我知道一件事——如果 v2 遇到不认识的东西会崩，那它就永远停在八十三行。现在它不崩了，它就能长。

人也一样。

我关了电脑。屏幕暗下去，屋里只剩台灯那一圈光，和窗外面路灯漏进来的一小块。

站起来，走到婴儿房。

七七睡得正香。不烧了。小脸白白净净的，一只拳头攥着举在耳朵边上，嘴半张，呼吸很轻。

我站在门口看了一会儿。

第二天早上我是被一巴掌拍醒的。

七七站在婴儿床里，两只手扶着栏杆，看见我睁眼，咧嘴笑，一巴掌拍在床栏上，啪的一声。她退烧以后精神足，站得比发烧前还稳，还知道晃两下。

老婆翻了个身，哼了一声，没醒。

我把七七抱出来。她身上有一股奶味混着痱子粉的味道，头发是汗湿的，贴在额角。我抱着她去书房，单手开了电脑。

我又跑了一次 v2：

```python
remember("2027-06-17", "七七退烧后第一次自己扶着床栏站起来", tag="learned")
```

known 里多了第二条。

我盯着那行字看了一会儿。

原来"学会"不只是考过一科。她学会站，也是。

我在黑暗里又想起那个念头——如果我死了，她怎么办。

v2 会记住她发烧这件事。会记住 2027年6月15号。会记住我害怕。

跨年夜第一道钢印是"考过"，第六道是方舟必须造好。这一道，第七道：错可以先收着，不急着排。pending 只管收，不管排——人也是，疼的、不会的，先活着接住，别急着给自己判输。

```python
# 第七道钢印：错可以先收着，不急着排。人也是。
```

但 v2 不会回答"如果我死了她怎么办"。回答那个，需要别的东西。我现在还不知道那是什么。也许不在代码里，在明年那两张证书里，在那个还没买回来的硬盘里。v2 在等。七七在长。我在找。
