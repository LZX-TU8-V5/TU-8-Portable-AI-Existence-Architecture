# 第十六章·AI楼盘

一

四月。

离考试还有一个月的时候，老赵给我打了个电话。那天下午我刚从工地回来，鞋底还沾着水泥灰，正蹲在书桌前做经济法最后一套模拟卷。

桌角堆着七七的奶瓶和一本翻烂的《经济法基础》，我俩的东西挤在一起，谁也少不了谁。手机响的时候，我正卡在一道计算题上，企业所得税的递延，算了两遍对不上。

"小李，楚省那边出了个新楼盘，全AI设计的，你有空去看一眼不？"

"看什么？"

"看看人家怎么搞的。三线城市，精装交付，AI出图AI选材AI报价，整个设计周期从三个月压到两周。"

"我不用看。"

"你不去？行业都变了你还不看？"

"我下个月考试。"

老赵在电话那头沉默了两秒。"行，那你先考。考完了去看看。"

我挂了电话，把手机扣在桌上，继续做那套卷子。最后一道大题是企业所得税的汇算清缴，我算了两遍，数字对上了，才搁笔。可那股子松快只停了一瞬。手机屏幕暗着，我盯着它，脑子里全是那个"十五万全包"。题做对了，又怎样。人家一张图出来，顶我跑三趟工地。

但那天晚上我还是打开了手机，搜了这个楼盘的名字。

新闻很多。效果图很漂亮，玻璃幕墙，大落地窗，户型图标注清晰，连家具摆放都标了尺寸。评论区一片叫好——"终于不用被设计师坑了""AI设计便宜又好看""两室一厅全包才十五万"。我一条条往下翻，有人问售后谁管，没人答。有人问能不能改户型，回复是"AI最优解，不建议改"。最优解三个字，看得我后背发凉——我的客户，从来都是先改三遍才满意的。

十五万。全包。含硬装含软装含设计费。

我的客户做同样的配置，少说二十五万。

差了十万。十万是什么概念？是很多人一年的存款。是七七两年的奶粉钱。是我蹲在书桌前做了一百五十个小时题、换来的那些进步，折算成钱，不够给七七买一年奶粉。

我关了手机。屏幕黑下去，房间里只剩书桌上的台灯，和窗外面工地远处的一盏灯。

我没有再看。但那个十五万的数字，像根刺，扎在脑子后面。我干一单设计，利润摊下来，也就那样。人家全AI，十五万全包，我还怎么跟人比？我把书翻到资产那章，可眼睛看着字，脑子里是那张效果图的玻璃幕墙。

我没有再看。但我记住了那个数字。

二

考完试以后我去了。

自己开车去的。江城到那个三线城市三个半小时，高速费一百二，油费另算。出发前老婆说你别乱花，我说就当是老赵让看的，去看看。

到了楼盘，售楼处很气派。大玻璃幕墙，里面摆了沙盘，穿制服的置业顾问笑容满面，门口的喷泉还在喷水，水珠子溅到我的鞋面上。

我装作看房的。一个姑娘接待了我，二十出头，工牌上印着"置业顾问小周"，带我看了样板间。进门换鞋套的时候，她递给我一双一次性拖鞋，蓝色塑料的，踩上去吱吱响。走廊墙上挂满了户型图，每一张都标着"AI设计"的红章。

三室两厅，一百一十平。客厅很大，落地窗，灰色地砖，白色墙面，原木色柜子。极简风。看起来干净利落。

我仔细看了细节。

我用手丈量了客厅的开间，一步，两步，三步，比图纸上标的少了差不多十公分。样板间的家具都是缩水款的，显得大。真摆进自家东西，就不一样了。

踢脚线和墙面的缝隙不均匀，有的地方两毫米，有的地方五毫米，用手摸能感觉到那道坎。卫生间的地砖坡度不太对，我倒了一点矿泉水在地上，水没立刻往地漏走，停在那儿打了个转。厨房的操作台高度是标准的八十五厘米，但灶台和水槽没有做高低差——我站那儿切了两手空动作，腰就觉得别扭，长时间用起来会酸。我蹲下去看地漏，盖板是塑料的，边缘毛刺没处理。这些细节，图纸上看不出来，图纸只画了"此处地漏"，不画毛刺。人蹲下来，才看见。

这些是AI设计不出来但人会知道的东西。我干这行七八年，进门扫一眼就知道哪里不对。

但来看房的人不会注意这些。他们看到的是：新、大、漂亮、便宜。一个大爷跟着儿子来看，问这房子能落户不，儿子说能。大爷又问物业贵不贵，儿子说比周边低。大爷点点头，没问墙平不平、地漏通不通。他这辈子的经验，在这套房子里用不上。一对年轻夫妻在我旁边转，女的拉着男的手说"以后这就是咱家"，男的点头，眼睛亮亮的。

"以后我做饭你洗碗。""行，你设计的厨房你说了算。"他们笑着往前走，没看见踢脚线那道坎。我站在原地，忽然想起我给客户做的第一套房，那家的女主人特意让我把操作台降了五厘米，因为她矮。AI不会知道她矮。

"这个户型的设计是AI做的吗？"我问。

"是的！全AI设计，全屋智能，交付的时候还送一个智能音箱。"姑娘很骄傲，像在说自家孩子考了第一。她又补了一句："现在的设计都是AI出的，又快又便宜，您看这墙面多平。"我伸手敲了敲那面墙，空心砖的声音，闷闷的。平是真平，可我知道里面是什么。

"设计费多少？"

"含在房价里了，不需要单独付。"

不需要单独付。设计费被摊进了建筑成本，像钢筋水泥一样成了基础设施的一部分。

设计不再是服务了。是标配。

我谢了姑娘，说再自己转转，她去接下一拨客人了。我站在客厅中央，看着那扇落地窗外的太阳，忽然觉得那道不均匀的踢脚线缝，比我去年画的一百张图都刺眼。我在客厅中间站了很久。阳光把我的影子投在地砖上，拉得老长。影子踩在那道坎上，一高一低。置业顾问小周的笑声从远处飘过来，是接待下一拨客人的。那笑声跟刚才一样，骄傲，亮堂。可我知道，她骄傲的那面墙，里面是空的。

三

回去的路上，我在服务区停了一下。

买了杯咖啡。六块。纸杯烫手，坐在服务区的长椅上喝。

咖啡是速溶的，甜得要命。但我不在乎。服务区的灯管嗡嗡响，头顶那盏还一闪一闪的。几个货车司机在旁边抽烟，火星在暗里一明一灭。我捧着杯子，手心的温度盖过了晚风。

我在想一件事。手机搁在长椅上，屏幕还亮着，是老赵发来的消息："看完啥感受？"我没回。此刻回什么呢。说那五分？说那十万？说那道踢脚线的坎？他说行业变了，我看见了，可我没想好怎么接。

AI出的方案八十分。我的方案八十五分。差五分。这五分是：踢脚线的缝隙、地砖的坡度、操作台的高低差。

五分值不值十万块？

不值。

至少对绝大多数人不值。他们要的是便宜、新、能住，那五分藏在墙根和腰后的别扭里，看不见。

那我的存在价值是什么？是那五分吗？如果五分不值钱，我是不是也不值钱？

风从服务区尽头灌过来，吹得纸杯盖翻起来。我想起老赵说的"行业都变了"。是变了。可变的不是我会不会画图，是我那五分，在别人眼里，到底值不值钱。值不值，是别人定的，不是我。

我把咖啡喝完了。空纸杯捏扁，扔进垃圾桶。垃圾桶满了，纸杯压在一堆快餐盒上。服务区的垃圾桶，装的是一上路的人，和他们的困。

上车。发动。

高速路上车很少，天已经暗了，远光灯照出去两道白光，劈开面前的黑。电台在放一首老歌，断断续续，信号不好，唱两句停三秒。我没换台，就让它断着。我一边开一边想。

也许我不应该跟AI比那五分。也许我应该换一条赛道。

会计。这条路我想了很久。从第一次差五分那天起，我就知道，画图这碗饭，AI端起来比我稳。但我手里的笔，签下去的字，它端不了。

借贷必相等。资产等于负债加所有者权益。这些规则不会因为AI来了就变。AI可以做账，但它不能签字。审计报告要注册会计师签字。税务申报要持证人员经办。证，是AI替不了的。

我想起考场上那道我没做完的分录。资产、负债、所有者权益，三条线，借贷两边必须平。平不了，账就是错的。人也是，得有个证，证明你站在这边，不是那边。

证。

那个我考了两次还没考过的初级会计证。两次。差五分，差四分。下一次，不能再差了。

导航说还有两个半小时。高速两边的灯杆一排排往后退，像我那些没签下来的单子。一个接一个，过了就过了。我忽然笑了一下，笑自己较真。AI出图快，可AI不会在暴雨天跑工地，不会蹲在毛坯房里闻那股潮味，不会知道这家女主人矮五厘米。

我把方向盘握紧了一点。

回到家已经晚上十点。老婆睡了。七七也睡了，小被子团在肚子上，一只手举在头顶，睡得张着嘴。我把车钥匙轻轻放在玄关的鞋柜上，怕那声轻响吵醒谁。脱了鞋，光脚踩在地板上，凉。客厅的路由器绿灯还亮着，一闪一闪，跟守夜似的。

我坐在电脑前，打开v1.py。

把所有注释重写了一遍。不是改代码，是改注释。

原来的注释写的是技术说明：

```python
# 初始化变量
# 读取输入
# 输出结果
```

我全改成了人说的话：

```python
# 七七今天会翻身了
# 我还是那个赚七万块的设计师
# 但也许我可以是别的
```

代码没变。但字变了。

就像我没变。但方向在变。我把那段注释又读了一遍。"七七今天会翻身了"——她确实会了，我没在场，是老婆发视频给我看的。"我还是那个赚七万块的设计师"——这句话，是我在跟自己确认。"但也许我可以是别的"——这句，是今晚才敢写上的。

我关了电脑，站起来，走到七七床边。她翻了个身，哼了一声，没醒。我给她把踢开的被子重新掖好，站那儿看了一会儿。

窗外江城的灯一盏盏灭了。我关了台灯。黑暗里，七七的呼吸声很轻，一下，一下。

跨年夜的第一道钢印是"考过"，第二道信号，第三道听懂，第四道是明年两科一起过。这一道——第五道——是今晚写在 v1 注释里的那句：但也许我可以是别的。方向变了，路还没看清，但印子先盖了，免得自己又缩回去。

我把那段注释又看了一遍，在最后补了一行：

```python
# 第五道钢印：也许我可以不是设计师了。
# 但 v1 不会失业，它只会记。
```

考过了，我就不再是"还在考"的爸爸。可"设计师"这三个字，我也在慢慢不再是了。方向变了，路还没看清——而路尽头站着的那行代码，正在替我把客户一个一个接走。
