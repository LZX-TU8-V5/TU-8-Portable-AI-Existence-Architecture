# 第十二章·跨年夜

一

12月31号。

晚上十一点。老婆肚子又疼了——不是要生那种疼，是生完七七之后一直没恢复好的那种。她躺在床上，手按着小腹，脸皱着，额头一层细汗。我伸手碰了碰她手背，凉的。她没躲，只把手指又往小腹上压了压。我下意识去摸床头柜上的热水袋，空的，昨天忘了灌。去厨房接了热水灌上，拧好盖塞她怀里。她接过去，手终于从小腹上挪开了。

"去医院吧？"

"不用。老毛病。躺会儿就好。"她闭了眼，"你别老盯着我，去客厅待着。"

我给她掖了被角，床头灯调到最暗。她呼吸慢慢平下来。

白天我一直在改老赵那套图的报价，忙到天擦黑才想起今天跨年。她没说，可我知道她疼了一整天——生完七七这大半年，腰没利索过，抱孩子、弯腰换尿布，哪样不费腰。我嘴上说"明天带你去医院看看"，心里清楚明天元旦门诊歇着，这句话又得往后拖。疼在她身上，急在我心里，可我这双手，除了改图、背分录，好像什么也替不了她。

七七在婴儿床上睡了。我给她把踢开的被子重新掖好，站那儿看了一会儿。她睡相跟她妈一样，嘴微微张着，呼吸一长一短。五个月零十七天。从七斤二两抱到现在十四斤，还是觉得是小小的一团。

我走到客厅。电视开着，跨年晚会。舞台灯乱闪，主持人声音很大，观众喊倒计时。跟我没关系。手机屏幕还停在老赵发来的那张客厅效果图，墙白得发光。他最后那条语音我还没点开——我知道他想听什么，也知道我答不出。

我坐沙发上，开会计App。

复习。

这时候背什么？明天就是2027年了。明年5月考。还有五个月。五个月，把经济法从55分拉到60以上——去年差的那五分，一直搁在心里。

我翻到"增值税"那一章。

> 增值税税率：13%、9%、6%、0%
> 小规模纳税人征收率：3%
> 不得抵扣的进项税额：用于简易计税方法计税项目、免征增值税项目、集体福利或者个人消费的购进货物……

心里默念。念着念着，电视声音成了背景。

念到第三遍，我忽然走神。

脑子里不是税率，是下午老赵发我那张图——一户人家客厅，AI出的效果图，墙全打通，开阔得像展厅。老赵说业主喜欢，问我要不要也这么改改方案。

我想起七七出生那年接的一个单子。业主拿AI图来，非要我把一面承重墙抹掉，说"AI说没问题"。那墙二十四公分厚，钢筋混凝土，扛着楼上三户。我嘴上应了，手底下留了心眼，图纸还是按原结构走的。后来那业主找了别的设计师，真去敲了——我没再跟。

AI说能改的，真塌了算谁的。

那面墙一旦敲了，楼上三户的地板、墙面、吊顶，迟早出问题。不是会不会，是早晚。业主信那张图，是因为图好看，线条干净，没有一道裂缝——可真房子不是图，真房子有承重，有钢筋的脾气，有混凝土干了藏着的应力，那些AI画不出。我那天留的那手，是我这辈子少有的、没顺着客户来的硬气。现在想起来后背还有点发凉：万一我当时手软了呢？万一我也信了那张图呢？

这根刺，比经济法那根还深。

我把手机按灭。客厅角落，路由器那盏绿灯一闪一闪，在桌角守着这个六十平的小屋，也守着屏幕上那些越来越像真人的假脸。

它从七七出生那阵就亮着。我以为早忘了，今晚又看见了。

这盏灯，是屋里唯一没断过电的东西。老婆生七七那晚它亮着，我改图到凌晨它亮着，连我好几个月没交齐房租、跟房东在电话里吵起来的那晚，它也没灭。它不挑日子，不挑心情，插上电就亮，亮了就守着。我那些给自己下的命令，没一个比它靠得住。可今晚它一闪一闪，我竟觉得它在替我把着什么——把着这个家还没散。

二

十一点四十。

老婆喊我："老公，七七醒了。"

我进去。七七在婴儿床上扭，没哭，眼睛睁着，黑漆漆的眼珠子盯着天花板。

我把她抱起来。轻了——不是真轻了，是我习惯了。六斤二两抱到现在十四斤，觉得还是那么一小团。她头发有一股奶香味，蹭在我下巴上。

她看着我。不笑不哭，就是看。

"七七，"我说，"今天跨年。明天你就半岁了。"

她听不懂。可她的手抓住了我食指。攥得紧。就这么几根小指头，力气大得不像五个月的孩子。我忽然想起产房外那晚，我也是在等，等一双手攥住我。

去年这时候，我还在产房外的走廊里，坐塑料椅，尾椎骨硌得生疼，等她从她妈肚子里出来。那把椅子硬得硌人，可那天我一点没觉得累。现在想想，那种硬是踏实的硬——你知道里面有东西撑着，不会塌。

不像有些墙，看着结实，里面是空的。

产房那台胎心监护仪我到现在都记得，嘀、嘀、嘀，规律的，像在数她心跳给我听。我隔着门听，每一声都像在说"还活着，还活着"。后来七七出来，那声音停了，换成她真哭的真声。我那时想，这辈子只要听见这俩声，别的都不重要。

我抱着她在客厅走，拖鞋在地板上拖出轻微的沙沙声。一边走一边继续背：

"借：应交税费——应交增值税（销项税额）。贷：银行存款……"

七七不吵。她听着我声音，很安静，好像我背分录的节奏像催眠曲。

卧室门缝里漏出一点光。她在里头也应了一声"十、九、八"——声音闷闷的，是跟着电视数，也是陪我。

电视里开始倒计时。

"十！九！八！"

我抱着七七站窗前。外面江城夜空没有星星，永远是灰的，灯光映在云层上。

"七！六！五！"

我低头看七七。她眼睛亮亮的，映着电视的光。

"四！三！二！"

"一！"

"新年快乐！"

烟花在电视里炸开。窗外没有——江城禁放烟花。

七七被声音吓了一下，缩了缩，又放松了，小手还攥着我食指。

我对她说了一句话。

不是"新年快乐"。

是：

**"2027年，爸爸考过。"**

这话出口，我心里咯噔一下。像自己给自己下了道命令，按下去，就改不了了。

我后来给这种东西起了名，叫"钢印"。不是盖在纸上的，是刻在自己身上的。你给自己下的命令，旁人改不了，你自己也反悔不了。2027年考过，这是我给自己的第一道钢印。

可说实话，这不是头一回给自己下命令。v1刚写出来那年，我拍胸口说"要从这行站住脚"；七七出生前，我说"要让她过得好"；就连去年报会计班，我也对着镜子说过"这次一定过"。那些话，说过就飘了，没一道刻住。因为都还带着讨价的余地——"站住脚"嘛，站到哪儿算站住；"过得好"嘛，好到什么份儿上算好。只有"2027年考过"不一样。它没余地。非过即不过，干脆得像按了开关。所以我才怕。怕的不是考，是这印子按下去，我就没退路给自己找了。

卧室里传来老婆的声音："新年快乐。"哑着的，是疼的，也是真的。

我应了一声。

三

凌晨一点。

七七放回去了，睡了。老婆也睡了。

我坐书房里。电脑开着，屏幕上是v1.py。路由器那盏绿灯在桌角一闪一闪，像在替我看家。

我在最后一行后面加了一行：

```python
remember("2026-12-31", "跨年夜。七七半岁。明年考过。全年赚了7万。不够，但活着。")
```

运行了一下。文件夹里多了一个txt：`2026-12-31.txt`。

打开看：

```
跨年夜。七七半岁。明年考过。全年赚了7万。不够，但活着。
```

v1记住的第一件事。

我盯着这行字，忽然有点慌。

这些txt，就躺在电脑一个文件夹里。哪天硬盘坏了，或者我手一抖删错了，全没了。七七半岁、老婆的疼、那七万块、还有我给自己下的钢印——就剩空气。

我得有个比这文件夹结实的地方。

我想起去年逛电脑城，见过一种加密硬盘。手掌大，要密码，砸了也读不出，除非你知道那串数。当时觉得多余，现在觉得，那是给七七留东西最好的容器。电脑城那老板递给我时笑："你存啥宝贝？砸了也读不出。"我没答。现在我想，宝贝就是这些txt，和这几行代码。

等哪天，我把这些txt、把v1.py、把我画过的图、把我写给七七的话，都存进去。设个密码，只有她将来能开。那不是一块硬盘，那是我给她造的一只盒子——砸不烂，删不掉，等我不在了，它还在。

密码我想用她生日——七月十四。简单，可只有她自己会去试。我在想，里面除了txt和代码，还得有一封信。写给七七的。不是"爸爸爱你"那种空话，是告诉她：你爸这辈子没混出什么名堂，可你出生的那年，他给自己下的每一道命令，都是真的。他怕过，怂过，可没逃过。还有那面墙——如果将来你看见谁家墙被AI图改没了，替你爸记着，那墙后面扛着的是人。

这个念头一来，就跟我那道钢印一样，按下去了。

我关了电脑。

屏幕灭了，屋子里只剩路由器那点绿光，和窗外路灯照着的梧桐影。我站了一会儿，听见楼下有人放炮仗，被物业劝走了——江城禁放，连这点响动都短。

站窗前。外面安安静静，2027年的第一个小时。六楼，没电梯，出租屋。窗外是梧桐枝杈和路灯。

我伸手摸口袋——那张折了三折的纸条还在。

"初级会计——9月考试——报名费140——还来得及吗？"

来不及也得来。

我把纸条塞回口袋最里层。它不是计划，是退路——真到山穷水尽那天，至少还有个证，证明我曾经想过要站起来，不是躺着等淹。口袋布磨得发软了，那张纸的边角却还硬。我拍了拍口袋，确认它还在。

我回到卧室。老婆侧着身，呼吸轻。七七在婴儿床里，拳头攥着，嘴半张。

2026年过去了。

我想起下午那张AI图，业主家墙全打通的客厅。我但愿那面二十四公分的墙，这世上还有人替它撑着。也但愿我给七七造的那只盒子，比那些墙结实。

那个盒子，我后来在心里叫它"方舟"。不是诺亚那种，装不下万物，只装得下我这点破烂：几张图、几行代码、几句话。可它是我的船。江城要淹，行业要淹，AI的浪一浪接一浪，我站不住的时候，至少这艘船替我兜着七七。船小，但结实。

溺水的人还在水里。但头已经探出水面了。

能喘气。

就够了。
