# 《钢印》第四章·甲醛

> 视角：父亲（第一人称"我"）｜年代：2026年6月｜主题：我是毒源。

---

## 一·签字

六月。江城的梅雨季。

不是下雨。是空气自己在出水。墙皮发霉，卷边的地方翘起来，手指一碰就掉一层粉。工地上的木板长了一层白毛，像霉斑在木纹里发了芽。安全帽里闷得像扣了只蒸笼，摘下来头发能拧出水。

业主催工期。

"李工，下个月必须搬进去。小孩九月份要上学区，晚了就报不上名。"

"陈哥，甲醛还没散。你这柜子是六月三号装的，至少得通风三个月——"

"通风三个月？"他打断我，"我租的房子八月到期！多住一个月多交四千五！你让我去哪住？露宿街头？"

我张了张嘴。

我想掏出手机，搜一条"甲醛中毒案例"给他看。想跟他说那个三岁女孩住进新装房半年后的事，想说白血病的发病周期，想说那个我前天在新闻里看到、躺进收藏夹就没点开过的数字。

但我没掏。

房租到期。孩子上学。四千五。

这三个词，像三块砖，一块一块，把我嘴里的那句话压了回去。

我咽了口唾沫。喉咙里那层膜更厚了，像是把那些想说的话都黏在了嗓子眼。我看了眼自己沾着墙灰的鞋，又看了眼窗外——江城的天，梅雨季永远看不到蓝色，灰蒙蒙的，像一块洗不干净的布。我想起我老婆挺着七个月的肚子，在超市货架前比价的样子。那个业主的孩子要上学区，我的孩子要降生。我们都在为下一辈挤命。我凭什么拦他？凭我手机里那条没点开的新闻？

我站在那套刚装完的房子里。空气黏糊糊的，带着一股刺鼻的味道——不是新家具那种淡淡的木头香，是胶水和油漆搅在一起的辛辣，像一层膜，糊在口鼻上，呼吸都觉得发黏。阳光从落地窗照进来，光柱里浮着一层尘埃，每一粒都在慢悠悠地飘，像都是甲醛的载体，被光照得无所遁形，又无可奈何。

"李工，你到底能不能验收？"

我看了眼手机日历。6月18号。装修完第十五天。

十五天。甲醛释放周期三到十五年。十五天，连个零头都不够。

"能验。"我说，"但我得跟你说明白，这个入住时间——"

"我自己负责。"他把免责条款拍在茶几上，"写个免责就行。出什么事我自己担，不找你。"

我签了。

笔尖划过纸面的时候，我想起昨天在论坛看到的那句话——"如果你明天就死了，能留给孩子什么"。我当时打的是"留一段代码"。现在这笔签下去，我留给孩子的是什么？是一个可能吸了十五年甲醛的业主家，和一个签了字、什么责任都不用负的自己。

手有点抖。不是怕，是那种——你明明知道前面是坑，还是得抬脚迈进去的无力。我想起刚入行时师傅说的话：'设计师是替业主兜底的人。'那时候觉得挺光荣。现在才知道，兜底的意思是，坑来了，你先跳。

他搬进去了。

第二天，他在业主群里发了九张照片：客厅、卧室、厨房，挨个拍了一遍，配文"终于住进新家了，感谢李工"。下面一排点赞。

我没点赞。

## 二·流鼻血

六月二十几号。另一个工地。老赵的。

一个复式，业主不急，工期排到了九月，难得。我在二楼量卧室的尺寸。卷尺拉开，三米六，记在本子上。弯腰的瞬间，鼻腔深处突然传来一阵奇怪的瘙痒——不是打喷嚏那种痒，是像有什么东西在血管壁上，轻轻刮了一下。

紧接着，一股温热的液体，毫无预兆地涌了出来。

我下意识直起腰，手背往鼻子上一抹。

红的。

鲜艳得刺眼。

我赶紧仰起头，另一只手慌乱地去摸口袋里的纸巾。血顺着鼻腔后壁流进喉咙，一股浓烈的铁锈味，混着刚才吸了一上午的油漆味，在嘴里发酵成一种令人作呕的怪味。视线开始模糊，眼前的毛坯房在旋转——那面刚刷了腻子的墙，白得晃眼，像一张巨大的、没有表情的脸，冷冷地盯着我。

"小李？怎么了？"老赵的声音从楼梯口传来，带着回声，空荡荡的房间里显得格外响。

"没事！"我捏着鼻子，声音闷在喉咙里，"上火！"

我站在空荡荡的房间里，仰着头，看着天花板预留的灯线孔。血还在流，浸透了第一张纸巾，又渗到第二张。我摸出手机想看时间，锁屏上正好弹出一条推送——"AI智能家居，一键净化全屋空气，甲醛清零看得见"。

我盯着那行字。

一键。清零。看得见。

我低头看了一眼手里那团暗红色的、浸透的纸巾。

高科技的承诺，和我掌心里真实的、温热的、带着铁锈味的血，中间只隔着一句"一键"。

他住进去了。我站在这里，用我的血，给他的新家做了一次最真实的空气质量检测。

纸巾堵了五分钟才止住。我把脏纸巾塞进口袋，没扔——工地上没有垃圾桶，扔地上不好看，扔建材堆里怕扎到人。塞口袋是习惯。

量完尺寸下楼，老赵递了瓶水过来。

"你最近是不是太累了？"

"还好。"

"你老婆快生了吧？"

"七月。"

"那你还天天跑工地？歇歇。"

"歇不起。"

老赵没再劝。他懂。干这行的，谁歇得起。他转过身去搬龙骨，背影在灰尘里显得有点驼。我拧开水瓶盖，水有点烫嘴，但喉咙里那股铁锈味被冲淡了一点。我想起那个业主发的朋友圈——"终于住进新家了"。他住进去了，配文感谢我。而我站在这里，鼻子还在隐隐发酸，用血给他做了一次检测。我们好像达成了某种共谋：他负责自己的健康，我负责把字签了。代价算在谁头上，没人提。

我低头又看了一眼手里那团暗红的纸巾。我想，这大概是我做过的最诚实的一份验收报告。没有美颜，没有滤镜，没有AI生成的完美效果图。就是血。温的，红的，带着铁锈味。它比任何仪器都准，因为它直接长在我身上。可这份报告，没有人会看。业主不会，平台不会，那个做AI一键净化器的公司更不会。

## 三·回家

晚上回家。

老婆坐在沙发上看手机，肚子比上周又大了一圈。她抬眼看我，笑了："回来了？饭在锅里热着。"

"嗯。"

我站在玄关换鞋，没往里走。

我闻到了。不是从房子里闻到的——是从我自己身上。衣服上，袖口，领口，甚至鞋面上，都沾着今天跑的那两三个工地的味道。胶水、锯末、油漆，混着梅雨季的霉。淡淡的，但我的鼻子今天特别敏感，像被那场鼻血通了窍，什么味道都往脑子里钻。

我想进去。想换身衣服就靠过去，把手搭在她肚子上，等七七动一下。

但我没动。

我进了卧室，把外套脱下来，翻过来闻了闻。甲醛味。淡的，但确确实实有。裤子也有，鞋上可能也有。

我把衣服全脱了，换了一身干净的。把脏衣服塞进洗衣机，没开——怕吵到她，明天再洗。

然后我去卫生间。

水流开到最大。冰凉的水冲过手指，肥皂沫在指缝间破裂，发出细碎的、几乎听不见的声响。我看着镜子里自己：鼻头通红，眼睛底下两片青黑，像被人揍过。

我洗了手。两遍。又洗了脸。

"我是个毒源。"镜子里的那个人想。今天我吸进去的，比那个业主多十倍。他们住进去的时候甲醛已经散了大半，我量房的时候是浓度最高的时候。我不量房就没有收入，可我量完房，身上就带着这个。

我关掉水龙头。安静下来的瞬间，耳朵里嗡了一声，像工地上那种持续的、低频的轰鸣，迟迟不肯散。我盯着镜子里那张脸——三十四岁，比我爸走的时候还年轻几岁，可眉眼之间已经全是疲态。我突然很怕。怕七七生下来，我肺里已经装满了这些东西。怕我抱她的时候，那些看不见的分子，从我的皮肤，渗进她的。

洗完碗我走到沙发旁边。水龙头开得很大，水声盖过一切。我看着水流冲过手指，想起白天在工地仰头堵鼻血的样子，纸巾上那一坨暗红色的东西。甲醛。一天跑两三个工地，每个都是刚装完的。我吸进去的比谁都多。但我不跑就没有钱，七七下个月就要来了，奶粉、产检、房租，哪一样都不等人。

老婆已经侧躺着了，一只手搭在肚子上。

我在沙发另一头坐下。没靠过去。

以前我会把头靠在她肩膀上，或者手搭在她肚子上等七七动。但今天我不敢。我怕衣服上还有味道，怕灰尘，怕那些看不见的东西，碰到她，碰到七七。

她好像感觉到了什么，但没说。

我想说点什么。想说今天流了鼻血，想说鼻子到现在还发酸，想说我又吸了一天的甲醛。可话到嘴边，还是咽了。她怀着七个月的身孕，不该替我担这些。我把手轻轻覆在她搭着肚子的手上，隔着一层薄薄的睡衣，感觉到了里面那点温热的、缓慢的起伏。

我们就那样坐着。客厅的小夜灯亮着，窗外梅雨没停，滴答滴答打在空调外机上，像某种缓慢的、不会停的钟。

我想凑过去，把头靠在她腿上。就一下。可我闻到自己袖口残留的那点味道，又停住了。不是怕她嫌，是怕那些东西。甲醛没有颜色，没有声音，它就在空气里，慢条斯理地，钻进每一个它想钻进的人。我挡不住。我连自己都挡不住。

很远的地方，我伸手碰了碰她的脚背。

她没动。

但她的脚趾，轻轻勾了一下我的手指。

## 代码注释

深夜。

等她睡了，我把电脑抱到腿上。屏幕的蓝光，在黑暗里像一片小小的海。路由器那盏绿灯还在闪。一闪，一闪。我没看它。

我打开v1.py。光标在末尾一闪一闪，像在等我。

我打了一行字。很慢。

```python
# 2026.06.xx
# 签了免责条款，流了半包纸巾的血。
# 但我不敢靠近她。
# 我是毒源。
# v1.add_sensor("smell", True)  # 增加嗅觉监测，虽然没人会在意
```

我看着那行字。井号后面每一个字，都打得很慢。

"我是毒源。"——那个业主住进了新家，配文"感谢李工"。而我站在工地里，用血给他做了一次最真实的检测。我签了字，他住了进去，我们好像达成了某种共谋。但真正的代价，是我不敢靠近自己快要生产的老婆。

我把文件保存了。

合上电脑。黑暗里，只有路由器的绿灯还在闪。一闪，一闪。像什么东西，在替我记着。可它记不下业主那句"AI说没问题"——那面二十四公分的承重墙，明天就会被别人敲掉。图好看，墙不会说话。
