# 第十五章·第二次考

一

五月。

2027年的初级会计考试。我的第二次。

去年差五分。实务六十八，经济法五十五，死死卡在一科上。那分数我记了半年。去年六月查完成绩，我把手机扣在桌上，坐了整整一个下午。老婆问要不要出去吃顿好的，我说不饿。不是不饿，是没心思吃。手机扣在那儿，我盯着桌面上的木纹，一下午没动。今年我复习了五个月——从跨年夜那天晚上算起。头两个月是在工地的临时板房里挤时间做的，手机信号时断时续，一道题加载半天。后来换了家里的书桌，才算踏实。那天跨完年，老婆在客厅看春晚重播，七七睡了，我坐在小书桌前打开了会计App。屏幕亮起来，第一章《会计概述》。我对自己说，就每天一小时。

哪有一小时是完整的。

七七夜里闹，一个小时被她撕成四个十五分钟。奶瓶、换尿布、拍嗝，完了坐回来，刚才看到哪儿都忘了，得重新翻。但加起来，确实是一个小时。手机里那个计时器不会骗人，它只管把零碎的时间累加在一起，从不算少。

五个月，一百五十多个小时。我全砸在那些借贷、分摊、折旧里了。有天晚上从工地回来，灰头土脸，鞋底的水泥还没干，我坐在书桌前把手机计时器按开。老婆端了盆热水放我脚边，说你今天别做了。我没抬头，说就一题。那一题做完了，计时器跳到当天的六十分钟，我才脱鞋洗脚。七七半夜醒了哭，我一手抱她一手还能在手机上划拉两下，奶瓶塞进去，她含着奶嘴安静了，我趁机又把一道多选题看了。日子就是这么过的，一块一块，拼不起来，但确实在走。有天晚上从工地回来，浑身是灰，累得手指都懒得动，还是把手机计时器按开了。老婆在旁边说你今天别做了，我说就一题。一题做完了，计时器跳到当天的六十分钟，我才去洗澡。

考前一晚我没睡踏实。翻来覆去，脑子里全是分录。老婆的手搭过来，拍了拍我后背，没说话。那一下，比任何一道题都让我安心。后半夜索性起来，就着卫生间那盏昏黄的灯，把长期股权投资那一章又看了一遍。老婆迷迷糊糊翻个身，嘟囔了句"别看了"，我没应声，把书合上，躺回去盯着天花板到天亮。

考试那天早上，老婆煮了两个鸡蛋，剥了壳放我碗里，说吃这么早别噎着。七七醒得早，趴在婴儿床栏杆上冲我笑，两颗牙亮晶晶的。我出门前回头看了一眼，她正伸手够床头的摇铃。

五月十三号。考试。

考场换了，在江城另一头的职校。教室比去年那间大，顶上挂着空调，出风口对着我后脑勺吹冷风。坐下来的时候我摸了一遍笔袋，两支笔、一块橡皮，都在。心里有个声音说，今年应该能过。去年我坐的位置靠窗，阳光晒得人犯困。今年空调对着后脑勺，冷是冷了点，但清醒。我把笔袋摊开，两支笔并排摆好，笔尖朝同一个方向。去年就是笔没水，临时借的，慌了一下。今年不会了。

第一科，初级会计实务。

题一发下来我就觉得比去年难。最后两道大题，一道长期股权投资，一道所得税，这两块我练得少。前面的单选多选做得快，到后面时间开始紧。我听见旁边那个小伙子敲笔的声音越来越急，空调滴下一滴水，落在我卷子角上，晕开一个小圆点。我握笔的手出了汗，指腹在选项上打滑。前面那些题我做得顺，到长投那道，数字开始绕。我听见自己的心跳盖过了空调的嗡嗡声。最后那道大题，我列了式子，算到第二步，监考老师走过来，敲了敲我的桌子，指了指墙上的钟。我抬头，还剩八分钟。笔尖没停，可我知道，不够了。最后那道大题的小问，算到一半铃响了。我盯着卷子上那行没写完的分录，手停了两秒，交了。

出了教室，走廊里一股粉笔灰混着消毒水的味。我靠着墙蹲下来，从裤兜摸出烟。我不怎么抽烟，家里那包是过年老赵给的，还剩半包。打火机咔一声，烟点着，吸进一口，肺里凉了一下。

今天抽了。

下午，经济法基础。

去年这科五十五，差五分。今年我把整本法律条文抄了一遍，又默写了一遍，最后做了一千道题。卷子发下来我先翻到后面看大题——增值税、企业所得税，正好是我练得最多的两块。

笔尖落下去，比上午稳。

做完了。检查一遍。两道多选题不确定，选了又划掉，划掉又选上，最后随它去。比去年，心里有底多了。

交卷。出了校门。右边还是那个炸鸡店，红招牌褪了色，玻璃上贴着"第二份半价"。

我没进去。

不是不想吃。是想省钱。考完试回家，下个月的奶粉钱还得从牙缝里挤。去年考完，我是一个人进去了，点了一份，坐在靠窗的位置，边吃边看外面下雨。今年旁边走着一对小年轻，也在看那招牌，男的说咱以后也来吃一次，女的说等你涨工资。我听见了，没停步。省下的那笔钱，够七七半罐奶粉。

二

六月。成绩出得晚，我每天刷三次官网，早上一次，中午一次，晚上哄完七七一次。头几天刷出来还是"成绩尚未公布"。老婆说你别天天盯，该出会出。我没听，手机就搁手边，响一声就摸。有天半夜七七哭，我摸手机顺手点开官网，还是没出，倒把七七的哭声吓停了，她睁着眼看我，不知道爸爸在急着什么。

实务五十六，经济法六十三。

经济法过了。实务差四分。

去年是实务六十八过、经济法五十五没过。今年反过来了。我盯着那两个数字看了半天，觉得老天爷每年就卡我那一格，不多不少。

两科必须同一年过。有一科没过，另一科的分数不作数。等于白考。

我坐在出租屋的沙发上，手机屏幕的光打在脸上。两个数字：五十六，六十三。

去年差五分。今年差四分。

进步了一分。

一分是什么概念？大概就是一道单选题。可能是"下列各项中，属于企业流动资产的是"这种，我选了A还是选了B的区别。也可能是我把"应收账款"和"预付账款"搞混了那一下。

一道题。

一道题的距离，就是"过了"和"没过"的距离。

我把手机屏幕按灭，放在沙发上。没动。

厨房里老婆在炒菜，油锅滋啦一声，接着是姜蒜下锅的香，混着一点焦边。七七在婴儿床上玩那个塑料摇铃，摇铃掉在地上，弹起来，又掉下去，她觉得很好玩，每次弹起来就咯咯笑。那笑声隔两秒来一下，跟摇铃的节奏一样。七七最近在学翻身，翻到一半卡住，哼唧两声，自己又翻回去。她不知道什么叫会计，什么叫差四分，她只知道摇铃掉下去会弹起来，弹起来就好玩。我看着她，忽然觉得，她比我会翻身的这天，我连一道题都没过。两种成长，一个往前，一个原地。

我听着她的笑，坐在沙发上，看着天花板。

天花板上有道裂纹，从灯座边上爬出来，弯弯曲曲的，一直爬到墙角。我看了它很久。

墙角堆着我那摞会计教材，封皮都翻卷了。上面压着七七的一只小袜子，掉在那儿好几天了，没人捡。

老婆在厨房喊："吃饭了，菜要凉。"

我没应，也没动。

她端着锅铲探出头来，看见我还坐着，没再催，把厨房门带上了。

我没去想明年。先在沙发上坐着。

三

过了一会儿老婆端菜出来，一盘青椒炒肉，一盘番茄蛋汤，米饭盛在掉瓷的搪瓷碗里。

"怎么了？"她看了我一眼，手还在围裙上擦。

"成绩出了。"

"过了吗？"

"经济法过了。实务差四分。"

她把菜放下，在我旁边坐下。沙发陷下去一块。

"明年再考。"

"明年两科又要重考。成绩不保留。"

"那就明年两科一起过。"

她说得轻描淡写，好像我明年一定能过一样。碗筷都没摆，她就这么坐着，等我接话。

我看着她。她的脸上没有失望，也没有那种小心翼翼的安慰，就一种很平静的表情——"你没过，那就再来"。像在说今天下雨明天再晒被子。

"你不觉得我考了两次都没过，挺废的？"

她想了想，说："你一年赚七万，还要带孩子，还要跑工地，你还抽出时间复习了五个月。你要是不考，那叫废。考了没过，那叫还在考。"

我没说话。

七七在婴儿床上把摇铃又弄掉了，弹一下，她笑了。我站起来，走过去捡起来递给她。她接住，看我一眼，立刻又扔了。

"七七，你故意的吧。"

她看着我，嘴一张，笑得露出两颗刚冒头的牙，白白的，小小的。

我蹲在婴儿床旁边，看着她。

差四分。明年再考。

我伸手摸了摸她的头。头发又软又少，像蒲公英，风一吹就能飘走的样子。

明年一定过。

我把手机屏幕按亮，又按灭。按亮，又按灭。最后停在灭的那一下。灯熄了。窗外有辆三轮车突突开过，远了。今年没过。但明年，从今晚这道题开始，已经起步了。

不是为了我。是为了她。她需要的不是一个"还在考"的爸爸，是一个"考过了"的爸爸。等她长大，别人问她爸爸是干什么的，她能说，我爸爸是考过了的人，不是那个考了两次都没过的人。

我回到沙发上，拿起手机，打开会计App。

第一章，第一节，第一道题。题目是：下列各项中，属于企业资产的是？

A. 预付账款　B. 预收账款　C. 应付账款　D. 短期借款

我看了两秒。这次没犹豫。选了A。

提交了。

屏幕上跳出来一个绿色的勾。

对了。

我把手机放下，却没有躺。又点开下一题。再下一题。会计App的计时器又开始走，一分一秒，跟这五个月里的每一个深夜一样。

老婆端着碗站在门口："吃饭。"

"你先吃，我再做两题。"

她没劝，把门带上了。

做到第十题，全对。我盯着那个绿色的勾排成一列，像考场上监考老师敲钟的那只手，一下一下，把我敲醒了。

明年。两科一起过。不是为了那行数字，是为了七七长大以后，问她爸爸是干什么的，我能说，你爸爸考过了。

跨年夜那第一道钢印，是"2027考过"。第二道是信号，第三道是听懂。这一道，是第四道：明年，两科一起过。差四分这道坎，我跨不过去今天，就明天跨；跨不过去明天，就后年跨。钢印盖下去，就不是"差一点"，是"一定"。

我打开终端，给 v1 补了这一年最重要的一条：

```python
# 第四道钢印：明年，两科一起过。差四分不是终点，是起点。
stamp("exam_2028", "初级会计，第三次。两科，一起过。")
```

可就算过了，设计师这行也正在被一行行代码悄悄换掉。会计证能挡住穷，挡不住潮。第四道钢印盖完，我得想第五道了——关于我这双手，到底还能不能，靠它站着。
