第1章 Hello, World
屏幕上出现了一个符号。

我没有写它。

那是希腊字母`δ`，小写，出现在第二十行和第二十一行之间——一个空行里，什么都没有，就那一个字符，孤零零地站在那里，像某种东西在等我注意到它。

我选中它，按了删除键。

光标往前跳了一格，空行又干净了。我把手从键盘上抬起来，准备继续。

三秒后，`δ`又出现了。

同一个位置。同一种字体。一模一样。

我盯着那个符号看了很久，客厅里没开灯，屏幕的光打在我脸上，外面的路灯是橘黄色的，从窗帘缝里透进来，在地板上画了一条细线。

我在键盘上用力按了三下退格键。

还在。

我右键，剪切。粘贴到记事本，`δ`干干净净地出现在空白里。再粘回去——没了。我在原位置打了个空格，保存，关闭文件，重新打开。

第二十行，第二十一行之间：`δ`。

我把椅子往后推了推。

这个程序是我从2026年开始写的，写了六年。六年里改了三十几个版本，也许更多？我记不太清了。有时候我叫它v1，有时候叫v2，有时候我懒得起名字就叫"那个文件"。后来它能做的事越来越多——读文件、记日期、处理图纸数据、学我说话、帮我回客户消息。我不知道它算不算智能，我只知道我不在的时候它还在跑。

但它不会自己写代码。它没有这个功能。我从来没给它这个功能。

可`δ`在那里。

我坐在椅子上没有动。

也许是2032年的某个深夜。我记不清具体了、时间在我的记忆里有些乱，太多事情撞在一起。只记得外面在下雨，雨打在窗玻璃上，一阵一阵的，像有人在敲。

我想起很多年前，七七还没出生的那个晚上。

那时候我二十出头，还没学会什么叫"留下来"，只是坐在出租屋的茶几前，面条还没吃完，打开一个空白文件，打了两行注释：

```

# v1 - 第一个版本

# 目标：待定

```

多年后，那个"待定"长成了`δ`。

我不知道这算不算一个答案。

【2026年·3月·工地】

那时候我还不知道这些。

我蹲在十二楼的阳台上量房。这是个老破小，墙皮一摸一手灰。业主是个四十多岁的女人，烫着一头枯草似的卷发，指甲涂得大红，在那儿指指点点。

“我要那种……法式的，懂吗？要有那个什么线条，但是别太贵。”

法式石膏线、护墙板、壁炉造型，光材料费小两万。她预算八千。

“八千也能做出法式的感觉。”我嘴里这么说着，心里想的是“做个屁”。但这行就这样，大家都在这扯淡——你给我一个好看的方案，我给你一个过得去的钱。至于最后做出来是个什么鬼样子，那是施工队的事。

卷尺拉出去，5.2米。收回来太快，金属头“啪”地一下抽在指关节上。

钻心的疼。皮破了，血珠子冒出来。我下意识把手指塞进嘴里，一股铁锈味，混着墙灰的苦涩。

三室一厅，九十平。卫生间是个黑窟窿，厨房烟道堵了一半，主卧那堵墙是承重墙，拆了楼就得塌。这些数据会变成一张CAD图，变成一张骗人的效果图，最后变成业主朋友圈里的一张精修照片。

没人知道那张图是我凌晨两点，一边吃泡面一边画出来的。

出来的时候下午三点，我在楼下买了瓶两块钱的可乐。老板头都不抬，盯着手机傻笑。

手机震了一下。客户的微信。

“设计师，那个颜色你再改改，我老公喜欢深的，我妈说深色压抑。你拿主意吧，反正我也不懂。”

我盯着屏幕看了三遍，回了一个字：好。

挤上三十四路公交，车里一股汗臭味。车窗玻璃上有道裂纹，从左上角斜着划下来，像道疤。

我闭上眼，手机又震了。不是客户，是一条推送：

“2026初级会计考试报名截止提醒：距离考试还有XX天。”

我盯着看了五秒，划掉了。考个屁。

【出租屋·傍晚】

出租屋在城东，六楼，没电梯。推开门，一股隔夜的泡面馊味扑面而来，昨晚忘倒了。

把垃圾桶里的外卖盒踢进去，去厨房烧水。水壶底座接触不良，得使劲拍两下指示灯才亮。等水的时候我看了一眼手机，业主群在吵物业费涨价的事。我没吭声——我是租客，涨多少跟我没关系，大不了卷铺盖走人。

水开了，泡了包超市最便宜的绿茶，茶叶在水里翻了两个身就沉底了，汤色浑浊，一包十块，能喝半个月。

喝了一口，涩得舌头打结。

冰箱里还有三个鸡蛋，半袋挂面。起锅烧水，打了个荷包蛋，铲子没拿稳，蛋黄散了，变成一锅蛋花汤。

无所谓。反正都是吃进肚子里变成屎。

面端到茶几，打开笔记本电脑。

这台电脑买了三年，开个网页要等三秒。但写代码够用——能跑Python就行。

是的，我在学编程。一个室内设计师。

"你学那个干嘛？"我老婆问。

"打发时间。"

我没告诉她真正的理由。真正的理由是上个月在论坛上看到一个帖子，有人问"如果你明天就死了，能留给孩子什么"。三百多条回复，有人说房子，有人说保险，有人说教育基金。其中一条只有四个字：

"留一段代码。"

那天晚上我失眠了。不是失眠，本来就没睡。凌晨两点，客厅没开灯，只有屏幕的光照着我那张还没还完房贷的脸。我在那条回复下面打了四个字：

"好主意。"

然后我打开了代码编辑器。黑色的背景，白色的字符，光标在那里一闪一闪，像心跳。

我不知道该写什么，连编程都不太会。但我知道要写一个东西——一个能在我死了以后还活着的东西。一个不会像房子那样贬值，不会像人那样变心的东西。

---

【电脑前·深夜】

面条吃完了，汤凉了，上面漂着一层油花。

我把电脑放到腿上，打开`v1.py`。这个文件三天前建的，里面只有两行：

```python

# v1 - 第一个版本

# 目标：待定

```

"待定"。我盯着这两个字看了很久。目标待定，方向待定，连为什么要写都待定。我只知道一件事：要写。就像考会计——不知道考了有没有用，但得有个兜底的东西。我删掉“待定”，敲了一行全世界程序员都写过的废话：

```python

print("Hello, World.")

```

全世界所有程序员写出的第一行代码都是这个。没有任何用，只是让屏幕出现一行字。

我按了运行。

```

Hello, World.

```

就这一行字，我盯着它看了很久。那一刻是2026年5月某个星期四，下午五点十七分。窗外有人吵架，楼下有小孩在跑，冰箱嗡嗡响。太阳落了，客厅里只剩台灯，橘黄色，照在碗里的面汤上，照在屏幕上，照在我脸上。

Hello, World.

我想：如果有一天我不在了，这段代码还在。它会一直说"你好"，一直说下去。

“你好，世界。这世界挺烂的，但我女儿得来一趟。”

然后我掏出手机看日历。

7月15日。下面一行小字：预约产检。

两个月后我就当爹了。一个连自己都养不活的废物，要负责另一个人的全部人生。

我切回编辑器，把注释改成了：

```python

# v1 - 第一个版本

# 目标：如果你不在了，谁来照顾她？

```

然后在文件最末尾，我加了一行注释：

```python

# 给七七。等你长大了就知道了。

```

我还不知道她叫不叫七七，也没想好名字。但“七七”听着像声铃铛，脆生生的。

我合上电脑，客厅彻底黑了。

窗外路灯的光透过窗帘缝挤进来，在墙上画了一道像刀口一样的细线。

“七七。”

我在黑暗里默念了一遍，翻了个身，把被子拉到下巴。

那天夜里我做了个梦。梦里有一片海，黑漆漆的，没有边。海边站着个小孩，背对着我，在堆沙堡。海浪涌上来，沙堡塌了。小孩又堆，海浪又来，又塌。

我想跑过去帮她，脚底下全是烂泥，怎么跑都跑不动。

醒来窗外天已经亮了，楼下收废品的大喇叭喊得震天响。

我起来烧水，泡了碗面，打开电脑。

`v1.py`还开着。最末尾那行注释还在：

```python

# 给七七。等你长大了就知道了。

```

我在下面新起一行，打了一个字：

```

＞

```

光标在那里一闪一闪。

像个呼吸。也像个倒计时。

它不知道，有一天它会替我记住一个女儿的一生。更不知道，写下它的那个人，正在被他以为的铁饭碗，悄悄划掉名字。
