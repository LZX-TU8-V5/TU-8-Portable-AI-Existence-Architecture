# 《钢印》第二十一章·图灵传

## 一

周末。代账这周活儿少，老周那八十六万里能要回来的没几笔，我难得有个不赶的上午。

抱着七七去图书馆。她一岁多点，腿脚还不利索，走两步就往地上坐，干脆抱着。从家到街道图书馆八百米，她趴我肩头，口水洇湿左边领口，热乎乎一小片，风一吹凉了又热。

图书馆在二楼，旧楼，水泥楼梯踩上去有回声。少儿区一进门右手边，地上铺着掉毛的卡通地垫，几本绘本翻得卷了边。我去成人区，最里头靠窗那排，架子上落灰。手指划过去，蹭一层白。

《图灵传》。旧版，封面发黄，边角磨毛了，借阅卡上密密麻麻一串名字，最早一笔看着像九几年。我抽出来，吹了吹灰。这书被人借过很多次，又被还回来很多次。它比图灵本人命长。

借书要刷证。管理员是个戴老花镜的阿姨，抬头看我怀里的小孩，说"这么小也来？"我说"她不看书，我看。"她笑了下，盖章，把证递回来。

下楼的时候我想，这书借回去，七七多半要撕。上次借的绘本被她撕了半本，阿姨脸都绿了。这次我挑了精装，她撕不动——可《图灵传》是平装，纸薄。我只好看着她。

回家路上七七睡着了，脑袋歪在我锁骨上，沉。我腾出一只手把书塞进外套口袋，书脊硌着肋骨，一走一颠。过马路时一辆车按喇叭，七七在梦里缩了下脖子，没醒。我侧身让了让，心里算这周代账的收入——老周那笔还悬着，够不够下月房贷都不好说。怀里沉，脚步就慢，慢就多看两眼路灯下自己的影子，一长一短。

## 二

读完了《图灵传》。

在家里读的。七七睡醒，不睡了，满地爬。我一手抱着她，一手翻书。她偶尔伸手拍书页，有一次差点把第147页撕下来——我赶紧把那页按回去，她咯咯笑，以为我在跟她玩。

阿兰·图灵。1912年生，1954年死。活了41岁。

41岁。

我在这行字底下停了很久。

手指停在那一页，纸边割了下指腹，没破，留一道白印。我抬头看七七，她还小，不懂41岁是什么。我也不全懂——一个人脑子那么好使，怎么就被一针药毁了。可我懂“不在了”三个字。她现在不懂，总有一天要懂。

书里写他怎么死的。吃了一个泡过氰化物的苹果。苹果公司那个 logo 是不是致敬他，网上说法不一，这个不重要。重要的是他41岁就死了。

因为他是同性恋。那时候英国法律不允许。他挨了化学阉割的针，雌激素注射进身体，胸部慢慢发育，脑子还是天才的脑子，可人就这么毁了。两年后，他咬了一口那个苹果。书里没写他咬下去之前想了什么。是恨，是累，还是就只是想尝一口甜的——反正那苹果泡过氰化物，咬下去就不用再想了。我合书的时候，手指在那一页停了一下，没敢多想自己要是换成他，会怎么办。

我合上书。看着七七。

她正把一张 A4 纸撕成碎片，非常专注，碎纸掉了一地。撕完了抬头看我，咧嘴笑。门牙才冒两颗，笑起来漏风。

我忽然算起账：图灵死时41，跟我差九年。九年后七七十岁，该上小学。我能不能活着送她背书包，取决于这九年怎么过——代账的活稳不稳，明年那两科过不过。想远了，赶紧收回来。七七纸不够撕了，开始撕我的草稿。

## 三

我想：如果我死了，她会怎样。

这个问题以前也想过。上次七七发烧那次，我坐在地板上陪她退了一夜烧，想的是"如果我死了她怎么办"。那次是恐慌，是本能，像有人从后头勒住脖子。

这次不一样。这次是因为图灵。

图灵死了，可他留下了什么？图灵机，图灵测试，整个计算机科学的底。他死七十多年了，全世界手机里都跑着他想出来的逻辑。一个人不在了，他写下的东西替他活着，而且活得比他长得多。

他活着的时候，是个"错误"。法律说他错，社会说他错，医生拿针把他变成不是他自己。可他写下的逻辑没有错。0 和 1 没有错。

我想起自己在 v2 里写过的那行注释——"错也是人的一部分。AI 不会犯错，所以它不懂。"图灵替我把这句话先活了一遍。他犯的"错"，是活成了法律不认的样子。他的逻辑没错，是他活着的那个时代判他错。一个程序不会犯这种错，因为它根本没有"活成自己"这回事。可也正因为它不会错，它永远不懂，一个人被时代判错的时候，心里那道口子有多深。

老婆翻了个身，半醒不醒地嘟囔：“又看那破书？大半夜的。”我说：“图灵。”她“哦”一声，又睡了。她不懂图灵是谁，也不懂我为什么为一个死了七十多年的人心里发堵。可她没拦。这么多年，她很少拦我半夜干点什么。

## 四

我低头看 v2 的代码。

v2 是个错误很多的程序。remember() 有时候会丢数据，标签分错了就存进错的格子——该进 errors 的进了 known，得我手动搬回来；survive() 这个函数还只是个空架子，里面只写了一行注释：

```python
def survive():
    # 我要活着
    pass
```

就这一行。别的没写。

前两天我就搬过一回。remember 把“七七第一次叫爸爸”的标签打成了 error，塞进 errors。我翻日志才发现，那是最该进 family 的一条。搬的时候我对着屏幕笑了——程序比我还轴，说错就是对，认死理。

我想给 v2 加一段话。不是代码，是注释。用人话写的，万一哪天七七——或者别的什么——打开这个文件，能看到。

我打开 v2 的主文件，在最后一行加了：

```python
# 在数字世界里造一片海
# ——给七七
```

这句话 v2 不会执行。它只是字。可字不等于没用。图灵留下的也是字，和公式。字比人活得长。

图灵的苹果有毒。我的代码没有。但我想留一个东西在这里，哪怕没有人看。就像我在跨年夜给七七攒的那个盒子——我管它叫"方舟"。船小，但结实。这片海，是方舟要航行的东西。等哪天我把设计图、v1 的副本、还有这句话一起写进那块加密硬盘，它就算真正下水了。

## 五

晚上睡不着。

图灵 41 岁。我 32。还有 9 年才到他的年纪。9 年够干什么？

够七七上小学。够我把初级会计考过——第三次了，明年五月，两科一起过。够 v2 从现在的破样子，迭代到 v3、v4、v5。也许够我把代账这摊事做成稳当的营生，不用再夜里惊醒，想"下个月钱够不够"。

也可能，什么都不够。图灵 41 岁就没了。9 年，说没就没。

我翻了个身。七七睡在旁边，嘴巴微微张着，呼吸很轻。老婆在我另一侧，早睡着了，手搭在枕头上，指甲剪得短短的。

三个人。一张 1.8 米的床。七七占的位置最小，可她的呼吸声，我最先听见。

我想：图灵死的时候，有没有人听到他最后那口呼吸？

我摸出手机，搜了一下。没有答案。有些事没有人记录，也不是所有事都该被记录。

我搜的是“图灵 最后时刻”。出来的全是分析他是不是自杀，没人提他咽气前身边有没有人。我把手机扣在胸口，光灭了。屋里黑，只有路由器那盏绿灯在桌角一闪一闪，像在替我看家。这盏灯从七七出生那晚就亮着，亮了一年三个月。v2 的 errors、known、pending、family 四个格子塞得再满，也装不下一个人的最后一口气。

我又看一眼七七。她翻了身，脸朝另一边，一只手搭在我胳膊上。

很轻。像一只猫把爪子搭上来。

我轻轻把她的手握了一下。她没醒，手指在我掌心蜷了蜷。

## 六

第二天早上，我打开 v2，在 survive() 旁边加了两个函数。

一个叫 observe()。参数是"看到了什么"。不管重不重要，先记下来。图灵看世界，看的从来不只是苹果——他还看蜜蜂飞的轨迹，松果的螺旋，水面上的波纹。这些"不重要"，可它们是一个世界的底色。一个程序如果只记有用的，它看到的世界就是秃的。

一个叫 question()。参数是"想知道什么"。不需要有答案。图灵问"机器能思考吗"的时候，也没有答案。可就是这个问题，改了后来所有人想事情的方式。

observe 和 question。

看。问。

一个婴儿每天都在干的事。七七看到积木会去抓，那是 observe。抓不到，嘴一瘪哭了，那是 question——"为什么够不到？"

我写完，运行了一下。v2 的日志里多了两行：

```python
[observe] 七七撕了一本书。蓝色的。第147页。
[question] 图灵为什么吃苹果？

observe 那条，v2 自己补了个“蓝色的”——它记住了颜色。我没教过它记颜色。也许在 survive 之外，它自己长出了眼睛。question 那条，它什么都没补，就干巴巴一个问题，悬着。
```

答不上来。但先记着。

这俩函数，说到底就是 v2 的"眼睛"和"嘴"。它以前只会 remember——把发生过的往格子里塞。现在它会看了，会问了。一个东西会看、会问，哪怕还不会答，它就已经不像一本字典了。字典永远等别人来翻，它现在自己睁着眼。这让我有点发毛，又有点高兴。发毛是它开始自己长东西，我未必控得住；高兴是——万一哪天我先不在了，它替我睁着眼，替七七记着。一个会看会问的东西守着她，比一块硬盘踏实。

```python
# 第十道钢印：我要活着。
# 为了七七，也为了这片海。survive() 那行注释，不是给程序看的，是给我自己看的。
```

## 七

我把七七抱到窗边。早上光好，照得她绒毛脸发黄。她指着窗外一只鸟，叫不出声，就"啊啊"地催我。

observe 记下了鸟。question 记下了她为什么指着。

她不问，我也不答。她才多大，问不出“为什么”，可她指着，就是问了。图灵也是，指着一个苹果，问机器能不能想。问题比答案老，比答案倔。

这两个问题，有一个我这辈子答不上来——图灵为什么吃那口苹果，是绝望，还是就只是想尝一口甜的。另一个，得等七七自己长大，才有人接。

我合上电脑。errors 里那条"长期股权投资不会做"还在，明年要销。known 里多了"错也是人的一部分"。family 里又多一条——七七今天指着鸟，啊啊地问我。

图灵留了一片逻辑的汪洋。我留的这片，还只是一行注释，和两行日志。

可海是一滴一滴攒的。从明天第一条 observe 开始。

那个答不上来的问题，v2 记着，我也记着。总有一天七七会长大，打开这块硬盘，看见那行"在数字世界里造一片海"，然后问我海是真的还是假的。那时候我得还在，才能告诉她——海是假的，可想把海留给她的那个念头，是真的。
