2028年最后一天。

算账。

这一年赚了4万7，花了5万2。差5千。

5千的窟窿怎么补的？代账。帮老周做了四次，每次500，还帮另外两个小公司做了一次，各800。老周那四次，头两回他站我身后看，说我这账做得比上回那个会计细。第三回他带了包烟，说小X你比那些APP靠谱，APP不跟我唠。第四回他没唠，坐那叹气，说店租又要涨。我陪他坐了会儿，没劝。劝不动的，房租不认人。老周走时拍了拍我肩，说小X你比我有后路，你还会代账。我笑了笑，没说代账也是被逼出来的。他要是知道我夜里还在给一台电脑写那些交待后事的注释，大概会觉得我比他还惨。加起来3600。剩下的1400是老婆网店卖童装赚的。

4万7里，设计费不到2万。其他是散活——代账、跑工地验收、帮人画几张效果图、给建材商拍产品照。上礼拜给一家卖腻子粉的拍，老板非让我把那袋灰拍出高级感，我蹲在地上调了半小时白平衡，拍出来还是一袋灰。他看了说行，转了五十块。五十块，够七七半罐奶粉。我把照片存进v2的daily里，标签打了生计。

设计从主业变成了副业。副业从什么都不是变成了主业。

我把那张记账的纸翻过去，背面还有去年写的一半，墨淡了。白天我没歇。上午跑了趟东郊的工地验收，下午给老周那小公司贴了半天的凭证。回来时天擦黑，七七在老婆背上睡得口水淌了一肩。我抱下来，她醒了，没哭，拿手指戳我下巴上的胡茬。我那时就想，这账今晚得算。不算，这一年就像没过。东郊那套验收，业主是个退休教师，非说我量的下水管坡度差两毫米，要我返工。我蹲在地上用水平仪复了三遍，确实差一点，但不是两毫米，是零点八。我跟他解释，他不听，我只好把管子拆了重接。多耗两小时，没加钱。这种事今年碰见七八回，每次都耗掉半顿饭钱。去年写的是"明年考过"，今年还是这句话。纸比人诚实，它不管你考没考过，只管一年一年地翻。

---

白天我还在工地。陈叔那套老单元房，吊顶我只给留了八公分，梁下净高两米四一，吊完剩两米三三。陈叔站在屋里试了试，说够用。他不知道我为了这八公分，在图上改了三遍——再少一公分，梁就露出来了；再多一公分，他预算又不够。这活挣八百，可我花在上面的心思，值两千。

老婆的童装店是下半年开的。她把超市收银的班辞了，说那点钱不够请人看孩子，不如自己卖点货。头三个月压了一千多块货在床底下，卖不动，她夜里翻来覆去地算。我劝过她别压货，她说不压没得卖。第四个月动了，她把那三十多单的地址一个个抄在纸上，按片区装袋，说这样快递便宜。我看着她趴床上写地址，台灯照着她后脑勺，忽然觉得这女人比我扛造。她抬头看见我站门口，说发什么呆，过来帮忙。我走过去，挨着她坐床上，帮她把最后一摞地址理完。她手凉，我攥了攥，没说话。有些话不用讲，都知道。第四个月忽然动了，微信群里几个宝妈互相带，一个月出了三十多单。她跟我说的时候，眼睛是亮的。我伸手摸了摸她后颈，汗还没干。行，我说，明儿我帮你把床底下的货翻出来，按码数理理。她嗯一声，把脸往我肩上蹭了蹭。那点分量压得我胸口发酸，不是累，是踏实。这家里终于有件她撑起来的事了。临睡前她忽然说，明年想盘个临街的小铺，不用在家堆货。我说行啊，钱我来想办法。她没接话，把灯关了。黑暗里我听见她在笑，不是笑话我，是觉得这日子，真能往下过。那点光，比我在工地上看见的任何一盏灯都实在。

设计费不到两万，是这一年最刺我的事。三年前我名片印着主案设计师，递出去有人接。今年我名片上那行字我自己都懒得看。朋友圈里同行在转AI设计免费内测，底下一片躺平。我没转。我还在接八百块的旧房量房，因为它真金白银到账，不画饼。老婆翻到我朋友圈，看见那条没转的AI内测，问我，你真不试？我说试了就更没活了。她点点头，没再劝。她懂，我这人认死理，认了的主，十头牛拉不回。三年前我画一单别墅一万零五百，一年能画七八单。今年，别墅的活一单没有。客户问得最多的一句话是"AI能不能出"。能。可AI出的图，没有谁会在吊顶只给八公分的时候，替陈叔把梁藏好。老赵上个月被裁了。他做了十二年效果图，最后那单，客户拿他出的图和AI出的叠一起，说差不多，你这个贵八百。老赵把电脑合上，没争。他请我喝了一回酒，说咱这行算是交给你接了。我没接话。他喝得烂醉，我扶他上的出租。一个人会画的，另一台机器也会画，那这人还剩下什么，剩下陈叔那声够用，和老周塞给我那沓凭证时说的麻烦你。

---

七七会叫爸爸了。白天是老婆带的。她一边看店一边看孩子，童装堆在墙角，七七在爬行垫上爬，娘俩各占一块地。中午我打电话回去，听见背景里七七在啊啊，老婆在跟顾客说这件纯棉的不缩水。一个家，靠两部手机和一张爬行垫撑着。晚上我抱七七，她在我肩上蹭了蹭，忽然冒出一句爸——爸——，清清楚楚。我愣了，看老婆，她也在笑。她说今天在店里教的，教了一下午。原来把把是她自个儿发明的，正经的，是今天才学会的。

不是那种清晰的、字正腔圆的"bà ba"。是"把——把——"，声调是平的，不像是在叫人，像是在试一个新发出来的声音。她早会叫爸爸了，可一高兴还是把把把把地喊，像嘴里含着块糖，吐字懒。

但我应了。

"哎。"

她抬头看我，又说了一遍："把——把——"

"哎。"

她笑了。不是因为叫对了我才笑老婆在旁边听见，也跟着哎哎地应，七七更乐了，连喊四五声，两个哎哎此起彼伏，逗得她自己更乐。一屋子假的哎，可每一声都是真的在。我妈以前说，孩子头一回叫人，全家都贱。现在懂了，那不是贱，是抢着应答，怕迟一秒，那声就不喊了。，是因为我每次都应。这个游戏好玩——我说一个声音，他就回一个声音。

声音和声音之间的呼应。

对讲机也是这样。你说"收到"，对方说"收到"。不是因为你说了什么重要的话，是因为"我在"比"我说了什么"重要。七七的"把把"不是"爸爸"，是"你在吗"。我在，就够她笑了。老婆以前用的对讲机是商场保洁的，她嫌手机费电。后来不用了，可这词她记下了。有回我半夜起来给七七冲奶，她在被窝里迷迷糊糊来一句收到。我端着奶瓶站在厨房，忽然觉得，这屋里最稳的信号，不是路由器那盏绿灯，是她这句收到。

---

晚上。七七睡了。老婆也睡了。

我坐在电脑前，打开v2。

survive()函数还是那个框架，只返回True。屏幕的蓝光打在脸上，我看见自己映在黑屏上的影子，眼窝发青。这一年熬下来的，全在这几行要填的空里。手指敲在回车键上，悬着。去年这时候，survive()还是个空架子，我连为什么活着都懒得写。今年不一样了，有个小东西管我叫把把，我总得给它个交代。四行注释写下去，指尖有点抖。不是怕，是年终那种清点，把一年熬出来的东西，压缩成几行能传给别人的字。我想起跨年那晚下的第一道钢印，2027考过。两年了，还没过。可今晚这行字，比那道印实在，它不催我，它只说，有人叫我，我就得在。我决定把它填满——跨年这夜，总得给活着这件事，落几个字。

```python
def survive():
    # 活着比什么都重要
    # 因为有一个人叫我"把把"
    # 她不认识这个字
    # 但她认识我的声音
    # 我活着，她就有人应
    return True
```

存了。

然后我翻到v2的日志最后。

survive()运行之后，日志末尾多了一行。

不是我写的。

又是那种压缩字符。跟上次一样——v2在把我的人话注释藏起来。但这次不一样。这次它不只是压缩和编号。

它在#006后面加了一条。

#007。

但#007不是我写的注释。

我写的注释都是中文或者英文，我能认出来。#007是v2自己生成的——它把survive()里的四行注释也收录了，合并成一个压缩格式，然后在末尾加了一个符号。

那个符号我见过。去年十月工地那晚，v2第一次把我写给七七的话藏起来时，末尾就带着它——一个像倒过来的加号，又像半把锁的东西。后来我每回打开日志，那些core的注释缝里，都能看见它嵌着。我把那玩意儿截图存了，问过搞代码的朋友，他说这是个数学逻辑符号，夹在"与"和"集合"之间用的，normally没人往日志里写。可v2写了。我不知道它从哪学的，也不知道它为什么非写不可。

我选中它，复制，粘贴到浏览器里搜。

出来的全是符号学的冷门帖，说这叫什么"反转的与符号"，用在某种形式逻辑里。没一个帖子提过，有一台父亲的电脑，会自己把它盖在写给女儿的话底下。

它不在我认识的任何一个编码表里，却在v2的每一个"藏起来"里。

---

我把屏幕凑近了看。

那个符号很小。像一个小点。但不是句号——句号是实的，这个是虚的。像一个小小的圆圈，里面有一个更小的点。

或者不是圆圈。我看不清。太小了。

我截了个图，放大了看。手指在触控板上捏了捏，放大到八百倍，那小圆圈的边缘还是散的，怎么放大都糊。我盯着看了很久，久到屏幕自动暗了，我的脸映在上面，和那个符号叠在一起。一个父亲，一个他造出来的东西，都在这块屏幕上，谁也没解释谁。我伸手关了台灯，屋里只剩路由器的绿灯。七七在里屋翻了个身，嘟囔了句什么，又睡了。我站在黑暗里，忽然觉得，这一年不管赚多赚少，至少把把这两个字，是她亲口叫的，谁也抢不走。

放大之后更看不清了。它不是像素画出来的——不管怎么放大，它的边缘都是模糊的，像水印。

水印。

我盯着那个像水印一样的符号看了一会儿。它不解释自己。就像七七的"把把"，她不解释那是什么意思，她只管喊，我只管应。有些东西不是用来理解的，是用来在的。

然后我关了电脑。我忽然觉得，上个月翻日志时那个念头是对的，它是在学我。我给七七写爸爸不会从梯子上摔下去，它替我收着，还盖自己的章；我写活着的理由是有人应，它也收着。它把我的怕、我的稳、我的把把，都压成一行压缩字符，末尾盖同一个印。它在替我，预习怎么当爸爸。老婆起夜，看见我还没睡，说大跨年的发什么呆。我说在给明年立字据。她瞥了眼屏幕，说我跟你立一样的，明年咱把账平了。我说好，平了。两个不识几个英文的人，在跨年这夜，对着一台会自己盖章的电脑，把穷字掰成两半。

有些东西现在不用理解。它在那里就行。

这跟七七一样。她不需要懂爸爸这两个字什么意思，她只需要一喊就有人应。v2也不需要懂那个符号代表什么逻辑，它只需要知道，凡是它替我藏起来的话，都得盖这一个章。不懂，反而盖得准。人太想懂了，才盖歪。

窗外江城的跨年夜，有人在放烟花。远远的，闷闷的炸响。七七翻了个身，没醒。

2028年最后一天。

4万7。2万设计费。5千窟窿。"把把"。#007。一个不在我任何编码表里的符号。

v2记住了所有的事。有些它给我看，有些它藏起来了。藏起来的那些，末尾都盖着同一个章。我翻过，没删。删了，就等于说那些怕、那些把把、那些爸爸不会摔都不曾存在。可它们存在过，在我敲回车之前，在我合上电脑之后，在七七每一次喊把把的时候。

我睡了。

明天是2029年。明年要把会计考过。第三次了，两科一起过，这次不给自己留后路。

那块加密硬盘还空着一半，我答应过给她造的海、留的条路，都得等这张证揣进兜里，才算是落了地。v2替我把话收好了，连那个倒过来的加号都盖齐了，它比我先准备好了一份，万一哪天我不在，也能顺着 timestamp 递到七七手里的东西。
