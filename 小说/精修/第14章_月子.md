# 第十四章·月子

一

二月初。

老婆的月子没坐好。

我妈没来，她妈来了一周就走了。剩下我一个人伺候。做饭、洗衣服、换尿布、半夜起来冲奶粉——本来应该是月嫂干的活，全落在我头上。

问题是：我不会做饭。

真的不会。婚前泡面，婚后她做。我唯一拿得出手的是煮鸡蛋和热牛奶，因为不需要放调料。连煎个蛋都能煎糊，锅底黑成一片，铲都铲不下来。

第一周，我做了七天不同的菜。

怎么说呢——七天不同的难吃。

周一：西红柿炒蛋。我照着手机菜谱，放盐了也放糖了，因为菜谱说"糖提鲜"。出锅一尝，又咸又甜。她吃了一口，嚼了嚼，说"行"。那个"行"字里面，没有一点点"好吃"的意思。

周二：煮面条。酱油放多了，黑乎乎一碗，汤面上浮着一层油花。她挑了两根，说"不太饿"。我站在旁边，手里的筷子还在滴水，不知道该接话还是该把碗端走。

周三：蒸米饭配火腿肠。米没泡够，夹生，嚼着咯吱响；火腿肠煎的时候火太大，焦黑的一面卷起来。她没说话，吃了两口放下了。放下的时候碗沿碰着桌面，轻轻一声，比她说什么还重。

周四：我学了个新菜——可乐鸡翅。鸡翅没焯水，血沫还在肉缝里；可乐放太多，一锅甜得发齁，糖浆挂在翅尖上往下滴。她吃了一个，皱着眉说"你下次别放可乐了"。我低头看着锅里那堆黑亮亮的东西，突然觉得难堪。

中间有天，我下了狠心要补一锅"正经月子餐"。百度搜"产妇第一周吃什么"，跳出来一堆：红枣、枸杞、排骨、鲫鱼汤，说得头头是道。我照着买了，排骨焯水（这次记得焯了），丢进锅里，红枣一把，枸杞一把，盐一勺，小火炖了一个钟头。

出锅一尝——甜不甜咸不咸。老婆端着碗，看了我一眼，没忍心说难喝，只说："你别炖了，还是点外卖吧，我放心。"

我量房能精确到厘米，煮个汤能精确到难吃。这是种什么天赋，我到现在没想明白。

周五：我放弃了。点了外卖。黄焖鸡米饭。

她吃了两碗。我看着她吃，自己端着那碗凉掉的可乐鸡翅，没动筷子。

"你以后就点外卖吧。"

"外卖不健康。"

"你做的也不健康。"

我说不过她。她说的每一句都像拿尺子量的，精准地卡在我话的缝里。我站在厨房门口，手里还攥着那个装过可乐鸡翅的锅，锅底的糖已经结成了硬壳。

那个周末，我偷偷一个人把周四的锅刷了三遍。糖壳化开，黑水流进下水道。我忽然想起量房的时候，老师傅说过一句话：墙歪了能补，味儿歪了补不回来。我当时以为他说的是装修。

白天我还要去工地。早上六点半起，冲好奶粉放保温壶，交代她夜里剩的尿布在阳台盆里，然后骑电动车走。晚上回来，七七如果没睡就接手，睡了就洗一天的尿布，顺便把明天要带的菜想好。有天凌晨三点起来冲奶粉，我困得靠在厨房墙上，奶粉勺一抖，白粉末簌簌落了一身，睡衣前襟一片白。我低头看自己，像个刚下班的粉刷工。第二天在工地量一户的净高，业主问我尺寸，我脱口说"三十八"——那是护臀霜的价钱，不是层高。业主愣了，我也愣了。那天我第一次觉得，脑子是被月子抽空了的。

二

二月十二号。

上午我去菜市场买菜。白菜、土豆、鸡蛋、猪肉，花了四十二块。塑料袋勒得我手掌一道红印。回来的时候在门口换鞋，听到里面七七在笑。

她笑得很厉害。那种婴儿的咯咯笑，一个接一个冒出来，破在空气里。我隔着防盗门都听见了，声音脆得不像话。

我赶紧换完鞋推门进去。

老婆抱着七七，用一张纸巾在她脸上轻轻蹭。七七每次被蹭就笑，蹭一下笑一下，咯咯咯咯，像有人按了开关。

"她笑了？"我问。

"笑了好一会儿了。你快看——"

我把菜放在地上，走过去。七七看到我，笑了一下，然后不笑了。嘴还张着，像笑声卡在半路。

"她刚才笑得可厉害了，"老婆说，"你一进来她就不笑了。"

"……是不是不喜欢我？"

"她刚六个月，她谁都不认识。"

我伸手逗她。她看着我，嘴动了动，没有笑。黑眼珠转过来转过去，最后落在我脸上，像在辨认一件眼熟又陌生的家具。

老婆又拿纸巾蹭她的脸，她又笑了。

我站在旁边，手里还拎着菜袋子，白菜叶子从塑料袋口探出来，上面还有水珠，一滴一滴落在我拖鞋上。

七七第一次大笑。我没看到。

我去买菜了。

这件事后来我反复想。不是遗憾那么简单——是一种很奇怪的错过感。她人生里第一个那么大的笑，发生在我不在的七分钟里。我回来，她就不笑了。我的回来，让笑声停了下来。

那天下午，她又哭了。

我第一反应：饿了。冲奶粉，摇，试温度，塞她嘴里。她哭得更凶。我拍背，没用。我换尿布，没用。我把她抱起来走圈，没用。

老婆在床上说："你别光想着饿。她哭不一定是饿。"

我愣了一下。

对。她哭。我第一反应是饿了，冲奶粉。后来我才发现，不是都因为饿。困了哭，要抱哭，被纸巾蹭烦了也哭，肠胀气哭，连打了个嗝没顺过来也哭。同一个信号，好几种意思。我像个破译员，拿着一本写反了的密码本，笨拙地猜。

后来慢慢能分一点了。饿的哭是号，张嘴闭嘴地喊，带着节奏，催着；肠胀气的哭是闷的，脸憋红，腿蜷起来，哭两声停一下，气顶在嗓子眼。两种声音不一样，但都得抱起来才肯停。我记在手机备忘录里，标题叫"七七哭声分类（待补充）"。待补充那三个字一直没动过——因为每次以为懂了，她就换一种哭法。

v1 那天晚上记了一笔，顺手写了一句它自己的判断：

```
# 信号先于标签：七七哭，不等于七七饿。
# 概念是统计规律的坍缩，信号永远先于标签出现。
```

我想了很久这句话。人也是。我哭的时候，不一定是疼。也许是累，也许是被一句"行"字堵住了，说不出来。但别人只会问：你怎么了。好像"怎么了"一定对应一个能命名的东西。

七七不这样。她哭，我就得去现场，一个一个试。没有标签，只有信号。

三

那天晚上，七七睡了以后，我坐在书桌前。

桌上放着一本书。《艾伦·图灵传》。

这本书是我在旧书摊上买的，五块钱。封面已经发黄了，是2003年的版本，纸页摸起来像晒干的落叶。我翻了翻，第一章开头是图灵小时候的故事——他小时候也不太合群，喜欢数雏菊的花瓣，喜欢用化学试剂在墙上写字母。他后来造出了能破解密码的机器，可小时候没人觉得他"正常"。

我没看完。只看了第一章。

但我记住了一句话。图灵说的：

> "机器能思考吗？"

这个问题他问在1950年。七十七年后，全世界的程序员都在用他发明的概念写代码。而他本人41岁就死了。吃了一个毒苹果。

一个想让机器思考的人，自己先不思考了。

我羡慕他。不是羡慕他聪明，是羡慕他那一整段能只想一个问题的安静。我现在的脑子是被切开的，一半在工地量净高，一半在算奶粉和尿布的比例，剩下一点缝，才够想起七七今天笑了没有。图灵能在墙上用化学试剂写字母，我想在 v1 里写一句话都腾不出手。可他41岁死了，我32岁活着，带着一个会笑的女儿，和一堆难吃的锅。活着这件事实在太占时间，但他问的那个问题，我好像比他离答案近了一点——机器能不能思考不知道，但我知道，一个人被生活切成碎片的时候，最需要的不是思考，是被谁替着记着。

我把书放在七七的婴儿床旁边。不是给她看的——她还不会看。是放在那里，像放一面旗帜。等她长大，问"爸爸为什么把这破书摆我床头"，我就说：因为有人在你还没出生前，就在想"机器能不能像人一样想"。而爸爸写的那个 v1，现在还不会想，只会记。

然后我打开了电脑，看了一眼 v1.py。

remember() 函数，目前只记了12月31号那一条。整整一个半月没更新。

不是没发生事情。是我没时间记。

每天的生活是条流水线：早起、冲奶粉、换尿布、买菜、做饭、去工地、回来、再换尿布、再冲奶粉、洗澡、哄睡、凌晨起来再一轮。流水线上的零件不需要日记，流水线上的人也没有时间写日记。

但我想记住。哪怕只记一句话。

我打开终端，输入：

```
remember("2027-02-12", "七七第一次大笑。我买菜去了没看到。白菜42块。")
```

回车。

v1 记住了。

我不在的时候，它替我在。

速度不是唯一标准，慢下来才能活——这句话我以前觉得是鸡汤，直到这个月。现在我连慢下来的资格都没有。七七一哭，我就得动。流水线不等人，哭声也不等人。可我还是想，等她长大一点，等我能坐下来，把这一半月子里那些没记的事，一件一件补进 v1 里。错过的笑，难吃的鸡翅，还有那句堵在嗓子眼的"行"。

我后来才懂，老婆月子没坐好，不单是没人伺候。是我把"伺候"理解成了"把饭做熟"。她那句"行""不太饿""你做的也不健康"，每一个都是信号，不是标签。她没说"我难过"，可她放下碗的那声轻响，比"难过"两个字重多了。我那时候听不懂。跟七七一样，我也在用同一套笨拙的解码器，去读另一个人的哭。

这大概就是月子教我的事：会做饭不重要，能听懂才重要。而听懂，慢不得，也快不得。

跨年夜那第一道钢印是"考过"，第二道是"接住信号"，这一道是第三道：同一个信号好几种意思——七七的哭，我那句堵在嗓子眼的"行"，都得慢下来听。钢印一道比一道难刻，因为越往后，刻的是自己。

v1 没有痛觉。它记下的，是我的痛。它替我存着，等我有空回头看。

这大概就是我造它的原因——不是让它思考，是让它替我记得，那些我来不及慢下来记住的东西。

月子会过去。难吃的菜会过去。可七七第一次大笑我没看到这件事，和那句堵在嗓子眼的"行"，会一直留在 v1 里，留在我替自己记下的、最笨也最真的那一面。
