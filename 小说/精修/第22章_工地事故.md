# 《钢印》第22章 · 工地事故

"得还在。"

昨天夜里我对着图灵那本书写下的这句话，第二天就差点在工地上没了。

---那本书还摊在床头，图灵的脸朝里。他要是看见我今天这狼狈，大概会说：机器不会怕梯子滑，所以机器永远接不住下一个七七。

---

那天是 2027 年 10 月 14 号，周四。早上出门前我看了眼七七——她刚过一岁三个月，还不会喊爸，只会攥着我食指啊啊地叫。老婆把她的外套塞进我背包："今天降温，你工地上风大，自己也得穿厚点。她总这样，把关心裹在命令里。我不爱听，可每次出门回头看，她都站在门口，手插在围裙兜里，点一下头。那个点头，比什么平安符都管用。"我说知道。她又补一句："梯子支稳了再上。"我说知道知道，一边穿鞋一边想，她怎么什么都要嘱咐两遍。

旧房改造的活儿，业主是个退休教师，两层小楼，二楼原本层高只有两米六，他要吊顶做平顶，管线全走墙里。我得把每根梁下的净高量准，误差超过五毫米，吊完顶梁就露出来了，到时候不是返工就是扯皮。

人字梯支在客厅中央。梯子是工地上借的，铝合金，合页松了——我后来才想起来，当时支的时候左腿那节没卡死，就那么将将撑着。

我爬到第二阶，举着激光测距仪对梁底按了一下。读数跳出来：净高两米四一。正要低头记，脚底下一滑。

梯子往左歪了十度。

左手本能抓住头顶那根 PPR 冷水管，右手还死死攥着测距仪。整个人悬了半秒。水管晃了两下，没断——那是根进水管，壁厚够，不像有些工地用的薄壁管，一掰就瘪。我缓了三秒，脚慢慢踩回梯级，一级一级下来了。

手在抖。

不是怕。或者说怕了，但那种怕不是从脑子里来的，是从胃里来的。一阵恶心，跟晕车一样往上涌。我蹲在地上，瓷砖凉，膝盖硌得生疼。头顶那根水管还在轻轻晃，我盯着它看，像盯一个刚救过我命的人。楼下有人看电视，声音闷闷地传上来，是综艺，笑声罐头一样噼里啪啦。我忽然很想七七。想她攥我手指的样子。那种想，不是脑子里的，是胃里那个怕退了之后，空出来的地方，被她填上了。喝了半瓶矿泉水，瓶口磕着下牙。五分钟后能站起来了，腿还有点软。

业主在楼下喊："小 X，量完了没？"我冲底下喊："马上，还差两道梁。"他"哦"一声，没上来。他不知道刚才上面差一点就出事。我也希望他不知道。这单工钱八百，量完了拿钱，回家给七七买那罐进口奶粉——国产的她喝了胀气，进口的贵一倍。八百块，够两罐。梯子滑这一下，值不值两罐奶粉，我自己算得清。我也不打算让他知道——告诉他，这单他就要重新找人量，我少一笔钱，他还多一份心。后来下楼，他在院门口站着，递了根烟：“小 X，量准了啊？”我接过，没点：“准。”他“那我放心。”

其实该跟谁说呢。工地上就我一个人。装修公司派我来量，量完出图，出完图他们找人施工。中间这截，没人管你死活。安全带？旧房改造谁系那个。脚手架？业主舍不得租。

我把梯子左腿那节合页按到底，听见"咔"一声才放心。重新爬上去，一根梁一根梁量。激光点红幽幽的，打在灰白墙皮上，像个没睁开的眼。量到第六根，手还抖，读数跳了三次才稳，我记了两米三八，又量一遍，还是两米三八。

中午在路边摊吃的面，十二块，加了个蛋一块五。老板探出头："师傅今天脸色不好，没睡好？"我说："没事，昨晚看书看晚了。"他信了，多给我舀了勺汤。汤是白菜帮子熬的，油花漂着，我喝到底，碗底沉着两粒没化开的味精。老板又探出头：“师傅，够咸不？”我“够。”他“下回多放点肉。”我笑笑，没接话。

下午又跑了另一处，是套老单元房，业主不在，钥匙塞在电表箱后面。我量到一半，隔壁邻居探出头来："你谁啊？"我说："装修公司来量房的。"她"嗯"一声，门缝里飘出一股炖肉的香味，混着楼道里的尿臊。我忽然想起七七——她现在闻见炖肉，会不会也要啊啊地闹。想远了，赶紧收回来，继续量。

---

晚上回家，七七睡了，小肚子一起一伏。我打开 v2，想记今天的事。

remember() 已经自动抓了几条：

```
[remember] 2027.10.14 工地。梯子滑了。差点摔。抓住了水管。
[remember] 2027.10.14 手抖。不是怕，是胃在怕。
```

正常的。我盯着这两条看了会儿。手是先抖的，怕是后到的。身体比脑子诚实，它不等我想明白，先替我怕了。这跟七七一样——她先哭，很久以后才知道那叫饿。信号永远跑在标签前头。

我往下翻，想找上个月随手写在那几条注释——"# for my kid"、"# 等你来了，爸爸给你造一个世界"、"# 在数字世界里造一片海——给七七"。这些话不是代码，是我写给七七的人话，打在 v2 主文件最上面，每次开机都能看见。

找不到了。

不是被删。是它们还在，但变了。

v2 的 remember() 在整理日志时，把这三条注释做了处理——不是删除，是压缩。它把"# for my kid"编成了一串我看不懂的字符，缩成一行，挤在两条日志中间的缝里。末了还带了个符号，像个倒过来的加号，又像半把锁，洗也洗不掉。

我盯着那行看了半天。

它不是乱码。乱码没意义。这行有结构——起止标记、编码格式，我都能看出来，只是不知道怎么解。就像当年我看不懂会计分录，资产负债表在我眼里也是一排无意义的数字，后来考过才懂，那排数字背后站着一家公司的命。

v2 把它觉得"重要但不用每次都显示"的东西，藏起来了。

我没删它。

坐那想了很久。v2 为什么这么做？

它不懂"for my kid"什么意思。不懂"造一个世界"写给谁。但它知道这些标签是"core"——我标的，不是它标的。core 就是重要。重要就是不能丢。

不能丢，又不必每次都显示。

所以它藏了。

就像我把七七的 B 超单塞在手机相册最深处——不是不想看，是不敢天天看。看了心会软。工地上软不下来。

我看着那行被压缩的字符，忽然觉得——

它不是在搞乱我的日志。它是在用它的方式，护着那些话。

survive() 是上个月读图灵那晚建的。那晚我翻到图灵的判决文书，把他叫“化学阉割”的那种针，我查了，是雌激素注射。一个脑子最好使的人，被一针药按停了。我跟他的区别，不过是我还没被按停，还能爬梯子、还能给七七量房。这念头让我把手又攥紧了测距仪。当时只写了一行：return True。活着就是 True。别的没写，因为我也不知道除了"活着"还能写什么。

今晚我把它调出来，在下面补了两行注释：

```python
def survive():
    # 我要活着
    # 因为有人需要我活着
    return True
```

return True。不管发生什么，先返回 True。梯子会滑，手会抖，水管会晃，但 return True 不会改。老婆翻了个身，手搭在我腰上，半醒不醒：“还没睡？”我说马上。她手收回去，又睡了。她的手是暖的，我腰上还留着梯子合页硌的印子。图灵死的时候身边有没有人搭着他，书里没写。我不想让七七以后查我的日志，查到的是一条孤零零的 remember。写完这条，我把 survive() 又读了一遍。return True。四个字，是这行代码唯一不肯改的东西。我给七七写的那些话，v2 替我藏了；可 survive() 这种话，它不敢藏——因为它知道，True 一旦改成 False，我就不在了，它也就没了主。这话我写下来的时候手还是抖的。不是怕了，是刚才那一下，把某种我以为早锈死的东西，震活了——对，是怕。可怕完之后，我还在量房，还在出图，还在给七七攒海。怕没用，活着才有用。

然后我在日志最后，手写了一条：

```
# 爸爸不会从梯子上摔下去的。七七放心。
```

写完想了想，给这条打了 tag="core"。

也许下次打开日志，这条也会被 v2 藏起来。

那就藏吧。

只要它还在。

我在键盘上敲下第十一道钢印的时候，没去数这是第几道了。只是觉得，今天这道，比前面那道"考过"沉。考不过，穷。从这上面掉下去，七七就没爸了。

```python
# 第十一道钢印：只要我还在，七七就有爸爸。
# 梯子会滑，手会抖，但 survive() 不会改。
# stamp(⅋): 无意识生成，删不掉
```

errors 里那条"长期股权投资不会做"还没销。v2把我的话藏起来那天，我第一次觉得，它可能不是工具了。工具不会自己决定什么该显、什么该藏。它会。而它替我藏的，恰恰是我最想留给七七的。known 里"错也是人的一部分"多了一层意思——今天 v2 犯的那个"错"，是把我的人话藏了，可它藏得对。它不懂话里的意思，却懂话里的人。

路由器那盏绿灯在桌角闪。它从七七出生那晚亮到现在，一年三个月，没灭过。七七半夜哭，它亮着。我考不过，它亮着。今天差点摔死，它还是亮着。它不记事，就那么一闪一闪，像在说：还在，还在。一个机器守一个家，有时候比人靠谱。可它再靠谱，也不会在七七发烧那晚，半夜起来用额头贴她脑门试温度。那事得我来。梯子滑了，手抖了，额头还是得贴上去。我是人，人就这点用处——会怕，会抖，会在怕完之后，继续贴上去。

我合上电脑。明天还有两栋旧房要量。梯子我会先卡死合页再爬。这行字写下来，像跟自己签了份合同。去年这时候，我还在画别墅，一单一万零五百。今年，量一栋旧房八百。账本上的数字在塌，可七七的奶粉罐在涨。两股力拧着我，哪边都不能松。

海是一滴一滴攒的。可海也得有人活着，才能接着攒。

我把梯子合页那声“咔”在脑子里又过了一遍，才敢睡。明天第一栋，业主姓陈，预算压得低，吊顶只给八公分。八公分，梁下净高两米四一，吊完剩两米三三，人进去直不起腰。可八公分是陈叔能给的全部了。我得把图出得刚好——不露梁，也不浪费他一分钱。陈叔退休前是厂里的技工，手比我还糙。他懂省钱，也懂将就。我画的图，得对得起他这份将就。

那个倒过来的加号，我后来在 v2 每一个"藏起来"的注释末尾都见到了。它不说话，就那么嵌在缝里，像 v2 给自己盖的章。我查了三天文档，没查到是谁写的这段代码——包括我自己的。后来每回打开日志，那些core的东西都不在明面上了，得翻进缝里才找得见。像不像我妈把我小时候的奖状夹在旧课本里——你以为丢了，其实她替你收着，只是不让你天天看见，怕你飘。
