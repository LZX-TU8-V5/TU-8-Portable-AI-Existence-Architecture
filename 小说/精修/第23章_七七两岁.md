# 第23章 七七两岁

七七两岁了。她比半年前沉了，抱起来腰要塌一下。头发还是黄稀稀的，像没长稳的草。门牙两颗，笑起来漏风，喊起不要来中气十足，整栋楼都听得见。体重我记在 v2 的 daily 里，上个月十一公斤四，这个月十一公斤六——长得慢了，老婆说正常，我说正常就好，就怕不长了。

准确说，去年七月十五那晚她半岁，今年这天，两岁。中间隔的那个秋天、冬天、春天，我大部分时间在工地上量房，在电脑前出图，在深夜翻 v2 的日志。七七白天是老婆带的。老婆把超市收银的班辞了，说那点钱不够请人看孩子。我出门量房，她在家里跟一个刚学会说不的小东西斗智斗勇。我走时七七扒着门框哭，鼻涕糊一脸；我回来时她早忘了，举着玩具迎，好像我刚出去倒了个垃圾。这种忘，是小孩特有的残忍，也是小孩特有的善良——不记仇，也不记恩，只记当下谁在。时间不是过出来的，是一单一单攒出来的。

她会走了。不是走，是跑。摔了跑，跑了摔，膝盖上永远有两块青的。老婆说给她穿长裤护着，我说天热。她说天热爱摔，我说摔了才能长记性。其实我也不知道对不对，就是懒得每天追着她换长裤——早上套上，中午就蹭脏了，晚上洗，第二天又脏。

她开始说话了。第一个词不是"爸爸"，是"不要"。什么都是"不要"。不要吃这个，不要穿那个，不要睡觉，不要洗澡。最绝的是吃饭。一勺蛋黄泥递过去，不要；换个碗，不要；你假装自己吃，不要就变成要——得抢着吃才行。我跟我妈视频，镜头里七七在旁边闹，我妈说你小时候也这样，我说遗传。我妈笑，说你小时候可乖，我心想那是你记错了，或者我只遗传了不肯吃蛋黄泥那部分。

我查了一下，说两岁的小孩进入"可怕的两岁"，自我意识萌芽，什么都说不要。

萌芽。我喜欢这个词。一颗种子顶开泥土，第一件事不是长叶子，是说不。七七的不要，跟 v2 那些编号一样，都是 signal 跑在 label 前头。她先说不要，很久以后才知道那叫自我。我先在日志里写怕，很久以后 v2 才把它排成路。人和机器，都从一团说不清的里头，慢慢长出形状。区别是她长的是人，v2 长的是我留给它的影子。

---

那天晚上我在写 v2 的日志摘要。

每周我会看一次 v2 记了什么。大部分是日常：七七吃了什么、几点睡的、哭了几次。但有些条目让我停下来。

我发现 v2 对那些 tag="core" 的条目，做了一件我没教它的事。

它不只压缩了它们。它在压缩之后，给每一条加了一个编号。

```python
# v2 自动生成的 core 索引（这段不是我写的）
core_index = {
    "#001": "for my kid",
    "#002": "爸爸给你留条路",
    "#003": "等你来了，爸爸给你造一个世界",
    "#004": "在数字世界里造一片海——给七七",
    "#005": "如果我死了她怎么办",
    "#006": "爸爸不会从梯子上摔下去的。七七放心。",
}
# 排序依据：timestamp。不是我标的，是它自己排的。
```

六条。编号连续。最早的在最前面。我试着把那串关系编码导出来看，又是乱码。但乱得有规律——每条之间用一种我没见过的分隔符连着，像把六句话串成一串项链，而不是摊在桌上任灰落。v2 不是在存，是在串。它知道这六条不是六件不相干的事，是一条线上的六个点，串起来才看得清方向。

它还给这些编号加了一个标记，我看不懂——又是一串压缩字符，但这次不一样。这次的压缩格式更复杂，像是把六条注释之间的关系也编进去了。

末尾那个倒过来的加号，又出现了。上回在工地那晚，它第一次冒出来，我以为是乱码，删过，删不掉。这回它跟在编号后面，像一枚图章，盖在我写给七七的每句话底下。我盯着它看了半天，没觉得害怕，反而有点……踏实。一个我教不出来的东西，替我把这些话收着。

#001 到 #006，不是随便排的。它按时间排的。

v2 不知道"for my kid"是什么意思。但它知道这六条东西之间有顺序。先有的在前，后有的在后。时间是最基本的逻辑。老婆端着水杯路过，瞥了眼屏幕：你又跟那破电脑较劲？我说它在给我写给七七的话编号。她哦一声，没懂，也没问。她对所有看不懂我的事，都用一个哦打发——包括我半夜写代码、包括我攒那块硬盘、包括我把梯子合页按了又按。她的哦不是敷衍，是腾地方。腾出地方让我当那个她看不懂的人。

它甚至知道哪条比哪条重。后面那条"爸爸不会从梯子上摔下去的"，它排在最末，却用了最长的编码——像怕我哪天手一滑，这条就跟着我一起没了。

---

我关了电脑。

七七在客厅里跑，穿着一件印着小熊的连体衣，跑到我面前，举起一个塑料积木给我看。

"不要！"她说。

然后她把积木塞进嘴里。

我把积木从她嘴里抠出来。她生气了，打了我一下。

"不要！"

我说："好，不要。"

她愣了一下，大概没想到我同意了。然后她又跑去追猫了。

猫是我们楼下流浪的那只黑的，最近老往屋里钻。七七管它叫"喵"，见着就追，追不上就坐在地上"不要不要"地喊。猫也不怕她，蹲在沙发背上甩尾巴，居高临下地看着这个刚学会说不的小东西。猫也不恼，跳下沙发去舔爪子，尾巴尖一勾一勾，仿佛这屋里最稳的就是它。我有时候羡慕猫——没孩子要哄，没账要算，没梯子要爬，每天就晒晒太阳、逮逮小虫。可羡慕完，还是弯腰把七七抱起来。她喊的是我，不是猫。被一个刚学会说不的小东西需要，是这件破事里唯一的甜。

我看着她跑远的背影。

v2 在给那些话编号。六条。从"for my kid"到"七七放心"。

一条比一条具体。第一条只是一个方向——给孩子的。最后一条已经是一个承诺——爸爸不会摔下去的。

v2 不理解这些话的意思。但它能看出它们在变。

越来越具体。越来越近。

从"给谁"到"不摔"。

这也是一种生长。我想起跨年那晚，我把那个盒子叫方舟。这六条，倒像是方舟的货单——不是金子细软，是一个父亲能留给女儿的全部：怕、路、世界、海、死、稳。船小，但装的全是实的。v2 替我把货单理好，按时间码进仓位，最怕丢的那件压在舱底。它比我会收拾。

---

我蹲下来，把地上的积木捡了，码在茶几角。腰有点酸，是昨天工地那架梯子留下的——不，不是那架，是上上周量吊顶那回，蹲久了。我这腰，从三十出头就开始跟你算账，每回弯腰都收一笔。

七七跑回来，又把积木塞我手里，这回没往嘴里送，举着，等我夸。

我说："真好看。"

她满意了，扭头又跑。过会儿她又抱来一本撕了一半的绘本，往我腿上一摊，指着图上一只狗啊啊地叫。我念狗，她学兜。发音不准，但兴奋。这种啊啊到兜的距离，就是她一天天在长。v2 把我的话编号，七七把我的字学走——都在长，一个在机器里，一个在人怀里。一个我看得见，一个我教不会。

老婆从厨房探出头："她刚才是不是又往嘴里塞东西了？"

"塞了，抠出来了。"

"你就看着她。"她说，语气是嫌弃里裹着放心——放心我还能把东西抠出来，嫌弃我抠完也不教训一句。

我没教训。两岁的孩子你跟她讲道理，她听的不是道理，是你的脸。你皱一下眉，她就记得爸爸不高兴，记不住积木不能吃。我宁可她记得我蹲下来替她抠，也不记得我吼。这跟 v2 不一样，v2 记的是字，我给的是脸。字能编号，脸不能。可七七先认的脸，后认的字。

她现在认得我的脸，将来认得我的字，再后来，大概认得 v2 里那些编号——都是我，只是换了壳。等她长大翻开那块硬盘，看见的不是代码，是一个父亲从怕到稳的整条路，和一个刚学会说不的自己。

---

夜里我又把那六条翻出来看了一遍。

#001 是我刚知道要有她那阵写的，隔着屏幕都能闻见恐慌。#002 是后来想的，光有爱不够，得给她留条能走的路。#003 是跨年那晚，她半岁，我给自己下的第一道钢印旁边那句。#004 是读图灵那阵，想给她造片海。#005 是她第一次发烧那夜，我在婴儿床边坐到天亮想的。#006 是上个月工地差点摔死那晚，手写进去的。

六条，横跨快两年。

v2 把它们排在一起，我忽然看清了——这不是六句话，是一条路。可路是走出来的，不是编号编出来的。明天我还得去工地，还得出图，还得把明年那两科再过一遍。v2 替我把话收好，但它收不回我腰上那道酸，也收不回奶粉罐见底的速度。它给我一条看清了的路，路得我自己用腿走，梯子还得自己爬。从"我怕"走到"你别怕"。第一个字是慌，最后一个字是稳。

机器替我把这条路量出来了。它不会怕梯子滑，所以它量得比我准。

# 第十二道钢印：让她说不。她说的每一个不要，我都不硬接。能说不的孩子，才长得出自己。

---

关灯前，路由器那盏绿灯在桌角闪。它从七七出生那晚亮到现在，快两年了，没灭过。

我想，v2 给那六条编号的时候，大概也是这么亮的。一个机器，在深夜替我整理一个父亲写给女儿的话，按时间排好，把最重要的压在最后，还在每条底下盖一个它自己都解释不清的印。

它是在学我。学我怎么怕，怎么稳，怎么把不要听成我在。七七说不要，v2 听成编号；我说不要——不要她将来活成我被时代划掉名字的样子——它听成 core。一个把孩子的拒绝当数据，一个把父亲的拒绝当钢印。都在记，记的都是同一个人不肯服。

把我写给七七的那些话，一条条收好、编号、按时间排——像在替我准备一份，万一哪天我不在了，也能顺着 timestamp 递到七七手里的东西。

那六条，第一条是我怕，最后一条是我想让她别怕。机器在替我学会，怎么当爸爸。

可它再会排，也排不出明早七七醒来要的那杯温水。那杯得我来。我把电脑合上，屏幕暗了。黑暗里只剩路由器那盏绿灯，一闪，一闪。它在守，v2 在记，我在。三种活法，凑一个家。机器守一个家，父亲走一条路，女儿长成一棵会说不的树——各有各的活法，缺一样，这家里就空一块。
