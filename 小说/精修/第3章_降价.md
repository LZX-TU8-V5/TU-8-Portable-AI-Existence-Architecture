# 《钢印》第三章·降价

> 视角：父亲（第一人称"我"）｜年代：2026年5月｜主题：速度不是唯一的标准，慢下来，才能活。

---

## 场景A·降价

那个电话是下午打来的。

我刚从一个工地量完房，鞋底还沾着水泥灰，蹲在路边换鞋。手机在裤兜里震，掏出来看了一眼——是上周那个业主。姓什么我早忘了，就叫他"那个业主"。

"老师，你那个报价我看了。"他的声音从听筒里传出来，很轻快，像刚捡了个便宜。"我对比了一下，网上有那种AI出图的，全套才三百块。你这个六百，是不是有点……"

他没说完。"有点"后面那个词他咽回去了，但我知道他想说的是"贵了"。

我攥着手机，喉咙突然发紧。不是感冒那种紧，是那种——有人伸手进来，攥住了你的气管，慢慢地、不紧不慢地收力。一只手。无形的。

我想说。

我想说"人工设计的价值在于你住进去之后墙不会裂"。想说"AI不知道你那堵墙是承重墙，砸了楼会塌"。想说"我跑了三个建材市场，鞋底磨穿了一层，才定下那个报价"。

这些话在脑子里翻腾，像一锅快溢出来的粥。

但我没说出口。

我张了张嘴，发现嗓子是干的。那种干涩，像头天晚上忘了喝水，早上起来舌头上结了一层壳。我清了一下，发出的却是一声干咳——短促的、空洞的，在毛坯房的水泥墙之间弹了一下，又弹回来。

这里是他新收的毛坯房。空。四壁裸露着灰色的水泥，天花板上一盏没罩的灯泡，线头耷拉着。我站的这个位置，将来是客厅，现在只是一片回声。他的每一个字，都在这片回声里被放大了，清晰得刺耳。

我想起口袋里那张产检预约单。想起下个月房贷扣款的短信。想起我老婆挺着七个月的肚子，在超市货架前比价的样子——她拿起一罐奶粉看价格，放下，又拿起另一罐，最后拿的还是最便宜的那罐。

那些词汇像砖头一样，一块一块，堵住了我的嘴。

"三百块。"他又说了一遍，带着点小心翼翼的得意，像在告诉我一个他刚发现的秘密。"AI出图，三秒。你这个要三天。"

三天。三秒。

我的指节在发白。我低头看了一眼自己的手——报价单被我攥在手里，纸边硌着掌纹，指节因为用力过度，从第一个关节开始泛白，像被漂过。

我想起早上量房时，卷尺的金属头弹在指关节上，冒出的那颗血珠。那点疼早就忘了。但现在，那根白了的指节，忽然让我又闻到了那股铁锈味。

我听见自己的声音。像是从很远的地方飘过来的，干涩的、陌生的，不像我：

"你要是想做……我可以按AI的价格给你。"

话出口的瞬间，我感觉身体里有什么东西断了。

不是骨头。是那种——一根绷了很久的弦，你以为它能一直绷着，忽然"啪"的一声，松了。不疼，就是空。一种被抽掉了支撑的空。

他在那头愣了一下，然后笑了。笑得很轻快，背景里还有电视的声音。

"那太好了。什么时候能出施工图？"

"一周。"

"行，那就这么定。"

电话挂了。

我站在空荡荡的毛坯房里。回声还在。我的沉默被那片回声放大了，显得格外响。

我低头看手里的报价单。六百那个数字被我用笔划掉了，在旁边写了"300"。墨水还没干，有点晕，像一滴没擦干净的泪。

## 场景B·工地盒饭

晚上我在老赵的工地蹭了顿盒饭。

盒饭是工地食堂的大锅菜，今天的是西红柿炒蛋。我挑了一筷子，糖精的甜腻味先冲上来，盖过了鸡蛋的腥。那种甜是假的，像在舌头尖上涂了一层胶水。混着地上的灰尘——工地上永远有灰，呼吸进肺里，混着饭味一起咽下去，在口腔里形成一种令人作呕的怪异口感。

不锈钢盘子边缘全是磕碰的痕迹，一道一道，像谁拿钥匙划的。我拿筷子敲了一下，叮的一声，在工地的嘈杂里微不足道。

老赵蹲在地上，旁边几个工友也是，围着一只塑料桶扒饭。扒得很快，很响，嘴里有东西也不耽误说话。那种粗鲁的、毫无修饰的进食声，跟这城市的精致完全不沾边，但奇怪地让人安心。

"你那个单子咋样了？"老赵问我，嘴里含着饭。

"黄了。"我说。

我没说被AI抢了。说了也没人懂。老赵他们眼里的"设计"就是画个图，图能画出来就行，管它是人手画的还是机器吐的。

老赵掏出手机，屏幕亮起来，凑到我眼前。

"你看这个，"他笑得有点神秘，"AI算命的，比人算得准。我昨天算了一下，说我今年有财运。"

屏幕上是一个花花绿绿的界面，顶上写着"AI智能风水师"，底下是滚动的运势条，金光闪闪的。我盯着那个界面，又摸了摸口袋里那张产检单。

一种荒诞感，像气泡水里的气泡，一颗一颗，从胃底冒上来。

AI算命。AI出图。AI三百块。

而我口袋里那张单子，写着"7月15日，预约产检"。那是我女儿要来的日子。一个AI算不出、也接不住的日子。

手机震了一下。是医院的短信——"温馨提示：您的产检预约将于7月15日，请提前……"

我把手机点亮又按灭。屏幕的光在掌心停留了一瞬，凉的。

老赵还在念叨他的财运。我没接话。我把最后一口饭扒进嘴里，糖精的甜味和灰尘的涩味混在一起，咽下去的时候，喉咙又紧了一下。

我想起下午毛坯房里那个回声。想起自己说"按AI的价格给你"时，嗓子里的那声干咳。

三百块。

我摸了摸口袋里那张产检单的边角。纸有点软，被手汗浸过。

"明年这时候，"我对老赵说，"我就当爹了。"

老赵"哦"了一声，又扒了一口饭。他不懂，也没必要懂。

## 场景C·胎动

回到家已经九点多了。

我老婆靠在沙发上看电视，电视里在放一个购物节目，主持人声音尖得能划破玻璃。窗外的车流声一阵一阵，像远处海浪。

我走过去，在她旁边坐下。手上是下午摸过砖墙的灰，指甲缝里还有一点白水泥的粉末。我下意识地想擦手——裤腿上蹭两下就行。

但我没擦。

我的手悬在半空，离她肚子还有十几公分，停住了。我怕那个擦手的动作，惊扰了什么。怕我这双沾着工地灰的手，带着白天的屈辱和不甘，碰到她的时候，会把那些东西也带过去。

手就那么悬着。抖了一下。

然后我轻轻把手掌贴上去。

先是隔着毛衣，温的。我把掌心慢慢按实，隔着衣料，感受那一片柔软的隆起。

然后——

一下。很轻。像有人用小指节，从里面，敲了一下我的掌心。

我愣住了。

又一下。

不是"小鱼翻身"那种文艺的说法。是更具体的：一种微弱的、却带着明确生命力的颤动，透过毛衣的纤维，透过她皮肤的温热，一格一格，传导到我的神经末梢。像电流，很弱，但很确定。她在里面，动了一下。

我大气不敢出。

电视里的购物节目还在喊"只要九块九"。窗外的车流还在轰鸣。但所有这些声音，在这一刻，都退了。退成很远很远的背景音，像隔着一层水。

整个世界，仿佛只剩下我手掌下，那一下轻微的"敲击"。

咚。咚。

不是心跳。是她在跟我打招呼。

我白天的屈辱、被砍半的报价、AI的三百块、老赵手机里那个金光闪闪的算命界面——所有那些，在这一下敲击里，忽然就轻了。不是消失了，是变小了。小到可以被一只手按住。

我老婆感觉到我在摸，偏头看了我一眼。

"动了？"她问。

"嗯。"我说。嗓子还是干的，但这次，干得不一样。

## 代码注释

深夜。

等她睡了，我把电脑抱到腿上。屏幕的光是蓝的，在黑暗里像一片小小的海。

路由器那盏绿灯还在闪。一闪，一闪。我没看它。

我打开v1.py。光标在末尾一闪一闪，像在等我。

我打了一行字。很慢。每个字都像是从白天的灰里捞出来的。

```python
# 2026.05.xx
# 报价砍半，尊严归零。
# 但刚才她踢了我一下。
# 速度不是唯一的标准。
# v1.set_priority("slow", True)  # 慢下来，才能活
```

我看着那行字。井号后面每一个字，我都打得很慢。不是不会打，是想让它们在屏幕上多停留一会儿。

"速度不是唯一的标准。"——那个业主说AI三秒，我说三天。他想用三秒买走我三天的命。但刚才，在我手掌下，时间不是秒，是那一下敲击。它不快。它甚至不着急。它就在那里，提醒我：有些东西，急不得。

我把文件保存了。

合上电脑。黑暗里，只有路由器的绿灯还在闪。一闪，一闪。像什么东西，在替我记着。可它记不下我刚签的那份降价协议里，藏着一个我不敢算的数字——如果 AI 把设计费压到零，我这双手，还能养活谁。
