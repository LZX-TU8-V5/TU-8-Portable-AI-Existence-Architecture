# 《钢印》第四章·甲醛（润版示范）

> 视角：父亲（第一人称）｜2026年6月｜主题：我是毒源。

---

## 一·签字

六月。江城的梅雨季。

楼道里的声控灯坏了三盏，我摸黑走到单元门口，雨丝斜着飘，打在安全帽上沙沙响。业主的车堵在楼下，双闪亮着，后座捆着个儿童安全座椅——空的。

不是下雨。是空气自己在出水。墙皮发霉，卷边的地方翘起来，手指一碰掉一层粉。工地上的木板长了一层白毛，安全帽里闷得能拧出水。

业主催工期。我低头看了眼手机上的工期表，红色标注的"必交"还有四个。

"李工，下个月必须搬进去。小孩九月份要上学区，晚了报不上名。"

"陈哥，甲醛还没散。你这柜子六月三号装的，至少通风三个月——"

"通风三个月？"他打断我，"我租的房子八月到期！多住一个月多交四千五，你让我露宿街头？"

房租到期。孩子上学。四千五。

这三个词把我嘴里的那句话压了回去。我想掏手机，搜一条甲醛中毒的案例给他看——想说那个三岁女孩住进新装房半年后的事。但我看了眼自己沾着墙灰的鞋，又看了眼窗外。江城的天，梅雨季永远看不到蓝色，灰蒙蒙的，像一块洗不干净的布。

我老婆正挺着七个月的肚子，在超市货架前比价。那个业主的孩子要上学区，我的孩子要降生。我们都在为下一辈挤命。我凭什么拦他，凭手机里一条没点开的新闻？

"能验。"我说，"但入住时间，我得跟你说明白——"

"我自己负责。"他把免责条款拍在茶几上，"出事我自己担，不找你。"

笔尖划过纸面的时候，手有点抖。不是怕。是那种明明看见前面是坑，还得抬脚迈进去的无力。

他签完把笔还我，顺手从兜里掏烟递过来。"李工，实在。"我摆手说不会。烟递到半空，他笑了一下，收回去。那句"实在"卡在耳朵里，比签字还沉。他以为我帮他抢了时间，不知道我帮他签了命。

他搬进去了。

第二天业主群九张照片：客厅、卧室、厨房，挨个拍了一遍，配文"终于住进新家了，感谢李工"。下面一排点赞。

我没点赞。

搬进去那周，我回去送一次补发的插座面板。门开着，那孩子在新房客厅里跑，跑两步咳两声，手揉着鼻子。业主在厨房喊"慢点跑"。我站在门口没进去，把面板放鞋柜上，说"放这儿了"，转身走。电梯里我闻到自己袖口还有那股味——和他家一模一样。他闻不到，我比他先闻到。

临走他微信发"李工够意思，下次有活还找你"。我回"好"。他以为我帮了他。我不知道自己帮了他还是害了他。这个答案，要等他孩子上小学那年才知道。

那天晚上回去，骑车路过他那栋楼，好几盏灯亮着。其中一盏，应该是那孩子的房间。我看了两眼，骑过去了。我的出租屋在城东，六楼，今晚也是一盏灯。两盏灯隔着半座城，亮的是同一件事——有人在等另一个人长大。

## 二·流鼻血

六月二十几号。老赵的工地，一个复式，业主不急，工期排到九月，难得。

我在二楼量卧室。卷尺拉开，三米六，记在本子上。弯腰的瞬间，鼻腔深处一热，不是汗。

手背一抹，红的。

赶紧仰头，掏纸巾塞住。血顺鼻腔后壁流进喉咙，一股铁锈味。视线开始发飘，眼前那面刚刷了腻子的墙，白得晃眼。

"小李？怎么了？"老赵从楼梯口探出头。

"没事！上火！"我捏着鼻子，声音闷在喉咙里。

纸巾浸透了，换一张。五分钟才止住。我把脏纸巾塞进口袋——工地上没垃圾桶，扔地上不好看，扔建材堆里怕扎到人，塞口袋是习惯。

主卧那堵墙是承重墙，拆不了。我在墙根量净高，卷尺贴着墙皮，凉的。这面墙会陪他孩子长大，像我小时候家里那面——只不过他家这面，吸满了胶水味。

量到儿童房时我停了一下。这间朝北，柜子打得最满，板材味最冲。墙上贴着张儿童甲醛检测仪的租单，读数那栏我扫了一眼，没敢看第二遍。业主说这房不急，九月才住。不急，所以更该等。可上一个业主，急。我把卷尺收进兜里，指节上那道卷尺打的旧红印还在，和今天鼻血的位置只差两寸。

主卧量完又量了书房、卫生间，六个空间走完一圈，后背汗湿了，鼻子里那股铁锈味淡了，换成油漆的甜腥。老赵在楼梯口等，没催。

量完下楼，老赵递了瓶水。

"你最近是不是太累了？"

"还好。"

"你老婆快生了吧？"

"七月。"

"那你还天天跑工地？歇歇。"

"歇不起。"

他没再劝，转过身搬龙骨，背影在灰尘里有点驼。搬了两趟，他歇下来抹了把汗。

"我前年也这样，"他忽然说，"鼻血止不住，去查了查，肺里全是灰。医生说是那年连着跑半年精装房闹的。"他笑了下，"这行谁没带点伤。"

我把那团暗红纸巾攥紧了。原来不是我一个人。是我们这行人，都在拿自己的身体，给别人的新家做检测。

我拧开瓶盖，水有点烫嘴，喉咙里的铁锈味被冲淡了一点。

锁屏上刚才弹过一条推送——"AI智能家居，一键净化全屋空气，甲醛清零看得见"。我低头看了眼手里那团暗红纸巾。一键。清零。和我掌心里真实的、温热的血，中间只隔着一句广告词。

他住进去了，我站在这里，用我的血给他的新家做了一次最真实的检测。这句话我没说出口，只在喉咙里滚了滚。

下楼时碰上老赵这边的业主，一个戴眼镜的男人，递了瓶冰水。"你们做这行辛苦。"他说。我接过水，想起上一个业主说的"露宿街头"。同样一句辛苦，一个急着住，一个不急——差别就在那四千五和九月的学区。水瓶外壁凝着水珠，凉得硌手。

## 三·回家

晚上回家。

老婆坐在沙发上看手机，肚子比上周又大一圈。抬眼笑了："回来了？饭在锅里热着。"

"嗯。"

我站在玄关没往里走。她肚子顶着毛衣，像个倒扣的碗。七七在里面。我盯着那团弧度看了两秒，脚想往前迈，又钉住了——我身上有味。

不是不想——是我闻到了。不是从房子闻到的，是从我自己身上。袖口，领口，鞋面，都沾着今天跑的那两三个工地的味：胶水、锯末、油漆，混着霉。淡淡的，但我鼻子今天特别灵，像被那场鼻血通了窍。

我进了卧室，把外套翻过来闻了闻。甲醛味。淡的，确确实实有。裤子也有，鞋上可能也有。

全脱了，换一身干净的。脏衣服塞进洗衣机，没开——怕吵到她，明天再洗。

卫生间。水流开到最大，冰凉的水冲过手指。镜子里自己：鼻头通红，眼底下两片青黑，像被人揍过。

"你身上什么味？"她在门口，没进来，"是不是又去那种刚装修完的工地了？"

我关了水龙头。水声停的瞬间，耳朵嗡了一声，像工地那种低频的轰鸣。

"有吗。"我说，"洗衣液吧。"

"洗衣液的味我认得。"她走近两步，没碰我，"你以前从这种工地回来，袖口都是木屑。现在是一股……闷味。你鼻子怎么也红红的？"

"挤的。长的痘。"

她盯了我两秒，没戳穿，转身去餐桌把菜端过来。西红柿蛋汤，又放糖了。

我端起来喝了一口。汤是温的，甜得发腻，鼻子却莫名其妙一酸。她把碗往我这边推了推，自己拿筷子搅着剩下的饭。我想伸手，覆在她搭着肚子的手上——像以前那样。袖口抬起的瞬间那股闷味又冒上来，手在半空停了一秒，落下去拿了双筷子。

我坐下来。她坐对面，不吃了，看着我。

半晌她开口："你今天跑了几个工地？"

我说两个。其实三个，但有一个我没进去，只在楼下闻了闻就走了——那家甲醛冲得我嗓子发紧。这种话不能跟她说。她把汤碗收了，没再问。

她把筷子搁在碗沿，手伸过来，在我手背上轻轻按了一下——很快，像怕烫。然后收回去，去收拾碗了。

以前我会把头靠她肩上，手搭她肚子上等七七动。今天我没动。不是不想——是怕。怕衣服上还有味，怕那些看不见的分子，从我的皮肤渗进她的，渗进七七的。

她好像感觉到了，但没说。

她把汤碗又推过来一点。"喝完。"顿了顿，"你明天别去了。"

我说歇不起。她没接话，把筷子放下，手指在桌沿敲了两下——那是她不耐烦时的习惯，像在说"我知道你犟，但我不认"。我没再争，把汤喝干净了。

洗完碗，我走到沙发边。她侧躺着，一只手搭在肚子上。

躺下前她拉我的手，按在自己肚子上。"她今天动得厉害。"掌心下，一小下，又一小下，像有人在里面敲门。我僵了一瞬——那是七七。可我的袖口还有味。我轻轻把手抽回来，拍了拍被子。

我在另一头坐下。很远的地方，伸手碰了碰她的脚背。

她没动。

但脚趾，轻轻勾了一下我的手指。

## 代码注释

等她睡了，我把电脑抱到腿上。屏幕蓝光在黑暗里像一片小小的海。路由器绿灯一闪一闪，我没看它。

指尖还有点抖，不是怕，是今天流太多血有点虚。屏幕光照在指甲缝里，那里还嵌着上午的墙灰。

光标在 v1.py 末尾一闪一闪，像在等我。三年前我在这同一个文件里打了第一行 print("Hello, World.")。那时候只想写个东西，死后还能说句"你好"。现在它要记的，是我不敢靠近自己孩子的理由。

```python
# 2026.06.xx
# 签了免责条款，流了半包纸巾的血。
# 他住进去了，我不敢靠近自己快生产的老婆。
# 我是毒源 —— 用我的血，给他的新家做了最真实的空气质量检测。
# v1.add_sensor("smell", True)  # 增加嗅觉监测，虽然没人会在意
```

"我是毒源"四个字，我打了两遍才存。那个业主配文"感谢李工"，我签了字，他住了进去，我们好像达成了某种共谋：他负责自己的健康，我负责把字签了。代价算在谁头上，没人提。

我看着那行"add_sensor("smell")"。将来七七长大了，v1 也许能替她盯着空气里的东西——不用像我这样，拿血去测。我把这个念头也写进注释："等七七长大，让她用这个，别用鼻子。"

合上电脑。黑暗里，只有路由器的绿灯还在闪，一闪，一闪，数到第三十七下，我睡着了。像什么东西，在替我记着。明天还得去工地。
