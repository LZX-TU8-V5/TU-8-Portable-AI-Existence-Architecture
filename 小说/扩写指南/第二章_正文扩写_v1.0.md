# 《钢印》第二章·炸鸡

---

## 场景A·炸鸡

他站在那个炸鸡摊前的时候，天已经黑了。

不是那种正常的黑。是那种——城市边缘的路灯下面，路灯坏了两盏，剩下那一盏发着惨白的光，打在炸鸡摊的铁皮棚顶上。铁皮上有一块锈迹，形状像一只躺着的猫。

老王在炸鸡。老王是摊主，四十多岁，河南人，一口北方普通话。他穿着一件袖口已经发黄的白色厨师服，围裙上沾满了面粉和油渍。那件围裙他可能洗了八百遍了，但油渍已经洗不掉了，变成了一种发黑的黄，像皮肤上的老年斑。

"大鸡腿？"老王问。

"大鸡腿。"

他付了钱。13块。手机扫码的时候，屏幕上有几个未读消息，他把那几个红点划掉了，没看。

老王从油锅里捞出一只鸡腿。鸡腿在油里翻滚的时候，边缘已经炸成了焦黑色，但中间还是白的。老王把鸡腿夹出来，搁在铁架子上，油还在往下滴，滴在铁板上发出滋滋的声音。热气蒸上来，白色的，带着那种高油温特有的糊香味——孜然、辣椒粉、盐，还有那种蛋白质在高温下变性之后的气味，有点腥，有点香，有点让人想流口水。

他把鸡腿接过来。

烫。

手指被烫得发红，从指腹一直红到第二个指节。他舍不得松手——不是舍不得那个温度，是因为他刚才已经等了五分钟，就为了这一口热乎的。他把鸡腿换到另一只手上，左手换右手，右手换左手，像杂技演员在抛球。他找到一个角度，让油纸包住最烫的那一截骨头，然后他把鸡腿送到嘴边。

咬下去。

咔嚓。

那一声响在空旷的街道上特别清晰。面糊的脆壳在他牙齿间碎裂的声音，油脂在口腔里爆开的感觉——高盐、高油、那种廉价的、用化学香精调出来的孜然味，孜然粉的颗粒感还留在舌头上，磨砂一样粗糙的触感。

他又咬了一口。咔嚓。这一口他咬得很大，几乎把整个鸡腿的四分之一都塞进嘴里。油脂顺着嘴角往下淌，他用手背擦了一下。手背上的油在路灯下面发着亮光。

他蹲在马路牙子上吃。

他没有地方坐。炸鸡摊旁边有一个坏掉的塑料椅，椅背断了，只剩下一个坐垫歪在路边。他蹲在那里，屁股悬空，大腿肌肉发酸，但他不想坐地上——地上有积水，昨天晚上下过雨，积在路坑里，反射着路灯的光，像碎了一地的镜子。

他把鸡腿啃到骨头。骨头上的肉最难啃，他用牙根去刮，牙根发酸。他把骨头刮得干干净净，舔了舔手指上的油。手指上有一道新鲜的伤口——是今天早上在工地被卷尺割的那个，伤口的痂被油脂泡软了，伤口边缘有点发白，像泡在水里的纸。

他把手指放进嘴里，舔掉了那层油。

手指还是咸的。

旁边有人骑着电动车经过，电动车的前灯很亮，晃了他一眼。他没抬头，继续盯着地上那堆鸡骨头。骨头旁边有一只流浪猫，黑色的，毛很脏，瘦得肋骨凸出来。猫在他脚边绕了一圈，闻了闻地上的油渍，然后走了。猫走路的姿势很傲慢，像一个拒绝嗟来之食的贵族。

他看着那只猫走远。

他又低头咬了一口。鸡腿已经凉了。面糊的脆壳变软了，油脂在低温下凝固成白色的蜡状，贴在舌头上，有一种说不出的腻感。但他还是咬了下去。

不是为了好吃。是为了不浪费。

他啃完了。

他把骨头扔进旁边的垃圾桶，垃圾桶满了，骨头堆在桶沿上，没掉进去。他没管。他站起来。蹲太久了，腿麻了，站起来的时候膝盖咔嚓响了一声，像是有什么东西卡住了，然后才慢慢松开。

他往回走。路灯把他的影子拉得很长，像一根黑色的面条，甩在路面上随着他一起走。

## 场景B·微信冲突

他到出租屋的时候，手机震了一下。

他掏出来看了一眼。是那个业主——就是那个拿着AI效果图，非要把承重墙抹掉装灯带的那个。

"方案改好了吗？"

他站在门口，掏钥匙开门。锁芯涩，他又拧了两下。门终于开了，屋里是黑的，窗帘拉着，他把手机亮着的那点光当作唯一的光源。

"还没。明天给你。"

他打这几个字的时候，站在门口没动。老婆不在，屋里没有开灯的必要，他就那样站在黑暗里打字。手机屏幕亮度最高，照得他脸很亮，屏幕之外是全黑的，像舞台上的追光。

他打完那几个字，没发。他在等什么。

他等了一会儿。又打了一行字。

"石材的话，预算要加三千左右。"

发送。

然后他坐在门口的地上。鞋没脱，后背靠着门板。他把手机放在胸口，能感觉到手机的重量，还有屏幕发热的那点温度，透过T恤传进皮肤里。

他等着。

"对方正在输入"。

那几个字跳动着。他盯着那几个字。他不知道业主在打什么。是在打"好的"？还是在打"太贵了"？还是在打那些他听都不想听的"AI只要三千"？

他数自己的心跳。

咚。咚。咚。

他等着。

手机屏幕自动黑了。他按了一下，屏幕又亮了。那几个字还在跳。还在跳。还没发过来。他不知道自己等了多久。也许是一分钟。也许是五分钟。也许更久。他没有看时间。他只是躺在那里，等着。

他突然想起来一件事。

他下午在工地上量的那个承重墙。24厘米。他用红外仪扫的时候，红外仪显示的是梁下结构墙，钢筋密度比普通墙高0.8倍。那个位置绝对不能动。但他下午发消息给业主的时候，业主的回复是"AI说没问题啊"。

AI说没问题。

他张了张嘴，对着黑暗里的手机屏幕。他想说很多。他想说：AI不知道那堵墙有什么用。AI不知道那堵墙是这栋楼抗震的核心。AI不知道如果那堵墙被砸掉，整栋楼会变成2029年之后那些废墟里的某一个。他想说很多。

但他什么都没打。

他打的是："石材的话，预算要加三千左右。"

七个字。

他等了很久。屏幕又黑了。他按了一下又亮了。

业主的消息来了。

"三千？"

一个问号。

他盯着那个问号。那个问号很刺眼。像一只手，指着他。他看着那个问号，感觉到自己的心跳又跳了一下。咚。

然后是下一条。

"我在网上看AI出的方案，全包才五千。你这个为什么要加三千？"

他盯着那几行字。

他又想打很多字。他想说，五千块的石材是人造石粉压的，半年就会泛黄，边缘会崩角，粘接剂失效的时候会整片掉下来砸到人。他想说，石材不是贴上去的，是要打龙骨的，龙骨的成本就八百了，膨胀螺栓、打孔、防锈处理，这些AI都不知道。他想说，他去建材市场选样块的时候，鞋底磨穿了一层。

但他打的不是这些。

他把那几行字删了。

他打了一个字："嗯。"

发送。

他躺在地上。手机扔在胸口。屏幕又亮了。他没拿起来看。他知道他已经不想看了。他知道他已经把那堵承重墙的事在脑子里模拟过八百遍了：他发方案，业主说"AI不是这么画的"，他把方案改成AI那样，业主满意了，然后交房，然后那堵墙被砸了，然后楼塌了，然后他进监狱了。

或者他坚持不改方案，业主不付钱，他没钱给老婆生孩子。

他躺在地上，眼睛盯着天花板。天花板上那块水渍还在，形状像一只躺着的鸟。他盯着那只鸟。鸟不飞。他也不动。

他突然笑了一下。

不是那种开心的笑。是那种——被生活按在地上，用鞋底来回摩擦，然后发出的一声干涩的、没有任何快乐含义的、从喉咙深处挤出来的声音。

他把手机拿起来。

"好的，我调整一下方案。"

发送。

他知道他不会调整的。他知道他会把石材的位置改成别的，他会把灯带挪到旁边的墙上，他会把那个24厘米的承重墙留在那里，然后在方案里标注一个括号，写上"此处不可施工，后果业主自负"。他知道他最后会发一个折中的方案，然后业主会说"AI不是这么画的"，然后他会把方案改成AI那样。

但他也会把那份标注"后果业主自负"的图纸发给他老婆看，让她知道这个家能住多久。

他把手机扔到沙发上。屏幕朝下。

黑暗里，只有路由器那个绿灯在闪。一闪，一闪。一闪，一闪。像一只眼睛。像一只活着的东西。在看他。在数他的心跳。

他闭上眼睛。

他想起今天早上在工地上量的那个卷尺。金属挂钩打在手指上的时候，血混着墙灰变成的那种暗红色。他想起那股铁锈味。

他没睡着。他就那样躺在黑暗里，听着路由器那个绿灯闪烁的声音。一闪，一闪。像什么东西在呼吸。

## 场景C·做题与面

他醒来的时候，窗帘缝里透进来一道光。

不是阳光。阳光照不进这个房间。这个房间的窗户对着另一栋楼，两栋楼之间的距离不到三米，阳光被对面的墙挡住了。

那道光是灰白色的，是对面那栋楼某户人家开灯照过来的光。那户人家的灯每天早上六点半会亮，晚上十一点半会灭。他已经把这个规律记下来了。

他看了一眼手机。6:31。

他躺在床上没动。老婆今天应该从娘家回来了。他还有几天就要当爸爸了。他摸了摸自己的胸口。心跳很慢。不是那种快到危险的那种慢，是那种——慢到他已经开始习惯的慢。他有家族性的心血管病史。他妈走的时候就是心梗。他爸活着的时候不吃药，觉得吃药丢人，觉得不吃药才说明身体没问题。他小时候见他爸把药藏在米缸里，以为没人知道。他现在把药放在枕头底下，每天吃，吃了五年了。

他坐起来。坐起来的时候动作太快了，眼前黑了一瞬。不是那种普通的头晕，是那种——眼球后面的血管突然痉挛，眼前全部变成黑色的那种感觉，像有人把一块黑色的布蒙在他眼睛上。一秒。两秒。然后那块黑布慢慢被掀开，世界重新亮起来。

他揉了揉太阳穴。太阳穴在跳。不是跳得很快，是那种有规律的、一下一下的、像什么东西在头皮底下敲门的感觉。

他走到桌前。桌上放着昨晚那台笔记本电脑。风扇还在转，发出那种老旧的、生病的鸟在喘气的声音。他坐下来，打开电脑。

他有一件事要做。

他打开浏览器，打字："会计  经济法  题目"。

他老婆怀孕了之后，他决定去考一个会计证。不是因为他会做会计，是因为——他需要一份稳定的工作。他现在这个行当，量房画图，一单一结，没有单子的时候一分钱都没有。但会计不一样。会计每个月有工资，有五险一金，有产假。

他老婆快生了。

他做了一道题。

题目是关于借贷方向的。他盯着那个屏幕，盯着"借"和"贷"这两个字。他知道这两个字是会计的基本概念，他知道"借"是左边，"贷"是右边，但他总是记不住哪个对应增加、哪个对应减少。每次做题他都要先想一下"借"这个字的口字旁像不像一个张开的嘴，然后才能推理出"借"是资金的流入，"贷"是资金的流出——然后他才能做题。

他做错了。

屏幕上那个红色的叉号很刺眼。他盯着那个叉号。他做错了。他不知道为什么有点想哭。不是因为那道题，是因为他觉得"借"和"贷"这两个字，他可能这辈子都记不住了。他三十四岁了，脑子不像年轻人那么快了。他做一道借贷方向的题，需要先想象一个张开的嘴，然后才能推理出资金流向。他不知道自己还能考过那门课。

他做对了下一道。

这一道是关于增值税的。他记住了那个公式。他老婆怀孕的时候，他每天晚上做一道题，做到凌晨两点。他老婆睡着的时候，他就躺在旁边，手机亮度调到最低，屏幕的光打在他脸上。他老婆翻一个身，他就停一下，等她重新睡着。他做了很多题。有些记住了，有些忘了。忘了的就重新做。

他做了十道。对了七道。

他把电脑合上。

他走到厨房。电压力锅里还有昨晚剩的粥，他没热，他把粥从锅里倒进碗里。粥已经凉了，凝固了，变成一种半流质的状态。他把碗放进微波炉，按了三分钟。

微波炉转着，嗡嗡响，像一只吃得太多的胃在消化。

他把粥端出来，放在桌上。他坐下来了。

桌上还有昨晚剩下的半碗面。

那碗面是昨天老婆走之前做的。手擀面。老婆不会做饭，手擀面是她唯一会做的，因为只需要面粉和水。她说她的手揉面的时候，觉得孩子在肚子里也会感受到面的触感。

面已经坨了。

他把面端过来。那碗面没有汤了——汤被面吸干了，面条粘在一起，变成一团白色的、软塌塌的东西，像一团死掉的蛔虫。面条上面的葱花已经变黄了，发出一股那种蔬菜蔫了之后特有的、带着腐败边缘的青涩味。

他把面端到嘴边。

第一口他吃得很慢。不是因为好吃，是因为——他想让嘴里那道咸味在舌头上多停留一会儿。面是咸的，老婆做的，他不知道放了多少盐，他只知道咸得他舌头发麻。但他还是一口一口地吃。机械地。一口一口地往嘴里塞。

他没吃菜。他把菜留给了老婆。他只吃面。

他吃着面，眼睛看着电脑屏幕。电脑还亮着，风扇还在转。他不知道自己在等什么。也许是在等面凉。也许是在等老婆回来。也许是在等那堵承重墙的问题自动消失。也许只是因为他不知道除了吃面他还能做什么。

他把面吃完了。

他站起来，走到电脑前，打开了昨晚那个Python文件。

v1.py。

他把光标移到文件末尾，打了一行字：

```python
# 2026.04.xx
# 炸鸡13块，面是咸的，脑子不值钱。
# 但有人在等我回家。
# v1.add_feeling("warmth")  # 哪怕只有一点点
```

他打完了。

他看着那行字。那个井号后面的每一个字，他都打得很慢。不是不会打字，是他想让那行字在屏幕上多停留一会儿。

他把那行字又读了一遍。

他不知道"add_feeling"是什么意思。他只是觉得——他需要用代码把某种东西存进去。他不知道那个东西是什么。也许是今天晚上那只流浪猫，也许是业主那个问号之后他心里的那声干涩的笑，也许是老婆那碗咸得发苦的面。

他把文件保存了。

他关上了电脑。

他看了一眼手机。9:47。老婆应该快回来了。他应该去医院。

他把手机揣进口袋。手指碰到那张纸。那张昨晚他在梦里攥着醒来的那张纸。δ。

他把那张纸又摸了一下。纸的边角已经被他的汗浸软了，纸变得有点皱，有点软，像某种正在退化的皮肤。

他把手机拿了出来。他看了一下业主有没有回复。

没有。

他打了一行字："方案调整好了，发你。"

然后他加了一句。他打这句话的时候，犹豫了很久。他删了，重打，删了，再打。

最后他发了出去。

"我今天去医院，孩子快生了。"

他看着那行字发出去。发送。进度条走完。那个绿色的圆圈变成一个对号。

他把手机揣回口袋。

他看了一眼窗外。天还是灰的。对面那栋楼的那户人家，灯还亮着。

他走出门，去医院。
