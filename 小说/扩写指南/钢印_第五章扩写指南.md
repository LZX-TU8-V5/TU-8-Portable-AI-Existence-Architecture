## 扩写指南

### 场景A：医院算账（"数字的重量"具象化）

#### 感官放大（必须增加）

| 感官 | 具体细节 |
|------|----------|
| 视觉 | 冷白光打在脸上，让人无处遁形的冰冷感 |
| 听觉 | 旁边孕妇打电话的声音像针一样扎进耳朵 |
| 触觉 | 计算器按键的触感，屏幕数字像倒计时 |
| 心理 | "一万四"是遥远的承诺，看得见，摸不着 |

#### 深化心理博弈（必须增加）

在算出"六千三"的余额时，增加内心挣扎：
- 想给老赵打电话预支工钱
- 想向父母开口
- 被"面子"和"自尊"压垮
- "想说却说不出口"的憋屈

#### 扩写示例

**原句**：
> 我掏出手机，打开计算器。这个月还剩的工地项目：两个。一个八月完工一个九月。按现在的报价，到手大概一万四。

**扩写方向**：
> 我掏出手机，手指在屏幕上划动，打开了那个绿色的计算器图标。屏幕的光有点刺眼，我眯了眯眼，开始输入数字。
>
> 这个月还剩的工地项目：两个。一个八月完工，一个九月。按现在的报价，到手大概一万四。
>
> 一万四。我盯着这个数字看了很久。它像是一个遥远的承诺，看得见，摸不着。
>
> 老婆产检今天花了多少？挂号28，B超120，血常规35，尿常规15……我一项一项地输入，计算器发出单调的"滴滴"声，像是在嘲笑我的窘迫。
>
> 加上之前的NT、糖耐、四维……这个月产检预算至少八百。
>
> 住院押金多少？同事说江城三甲医院顺产押金五千，剖腹产八千到一万。
>
> 我的银行卡余额：六千三。
>
> 六千三。如果顺产，押金五千，剩一千三。如果剖腹产——
>
> 我不敢往下算。手指悬在屏幕上，迟迟不敢按下那个等号。
>
> 把计算器关了。走廊的灯还是白的。旁边有个孕妇在打电话："妈，医生说都正常，你别来了，来了也帮不上忙……"
>
> 帮不上忙。
>
> 我连自己都快帮不上了。

### 场景B：回家路上（"温情"更具仪式感）

#### 拉长等待过程（必须增加）

- 车开到小区门口时，增加父亲的犹豫
- 想直接下车，又怕惊扰了这份宁静
- "想爱却不敢爱"的克制

#### 细化触觉体验（必须增加）

不要只写"她笑了一下"，要写：
- 笑容如何在昏暗的车厢里绽放
- 她手护住肚子的姿势
- 父亲看着侧脸时内心涌起的暖流

#### 细节清单

| 细节 | 内容 |
|------|------|
| 视觉 | 侧脸在车内灯光下的轮廓 |
| 触觉 | 手护住肚子的姿势 |
| 听觉 | 沉默中的呼吸声 |
| 情绪 | 内心的暖流 vs 刚才的数字冰冷 |

### 场景C：代码注释（"顿悟"的过程拉长）

#### 心理博弈（必须增加）

在写下 `# for my kid` 之前，增加内心挣扎：
- 试错了好几次
- 报错了，红色字体让他心慌
- 去百度查"Python怎么运行"
- 笨拙的尝试过程

#### 仪式感强化

这段代码的输入过程要写得像一种**宗教仪式**：
- 深夜的寂静
- 屏幕的蓝光
- 键盘的敲击声
- 与老婆孩子的呼吸声形成对比

#### 代码注释建议

```python
# 2026.08.xx
# 六千三。够吗？不够。
# 但她会来的。
# 不管够不够。
# for my kid
```
