# 第十八章·v2

一

六月。考完试的第二周。

成绩还没出，但我有种感觉——今年又是只过一科。实务做题的时候有两道大题没把握。

不管了。先做另一件事。

v1.py跑了四个月。27行代码变成了83行，因为我陆陆续续加了些功能——remember()、一个简单的日期记录、几个没写完的函数。

但它有个致命问题：**没有容错。**

什么叫没有容错？就是如果输入一个它不认识的东西，它就崩了。直接报错退出。像考会计——如果遇到一道不会的题就放弃了，整张卷子都不做了。

我考了两次，第一次差5分，第二次差4分。为什么进步了1分？不是因为变聪明了，是因为第二次我做了不一样的策略——不会的题先跳过，做完会的再回来猜。

**错了就记住，下次不错。不会的就先放着，先做会的。**

这就是容错。

---

二

我坐在电脑前。晚上十一点。七七睡了。老婆也睡了。

v2的思路很简单：

1. 出错了不崩，记下来
2. 记住了下次不错
3. 不会的先跳过，标记为"待学"

我重写了整个文件。从83行变成了200多行。

核心是一个新的数据结构：

```python
errors = []    # 犯过的错
known = []     # 已经掌握的
pending = []   # 待学习
```

然后remember()函数升级了。不只是记事情，还能分类：

```python
def remember(date, event, tag="daily"):
    if tag == "error":
        errors.append({"date": date, "event": event, "count": 1})
    elif tag == "learned":
        known.append({"date": date, "event": event})
    else:
        # 原来的日常记录
        with open("memory/" + date + ".txt", "a") as f:
            f.write(event + "\n")
```

很粗糙。没有数据库，没有索引，就是列表和txt。但逻辑是对的——**错了就存进errors，学会了就存进known，日常的就还是txt。**

下次遇到同样的情况，先查errors——有没有犯过？犯过就不犯第二次。再查known——有没有学过？学过就直接用。都不在，就进pending。

就像我考会计。

---

三

写完的时候凌晨一点了。

我运行了一下。输入了一条测试数据：

```python
remember("2027-06-15", "实务最后一道大题长期股权投资不会做", tag="error")
```

运行成功。errors列表里多了一条。

我又输入了一条：

```python
remember("2027-06-15", "借贷必相等，资产=负债+所有者权益", tag="learned")
```

运行成功。known列表里多了一条。

然后我加了一条日常的：

```python
remember("2027-06-15", "七七发烧退了。我在婴儿床边坐了一夜。如果我死了她怎么办？")
```

这次没有tag。默认是daily。

运行成功。memory文件夹里多了一个txt。

我打开看：

```
七七发烧退了。我在婴儿床边坐了一夜。如果我死了她怎么办？
```

v2记住了。三种东西：错的、会的、日常的。

分开了。不会搞混。

就像人脑一样——疼的东西和会的东西住的地方不一样。疼的地方亮红灯，会的地方亮绿灯。都不是的地方就先放着，等哪天想起来了再处理。

我关了电脑。站起来伸了个懒腰。腰很酸——在地板上坐了一夜，还没缓过来。

走到婴儿房。七七睡得正香。不烧了。小脸白白净净的，拳头攥着，嘴半张。

我站在门口看了一会儿。

v2会记住她发烧这件事。会记住我害怕。会记住"如果我死了她怎么办"。

但v2不会回答这个问题。

回答这个问题，需要别的东西。

我现在还不知道那是什么。但v2在等。七七在长。我在找。
