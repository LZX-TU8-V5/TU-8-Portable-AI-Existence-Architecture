凌晨三点。睡不着。

不是焦虑。是一种奇怪的清醒——脑子转得很快，但转的不是正事。是碎片。KTV包间的灯带颜色、老周代账的应收账款、七七画的那只猫、v3的2%沉默失败、奶粉280一罐。

这些碎片在脑子里乱撞，像弹球机里的球，碰到钉子弹开，碰到另一个钉子又弹开，没有方向，停不下来。

我爬起来。

客厅很暗。冰箱上七七画的"猫"在黑暗里看不见，但我知道它在那里。

我走到书房，打开电脑。屏幕的蓝光照出来，我眯了一下眼。

打开v3的代码。

不是要改什么。就是想看着它。代码不会乱撞。代码一行一行，有缩进，有顺序，有逻辑。从上到下，从左到右。不像我的脑子。

我翻到试错函数，看了一行：

```python
def try_new(current, errors, known):
    if current in errors:
        return find_alternative(current, known)
    return current
```

很简单。如果当前做法在错误列表里，就找替代方案。如果不在，就继续。

我盯着这行代码看了一会儿。

然后改了一行：

```python
def try_new(current, errors, known, uncertain=None):
    if current in errors:
        return find_alternative(current, known)
    if uncertain and current in uncertain:
        return try_careful(current, known)
    return current
```

加了一个参数：uncertain。如果当前做法在"不确定"列表里，不直接跳过，也不直接换——小心地试一下。

try_careful。小心地试。

不是猛踩油门，也不是踩刹车。是轻踩一下，看看车动不动。

---

改到一半，七七哭了。

不是大哭。是那种梦哭——"嗯——嗯——"两声，然后安静了。

我放下电脑，走到她房间。

她没醒。侧着身，嘴微微动，大概在做梦。梦见了什么？猫？积木？280一罐的奶粉？

我把被子给她掖了一下。她的手从被子里伸出来，抓住了我的食指。

攥得很紧。

我站在那里，手指被她攥着，另一只手垂着，电脑还亮着，v3的代码停在一半。

站了大概五分钟。

她的手慢慢松了。不是放开，是睡着了以后自然的放松。手指从我的食指上滑下来，搭在手背上，不动了。

我轻轻把手抽出来。

回到电脑前。

屏幕上v3的代码还在等我。光标闪着，在try_careful那行的末尾。

我打了几个字：

```python
def try_careful(current, known):
    # 小心试一下
    # 像半夜去婴儿房掖被子
    # 轻一点，慢一点
    # 如果她抓住了你的手，就站着别动
    result = test(current, limit=3)
    if result == "ok":
        return current
    return find_alternative(current, known)
```

limit=3。最多试三次。不是十次，不是一百次。三次够了。像七七摔跤——摔三次，第三次不哭了。

这些注释不是代码。v3不会执行它们。但它们在那里。

#014的位置，我预感v2会把它收进去。

---

存了文件。

看了一眼时间。凌晨三点四十七分。

七七还在睡。老婆还在睡。v3在跑。

我关了电脑，去客厅沙发上躺着，没回卧室。

因为我知道如果回卧室躺在老婆旁边，我的脑子又会开始转。但在沙发上，听着冰箱嗡嗡的声音，想着七七那只"猫"，想着v3的try_careful，想着#014——

慢慢就不转了。

不知道什么时候睡着的。

醒来的时候天亮了。七七站在沙发边上，拿手指戳我的脸。

"猫，"她说。

嗯。猫。
