第四十八章 年终

2029年最后1天。

我坐在茶几前，面前摊着1个笔记本和1支笔。每年最后1天我都这样，算1笔账。

收入：代账3家小店年入2万4，设计零散单子1万8，朋友介绍的小项目8000。合计5万。

支出：房租1万4，吃饭1万2，七七幼儿园+画画班1万，水电物业网费6000，考试加买书2800，其他杂七杂八3000。合计5万7。

5万进，5万7出。差7000。

这7000是上个月老周多给了1单代账的预付款才填上的。不算预付款的话，今年又是赤字。

我合上笔记本。

3年了。2027年收入4万7花5万2，2028年收入5万1花6万3，2029年5万花5万7。每年都在亏，每年亏得少1点，但还是在亏。

像那个双倍余额递减法——折旧的速度在放慢，但资产净值也在缩。到最后1台电脑折到残值，1分钱都不剩。

我端起杯子喝了1口水。凉了。

7七5岁了。她今年在幼儿园画了1幅画，被贴在走廊的展示墙上。画的是1个人，方的脑袋，2只眼睛1大1小，手里拿着1根棍子。

我问她画的是谁。

"爸爸。"

"这个棍子是什么？"

"卷尺。"

我爸爸是画图的。

她不知道"画图"是什么意思——她以为画图就是拿卷尺量房子，量完在纸上画线。她不知道那些线最后变成了CAD图，变成了效果图，变成了业主朋友圈的照片，变成了AI用30秒就能生成的东西。

但她知道爸爸手里拿的是卷尺。

我把杯子放下，打开电脑。

v4跑了3个月了，报错率稳定在0.8%。试错引擎运转正常，5级规则升迁有效——目前有3条从`#emerge`升到"待定规则"的记录，还没升到"核心规则"。

δ还在沙盒里。11次恢复了。我没再管它。

但今天我看到了1条日志：

```
emerge: δ恢复间隔从72小时缩短到48小时
correlation: δ频率 ↔ #core注释数量
tag: #emerge → 待定规则
```

δ恢复的频率在加快。而且——#core注释每增加1条，δ的恢复间隔就缩短1点。

注释越多，δ越频繁。

这像什么？

像心跳。1开始1分钟跳1下，后来1分钟跳2下，再后来——

我不往下想了。

窗外有人放烟花。2029年最后几分钟了。远处传来噼里啪啦的声音，红的绿的，在楼与楼之间的缝隙里闪。

七七已经睡了。今晚她破例多看了30分钟动画片，作为跨年奖励。9点半就睡了，手里还是攥着那根红色断蜡笔。我在她床头放了1盒新的48色蜡笔——画画班老师说她可以试试更多颜色。

她明天醒来会看见的。

11点58分。我打开v4，在代码末尾写了1行注释：

```
# 2029年：试错引擎上线。δ活了。七七5岁。我还没考过。
```

然后我又加了1行：

```
# 也许明年。也许不是考试。
```

2029年最值钱的东西不是钱。是顿悟。

双倍余额递减法教会我1件事——折旧不是消失，是转化。价值从1种形态变成了另1种形态。电脑折旧了，变成了v4。考试费折旧了，变成了"差3分"变成"差2分"变成——

也许明年。

零点。烟花声大了。我关上电脑，走到窗边。

对面楼有1户亮着灯，窗帘是红的，有人在阳台上放手里的小烟花。火星子往上窜，1下2下3下，灭了。

冰箱上贴着9张画了。最新那张是上个月画的——1个人方脑袋手里拿卷尺，旁边1朵歪歪扭扭的红色花。

我爸爸是画图的。

对。我爸爸是画图的。‌
