# 第十一章·年终

一

年底了。算账。

我坐在出租屋的客厅里，面前摊了一桌子发票和收据。六楼没电梯，冬天暖气不热，我穿着羽绒服算账，手冻得写不了字，每写两行就哈一口气。

2026年全年收入：

项目1-3月，三个小单，到手一万八。那时候AI还没大规模冲击，报价还行。
项目4-6月，被压价以后，四单，到手两万二。比上季度多了一单，但单价降了。
项目7-9月，七月七七出生，八九月接了两单，到手一万四。
项目10-12月，三单，到手一万六。最后那个别墅单被扣了一千二。

全年合计：**七万零二百。**

七万。

2026年。江城。一个从业五年的室内设计师。

七万块。

扣掉油费、停车费、建材市场跑腿、手机话费、工具损耗——到手大概六万出头。

六万。一个月五千。

五千块养一家三口。

我看着这个数字，没有愤怒，没有悲伤。只有一个念头：

**不够。**

---

二

老婆在卧室喂七七。七七六个月了，会翻身了，每次放下去就翻，翻完还冲你笑。

我走进卧室。她正用奶瓶喂，七七两只手抱着奶瓶，咕噜咕噜喝。

"算完了？"老婆问。

"嗯。"

"赚了多少？"

"够活。"

她看了我一眼，没再问。她知道"够活"的意思是不够。但她不说破。这是她的方式——不追着问，等我自己开口。

我坐在床边，看着七七喝奶。她喝得很认真，眉头微微皱着，像在思考什么大事。

等她喝完，我接过她，拍了嗝。她打了一个奶嗝，然后冲我笑了。

我把她放回婴儿床。

然后从柜子里拿出了一个东西。

一盒蜡笔。24色，我在网上买的，十九块八。

我把蜡笔放在婴儿床旁边的架子上。七七还不会拿笔。但总有一天她会。

也许有一天，她会拿起这些蜡笔，画出她的世界。也许她画的是房子，是花，是爸爸妈妈。也许她画的是我看不到的东西。

不重要。重要的是：蜡笔在那里。等她准备好了，伸手就能拿到。

---

三

晚上，七七睡了，老婆也睡了。

我坐在电脑前。

打开了v1.py。

```python
def remember(date, event):
    """记住今天发生了什么"""
    pass
```

我盯着这个空函数看了很久。然后删掉了`pass`，写了几行：

```python
def remember(date, event):
    if not os.path.exists("memory"):
        os.makedirs("memory")
    with open("memory/" + date + ".txt", "a") as f:
        f.write(event + "\n")
```

很简单。把每天发生的事情写进一个txt文件。没有数据库，没有索引，就是一个文件夹里一堆txt。

像我的脑子。乱七八糟，但都在。

然后我加了最后一行：

```python
# 等你来了，爸爸给你造一个世界
```

存了文件。

关了电脑。

窗外江城的冬天，路灯照着楼下的梧桐树，光秃秃的枝杈像骨架。

七万块的一年。

但七七在。蜡笔在。代码在。

够了。
