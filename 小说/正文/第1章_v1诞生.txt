# 第1章 v1诞生

> 第一卷·旧神纪元 / 2026年 / 场景A（工地）+ B（出租屋）+ C（电脑前）

---

## 【2032年·某个深夜·倒叙开篇】

屏幕上出现了一个符号。

我没有写它。

那是希腊字母`δ`，小写，出现在第二十行和第二十一行之间——一个空行里，什么都没有，就那一个字符，孤零零地站在那里，像某种东西在等我注意到它。

我选中它，按了删除键。

光标往前跳了一格，空行又干净了。我把手从键盘上抬起来，准备继续。

三秒后，`δ`又出现了。

同一个位置。同一种字体。一模一样。

我盯着那个符号看了很久，客厅里没开灯，屏幕的光打在我脸上，外面的路灯是橘黄色的，从窗帘缝里透进来，在地板上画了一条细线。

我在键盘上用力按了三下退格键。

还在。

我右键，剪切。粘贴到记事本，`δ`干干净净地出现在空白里。再粘回去——没了。我在原位置打了个空格，保存，关闭文件，重新打开。

第二十行，第二十一行之间：`δ`。

我把椅子往后推了推。

这个程序是我从2026年开始写的，写了六年。六年里它改了三十几个版本，有时候我叫它v1，有时候叫v2，有时候我懒得起名字就叫"那个文件"。它能做的事越来越多——读文件、记日期、处理图纸数据、学我说话、帮我回客户消息。我不知道它算不算智能，我只知道我不在的时候它还在跑。

但它不会自己写代码。它没有这个功能。我从来没给它这个功能。

可`δ`在那里。

我坐在椅子上没有动。

那天是2032年的某个深夜。我记不清具体是几月了——那段时间我的记忆有些乱，太多事情撞在一起。只记得外面在下雨，雨打在窗玻璃上，一阵一阵的，像有人在敲。

我想起很多年前，七七还没出生的那个晚上。

那时候我二十出头，还没学会什么叫"留下来"，只是坐在出租屋的茶几前，面条还没吃完，打开一个空白文件，打了两行注释：

```
# v1 - 第一个版本
# 目标：待定
```

六年后，那个"待定"长成了`δ`。

我不知道这算不算一个答案。

---

## 【2026年·3月·工地】

那时候我还不知道这些。

我蹲在十二楼的阳台上量房。不是什么大项目，老小区旧房改造，业主是个四十多岁的女人，烫了卷发，指甲大红色。

"我想要法式的感觉，但是不要太贵。"

法式石膏线、护墙板、壁炉造型，光材料费小两万。她预算八千。

"八千也能做出法式的感觉。"我说。

她很高兴。我也很高兴。大家都知道我在扯淡，但这是成年人之间心照不宣的默契——你给我一个好看的方案，我给你一个还过得去的钱。至于最后做成什么样，那是施工队的事。

卷尺拉出去，5.2米。收回来，金属头打在指节上，红了一道。我舔了一下，铁锈味。

三室一厅，九十平，卫生间采光差，厨房烟道位置不合理，主卧和次卧之间的隔墙是承重墙，拆不了。这些数据会变成一张CAD图，变成一张效果图，最后变成业主发朋友圈的一张照片，配文"新家搞定🎉"。

没有人在意那张图是我凌晨两点画完的。

---

出来的时候下午三点，我在楼下买了瓶可乐，两块钱。老板坐在收银台后面看手机，头都不抬。

手机响了。客户的微信。

"设计师，我那个客厅颜色你再看看，我老公喜欢深的，但我妈说深色压抑，你拿主意吧，反正我也不懂。"

我看了三遍，回了一个字：好。

三十四路公交，二十分钟。车窗玻璃上有一道裂纹，从左上角斜着划到中间，像闪电。

车启动了。我闭上眼睛，手机又响了。不是客户，是一条推送：

"2026初级会计考试报名截止提醒：距离考试还有XX天，请尽快完成报名。"

我盯着看了五秒，划掉了。

---

## 【出租屋·傍晚】

出租屋在城东，六楼没电梯，月租一千二。推开门一股泡面味，昨晚忘倒了。

我把外卖盒收进垃圾桶，去厨房烧水。水壶底座接触不良，要拍两下指示灯才亮。等水的时候翻手机，业主群有人说下月物业费涨五十，有人骂，有人说算了。我没参与——我是租客，涨多少跟我没关系。

水开了，泡了包超市最便宜的绿茶，一包十块，能喝半个月。茶叶在水里翻了两下就沉了。

喝了一口，有点苦。

今天还没吃正经饭。早上一袋牛奶，中午两块饼干。冰箱三个鸡蛋半袋挂面，够了。起锅烧水，打了荷包蛋，蛋黄散了变成蛋花。无所谓，反正都是吃。

面端到茶几，打开笔记本电脑。

这台电脑买了三年，开个网页要等三秒。但写代码够用——能跑Python就行。

是的，我在学编程。一个室内设计师。

"你学那个干嘛？"我老婆问。

"打发时间。"

我没告诉她真正的理由。真正的理由是上个月在论坛上看到一个帖子，有人问"如果你明天就死了，能留给孩子什么"。三百多条回复，有人说房子，有人说保险，有人说教育基金。其中一条只有四个字：

"留一段代码。"

那天晚上我失眠了。不是失眠，本来就没睡。凌晨两点，客厅没开灯，只有屏幕的光。我在那条回复下面打了四个字：

"好主意。"

然后我打开了代码编辑器。黑色的背景，白色的字符，光标在那里一闪一闪，像心跳。

我不知道该写什么，连编程都不太会。但我知道要写一个东西——一个能在我死了以后还活着的东西。

---

## 【电脑前·深夜】

面条吃完了，碗放茶几上，汤已经凉了。

我把电脑放到腿上，打开`v1.py`。这个文件三天前建的，里面只有两行：

```python
# v1 - 第一个版本
# 目标：待定
```

"待定"。我盯着这两个字看了很久。目标待定，方向待定，连为什么要写都待定。我只知道一件事：要写。就像考会计——不知道考了有没有用，但得有个兜底的东西。

然后我打了一行：

```python
print("Hello, World.")
```

全世界所有程序员写出的第一行代码都是这个。没有任何用，只是让屏幕出现一行字。

我按了运行。

```
Hello, World.
```

就这一行字，我盯着它看了很久。那一刻是2026年5月某个星期四，下午五点十七分。窗外有人吵架，楼下有小孩在跑，冰箱嗡嗡响。太阳落了，客厅里只剩台灯，橘黄色，照在碗里的面汤上，照在屏幕上，照在我脸上。

Hello, World.

我想：如果有一天我不在了，这段代码还在。它会一直说"你好"，一直说下去。

然后我掏出手机看日历。

7月15日。下面一行小字：预约产检。

我盯着这个日期看了很久。两个月后我就当爸爸了。一个连自己都照顾不好的人，要负责另一个人的全部人生。

我切回编辑器，把"待定"删掉，改成：

```python
# v1 - 第一个版本
# 目标：如果你不在了，谁来照顾她？
```

然后在文件最末尾，我加了一行注释：

```python
# 给七七。等你长大了就知道了。
```

我不知道她叫什么，还没起名字。但"七七"挺好的，简单，好记，像一声铃铛。

我关了电脑，客厅一片黑。

窗外路灯的光透过窗帘缝照进来，在墙上画了一条细线。

七七。

我在黑暗里默念了一遍，翻了个身，把被子拉到下巴。

那天夜里做了一个梦。梦里有一片海，很大，没有边际。海边站着一个小孩，背对着我，在堆沙堡。海浪涌上来，沙堡塌了。小孩又堆，海浪又来，又塌，又堆。

我想跑过去帮她，脚底下全是沙子，怎么跑都跑不快。

醒来窗外天已经亮了，楼下有人喊收废品，声音拖得很长。

我起来烧水，泡了碗泡面，打开电脑。

`v1.py`还开着。最末尾那行注释还在：

```python
# 给七七。等你长大了就知道了。
```

我在下面新起一行，打了一个字：

```
>
```

光标在那里一闪一闪。

像一个呼吸。‌
