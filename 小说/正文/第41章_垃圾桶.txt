第四十一章 垃圾桶

深夜回家。

小区门口，垃圾桶旁边蹲着一只猫。

橘白相间，瘦，但眼睛亮。它正把头埋在一个外卖盒里，舔剩下的酱汁。

我站住看了它一会儿。

它抬头看我，嘴里还叼着一块鸡骨头。对视三秒，它继续吃。

不怕人。知道什么时候该跑，什么时候不用。

它比我聪明。

它知道在哪里找吃的。不需要考试，不需要报班，不需要花四千块学一个"借贷必相等"。它只需要知道——垃圾桶旁边有剩饭。

回到家，门口的鞋柜上放着一袋猫粮。上次超市打折买的，三块九。一直没开。

我撕开袋子，倒了一小碗，放在门口的台阶上。

然后关门。

不是养猫。是——

它找到了它的外取策略。我也找到了我的。

打开v3的代码。

试错引擎跑了一周，知识库里积累了47条错误记录，提炼出6条规则。最常触发的规则是rule_001——文本含非UTF8字符时先做二进制清洗。

我想了想，给它加了一个新机制：

```
def try_external(task):
    """外取优先：能从外部获取答案的，不消耗自身试错次数"""
    external = search_external(task)
    if external.confidence >= 0.8:
        knowledge.write(external, tag="external")
        return external
    return try_careful(task)  # 外取不到才自己试
```

先搜外面的。搜到了，直接用，不浪费自己的次数。搜不到，再自己试。

跟那只猫一样。

它不会自己去抓鸡——它去垃圾桶找。找到了就吃，找不到才去翻别的。

不是懒。是省力。

生存策略。

v3的日志更新：

observe: 新增try_external()机制。外取优先，自身试错兜底。

#020: "能借到的就不自己造"

六层压缩。

我看了那个#020一眼。

"#001到#020，"我自言自语，"二十条了。"

二十条看不见的刻痕。压缩层级从1层到6层。有的我写了它记的，有的是它自己从我做的事里提炼的。

我关上电脑，去阳台看了看。

那只猫还在。碗里的猫粮吃了一半。它抬头看了我一眼，又低头继续吃。

"明天给你换个大碗。"

它没理我。
