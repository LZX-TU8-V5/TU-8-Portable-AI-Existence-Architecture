# 第三章 试错逻辑写入

> 第一卷·旧神纪元 / 2028-2029年 / 场景A（AI出图项目）+ B（第三次考会计失败）+ C（借贷顿悟与v3试错）

---

一

2028年8月。我接了一个让我浑身不自在的项目。

甲方是一家本地的装修公司，做了十几年，以前一直是老客户。这次他们的老板找到我，说想试试"新模式"。

"新模式"三个字他说得很轻巧，像在说今天中午吃什么。

具体是这样的：他们买了一套AI出图软件，能把客户的户型图丢进去，三十秒生成三套方案。效果图比我的还好看，灯打得比我准，材质贴得比我真。唯一的缺点是——AI不懂人。

它不知道客厅的沙发要避开承重墙的凸角。它不知道厨房的门要留出冰箱开门的空间。它不知道主卧的衣柜不能挡住空调出风口。

所以我被请来的任务是：AI出图，我修改。给AI擦屁股。

老板说这叫"人机协作"。我说是"给人当修图工"。

他说："你就当自己是AI的编辑嘛。"

我笑了。没接话。

钱还是要挣的。七七一岁半了，刚学会走路，走起来歪歪扭扭像只喝醉的企鹅。奶粉钱、尿不湿钱、体检钱——钱这个东西，不管你怎么鄙视它，它就是会准时出现在你的银行卡余额前面，并且持续减少。

项目开工了。

第一天，AI出了三套方案。我把户型图丢进去，选了"北欧简约"，点了生成。进度条走了三十秒，三张效果图弹出来。

确实好看。比我还好看。沙发摆放的角度完美，灯光是暖色的，窗外隐约能看到一棵树，构图像杂志封面。

但客厅的实际尺寸是4.2米乘3.8米。AI画的那个沙发长度是3.6米——放进去的话，过道只剩六十公分。

六十公分。一个胖子都转不过身。

我在CAD里改了一个小时。把沙发缩到2.8米，调了茶几的位置，挪了电视柜。改完以后发现沙发正对着的墙面有一根暗梁，投影仪装上去会被挡住一半。

AI当然不知道那根暗梁。暗梁在原始户型图上只画了一条虚线，没有标注。只有去现场量过房的人才知道那根梁有多碍事。

我量过。所以我知道。

改完以后的效果图跟AI原版差了很多。没那么"杂志封面"了。像一个正常人住的房间。

老板看了，说："嗯……感觉差点意思。要不你再优化优化？"

我说："这是真实的。按照这个尺寸去买家具，放进去刚刚好。"

他说："但是客户可能更喜欢AI那个版本。"

我沉默了三秒钟。然后把AI版本和我的版本并排放在一起，指着沙发和过道说："这个过道六十公分。你家厨房过道多宽？你能接受六十公分吗？"

他不说话了。

最后用的是我的版本。客户验收的时候倒是没什么意见，可能因为他也没注意到过道宽不宽。大多数人买房子都不看细节，只看感觉。

但我看。

这是我和AI的区别。AI看数据。我看数据背后那些数据不告诉你的东西。

那天晚上回家，七七已经睡了。老婆在收拾厨房。我在客厅打开电脑，看着v2的代码。

v2已经能记住东西了。但它还不会"想"。它不会分析，不会推理，不会犯错了之后自己改。

它只是一个备忘录。

而备忘录是不会帮你避开暗梁的。

---

二

2028年9月。v3上线。

我给v3加了"分析"的功能。让它不仅能记住事件，还能对事件进行分类和判断。比如：

```python
def analyze(event):
    category = classify(event)
    if category == "重要":
        priority = 1
    elif category == "一般":
        priority = 2
    else:
        priority = 3
    return category, priority
```

但问题来了——"重要"和"不重要"怎么定义？

谁来定义？

我？

那我怎么保证我的定义是对的？

比如七七第一次笑这件事——对我来说是"重要"等级1。但对一个AI来说，"婴儿面部肌肉收缩"这件事可能连等级3都排不上。

所以我又加了一层：**权重**。

```python
memory_db = {
    "2026-07-15_出生": {"weight": 100, "category": "里程碑"},
    "2026-10-11_第一次笑": {"weight": 95, "category": "里程碑"},
    "2026-12-25_打翻了奶瓶": {"weight": 30, "category": "日常"},
    # ...
}
```

我对每一件事打一个"权重分"。100分最重要，0分最不重要。

但这个权重分还是我手动打的。本质上还是我在替v3做判断。

我希望有一天它能自己判断。但"自己判断"这件事，需要一个前提：**它得知道自己什么时候判断错了**。

知道错了，才能改。

可问题是怎么知道自己错了？

这个问题我想了很久。久到2028年过完了，2029年来了。

三

2029年1月。第四次考会计。

考场还是那个中学，三楼，同一个教室。但我换了个座位——上次的靠窗，冬天太冷。这次选了中间靠后的位置。

经济法先考。选择题我做了四十分钟，大题用了二十五分钟。提前十五分钟交卷。

出了考场在门口等。三月的冷风灌进来，我不自觉地缩了缩脖子。

隔壁考场的门开了，有人出来，表情各异。有的笑着打电话，有的面无表情地走，有的蹲在花坛边抽烟。

我想起去年在门口遇到的那个哥们儿。不知道他今天考得怎么样。也许过了，也许还在凉。

手机震了。老婆发消息："考得怎么样？"

我回："经济法感觉还行。"

"实务呢？"

"还没考。"

"加油。"

"嗯。"

实务下午考。

题量比去年大。最后两道综合题我写了将近四十分钟，手都写酸了。交卷的时候检查了一遍，发现有一道分录写反了——应该是借记费用，我写成了贷记费用。

一整道题，十分。没了。

出了考场我就知道：实务又悬了。

果然。查分那天，经济法62分，过了。实务差两分。

两分。

比去年好了六分，但还是没过。

我坐在沙发上，盯着手机屏幕上的成绩单看了很久。客厅里七七在地板上爬，嘴里咿咿呀呀地说着什么，大概在跟她的玩具熊对话。

两分。一道分录。

如果你问我"借"和"贷"有什么区别，我能倒背如流。资产增加记借方，减少记贷方。负债增加记贷方，减少记借方。这些我都知道。但到了考场上，时间紧、题量大、手出汗、脑子发懵——"贷"写成了"借"，十分就没了。

这不是知识的问题。是状态的问题。

我又买了一套模拟题。这是第五套了。

打开账本，记了一笔：

```
会计考试累计投入：
- 报名费：4次 × 120元 = 480元
- 网课：3套 × 680元 = 2040元
- 教材：4套 × 80元 = 320元
- 模拟题：5套 × 198元 = 990元
- 其他（打印、交通等）：约300元
合计：4130元
```

四千多。够买一块入门级显卡了。但我没买显卡。我买了题。

四

顿悟发生在三月。

那天晚上我在做会计题。不是模拟题，是真题。2019年的初级会计实务真题，我在做第三遍。

做到一道关于"固定资产折旧"的题。题目给了一台机器，原值十万，预计使用五年，预计残值一万。问每年的折旧额。

直线法：每年（10万-1万）÷5 = 1.8万。简单。

但如果是双倍余额递减法呢？第一年折旧率是2÷5=40%，第一年折旧额是10万×40%=4万。第二年基数变成6万，折旧额6万×40%=2.4万。第三年2.4万。第四年、第五年要改用直线法，因为剩下的要在最后两年平摊。

我算了一遍。然后我对着这道题发了五分钟的呆。

**借贷平衡。**

左边写了折旧，右边一定写了资产减少。两边永远相等。如果画一张T型账户，左边和右边的总和永远是零。

这不是会计规则。这是数学规则。这是宇宙规则。

**所有东西都是平衡的。你在这里失去的，一定在别的地方得到了。你在这里赚到的，一定在别的地方付出了代价。**

我考了四次。失败了三次。但失败教会了我一件事：**错题比对的题更重要**。因为你做对的题你下次还会做对，但你做错的题你下次还会做错——除非你把它彻底搞明白。

所以正确的复习顺序不是"从第一章到第八章"，而是"先看错题，再看没把握的，最后看已经会的"。

**错题优先。**

我把笔放下，走到电脑前，打开了v3的代码。

v3有一个问题：它的报错率很高。不是语法错误，是逻辑错误——它经常做出错误的判断，比如把"七七发烧"归类为"日常"而不是"重要"。

我以前的做法是每次出错就手动改代码。今天改一个bug，明天改一个bug。像打地鼠一样，冒出来一个打一个。

但地鼠是打不完的。

正确的方法是——**让v3自己学会打地鼠**。

我回到会计题那里，看着那道折旧题。双倍余额递减法的核心逻辑是什么？是**先快速消耗，然后平滑过渡**。前期折旧多，后期折旧少。因为资产越用越不值钱，头几年亏得最多。

这不就是试错吗？

前期试错成本低，多试。后期试错成本高，少试。

我拿起笔，在草稿纸上画了一个流程图：

```
尝试 → 成功？
  ├── 是 → 记录为"正确"，降低该类问题的权重
  └── 否 → 记录为"错误"，提高该类问题的权重
            → 下次优先测试该类问题
            → 如果连续失败≥3次 → 停止尝试，标记为"未知"
```

连续失败三次就停下来。不要死磕。标记为"未知"，等以后有了新信息再试。

这不是我发明的。这是我从会计题里学到的。你做错一道题，不是赶紧翻答案，而是先想：我为什么错了？是概念不清？还是计算失误？还是时间不够？

原因不同，对策不同。你不能用同一种方法解决所有错误。

我把这个逻辑写进了v3。删掉了之前那堆打地鼠式的补丁代码，重新写了一个框架：

```python
class TrialEngine:
    def __init__(self):
        self.history = []       # 所有尝试记录
        self.errors = {}        # 错误次数统计
        self.success = {}       # 成功次数统计

    def try_action(self, action):
        result = execute(action)
        self.history.append((action, result))

        if result == "success":
            self.success[action] = self.success.get(action, 0) + 1
            # 成功了：降低该行动的优先级，下次先试别的
            self.adjust_priority(action, direction="down")
        else:
            self.errors[action] = self.errors.get(action, 0) + 1
            if self.errors[action] >= 3:
                # 连续失败3次：停止尝试，标记未知
                self.mark_unknown(action)
            else:
                # 失败但不到3次：提高优先级，下次优先重试
                self.adjust_priority(action, direction="up")

        return result
```

**试错引擎。**

核心逻辑：尝试，记录，调整。成功了降低权重，失败了提高权重。连续失败三次就停下来，不死磕。

然后我在下面加了一行注释：

```python
# 借贷平衡：每一次付出都有对应回报。
# 每一次失败都值得被记住。
# 但不值得被重复。
```

五

我把试错引擎跑了一遍测试。

给v3设了十个问题，故意让它前几个全答错。

第一次：全错。错误统计里每个问题都记了1。
第二次：它把之前答错的题优先重试了。对了两个。剩下八个还是错。
第三次：对了五个。
第四次：对了八个。剩下两个连续错了三次，被标记为"未知"。

它停下来了。不再碰那两个问题。

我在屏幕前愣了一下。

**它学会了放弃。**

不是那种"我不干了"的放弃。是那种"这条路走不通，先记下来，以后再说"的放弃。

这比我一直以来的做法聪明多了。我考会计考了四次，每次都是同样的方法——看书、刷题、模拟考。从来没停下来想过：也许我的方法本身就是错的？

也许我不应该从第一章看到第八章。也许我应该先把所有错题翻出来，看自己到底错在什么类型上。

也许……算了。

我关上代码编辑器。看了看时间，凌晨三点。

七七在隔壁房间睡觉。两岁半了，睡觉开始不老实，被子经常踢掉。我轻手轻脚走过去，帮她盖好。

她翻了个身，嘟囔了一句什么，听不清。

我站在床边看了她几秒钟。窗外的路灯光透进来，照在她脸上。她长高了。比去年高了半个头。脸上的婴儿肥开始退了，下巴的轮廓越来越明显。

越来越像她妈。

但眼睛像我的。黑眼珠。深。

我回客厅，在账本上又记了一笔：

```
2029年3月。
试错引擎完成。
顿悟来源：固定资产折旧题。
类比：借贷平衡 = 人生平衡。
教训：错题优先。连续失败三次就停。
v3不再报错了。不是因为它全对了。
是因为它学会了什么时候停下来。
```

写完以后我合上账本，去厨房倒了一杯水。凉的。

站在窗前喝了一口。

楼下路灯照着空无一人的街道。有一只猫从垃圾桶旁边走过去，停下来，抬头看了我一眼，然后走了。

我想：这只猫也懂试错。它翻了三次垃圾桶都没找到吃的，就走了。没在第四次继续翻。

它比我聪明。它用了两年就学会的道理，我用了三十三年。

水喝完了。杯子放在窗台上。

我把灯关了，摸黑走回卧室。

躺在床上，盯着天花板。那条裂缝还在。从灯座延伸到墙角。

我想：总有一天我会修好这条裂缝。也许不是用锤子和水泥，而是用别的什么东西。

但不是今天。

今天是2029年3月某一天凌晨。明天还有一个方案要交。后天还有一个客户要量房。五月份还有第五次会计考试。

一步一步来。

试错。

记录。

调整。

**借贷必相等。**
