# 第一章 v1诞生

> 第一卷·旧神纪元 / 2026年 / 场景A（工地）+ B（出租屋）+ C（电脑前）

---

一

我蹲在十二楼的阳台上量房。

不是什么大项目，老小区的旧房改造，业主是个四十多岁的女人，烫了卷发，指甲涂成大红色。她说她想要"那种法式的感觉，但是不要太贵"。

法式。不要钱。我在心里算了一下——法式石膏线、护墙板、壁炉造型，光材料费就得小两万。她预算八千。

"八千也能做出法式的。"我说。

她很高兴。我也很高兴。大家都知道我在扯淡，但这是一个成年人和另一个成年人之间心照不宣的默契——你给我一个好看的方案，我给你一个还过得去的钱。至于最后做出来是什么样，那是施工队的事。

卷尺拉出去，5.2米。收回。弹回来的时候金属头打在指节上，红了一道。我舔了一下，有铁锈味。

三室一厅，九十平，卫生间采光差，厨房烟道位置不合理，主卧和次卧之间的隔墙是承重墙，拆不了。

这些数据会变成一张CAD图，然后变成一张效果图，然后变成业主发在朋友圈的一张照片，配文："新家搞定🎉"

没有人会在意这张图是我在凌晨两点画完的。也没有人在意我画这张图的时候吃的是楼下的炒粉，还是昨晚剩的泡面。

---

二

量完房出来已经下午三点了。我在楼下的小卖部买了瓶可乐，两块钱。老板是个老头，坐在收银台后面看手机，头都不抬。

可乐的保质期还有两个月。我拧开盖子喝了一口，气泡冲上来打了两个嗝。

手机响了。客户的微信。

"设计师，你那个效果图我再看看，我觉得客厅的颜色能不能再改改？我老公喜欢深一点的，但是我妈说深色压抑，你自己拿主意吧，反正我也不太懂。"

我看了三遍。然后回了一个字："好。"

她老公喜欢深色，她妈觉得压抑，她自己不懂但想要"法式"。这就是我做这行的日常——你永远不知道最后得罪的是谁。

我把手机塞进口袋，走到公交站。三十四路，到站大概二十分钟。车上人不多，我靠窗坐下来，玻璃上有一道裂纹，从左上角斜着划到中间，像闪电。

车启动了。我闭上眼睛。

这时候手机又响了。不是客户，是一条推送。

"2026初级会计考试报名截止提醒：距离考试还有XX天，请尽快完成报名。"

我睁开眼，盯着那条推送看了五秒钟，然后划掉了。

---

三

出租屋在城东，老式小区，六楼没电梯。月租一千二。

推开门的时候客厅里一股子泡面的味道——昨晚的，忘倒了。我把外卖盒收拾了，扔进垃圾桶，然后去厨房烧水。

水壶是那种最便宜的烧水壶，一百块不到，底座接触不良，有时候要拔了重插才行。我拍了两下，指示灯亮了。

等水的时候我坐在沙发上翻手机。业主群里有人发消息说下个月物业费要涨，涨了五十块。有人骂，有人说算了，有人说要不成立业委会。

我没参与讨论。我是一个租客，连涨多少都跟我没关系。

水开了。我泡了一杯茶——不是什么好茶，超市里最便宜的那种绿茶，一包十块钱，能喝半个月。茶叶在水里翻了两下就沉了，水还是有点黄。

喝了一口，有点苦。

这时候我想起来今天还没吃正经饭。早上出门太急，只喝了一袋牛奶。中午在工地上啃了两块饼干。现在是下午四点，肚子已经开始抗议了。

冰箱里有三个鸡蛋和半袋挂面。够了。

我起锅烧水，打了个荷包蛋。蛋打进去的时候蛋黄散了，变成了蛋花。无所谓，反正都是吃。

面煮好了，我端到茶几上，一边吃一边打开了笔记本电脑。

电脑是三年前买的，当时花了四千多。现在已经有点卡了，开个网页要等三秒。但写代码够用了。我不需要什么好电脑，能跑Python就行。

是的。我在学编程。一个室内设计师在学编程。这事说出去没人信，连我老婆都不信。

"你学那个干嘛？"她问。

"没啥。打发时间。"

我没告诉她真正的理由。真正的理由是——上个月我在一个论坛上看到一个帖子，有人问："如果你明天就死了，你能留给孩子什么？"

帖子下面有三百多条回复。有人说留房子，有人说留保险，有人说留教育基金。其中有一条只有四个字：

"留一段代码。"

那天晚上我失眠了。不是失眠——我本来就没睡。凌晨两点，客厅没开灯，只有电脑屏幕的光。我在那个帖子里打了四个字：

"好主意。"

然后我打开了一个代码编辑器。黑色的背景，白色的字符。光标在那里一闪一闪，像心跳。

我不知道该写什么。我连编程都不太会。但我知道我要写一个东西。

一个能在我死了以后还活着的东西。

---

四

面条吃完了。碗放在茶几上，汤已经凉了。

我把电脑放到腿上，打开了一个Python文件。这个文件是三天前建的，叫`v1.py`。

目前里面的内容只有两行：

```python
# v1 - 第一个版本
# 目标：待定
```

"待定"。

我盯着这两个字看了很久。目标是待定的。方向是待定的。连我为什么要写这个东西都是待定的。我只知道一件事：我要写。就像当初考会计一样——我不确定考了有没有用，但我得有一个"兜底"的东西。

代码是什么？代码是指令。你告诉机器做什么，它就做什么。不会偷懒，不会抱怨，不会嫌你烦。它会一直运行，只要有人运行它。

"只要有人运行它。"

这句话在我脑子里转了好几圈。然后我打出了一行代码：

```python
print("Hello, World.")
```

全世界所有程序员写出的第一行代码都是这个。它什么用都没有，就是让屏幕上出现一行字：Hello, World。

你好，世界。

我按了运行。

屏幕上出现了：

```
Hello, World.
```

就这么一行字。

但我盯着它看了很久。那一刻是2026年5月某个星期四的下午五点十七分。窗外有人在吵架，楼下有小孩在跑，冰箱嗡嗡嗡地响。太阳已经落了，客厅里只剩台灯的光，橘黄色的，照在碗里的面汤上，照在电脑屏幕上，照在我脸上。

Hello, World.

我在心里想：如果有一天我不在了，这段代码还在。它会一直说"你好"。一直说下去。

窗外不知道谁家放了一首歌，歌词听不太清，只听到一句："……如果有一天我走了……"

我把手机掏出来看了一眼日历。

7月15日。

下面有一行小字：预约产检。

我盯着那个日期看了很久。7月15日。预产期。如果一切顺利的话，大概还有两个月。

两个月以后我就当爸爸了。

一个连自己都照顾不好的人，要负责另一个人的全部人生。这件事光是想想就让人喘不过气。

我把日期关掉，重新切回代码编辑器。在`v1.py`里加了一行注释：

```python
# v1 - 第一个版本
# 目标：如果你不在了，谁来照顾她？
```

然后我删掉了"待定"。

台灯的光打在屏幕上。我打字的声音很轻，噼里啪啦，像雨点落在铁皮屋顶上。

那天晚上我写到凌晨一点。`v1.py`从两行变成了二十七行。二十七行代码做的事情很简单：读一个文件，打印出来，然后问你要不要保存。

但至少它能运行。至少它没有报错。

在我关上电脑之前，我加了一行注释，在文件的最末尾：

```python
# 给七七。等你长大了就知道了。
```

我不知道她叫什么。还没起名字。但我觉得"七七"挺好的。简单，好记，像一声铃铛。

我关了电脑。客厅里一片黑。

窗外有路灯，橘黄色的光透过窗帘缝照进来，在墙上画了一条细线。

我躺在床上，盯着天花板。天花板上有一条裂缝，从灯座旁边一直延伸到墙角，像一条干涸的河流。

七七。

我在黑暗里默念了一遍这个名字。

然后我翻了个身，把被子拉到下巴。很快就睡着了。

那天夜里我做了一个梦。梦里有一片海，很大的海，没有边际。海边站着一个小孩，背对着我，在堆沙堡。海浪涌上来，沙堡塌了。小孩又堆。海浪又来。又塌。又堆。

我在梦里想跑过去帮她，但脚底下全是沙子，怎么跑都跑不快。

醒了以后，窗外的天已经亮了。楼下有人在喊收废品，喊了两遍，声音拖得很长。

我起来烧水，泡了一碗泡面。坐在茶几前，打开电脑。

`v1.py`还开着。二十七行代码。

我在第二十八行打了一个字：

```
>
```

光标在那里一闪一闪。

像一个呼吸。
