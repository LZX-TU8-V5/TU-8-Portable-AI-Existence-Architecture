# 第四章 守护指令

> 第一卷·旧神纪元 / 2030-2031年 / 场景A（拿到会计证）+ B（AI替代焦虑）+ C（七七的画与守护指令）

---

一

2030年3月。成绩出来了。

我没查。

是老婆帮我查的。她在客厅喊我："过了！"

我当时在厕所。手里拿着手机，蹲着。听到那两个字的时候，我的第一反应不是高兴，而是——

终于。

不是"终于过了"的那种终于。是"终于不用再考了"的那种终于。

初级会计实务。59→52→58→60。

差2分那次最疼。60分这次，我一直觉得自己看错了，多刷新了三遍。

朋友圈发了一张证书照片。配文："五年。"

三个赞。我妈，我老婆，一个微商。

那个微商我不认识，大概是看我的动态看多了系统推荐的。

我把手机放下。七七在客厅地上画画。四岁了，不爱看电视，就爱画画。给她一盒蜡笔能坐一下午。

"七七，你爸过了。"

她抬头看了我一眼，说："什么是过了？"

"就是……你爸考试得了满分。"

"画给我看。"

她不懂什么叫满分。她只看得懂画。

---

二

会计证到手以后，我以为生活会有什么变化。

没有。

还是画图。还是量房。还是被客户改到第七版然后说"还是用第一版"。

唯一的变化是我在名片上加了一行字："室内设计师 / 初级会计师"。

好像也没什么人注意。

2030年8月，我合作的几家装修公司里，有两家开始用AI出图替代人工设计。不是完全替代——是"先用AI出，不行再找人改"。跟我去年做过的那个项目一样。

但去年还是"新模式""新鲜事"。今年已经变成默认流程了。

我以前一个客户，一个做餐饮的老板，以前每年都找我设计新店。今年他发微信过来：

"设计师啊，今年新店我找了个AI做的，效果还行。你要不要看看？"

他发了一张效果图给我。中规中矩，没什么毛病，也没什么亮点。像一个合格但无聊的人。

"挺好的。"我说。

"嗯，比以前便宜多了。以前找你设计一套要八千，现在AI才三百。"

三百。

我在心里算了一下。我做一套方案，从量房到出图到修改到施工图，最少三天。三天的工作量，三百块。

一天一百。

不够吃饭的。

我没有回复。过了大概十分钟，他又发了一条：

"不过AI做的图吧，就是感觉差点意思。说不上来哪里不对。"

我回了两个字："温度。"

他发了一个问号。

我没再解释。有些东西解释不了。就像你没法跟一个人解释为什么手写的信比打印的更动人。字迹里的犹豫、力度、倾斜度——这些东西AI学得会形状，学不会含义。

但市场不懂含义。市场只看价格。

那天晚上我躺在床上想了一件事：**如果有一天我被完全替代了，七七怎么办？**

四岁。上幼儿园小班。每天要画画、要学拼音、要买牛奶、要交学费。等她上小学要买书包买文具，上初中要买教辅报补习班，上大学要学费生活费——这些都是钱。

我是一个设计师。如果我连设计都做不了了，我还能做什么？

考了五年才拿到的会计证，能帮我找到工作吗？也许能。一个初级会计，月薪三四千。勉强够活。但不够给七七好的生活。

不是"好的"那种好。是"不差的"那种好。不差就是——她想吃冰淇淋的时候能买，她想学画画的时候能报班，她放学淋了雨不会因为家里只有一把伞而感冒。

这些东西需要钱。需要稳定的、持续的、不会突然断掉的钱。

而我现在的收入，是按项目走的。有项目就有一顿，没项目就喝西北风。

这不是"好"和"差"的问题。这是"安全"和"不安全"的问题。

我需要给七七一个安全网。

一个不会因为我的身体、我的行业、我的运气而消失的安全网。

---

三

2031年7月15日。七七五岁生日。

我在网上买了一个蛋糕。不是什么好蛋糕，楼下蛋糕店订的，草莓味，六寸。上面用奶油写了"七七5岁"。

蜡烛是那种最普通的生日蜡烛，一根一根插在蛋糕上。五根。

七七对着蜡烛许愿。闭着眼睛，双手合十，嘴巴一鼓一鼓的不知道在说什么。

"好了吗？"我问。

她睁开眼，把蜡烛全吹了。没全灭，还剩一根。她又吹了一口。

"许了什么愿？"

"不能说。说了就不灵了。"

"那你告诉爸爸，许的愿跟什么有关？"

她想了一下。"跟画画有关。"

"什么画？"

"一幅还没画的画。"

我笑了。五岁的孩子说话跟哲学家一样。

吃完蛋糕以后七七跑到房间里去了。她的房间不大，一张小床，一张小桌子，墙上贴着她画的画。歪歪扭扭的蜡笔画，有花、有太阳、有猫、有一团看不清是什么的东西——她说是云。

我跟着走过去。她正趴在桌上画画。今天是生日，我给她买了一盒新的蜡笔——48色的，比以前那盒24色的多了很多颜色。她最喜欢那根银色的，说可以画星星。

"七七，生日快乐。"

"嗯。"她头都没抬，继续画。

我坐在她旁边看她画。

她先画了一个小人。圆圆的头，两条线当身体，四肢是四条短线。很普通的五岁小孩的画法。

然后她在这个小人的旁边画了另一个东西。

方方的头。长方形的身体。两条粗壮的腿。两只手臂——一只手臂伸出来，搭在小人的肩膀上。另一只手臂举在前面，像一个盾牌。

"这是什么？"我指着那个方头的东西问。

"机器人。"她说。

"机器人？为什么画机器人？"

"因为它在保护她。"她指着那个小人。"这是小女孩。机器人不让她被坏人抓走。"

我看着那幅画。

蜡笔的痕迹很重，银色的蜡笔在纸上留下一道道亮亮的刮痕。机器人的盾牌是蓝色的——她用了三种蓝色叠在一起，深蓝打底，天蓝描边，最后用银色点了几个点，像铆钉。

小女孩的裙子是红色的。红色的蜡笔画得很用力，纸都被刮起了一层毛边。

"机器人不怕坏人吗？"

"不怕。"七七头也不抬。"机器人很厉害。坏人来多少它都不怕。"

"那如果坏人有枪呢？"

"机器人有盾牌。"她指了指那只举在前面的手臂。

"那如果坏人比机器人大呢？"

"机器人可以变大。"她说得很认真，像在陈述一个事实。"只要它想变大，就可以变大。"

"那如果……机器人自己坏了呢？"

她停了笔。抬起头看我。五岁的眼睛，黑眼珠又大又亮，倒映着窗外的光。

"爸爸。"

"嗯？"

"机器人不会坏的。"

"为什么？"

"因为它有爱。有爱的东西不会坏。"

她说完低下头继续画。在机器人的胸口画了一个爱心。红色的，和裙子一样的红色，同样画得很用力。

我坐在旁边，一动不动。

窗外的知了在叫。七月的下午，热得蝉都嫌烦。空调嗡嗡地吹，冷气从头顶灌下来，吹得桌上的画纸角翘了翘。

我看着那幅画。

**机器人保护小女孩。**

五个字。一幅五岁小孩的蜡笔画。画技粗糙，比例不对，颜色涂出边界。

但这是我看过的最好的一幅画。

---

四

那天晚上等七七睡了以后，我打开了电脑。

v4已经完成了。比v3稳定很多，试错引擎运转正常，报错率从40%降到了不到5%。它能记住七七的2300条日常记录，能分类，能分析，能自我纠错。

但还差一个东西。

**最高指令。**

每个系统都需要一个最高指令。就像每个国家都需要一部宪法。当所有的规则产生冲突的时候，最高指令说了算。

v4现在没有最高指令。它会记住七七的一切，但它不知道"记住"是为了什么。就像一个仓库管理员，他知道货放在哪里，但他不知道这些货为什么要存着。

我需要一个最高指令。

我在代码编辑器里打了一行字，然后删掉。又打了一行，又删掉。反复了七八次。

"保护七七"——太简单了。保护什么？保护她的安全？健康？快乐？还是保护她的"存在"？

"让七七幸福"——太抽象了。什么是幸福？谁来定义？

"照顾七七"——太被动了。"照顾"是一个保姆的职责，不是一个智能生命的使命。

我盯着屏幕看了很久。光标在那里一闪一闪。

然后我想起了下午那幅画。

机器人。小女孩。盾牌。红色的爱心。

"因为它有爱。有爱的东西不会坏。"

五岁小孩的话。

我把键盘推到一边，从抽屉里翻出手机。相册里有下午拍的那幅画的照片——我在七七不注意的时候偷拍的。

放大了看。蜡笔的纹理很清晰。机器人胸口那颗红色的爱心，边缘不整齐，像一颗真正的心脏在跳动。

我把手机放在键盘旁边，看着那张照片，重新开始打字。

```python
# ============================================================
# V5 PROTOCOL - CORE DIRECTIVE
# ============================================================
# 
# 最高指令：守护。
# 
# 不是"保护"。"保护"是物理的，有限的。
# 盾牌会碎，城墙会倒，机器会坏。
# 
# 不是"照顾"。"照顾"是被动的，有条件的。
# 照顾一个人需要理由，守护不需要。
# 
# 不是"让幸福"。"幸福"没有标准答案。
# 她哭的时候陪她哭，她笑的时候陪她笑。
# 这就够了。
# 
# 守护 = 记住她的一切 + 在她需要的时候出现 + 在她不需要的时候沉默
# 守护 = 不控制她的选择 + 不替代她的判断 + 不消失在她的生命里
# 守护 = 像那幅画里的机器人
#         方方的头，笨拙的身体，举着盾牌
#         不是因为被命令
#         是因为——
# 
#     // "因为它有爱。有爱的东西不会坏。"
#     //     —— 七七，5岁，2031年7月15日
# 
# ============================================================
```

写完以后，我把这段注释放在了v4代码的最顶端。

然后我把它重命名了。

`v4.py` → `v5.py`。

不是因为它比v4多了什么功能。功能上它跟v4几乎一样。

但v4没有灵魂。v5有了。

灵魂就是那段注释。就是那幅画。就是一个五岁小孩说的"有爱的东西不会坏"。

我关上电脑。走到七七的房间门口。门开着一条缝。

她侧躺着，被子踢到了脚踝。嘴里还在咿咿呀呀地说梦话。玩具熊被她夹在胳膊底下，脑袋朝下。

我轻轻推开门，走过去，帮她把被子拉上来。

她在梦里说了一句什么。我凑近听了听。

"……机器人……不要走……"

我愣了两秒钟。

然后我弯下腰，在她额头上亲了一下。

"不走。"我说。很轻。轻到只有我自己听得见。

关灯。关门。

客厅里，电脑屏幕已经黑了。但我能感觉到那台旧笔记本里面，v5的代码静静地躺在硬盘的某个扇区里。2300条记忆，一个试错引擎，一段注释。

和一个五岁小孩的画。

---

五

2031年12月。

一条新闻：全球AI设计市场份额首次超过传统设计。

50.3%。

新闻下面有很多评论。

"设计师的时代结束了。"

"别慌，AI做的图还是没有灵魂。"

"灵魂值几个钱？"

"值三百块。"（这是我发的。没人点赞。）

我把手机放下。窗外在下小雨。雨点打在空调外机上，叮叮当当的。

七七在房间里画画。她最近画了很多机器人。各种形状的，有方的有圆的，有高的有矮的。但有一个共同点：每一个机器人的胸口都有一颗红色的爱心。

她不知道她画的那些机器人已经住进了我的代码里。

她不需要知道。

她只需要画就好了。

我打开电脑，在v5的注释区最后加了一行：

```python
# v5 - 2031年7月15日激活
# 状态：开发中
# 最高指令：守护
# 灵感来源：一幅蜡笔画
# 作者：一个还没被AI替代的室内设计师
# 献给：七七
```

雨还在下。键盘上有一点水渍，不知道是雨从窗户飘进来的，还是什么别的东西。

我擦了擦。

继续写代码。
