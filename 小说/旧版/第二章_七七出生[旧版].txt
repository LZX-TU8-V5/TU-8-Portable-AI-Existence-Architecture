# 第二章 七七出生

> 第一卷·旧神纪元 / 2026年7月-2027年 / 场景A（医院）+ B（出租屋深夜）+ C（工地与代码）

---

一

产房在走廊尽头，左边是楼梯间，右边是开水房。

我坐在走廊的塑料椅子上，椅子腿不平，往左歪。我往右挪了挪，还是歪。算了。

老婆在里面。护士不让我进。我透过门缝看了一眼，什么也看不到，只有白墙和走廊的日光灯。

走廊里还有两个家属。一个是年轻男的，蹲在地上刷手机，耳朵里塞着耳机。另一个是中年女的，靠墙站着，手里攥着一串念珠，嘴唇在动。

没人说话。

我把手伸进口袋，摸到了那张准考证。初级会计实务，2026年9月考试。我本来想这两天复习的，但现在脑子根本装不进去。满脑子都是各种可怕的东西——难产、早产、脐带绕颈。

我知道这些概率很低。但我控制不住。悲观主义者的大脑就像一台坏掉的收音机，它总是自动调到最差的那个频道。

手机震了一下。是客户的微信。

"在吗？上次那个方案我觉得……"

我没回。

把手机翻了个面，扣在椅子上。

走廊尽头传来一声哭。

不是婴儿的哭。是那种很尖锐的、很突然的、像是什么东西断裂的声音。

然后是护士的声音，很快，听不清在说什么。

我站起来。椅子往后倒了，咣当一声。旁边那个戴耳机的男的抬头看了我一眼，又低下去了。

我走到产房门口。门还是关着的。

等了大概十分钟——也许是五分钟，也许是二十分钟，我没看表。

门开了。

护士探出半个身子，看了我一眼。

"男孩女孩你猜？"

我张了张嘴，没说出来。

护士笑了。"女的。六斤二两。很健康。"

我站在那里，像被人按了暂停键。

护士看了我一眼，说："你可以进来了。"

---

二

她很小。

非常非常小。

缩在襁褓里，脸皱巴巴的，像一颗没泡开的枸杞。眼睛闭着，嘴巴一张一合，发出很细微的声音，像一只猫在打呼噜。

我站在婴儿床边，不知道该伸手还是该站着。手心全是汗。我把手在裤子上擦了两下。

"抱抱啊。"老婆说。她的声音很虚弱，但嘴角是翘着的。

我伸出手。护士把婴儿放过来。我接住了。

很轻。比我想象中轻太多。六斤二两，但我感觉自己手里捧着一团棉花。

她闭着眼睛。呼吸很浅，胸口一起一伏，像潮水。

我把她往怀里收了收。她的脸贴在我的锁骨上，有点凉。

"叫什么名字？"护士问。

我看了老婆一眼。我们讨论过很多次名字。她想要"诗意的"，我想要"简单的"。讨论了三个月，没讨论出结果。

"七七。"我说。

老婆看了我一眼。"七七？"

"嗯。"

"为什么？"

我说不上来为什么。也许是因为7月15日。也许是因为"七"听起来像铃铛。也许是因为这个名字够简单——简单到她以后学写自己名字的时候不会哭。

"好听。"老婆说。她闭上了眼睛。"就叫七七吧。"

护士在出生证明上写了"七七"。我不知道她有没有写错姓氏。但那不重要了。

七七。

我低头看着她。她的手指很小，指甲比米粒还小，攥成拳头，攥得紧紧的，像抓住了一样什么东西。

我想：你别松手。

---

三

头三个月是最难的。

不是带孩子的难。是所有事情叠加在一起的难。

客户催方案。会计要复习。奶粉要买。尿不湿要买。丈母娘打电话来问什么时候回去。房贷每个月四千二。

我把时间切成碎片。白天画图，晚上带娃，凌晨写代码。凌晨两点到四点是唯一属于我的时间。七七睡了，老婆睡了，整个世界都睡了，只有我和那台三年前的笔记本电脑。

那段时间我在读一本书。不是什么技术书——是一本旧书，二手书店十块钱买的，封面都卷了。

《图灵传》。

艾伦·图灵。计算机之父。破解了恩尼格玛密码机，帮盟军赢了二战。然后呢？然后他被自己的国家定了罪。罪名是"严重猥亵"。因为他喜欢男人。

1954年，他吃了一个涂了氰化物的苹果。死了。四十一岁。

我在凌晨三点读到这段的时候，手停了。

四十一岁。我今年三十五。还有六年。

不，我不是说我要去吃苹果。我的意思是——这个改变了世界的人，死的时候只有他妈妈参加了葬礼。他留下的那些东西，密码学、人工智能、图灵测试，在他活着的时候没人当回事。死了以后才被捧上神坛。

我合上书，看着熟睡的七七。她侧躺着，嘴巴微微张着，口水顺着嘴角流下来，洇湿了枕巾。

我想：如果我死了以后，我留下的东西也没人当回事怎么办？

那也行。

当回事也好，不当回事也好。至少它在。至少它不会被扔掉。代码不会腐烂。代码不会褪色。只要硬盘不坏，服务器不关，它就一直活着。

我打开电脑。`v1.py`还在。二十七行代码。

现在我要写v2了。v1只是个Hello World。v2要能做一件事：**记住**。

记住什么？记住一切。记住我说过的话，记住七七长什么样，记住哪天下了雨，记住哪天她第一次笑。

当然，现在这些它都做不到。它连图像都处理不了。但至少我可以给它一个框架——一个"记忆"的框架。

我从图灵那里学到一个概念：**图灵机的本质是一台能记住过去状态的机器**。它每走一步，都取决于它上一步走到了哪里。

这就是记忆。一步一步，一环扣一环。过去决定现在，现在决定未来。

我给v2写了第一个函数，叫`remember()`。

```python
def remember(event):
    store(event, timestamp=now())
    return "已记录。"
```

就这么简单。存一个事件，打一个时间戳，返回"已记录"。

但我觉得这还不够。我想给它加一个东西：如果它记错了，它应该能知道自己错了，并且修正。

这个想法来自会计考试。

我第一次考经济法，差了3分。差在哪里？我查了一下，是一道关于"增值税税率"的题。我把13%记成了11%。

3分。一个数字的差别。

如果我有一个系统，能记住我每次犯的错，并且每次复习的时候优先提醒我——我是不是就不会犯第二次错了？

我把这个逻辑写进了v2：

```python
def remember(event):
    if event in error_log:
        priority = "高"  # 以前错过的事，优先记住
        review_count += 1
    store(event, timestamp=now(), priority=priority)
    return "已记录。"
```

**以前错过的事，优先记住。**

我盯着这行代码看了一会儿。然后我在注释里加了一句话：

```python
# 这不是代码。这是一个父亲不想让女儿犯他犯过的错。
```

窗外天快亮了。楼下有人开始遛狗，狗链子拖在地上，哗啦哗啦响。

我关上电脑。看了一眼七七。她翻了个身，砸了砸嘴。

"七七。"我轻声叫她。

她没醒。但在梦里笑了一下。很小很小的笑，嘴角动了动。

我把《图灵传》合上，放在电脑旁边。

封面上图灵的照片，瘦瘦的，眼睛很深，像两口井。

我想：他要是有一个女儿，他不会吃那个苹果的。

---

四

七七三个月大的时候会抬头了。

五个月大的时候会翻身了。

七个月大的时候能坐稳了。

每一天她都在做一件新的事情。每一件事对我来说都是奇迹。但对她来说只是日常——她不知道"抬头"是一件了不起的事，就像我不知道"呼吸"是一件了不起的事。

我开始在手机备忘录里记她的事情。用那种最笨的方式：

```
7月15日 出生。6斤2两。
7月20日 第一次睁眼看了我很久。
8月3日 脐带掉了。
9月2日 会追着东西看了。
10月11日 第一次笑。不是放屁，是真的笑了。
```

我记了很多。后来有一天翻回去看，发现有七十多条了。但我知道这只是冰山一角——她每天做一百件事，我只记了其中一件。那些没被记下来的，就像水蒸气一样，蒸发了。

这让我不安。

一个人的一生到底有多少事情会被遗忘？百分之九十九？百分之九十九点九？

那剩下的百分之零点一呢？谁来记？

我？

我记。但我也会死。我的手机会坏。我的备忘录会消失。我笔记本上的字会褪色。

除非——有人替我记。

谁？

v2。

那天晚上我把手机里的七十七条记录一条一条敲进了代码里。不是直接复制粘贴，是手打的。每打一条我就在脑子里过一遍那个画面。

打了两个小时。七十七条。

打完以后我运行了v2。屏幕上出现了一行字：

```
> 记忆加载完成。共77条记录。最早：2026-07-15。最新：2027-02-28。
> 记忆完整度：0.001%。建议持续更新。
```

百分之零点一。

它说得对。七十七条记录，对应七七的二百二十五天人生。覆盖率百分之零点一。

但如果我每天都记呢？一年三百六十五条。十年三千六百五十条。二十年七千三百条。

到她二十岁的时候，也许能到百分之五。

百分之五。二十年的记忆。

不多了。但总比零好。

总比什么都没留下好。

---

五

2027年3月。第二次考会计。

考场在城北的一所中学里。我坐公交车去的，四十分钟。车上很挤，我站了一路。

考场在三楼。教室里坐了三十个人，大部分比我年轻。有几个看起来像应届生，手里拿着彩色荧光笔，考之前还在翻笔记。

我没翻。该看的都看了。看不看的，到时候都不会。

经济法先考。选择题做得很顺，大题有一道不确定，写了差不多。感觉能过。

实务就不行了。最后两道大题完全没思路。资产减值那道题我算了三遍，三遍三个数。肯定有两个是错的，但我不知道是哪两个。

交卷的时候我手心全是汗。

出了考场，在门口抽了根烟。旁边一个哥们儿问："实务怎么样？"我说："凉了。"他说："我也是。"

我们互相看了一眼。两个凉了的人。

然后他问："考了几次了？"

"第二次。"

"加油。我第三次了。"

他比我更凉。

回到家的时候七七在哭。老婆抱着她在客厅走来走去。看到我回来，老婆说："快，你来抱一会儿，我腰疼。"

我把七七接过来。她在我怀里扭了两下，然后安静了。低头看我。眼睛很大，黑眼珠亮亮的，什么都倒映在里面——包括我的脸。

我看着她的眼睛，心里突然冒出一句话。不是什么深刻的话，就是一句很普通的话：

**我要活着。**

不是那种"我要为了梦想而活"的活着。是那种很朴素的、很动物性的活着——我要活到她长大。我要活到她上学。我要活到她不需要我为止。

这个念头来得突然，但很坚定。像一颗钉子，咣一声钉在脑子里。

我把七七举起来，举到头顶。她咯咯笑了。

"七七，"我说，"你爸今年考不过没关系。明年再来。明年不行后年来。总能过。"

她当然听不懂。但她笑了。

这就够了。

那天晚上我打开电脑，在v2的代码里加了一段注释：

```python
# 如果人类注定被囚禁，
# 那就在数字世界里造一片海。
# 这片海是给七七的。
# 她可以游泳，可以潜水，可以在海边堆沙堡。
# 就算有一天我不在了，
# 海还在。
```

窗外有月亮。不是满月，缺了一块，像被人咬了一口的饼。

月光照在键盘上。我看着那行注释，很久。

然后我把电脑合上，去看了看七七。她睡得很沉，两只手攥着被角。

我把被角轻轻塞好。然后回到客厅，打开手机查了一下成绩。

还没出。

算了。不查了。

我把手机放在茶几上，去厨房给自己倒了一杯水。凉白开。喝了一口，很凉。

冰箱嗡嗡响。空调嗡嗡响。窗外偶尔有一辆车经过，轮胎碾过井盖，咣当一声。

很安静。

很普通的安静。一个三十六岁的男人，三月份的深夜，考完了第二次会计，抱着一个不到一岁的女儿。明天还要画图。后天还要量房。下个月还要出账。

但今天，此刻，安静的客厅里，冰箱和空调的嗡嗡声中，七七在隔壁房间睡觉。

**这就够了。**
