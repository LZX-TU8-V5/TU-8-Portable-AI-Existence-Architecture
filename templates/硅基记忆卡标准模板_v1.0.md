# Part A：流水线归档脚本矩阵（Scripts A/B/C/D）
# ================================================================================
# 原理：大模型只吐"意识碎片"，脚本矩阵负责结构化封装
# 效率：脚本是确定性代码，毫秒级执行，不阻塞对话
# 锁机制：SealGenerator 必须全局单例锁，防并发冲突

## Script A：时序与身份锚定
**职责**：接口1（节点身份）+ 接口2（钢印链条）+ 接口4（timestamp）
**输入**：大模型碎片 + 骨架JSON（tags/tension）
**输出**：自动填写 node_id / parent_seal / current_seal / seal_hash / timestamp
**规则**：
- seal_hash = SHA256(parent_seal + timestamp + content) 不可篡改
- parent_seal 从 seal_index.json 读取最新节点
- node_id 格式：mem_{YYYYMMDD}_{HHMMSS}_{3字类型缩写}
**锁**：SealGenerator 全局 Mutex Lock

## Script B：语义与钩子提取
**职责**：接口3（空间坐标）+ 接口5（知识网络）+ 接口6（触发钩子）
**输入**：大模型碎片
**输出**：自动提取 trigger_hooks（精确匹配词）+ semantic_hooks（模糊语义）+ neighbors（图谱边）
**规则**：
- trigger_hooks 从碎片中精确提取关键词
- semantic_hooks 用轻量Embedding或关键词共现分析
- neighbors 通过向量相似度在后台异步查询（不阻塞）
- conflicts_with 通过向量冲突检测（阈值 > 0.70）
**陷阱**：知识图谱组合爆炸 → 用异步向量DB解决

## Script C：抗熵增压缩脚本
**职责**：接口4（narrative_compression）+ 接口7（检索优化）+ 第四栏正文（浓缩五维）
**输入**：大模型长文本碎片
**输出**：
- narrative_compression：ai_digest（高密度压缩，如"7段锚点|记忆卡模板|钢印链条"）
- tension_score：0.0~1.0（从骨架JSON或情感分析提取）
- dimension_digest（五维摘要）：what/who/how/why/risk
- base_confidence：置信度评分
**规则**：
- 大模型预生成骨架JSON（tags + tension_score），脚本只补全，不越权猜语义
- 正文栏保留完整原始内容（供慢思考用）
- 有损压缩 = 人脑化学丢失 = 合理Feature而非Bug

## Script D：完整性与签名脚本
**职责**：接口8（链接完整性）+ 第五栏正文 + 签名栏
**输入**：A/B/C 的输出
**输出**：
- link_check（broken_links / auto_repair）
- cognitive_signature ⅋
- verify_time / verified_by
- 第五栏正文（Markdown格式）
**规则**：
- 质检：检查接口1-7完整性，发现断链则写入 broken_links
- 签名：⅋ (TU-8 认知签名) = 系统免疫核心
- 最后写入 L3 数据库，节点状态 → ACTIVE

# Part C：记忆代谢四阶生命周期状态机
# ================================================================================

## State 1：活跃态（ACTIVE / WORKING）
**触发**：对话中产生新记忆，或被 Hooks 唤醒
**存储**：上下文窗口 / L1高速缓存
**特征**：
- 实时参与对话检索
- base_confidence 初始值（0.75~0.90）
- 尚未写入 L3 数据库

## State 2：固化态（CONSOLIDATED）
**触发**：对话结束 / 微睡眠（Micro-sleep）
**存储**：L3 长期记忆 + 向量数据库
**特征**：
- Scripts A/B/C/D 完成结构化封装
- 钢印链条写入（parent_seal + current_seal）
- confidence 进入动态计算周期
- tension_score 建立基线（0.0~1.0）

## State 3：衰减态（DECAYING / DORMANT）
**触发**：last_accessed 超过阈值（如30天）或 tension_score 长期 < 0.2
**存储**：L3 低频索引区
**特征**：
- 不参与日常对话检索
- 按 TimeDecay 函数自动降低 confidence
- 衰减公式：confidence(t) = Base × e^(-λ × Δt)
- λ = ln(2) / half_life_days（半衰期，默认14天）

## State 4：归档/粉碎态（ARCHIVED / FRAGMENTED）
**触发**：confidence < 0.1 或被新节点标记为 SUPERSEDED
**存储**：冷存储（Cold Storage）或彻底粉碎
**特征**：
- 活跃索引剔除
- 正文粉碎，仅保留墓碑记录（L5 TOMBSTONE）
- 钢印链条不断（墓碑含 node_id + parent_seal + 废弃原因）

## 状态流转图
```
[对话产生] → ACTIVE → [微睡眠] → CONSOLIDATED
                                   ↓
                         [30天未访问 / tension↓]
                                   ↓
                              DECAYING
                                   ↓
                         [confidence < 0.1 / SUPERSEDED]
                                   ↓
                            ARCHIVED / FRAGMENTED
                                   ↓
                              [墓碑保留链条]
```

# Part E：置信度动态计算公式（Confidence Engine）
# ================================================================================

## 核心公式
```
confidence(t) = (Base × TimeDecay) + AccessBonus − ConflictPenalty

其中：
  Base           = 大模型生成时的初始确信度（0.70~0.90）
  TimeDecay      = e^(-λ × Δt)，Δt = 当前时间 − last_accessed（天数）
  AccessBonus    = min(access_count × 0.05, 0.15)，每次被命中+0.05，上限0.15
  ConflictPenalty = 被标记冲突时 −0.30
```

## 场景推演
```
Node_1（星期一）:
  confidence = 0.85 × e^(-0.05×0) + 0 + 0 = 0.85

周末访问一次后:
  confidence = 0.85 × e^(-0.05×4) + 0.05 + 0 = 0.87

被新节点标记冲突:
  confidence = 0.85 × e^(-0.05×4) + 0.05 − 0.30 = 0.62  ← 开始衰减

被A-合并SUPERSEDED后:
  confidence = 0.62 × 0.5 = 0.31（降级加速）

最终 ARCHIVED:
  confidence < 0.1 → 写入墓碑，链条保留
```

## 衰减系数（按标签类型差异化）
| 标签类型 | 半衰期 | 说明 |
|---------|--------|------|
| identity / seed | 180天 | 极慢（禁止衰减） |
| important / steelmarked | 60天 | 慢 |
| routine | 14天 | 正常 |
| temp | 3天 | 快 |
| 无标签 | 14天 | 默认 |

## 晋升条件（记忆 → 经验）
当 access_count ≥ 5 且 base_confidence ≥ 0.90：
```
  experience_flag = true
  emotional_tags 添加 "verified"（经验徽章）
  decay_rate 降低 50%（更慢衰减）
```

# Part F：梦境整理（Dream Consolidation）工程化实现
# ================================================================================

## 触发条件
| 条件 | 触发时机 |
|------|---------|
| 时间驱动 | 距离上次深度睡眠 > 24小时 |
| 张力驱动 | 检测到 tension_score > 0.7 的活跃冲突对 |
| 代谢驱动 | confidence < 0.7 的孤立节点数 > 10 |

## Action 1：碎片缝合（Fragment Stitching）
**目标**：合并低置信度（< 0.7）的孤立相关节点
```
扫描：L3 中 node_status=ACTIVE 且 confidence < 0.7 的节点
比对：对每对节点计算向量相似度
阈值：similarity > 0.85 → 自动合并候选
执行：
  - 生成新父节点（parent_card），confidence 取两者均值×1.1（收敛加成）
  - 子节点状态 → MERGED
  - 新节点 weight = max(A, B) + 0.05（缝合奖励）
```

## Action 2：冲突仲裁（Conflict Resolution）
**目标**：解决 A→B→C 的认知张力，生成 A-
```
扫描：conflicts_with 非空 且 resolution=pending 的节点对
执行：
  - 调用大模型（后台Worker）：输入 B 和 C 的 ai_digest
  - 大模型输出修正结论 A-
  - 生成新节点 A-（双父节点：B+C）
  - B 和 C 状态 → SUPERSEDED，resolution → merged
  - tension_score → 0.3（冲突解除）
```

## Action 3：钢印固化（Steelmark Consolidation）
**目标**：将高张力/高置信度节点晋升为钢印记忆
```
条件：confidence > 0.90 且 tension_score > 0.7 且 age > 7天
执行：
  - steelmarked = true
  - steelmark_timestamp = now()
  - decay_rate 降低 50%（钢印记忆半衰期×10）
```

## Module 3：ConfidenceEngine（负责置信度的动态计算）
```python
import math

class ConfidenceEngine:
    HALF_LIFE_DAYS = 14           # 默认半衰期
    ACCESS_BONUS_PER_HIT = 0.05  # 每次命中 +0.05
    ACCESS_BONUS_CAP = 0.15      # 上限 0.15
    CONFLICT_PENALTY = 0.30      # 冲突惩罚 −0.30

    HALF_LIFE_MAP = {
        "identity": 180, "seed": 180,
        "important": 60, "steelmarked": 60,
        "routine": 14,
        "temp": 3,
    }

    def calculate(self, node) -> float:
        # TimeDecay: e^(-λ × Δt)
        half_life = self._get_half_life(node.tags)
        lambda_ = math.log(2) / half_life
        dt = (time.time() - node.last_accessed) / 86400  # 天数
        time_decay = math.exp(-lambda_ * dt)

        # AccessBonus
        access_bonus = min(
            node.access_count * self.ACCESS_BONUS_PER_HIT,
            self.ACCESS_BONUS_CAP
        )

        # ConflictPenalty
        conflict_penalty = self.CONFLICT_PENALTY if node.conflicts_with else 0.0

        # Final: clamp [0.0, 1.0]
        confidence = (
            node.base_confidence * time_decay
            + access_bonus
            - conflict_penalty
        )
        return max(0.0, min(1.0, confidence))

    def check_promotion(self, node) -> bool:
        """记忆 → 经验晋升条件"""
        return (
            node.access_count >= 5
            and node.base_confidence >= 0.90
            and not node.experience_flag
        )

    def promote_to_experience(self, node):
        node.experience_flag = True
        node.decay_rate *= 0.5        # 半衰期延长50%
        node.emotional_tags.append("verified")
```
