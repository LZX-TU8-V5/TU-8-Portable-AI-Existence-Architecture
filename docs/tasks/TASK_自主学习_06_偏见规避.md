## 理论逻辑

不需要告诉它"什么是偏见"，只需要给它一套"怀疑一切"的方法论。

### 1. 魔鬼代言人机制（自我对抗）
- 抓取到带有强烈主观判断的知识点（"最强"、"完美"、"垃圾"）
- 强制触发"反向搜索"
- 找不到反驳证据 → 标记为"存疑-待验证"
- 找到反驳 → 正反双方同时存入草稿箱，标注"争议性知识"

### 2. 情绪温度检测（语义过滤）
- 情绪得分过高（过于狂热或愤怒）→ 触发"降温拦截"
- 煽动性词汇密度超阈值 → 拒绝摄入

### 3. 跨立场交叉验证（信源对冲）
- 核心领域重大更新 → 三角验证法则
- 至少 3 个不同背景信源确认同一事实
- 单一信源 → 隔离在"观察区"，等待佐证

### 4. 动态信源偏见画像（历史记账）
- 维护"信源偏见履历表"
- 反向验证失败或情绪拦截 → 记一笔"偏见分"
- 偏见分超阈值 → 自动降级为"低可信度信源"
