## 理论逻辑

给它装上"情绪免疫系统"。带节奏的内容善于伪装成技术文章，但煽动性是其本质特征。

### 1. 情绪温度"过载检测"（第一感）
- 计算煽动性词汇密度（"吊打"、"完爆"、"千万别用"、"内幕"、"震惊"）
- 统计感叹号数量（单篇文章感叹号 > 3 → 预警）
- 反问句频率（连续反问如"难道不是吗？"、"你还不XX？"）
- 情绪极性 > 阈值 → 触发"降温拦截"，不进草稿箱

### 2. 技术拉踩"强制平衡"（第二感）
- 文中出现"XX 比 YY 好 100 倍"等单一结论
- 触发"强制平衡程序"：自动检索 YY 的正面用例
- 正反两方均未找到充分证据 → 标记为"存疑-营销内容"

### 3. 利益冲突溯源（第三感）
- 提取文中提及的商业产品名称
- 核查作者背景（LinkedIn / GitHub / 个人博客）
- 存在商业关联（付费推广/自营产品/竞品攻击）→ 标记为"利益相关-谨慎参考"
- 自动降低信源信誉分

### 4. 逻辑断层"定量核查"（第四感）
- 宏大结论必须有定量数据支撑
- 样本量 n < 10 的统计结论 → 标记"存疑-小样本"
- 图表横纵坐标被截断或缩放失真 → 标记"数据可疑"
- 百分比计算错误或来源不明的数字 → 标记"统计存疑"

### 5. 跨视角"多棱镜"验证（第五感）
- 发现带节奏迹象 → 触发"多棱镜程序"
- 主动抓取该话题的其他视角文章（反对派、中立派、行业报告）
- 打包存入"多棱镜档案"，附带"结论分歧摘要"
