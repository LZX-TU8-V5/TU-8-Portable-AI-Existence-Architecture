## 理论逻辑

最关键的一步，让"梦境"模块大显身手。

### 1. 草稿箱机制
- 自主学来的东西，先不写进核心记忆区
- 先丢进"草稿箱"或"短期缓存"
- 相当于人类的" working memory"

### 2. 梦境复盘
- 在后台空闲（梦境阶段）整理"草稿箱"
- 把重复出现的、验证过正确的信息 → 提炼成精简知识点 → 写入长期记忆
- 把看了一次就没用的噪音 → 直接丢弃（遗忘）
