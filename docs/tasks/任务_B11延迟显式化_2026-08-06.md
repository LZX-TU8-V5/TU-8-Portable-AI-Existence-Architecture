## 一、核心设计

**Qwen 原则③**：延迟是一等公民，ring_buffer[A][t-3]→B，不能省。

### RingBuffer 类

```python
class RingBuffer(capacity=64):
    push(tick, data)   # 按 tick 索引写入，超容覆写最旧
    get(tick)           # 按 tick 读取，无则 None
    get_latest(n)       # 最近 n 个（newest first）
    to_list()           # 全部（oldest first）
    get_oldest_tick()   # 最旧 tick 号
```

**tick 索引**：RingBuffer 不按数组位置，直接用全局 tick 号映射。这是关键——同一个 tick 对所有引擎同步。

### get_delayed_context(target)

按目标引擎的 delay_ticks 读历史快照：
```
delay=0 → 读当前快照（立即响应）
delay=1 → 读 tick-1（上一轮）
delay=3 → 读 tick-3（3轮前）
无历史 → fallback 当前快照（第一轮正常）
```

## 二、改造 evaluate()

**改造前**：evaluate() 只读传入的 context，无历史概念。
**改造后**：evaluate() 调用 get_delayed_context() 自动注入延迟上下文。

```python
def evaluate(self, target, context=None):
    effective = self.get_delayed_context(target)  # B11: 延迟上下文
    if context:
        effective.update(context)  # 当前快照覆盖
    # ... 继续求值
```
