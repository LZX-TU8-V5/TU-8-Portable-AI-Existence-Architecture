## 核心架构决策

### 1. 双轨注入机制

| 机制 | 位置 | 职责 | 注入频率 |
|------|------|------|---------|
| Soul 注入 | SOUL.md | 身份锚点 + 价值观 | 每轮必注（<500 Token） |
| 外部注入 | AGENTS.md | 记忆模板 + 工作流协议 | 每轮必注或按需 |

**公式**：`[最终 Prompt] = [Soul 注入] + [外部节律注入] + [用户当前消息]`

### 2. 记忆模板字段设计

| 字段 | 类型 | 说明 |
|------|------|------|
| category | 闭集枚举 | 索引引擎（6类） |
| sentiment_signal | 闭集枚举 | 情绪信号（5档） |
| event | 文本 | 事件描述（去噪后） |
| decision | 文本 | 核心决策 |
| impact | 文本 | 意义与影响 |
| confirmation_status | 状态枚举 | 确认状态（5态） |
| confidence_score | 浮点数 | 置信度（0.0-1.0） |
| completeness_signal | 枚举 | 认知完整性标记 |

### 3. 四重防御机制

| 防线 | 机制 | 触发条件 | 动作 |
|------|------|---------|------|
| 第1重 | 信息增量熔断 | 零增量废话 | `[SKIP_MEMORY]` |
| 第2重 | 情绪-事实解耦 | 情绪化表达 | 过滤虚假事实，保留情绪 |
| 第3重 | 双向确认状态机 | ACK/NACK | 状态回写（pending→confirmed/rejected） |
| 第4重 | 置信度光谱 | 弱确认 | confidence_score 标记 |
