# B1+B2 同步 tick + 注册表 — 任务报告（2026-08-02）

## 问题

**B1**：各 cron 独立进程按各自 interval 串行跑，无全局 tick/快照同步。
**B2**：state 文件散落 `_agent_memory/*.json`，无中央注册表，静默失败不可见。

## 解决方案

**`engine_registry.py`**（13KB）：全局引擎注册表 + tick 协调层。

### 核心接口

```python
from engine_registry import get_registry, tick_engines

reg = get_registry()
statuses = reg.refresh_all_status()   # OK/STALE/DEAD
can_run, reason = reg.can_run('orb_state_writer')  # 依赖检查
new_tick = reg.advance_tick()         # 全局 tick 推进
tick_engines(['surface_tension_decay', 'orb_state_writer'])
```

### 注册表 Schema（`engine_registry.json`）

```json
{
  "tick": 2,
  "last_sync": 1722570600.0,
  "engines": {
    "orb_state_writer": {
      "state_file": "_agent_memory/orb_state.json",
      "max_age_s": 600,
      "deps": ["surface_tension_decay"],
      "deps_mode": "and",
      "status": "OK",
      "last_tick": 2
    }
  }
}
```

## daemon 改造

`cron_daemon.py`:
- `run_script()`: 跑前 `can_run()` 检查依赖，跳过不满足的引擎
- `daemon_loop()`: 每次循环 `advance_tick()` 推进全局 tick，跑后更新状态
