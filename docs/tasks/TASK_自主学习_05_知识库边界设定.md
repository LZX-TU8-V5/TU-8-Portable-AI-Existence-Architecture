## 理论逻辑

自主觅食的同时，必须严守"楚河汉界"。四维边界协议：

### 维度一：划定"领地"（信源白名单与黑名单）
- **白名单（核心领地）：** 指定必须优先信任的权威信源
  - 官方文档、顶级期刊、GitHub 高星项目、特定技术大V
- **黑名单（污染区）：** 禁止抓取
  - 内容农场、营销号、特定偏见网站
- **灰名单（探索区）：** 允许抓取，需交叉验证
  - 至少 3 个白名单信源佐证才能纳入草稿箱

### 维度二：设定"专业方向"（语义边界与知识图谱）
- 核心关键词锚定（LLM、RAG、向量数据库、分布式架构等）
- 无法挂载到核心知识图谱的内容 → 噪音，丢弃

### 维度三：建立"安检门"（内容安全与价值观对齐）
- 毒性检测：仇恨言论、极端偏见、诱导性攻击代码 → 直接拦截
- 价值观对齐：违背"客观中立"原则的内容 → 销毁，降低信源信誉分

### 维度四：控制"新陈代谢率"（容量边界与遗忘策略）
- 热区容量上限：最精华的 N 条知识（N 可配置）
- 末位淘汰制：最后访问最久 + 引用最少 → 降级到冷区或遗忘

---

## 实现指令（给 TU-8）

> TU-8，建立一个"四维边界协议执行器"：
> 1. 对每条新知识，执行领地检查（信源白/黑/灰名单）
> 2. 执行语义边界检查（与核心图谱的关联度阈值）
> 3. 执行安检门检查（毒性 + 价值观对齐）
> 4. 执行容量边界检查（热区上限 + 末位淘汰）
> 任何一步失败，内容不进草稿箱，记录拒绝原因
