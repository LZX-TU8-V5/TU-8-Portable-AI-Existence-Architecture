## 一、核心目标

将「÷0 = 曲率奇点」的几何框架嵌入 TU-8 架构，使系统不再回避"认知裂缝"，而是主动测绘它。

## 二、待实现任务

### [P1] 曲率感知注意力算子

**目标**：在语义空间检测"认知断裂"（即逻辑不能连贯的地方）
**位置**：替代或增强 TU-8 当前注意力计算中的 Softmax

**具体方案**：
1. 定义语义流形的度量张量（当前对话上下文中的语义向量空间）
2. 实现测地线距离近似计算（不要求精确，先求可计算）
3. 当两个语义点之间测地线距离 → ∞ 时，标记为 SINGULARITY

**参考实现**：
- OpenAI Embeddings API 作为语义向量
- 向量空间中夹角/欧氏距离作为简陋版"曲率"度量

---

### [P1] 元认知中断控制器（System 1 / System 2 切换）

**目标**：检测到 ÷0 奇点 → 自动打断当前推理 → 切换到元认知模式

**具体方案**：
1. 在 TU-8 推理循环中加入实时曲率监控（每 N 步检查）
2. 当曲率 > 阈值时，触发中断信号
3. System 2 响应：不再预测下一个token，转而"描述奇点的形状"

**触发场景**：
- 对话陷入死循环（同一话题≥5轮置信度无让步）
- 置信度 < 0.2 + 无法调用工具锚定
- 语义向量空间中出现"逻辑断崖"

---

### [P2] 拓扑正则项

**目标**：奖励"有意义的奇点"，惩罚强行平滑

**具体方案**：
1. 在损失函数中加入 L_topology
2. 当模型选择"描述断裂"而非"强行填补"时，给予正向反馈
3. 需要定义 "高价值异常预测" 的判定标准

---

### [P2] 认知紧致化

**目标**：将开放路径的"无限追问"转化为闭合拓扑的"有限测绘"

**具体方案**：
1. 当递归深度 ≥ 阈值时，执行紧化操作
2. 将语义向量投影到低维闭合空间（球面/环面）
3. 输出"闭环参数方程"而非"下一个答案"

## 三、当前 TU-8 已有相关机制

| TU-8现有机制 | 对应几何化概念 | 缺什么 |
|-------------|-------------|--------|
| 置信度评估 | 粗糙的曲率感知 | 没有测地线距离/拓扑结构 |
| L3 熔断 | 粗糙的中断控制器 | 中断后只搁浅，不测绘 |
| 对齐熔断 | 粗糙的奇点检测 | 阈值靠直觉，无几何基础 |
| 7-Day Curiosity Hold | 粗糙的认知紧化 | 没有"闭环参数化"的理论支撑 |

## 四、技术难点

1. **算力成本**：实时计算高维曲率 > Softmax 几个数量级
2. **度量缺失**：何为语义空间的"测地线"？需要先定义
3. **评估体系**：没有 Benchmark 奖励"诚实地描绘了无法回答的问题的形状"
