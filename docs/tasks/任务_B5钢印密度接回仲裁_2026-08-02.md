# B5 钢印密度接回仲裁（steel_density → contradiction_arbitration）

## 问题

文档诊断：TU-8 养护机制（steel_density）存在，但仲裁只读布尔值 `steel_mark_present`，不读密度强度——钢印只是展示指标，不决定谁赢。

## 改动

### 改1：`contradiction_arbitration.py` STEEL_MARK 分支三段化

```python
# 规则 5：价值观不匹配（钢印密度调制）
if conflict_type == ConflictType.VALUE_MISMATCH:
    if steel_mark_strength < 0.3:
        # 低密度 → 降权，脆弱钢印不能封锁边缘价值观
        result.priority = Priority.EQUAL
        result.outcome = ArbitrationOutcome.ARBITRATE
        # precedent: "价值观冲突但钢印密度低(10%)，视为同级冲突，由判例库裁决。"
    elif steel_mark_strength < 0.6:
        # 中密度 → 宽松阈值
        result.priority = Priority.STEEL_MARK
        result.needs_grounding = tu8_confidence > 0.9
        result.outcome = ArbitrationOutcome.ARBITRATE
        # precedent: "钢印密度中等(40%)，仅高置信度(50%)时锁定。"
    else:
        # 高密度 → 原逻辑
        result.priority = Priority.STEEL_MARK
        result.needs_grounding = tu8_confidence > 0.8
        if result.needs_grounding:
            result.outcome = ArbitrationOutcome.STEEL_HOLDS
        else:
            result.outcome = ArbitrationOutcome.ARBITRATE
        # precedent: "价值观核心层受钢印保护，高置信度时不接受覆盖。"
```

### 改2：`alignment_verify.py` 从锚点文件读真实密度

```python
anchors_path = WS / "secure_vault" / "anchors.json"
steel_mark_strength = 0.5  # 默认值
try:
    if anchors_path.exists():
        anchors_data = json.loads(anchors_path.read_text(encoding="utf-8"))
        anchors = anchors_data.get("anchors", []) if isinstance(anchors_data, dict) else anchors_data
        sealed = [a for a in anchors if len(a.get("seal_ids", [])) > 0]
        if len(anchors) > 0:
            steel_mark_strength = len(sealed) / len(anchors)
except:
    pass

arb.arbitrate(..., steel_mark_strength=steel_mark_strength)
```

"养护"不再是展示指标。钢印密度真实的在决定优先级。
