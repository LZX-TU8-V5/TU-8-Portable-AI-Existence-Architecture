# 任务_B6茧房防御接入dispatch_2026-08-06

## 目标
把 EntropyAwareRouter.route_with_defense() 接入 tu8_dispatch，使茧房防御进入运行时路由。

## 根因

- `EntropyAwareRouter.route_with_defense()` 存在但从未被调用
- `entropy_guard.py` 已接入 cron（监控+播种），但真数据需要路由接管点
- tu8_dispatch 的 `ContextAssembler.assemble()` 是唯一经过每条对话的隐式路由入口

## 实现

### `src/dispatch_cocoon_router.py`（6259B）

- `CocoonAwareRouter`：封装 EntropyAwareRouter + Intent→Chain 候选映射
- `INTENT_CHAIN_CANDIDATES`：9 种意图 × 3-7 条候选链，含置信度
- `route(intent)`：返回 `(selected_chain, cocoon_report, candidates)`
- `CocoonAwareRouter(entropy_guard=None)`：guard 为 None 时用置信度排序回退

### `tu8_dispatch.py` 接入（L498-510）

assemble() 末尾新增：
```python
assembly.metadata['cocoon'] = cocoon_report
assembly.metadata['routed_chain'] = selected_chain
```

茧房状态首次进入运行时上下文，成为 LLM 可感知的信息。
