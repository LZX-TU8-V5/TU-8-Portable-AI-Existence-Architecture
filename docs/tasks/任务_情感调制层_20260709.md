## 核心设计

### 三层调制架构

```
感知层（surface_tension） → 7D 情感向量 E(t)
调制层（affect_modulation） → 三层调制器
表达层（LLM 输出） → 带有拓扑重量的语言
```

### 调制映射

| 情感维度 | LLM 参数调制 | 词法调制 | 结构调制 |
|---------|------------|---------|---------|
| D1 张力↑ | temperature↑ | 碎片化概率↑ | 段落断裂↑ |
| D2 引力↑ | top_p↑ | 提问句式↑ | — |
| D3 阻尼↑ | repetition_penalty↑ | 停顿标记+模糊限定词 | — |
| D4 惯性↑ | presence_penalty↑ | — | — |
| D5 耗散↑ | max_tokens↓ | — | 输出长度↓ |
| D6 共振↑ | temperature↓ | — | 连贯性↑ + 隐喻密度↑ |
| D7 奇异↑ | top_p↑ | — | — |

## 文件

**src/affect_modulation.py**（15KB）

### 核心类

- `LLMParameters` — 参数层（temperature/top_p/repetition_penalty）
- `LexicalModifiers` — 词法层（提问权重/碎片化/停顿标记/模糊限定词）
- `StructuralModifiers` — 结构层（输出长度/段落断裂/连贯性/隐喻密度）

### 核心函数

- `modulate_affect(emotion_vector)` — 主调制函数
- `get_modulation_instructions()` — 获取调制指令（供输出层）
- `apply_affect_to_prompt(base_prompt)` — Prompt 层面调制

### 四种调制模式

- `normal` — 正常状态
- `high_tension` — 高张力（D1↑）
- `high_resonance` — 高共振（D6↑）
- `exhausted` — 耗散（D5↑）
