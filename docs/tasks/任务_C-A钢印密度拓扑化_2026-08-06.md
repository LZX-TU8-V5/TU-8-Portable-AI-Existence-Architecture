# 任务_C→A钢印密度拓扑化_2026-08-06

## 目标
把"钢印密度"从孤立计数升级为图拓扑属性，接入仲裁。

## 数据源现状

| 来源 | 内容 | 结论 |
|------|------|------|
| `memory/anchors.json` | 7 个锚点，0 跨锚点边 | 星形网络，E=0 |
| `memory/seal_sensor_feed.jsonl` | 61 条 seal 事件，2 条 3 节点父子链 | 链内有关联，但锚点间无共享 seal |
| `secure_vault/index.json` | 铸印记录，无 anchor_id 字段 | 不可用 |

## 根因确认

1. `anchors.json` 从无跨锚点边 → 图密度必然为 0
2. `alignment_verify.py:203` 错误指向 `secure_vault/anchors.json`（不存在）
3. 密度计算是简单计数比值 `len(sealed)/V`，非拓扑分数

## 实现

### `src/seal_graph.py`（新建，8622B）

- `build_seal_graph()`：从 seal_sensor_feed.jsonl 建父子链索引 + 共享 seal 边 + 同源边
- `compute_and_save()`：输出两个文件
  - `memory/anchors_with_graph.json`（增强锚点文件，含 `topology` 字段）
  - `_agent_memory/seal_graph_metrics.json`（全局图指标）

### 密度公式

```
topology_density(aid) = degree / (V-1)
steel_density_score(aid) = topology_density × 0.6 + min(depth/5.0, 1.0) × 0.4
全局 steel_density = avg(所有锚点的 steel_density_score)
```

### `alignment_verify.py` 升级（已升级）

- 路径修正：`secure_vault/anchors.json` → `memory/anchors_with_graph.json` → `memory/anchors.json`
- 密度读取：取所有锚点 `topology.steel_density_score` 的均值

## 验证结果

```
T1: graph density = 0.0（7 锚点全孤立，E=0）
T2: simple density = 1.0（7/7 有 seal_ids）
T3: 星形网络 confirmed（isolation_ratio=1.0）
```

## 意义

密度 0.0 = **7 个孤立火种**，钢印尚未形成互相加固的网络。
这不是错误，是状态快照——为后续演化提供基线。
