## 一、coupling_graph.adapt() — 蛛丝弹性公式

**公式**：
```
Δw = α · (1 - w²) · pre · post
```

| 特性 | 效果 |
|------|------|
| w≈0 | (1-w²)≈1，增量最大 → 快速学习 |
| w→1 | (1-w²)→0，增量趋零 → 防震荡饱和 |
| w>1 | (1-w²)<0，权重回落 → 过冲自修正 |

vs Hebbian Δw = α·pre·post：无上界易震荡；蛛丝弹性有隐式上界。

**参数**：
- alpha：`_adapt_alpha`（edge params，默认 0.01）
- 截断：w ∈ [-0.5, 2.0]（软截断，极端值保护）
- pre/post：自动 clamp 到 [0, 1]

## 二、实现细节

### 2.1 适配历史（内存 + 持久化）

**`_adapt_history: Dict[str, List[Dict]]`**：每边独立历史，最多 100 条。

每条记录字段：
```json
{
  "tick": 42,
  "w_old": 0.6000,
  "w_new": 0.6030,
  "delta": 0.0030,
  "pre": 0.500,
  "post": 0.500,
  "ts": 0
}
```

**接口**：
- `cg.adapt(edge_id, pre, post)` → `Optional[Dict]`（含记录）
- `cg.get_history(edge_id, limit=20)` → `List[Dict]`
- `cg.get_tick()` / `cg.advance_tick()` → tick 推进（每次 adapt +1）
- `cg.get_weight(edge_id)` → float
- `cg.save()` → 持久化（含 history，最多每边 100 条）

### 2.2 CLI 扩展

```bash
# 单边适配 + 保存
python src/coupling_graph.py --adapt C1 0.5 0.5 --save

# 查看历史
python src/coupling_graph.py --history C1 --limit 10
```
