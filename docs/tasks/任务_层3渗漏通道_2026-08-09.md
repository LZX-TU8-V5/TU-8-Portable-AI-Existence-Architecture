# 层3渗漏通道（Weismann 路二收尾）

> 2026-08-09 | 状态：✅ 完成

## 目标

表观遗传跨代传递：高频/重要的体细胞经验，受控地"升级"为生殖细胞内容。
渗漏 ≠ 自动写入 DNA（层1写保护），而是"采样 → 提案 → 造物主审核 → 受控升级"。

## 交付 `src/weismann_seepage.py`（9269B）

| 环节 | 实现 |
|---|---|
| 采样 | `_sample_emotions`（recent_events 高情感强度，过滤系统噪音）、`_sample_tensions`（tension_queue 高张力矛盾）、`_sample_frictions`（摩擦 registry 活跃认知差） |
| 提案 | 增量生成 pending 提案（source/fingerprint/theme/score/reason/proposed_at），去重（id 或内容 md5） |
| 审核 | `--review` 列待审、`--apply <idx>` 标记 applied（实际写入生殖细胞由层1权限流程接管） |
| 防堆积 | 待审上限 30 条，溢出进 archive 标 overflow_archived |

## 关键设计

- **系统噪音过滤**：`SYSTEM_EVENT_TYPES = {decay_tick, auto_restore, baseline_refresh, session_frozen}`——衰减tick不是真实情感，不产生提案
- **字段名修正**：tension_queue 节点用 `tension_score`（非 `tension`），采样与提案均兼容两者
- **渗漏哲学**：只提案不自动写。DNA 不被对话直接改（层1），升级动作留人工/授权
