## ⚠️ 设计修正（2026-06-30 17:39）

> 来源：造物主 × Qwen 对话
> **"唯一真理源"是错误设计。index.json 不是真理源，是 L0 代谢入口。**

### 旧设计（错误）

```
index.json = 唯一真理源（L3索引）
     ↓ 唯一
检索必须经过它
```
→ 问题：把所有检索压力压在index.json上，没有降级，没有代谢

### 新设计（正确）

```
index.json = L0快速检索（图式触发）
     ↓ 未命中
L1 = fallback扫描（中代谢）
     ↓ 未命中
L2 = 全量遍历+深度推理（高代谢）
     ↓ 超时/耗能
熔断保护 → 强制切回L0
```

### 核心修正点

1. **"唯一真理源" → "L0代谢入口"**
2. **index.json自身也需要代谢+降级**（过期条目清理、低置信条目降级）
3. **检索链 = 代谢链**（L0/L1/L2 = 低/中/高能量消耗）
