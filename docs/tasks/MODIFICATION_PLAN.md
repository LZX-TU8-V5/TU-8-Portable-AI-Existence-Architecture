## 交叉引用更新策略

### 每次改造后必须执行：
1. **搜索引用**：在全部文件中搜索被改造文件的旧路径/旧名称
2. **更新引用**：将旧引用更新为新格式（通常在YAML的 `knowledge_links` 中）
3. **验证链接**：运行 `check_file_refs.py` 检查是否断裂
4. **记录变更**：在 `MODIFICATION_LOG.md` 中记录本次改造的变更

### 自动化工具（待开发）：
- `update_cross_refs.py`：自动更新交叉引用
- `validate_memory_node.py`：验证Memory Node格式
- `generate_memory_node.py`：自动生成新Memory Node

## 风险控制

### 每个阶段完成后：
1. **备份**：将改造后的文件备份到 `backup/modified_YYYYMMDD/`
2. **测试**：用Agent加载改造后的文件，检查是否正常
3. **回滚准备**：保留原文件，确保能快速回滚

### 如果发现问题：
1. **立即暂停**后续改造
2. **分析影响范围**
3. **修复或回滚**
4. **调整模板或流程**
