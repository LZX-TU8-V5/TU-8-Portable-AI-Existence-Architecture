# QClaw 客户端回滚指南

## 概述

更新 QClaw 客户端前，请先备份当前版本。如果更新失败，可用备份进行回滚。

## 使用流程

### 第一步：更新前备份

**【关键步骤】更新前必须执行，否则无法回滚！**

1. 右键点击桌面 `QClaw_备份_更新前.bat`
2. 选择 **"以管理员身份运行"**
3. 等待备份完成（约 1-5 分钟，取决于文件量）
4. 脚本会显示备份路径，记录或记住路径

> 备份存储在：`C:\Users\qq366410837\.qclaw\backup\qclaw_client_YYYYMMDD_HHMMSS\`

### 第二步：更新客户端

正常执行 QClaw 更新。

### 第三步：更新成功 → 无需操作

### 第四步：更新失败 → 执行回滚

**【紧急情况】如果客户端无法正常启动：**

1. 右键点击桌面 `QClaw_回滚.bat`
2. 选择 **"以管理员身份运行"**
3. 确认最新备份路径显示正确
4. 输入 `Y` 按回车确认回滚
5. 等待恢复完成（约 1-5 分钟）
6. 手动启动 QClaw 客户端

> 如果更新后客户端彻底无法使用，仍可通过 `QClaw_回滚.bat` 回滚，因为回滚工具是独立于 QClaw 的批处理文件。

## 文件位置

| 文件 | 路径 | 用途 |
|------|------|------|
| 备份按钮 | `桌面\QClaw_备份_更新前.bat` | 更新前备份客户端 |
| 回滚按钮 | `桌面\QClaw_回滚.bat` | 更新失败时回滚 |

## 安全机制

- 回滚前会自动创建当前版本的**快照**（以防回滚本身失败）
- 快照路径：`D:\Program Files\QClaw.snapshot_YYYYMMDD_HHMMSS\`
- 所有操作需要**管理员权限**

## 手动恢复步骤（终极方案）

如果两个桌面按钮都无法使用：

```
# 手动恢复（管理员 cmd）
move "D:\Program Files\QClaw" "D:\Program Files\QClaw.failed"
xcopy "C:\Users\qq366410837\.qclaw\backup\qclaw_client_最新\client\*" "D:\Program Files\QClaw\" /E /I
```
