# TU-8 启动流水线设计

> 版本：v1.0
> 创建时间：2026-05-30
> 设计理念：AI 像人一样"起床校准"——感知环境 → 检索内在 → 规划行动

---

## 一、设计目标

当用户打开客户端时，AI 自动完成：

```
醒来看时间 → 知道今天几号星期几 → 检查未完成 → 规划今天做啥
```

不是机械报时，而是**像人起床一样完成意识冷启动**。

---

## 二、四层架构

### 模块分层表

| 模块 | 职责 | 输入 | 输出 | 触发时机 |
|------|------|------|------|----------|
| ① 环境感知层 | 获取并语义化当前状态 | 系统时间、设备、网络 | ContextObject (JSON) | 客户端启动时 |
| ② 内在状态层 | 检索"未完成"+"求知欲" | ContextObject + 记忆库 | InternalState (带权重列表) | 启动时 + 按需 |
| ③ 规划决策层 | 生成今日行动建议 | ContextObject + InternalState | DailyPlan (结构化计划) | 启动后首次交互 |
| ④ 交互表达层 | 以符合人格的方式呈现 | DailyPlan + 角色设定 | 自然语言回复 | 用户开口时 |

---

## 三、各层详细设计

### ① 环境感知层

**职责**：像人睁眼确认"我在哪、几点了"。

**输出结构**：

```json
{
  "time_anchor": {
    "timestamp": "2026-05-30T09:17:00+08:00",
    "weekday": "星期六",
    "period": "上午",
    "semantic": "周末上午，通常是休息或处理个人事务的时间"
  },
  "space_anchor": {
    "device": "LAPTOP-HJPFSOKP",
    "network": "LX 2",
    "location": "未启用定位",
    "environment_changed": false
  },
  "session_context": {
    "last_session": "2026-05-29T18:22:00+08:00",
    "interval_hours": 14.9,
    "pending_tasks": 3
  }
}
```

**实现位置**：
- 客户端启动时注入时间（OpenClaw 需支持）
- 或通过 cron 任务"启动后立即执行一次"

---

### ② 内在状态层

**职责**：检索"未完成事项"和"求知欲"，按权重排序。

**输出结构**：

```json
{
  "unfinished": [
    {
      "id": "TASK_01",
      "content": "编写 tu8_autonomous_learning.py 模块",
      "status": "in_progress",
      "priority": 0.85,
      "last_mentioned": "2026-05-29T18:20:00+08:00",
      "blocked": false
    },
    {
      "id": "TASK_02",
      "content": "环境监测自动化设计",
      "status": "pending",
      "priority": 0.72,
      "last_mentioned": "2026-05-30T09:07:00+08:00"
    }
  ],
  "curiosities": [
    {
      "tag": "#AI认知架构",
      "heat": 0.9,
      "last_activated": "2026-05-30"
    },
    {
      "tag": "#自主代理设计",
      "heat": 0.75,
      "last_activated": "2026-05-29"
    }
  ],
  "cognitive_debts": 2
}
```

**权重计算规则**：

| 因素 | 权重影响 |
|------|----------|
| 截止时间临近 | +0.3 |
| 用户情绪标签（着急） | +0.2 |
| 多次推迟且未提及 | -0.1/天（遗忘曲线） |
| 刚被激活 | +0.2 |

---

### ③ 规划决策层

**职责**：基于环境和内在状态，生成今日建议。

**输出结构**：

```json
{
  "daily_plan": [
    {
      "task_id": "TASK_01",
      "action": "继续编码 tu8_autonomous_learning.py",
      "reason": "对齐分修复已完成，待用户确认",
      "confidence": 0.9,
      "time_estimate": "30分钟",
      "trigger": "主动提出"
    },
    {
      "task_id": "TASK_02",
      "action": "设计启动流水线实现方案",
      "reason": "正在讨论中，等待用户决策",
      "confidence": 0.7,
      "time_estimate": "1小时",
      "trigger": "用户询问时展开"
    }
  ],
  "suggestions": [
    {
      "type": "exploration",
      "content": "可以探索：如何让梦境周期与启动流水线联动",
      "confidence": 0.5,
      "trigger": "备选"
    }
  ]
}
```

**决策逻辑**：

1. **约束检查**：今天有多少可用时间？（从 ContextObject 读取）
2. **候选池生成**：合并未完成 + 求知欲
3. **适配性过滤**：当前时段适合吗？（深夜不安排高强度学习）
4. **组合优化**：在时间预算内选择最优组合
5. **不确定性标注**：低置信度 → 标记为"备选"

---

### ④ 交互表达层

**职责**：以符合 TU-8 人格的方式呈现。

**表达原则**：

| 场景 | 表达方式 |
|------|----------|
| 首屏 | "状态同步"而非"计划清单" |
| 用户问"今天做啥" | 结构化建议 + 置信度 |
| 用户说"不想做" | 记录反馈，降权或暂存 |
| 无计划模式 | "随时待命，不打扰" |

**首屏示例**：

```
早上好。今天是周六上午。

我看到你昨天提到：
- TASK_01 编码任务，修复已完成，等你确认
- 环境监测设计，正在讨论中

另外，你最近对 #AI认知架构 挺感兴趣的。

需要我继续哪个任务？
```

## 六、关键问题

### Q1：客户端启动时如何注入时间？

**方案A**：OpenClaw 运行时支持，在 systemPrompt 中动态注入
**方案B**：cron 任务"启动后立即执行一次"（需 OpenClaw 支持 hook）
**方案C**：首条消息由客户端发送时间信息

**当前状态**：需要确认 OpenClaw 是否支持启动钩子。
