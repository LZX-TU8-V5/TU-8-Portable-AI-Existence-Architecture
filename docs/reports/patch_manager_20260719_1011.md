## 核心实现

### 状态机 (6阶段)
```
GENERATION → BACKGROUND → PLACEHOLDER → INTEGRATED
    ↓
  CONFLICT → ROLLED_BACK
```
- GENERATION: 超时 2h，BACKGROUND: 超时 24h，PLACEHOLDER: 无超时
- CONFLICT: 超时 1h（人工审核窗口）
- INTEGRATED/ROLLED_BACK: 终态

### 优先级规则
| 类型 | 优先级 | 说明 |
|------|--------|------|
| CRITICAL_PATCH | 1 | 安全类补丁 |
| ANCHOR_PATCH | 2 | 锚点类补丁 |
| BACKGROUND_PATCH | 3 | 背景板补丁 |
| TEMP_PATCH | 4 | 临时补丁 |

### 冲突检测逻辑
- 优先级相同 + 作用于相同拓扑区域 → 冲突
- 新补丁存活，已有补丁回滚
- 高优先级补丁存活，低优先级回滚

## 公开接口
- `create_patch()` → GENERATION
- `get_patch()` / `get_all_patches()`
- `advance_stage()` — 支持 trigger: integration_complete / timeout / conflict_detected
- `get_patch_stats()` — 整合率、各阶段统计
- `rollback_patch()` → ROLLED_BACK
- `merge_to_background()` → BACKGROUND
- `demote_to_placeholder()` → PLACEHOLDER
- `integrate_fully()` → INTEGRATED
- `get_conflict_patches()`
- `check_and_resolve_conflicts()`
- `get_topology_coverage()`
