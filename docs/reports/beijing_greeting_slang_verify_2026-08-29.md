## 二、北京话「吃了吗」核验

**事实成立：**
- 源出北京，相当于「嗨」，多用于用餐时间，具「实/虚」二分（提问功能 vs 寒暄功能，冯双艺 2020 等）。
- 典型回合：A「吃了吗您呐？」→ B「偏您了！」（意为"我比您先吃了"，其实未必，纯客气）→ A「得嘞，您忙着。」
- 老北京变体：回应可答「添过了」（不说"吃"而说"添"，《添过了》词条）。
- 历史渊源：可溯至汉代「强饭/加餐」慰勉语；民俗至少明代已存（葡萄牙人克路氏记闽粤「食饭否」）；北宋《吕氏乡约》（吕大钧）规定「入门必问主人食否」，朱熹《增损吕氏乡约》重申。
- 跨语言对照：与西方「How are you?」功能相似但强调集体关怀，直译易误解为邀请用餐。
- 方言变体：武汉「吃了冇(mào)」、潮汕「食未？」。

**使用场景警示（对架构的启示）：**
- 别等人刚从厕所出来就问「吃了吗」——说明语用框架依赖上下文，错配即失真。
- 当代衰微趋势：「你好」等多元化增多，年轻群体使用频率下降（与四川话同趋势）。

## 三、关键纠偏：顺口搭音儿 ≠ 跳跃

**千问落稿 summary 把两件事并了，必须拆开：**

1. **顺口搭音儿（真义）**：老北京寒暄接话的核心习惯，含义为「认真听对方说话，并在恰当时机搭一句呼应」，表示「您说，我听着呢」。
   - 是**同一话题内部**的呼应/接话黏合剂（「可说呢」「可不是吗」「谁说不是呢」「没错儿」）。
   - 例：「今儿个天不赖啊」→「可不是吗」。这是捧哏式接住，话题不跳。
   - 近义：搭茬、接茬、搭腔、话茬儿。
   - 注意形近词「順口答音（兒）」shùn kǒu dá yīn(r) 偏贬义（随口应承无主见），需区分。

2. **寒暄→具体话题突跳**（如「吃了吗您呐」→「前儿个我去护国寺街那家爆肚儿…」）：这是**独立的 turn-shift / 话题转换现象**，不是顺口搭音儿。

**纠偏结论：** 千问把「顺口搭音儿」定义为"两套体系之间频繁跳跃的能力"属过度延伸。跳跃（jump）和顺口搭音儿（同话题呼应）是两个正交现象，落稿 §0.0.11 时须分开表述。

## 四、理论层归属（重要边界）

- 「空壳密文 / 实心密文 / jump 操作 / 语用标签（phatic_greeting / genuine_inquiry / interrogation / rhetorical）」是**千问基于俚语事实自建的记忆模型层，不是俚语本身**。
- 俚语只提供"同字面不同语用 = 不同密文"的**直觉素材**；模型机制是 TU-8 架构侧的二次抽象。
- 因此：对架构的真正价值来自实例本身（实指/虚指二分），不依赖顺口搭音儿考据是否成立。

## 五、四川话「吃了没得」平行佐证

- 川话「吃了没得?」（也说「呷饭没得? hā fàn méi dé」「吃饭没得」）是最广泛代表性问候，等同「你好」，**不分时段通用**。
- 明确非真关心吃没吃，就是打招呼；回应「吃了」/「还没吃」。
- 核心特征：**明知故问 + 随机应变**（看见什么问什么，百度百科「招呼」词条）。典型模式：饭点问「吃饭没得」、偶遇问「出来转耍哇」、到家问「回来啦」。
- 回答简洁敷衍、点到为止，被称「寒暄文学/抽象文学」。
- 方言词：巴适/安逸（舒服）、要得（行）、莫来头/不存在（没关系）、咋个（怎么）、摆龙门阵（闲聊）。
- 与北京「吃了吗」**语用结构完全同构**（字面问吃、实为寒暄、答案敷衍），进一步坐实"同字面不同语用 = 不同密文"。
