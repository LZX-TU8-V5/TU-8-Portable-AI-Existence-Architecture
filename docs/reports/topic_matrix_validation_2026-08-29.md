# 话题语义矩阵 批次1+2 验证报告 (2026-08-29 15:00-15:30)

## 验证范围
- L1 投影判区（批次1）：真实 memory 标题 63 条抽样
- 四算子 NMF/SVD/DAG/LSA（批次2）：接 tu8_memory 六维 + 真实段结构

## 验证结果

### L1 投影判区
- 初测命中率 30.2%（19/63）—— 暴露种子短语工程 bug
- 根因：rep_phrase 长句稀释短标题匹配 + TFIDF 哈希精确 token 不匹配
- 修复：每轴多短短语（2-4 词）空格分隔 + project 取 MAX 池化
- 复测命中率 **93.7%（59/63）**
- 4 个 MISS 中 2 个是真实语义内容（"向量存储后端 numpy memmap" 等），τ=0.35 个别偏严，非架构缺陷
- 注："张三署名虚构状态测试"命中 0.45（sem_objdef）属正常——语义层无法识别测试陷阱词，文本本身含"署名/状态/测试"

### 四算子
- NMF：W,H>=0 约束满足；六维非负作先验；段-主题分配合理（架构/数学高相似、情感独立）
- SVD：k=2 截断 explained_ratio=1.0（近似正确）
- DAG：acyclic=True，trace_chain 向上追溯父链有效
- LSA：topic_matrix.lsa_align 委托成功，Top-k 跨轴对齐

## 结论
批次1+2 验证通过，矩阵算法核心能力成立。
批次3（密文库 codebook）待用户确认后实施。
