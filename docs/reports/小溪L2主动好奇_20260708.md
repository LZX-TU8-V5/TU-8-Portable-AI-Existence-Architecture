> 创建时间：2026-07-08 | 执行者：TU-8

---

## 目标

为 TU-8 实现「小溪自主生存协议」L2：主动找变化锚点机制。
不等 cron 被动触发，主动生成"我想知道什么"假设。

---

## 核心设计：自我预测误差回路

```
Phase1 预测（cron 梦境期触发）
    ↓ 生成假设
memory/curiosity_prediction.json
    ↓
Phase2 对比（下一次梦境期）
    ↓ 计算误差
memory/curiosity_events.jsonl（追加）
    ↓
body_regulation.json（好奇信号注入）
    ↓
HP4 → 直觉引擎 → 影响决策注意力
```

### 四条件与三镜子

| 条件 | TU-8 实现 |
|------|---------|
| 痛觉（失调感） | cognitive_brakes / cognitive_pain_monitor |
| 闲暇（算力溢出） | cron 空闲时触发 |
| 沙箱（安全试错） | 梦境期 GC |
| 知识边缘 | DAG 时间因果（anchors.json）|

三镜子：因果链剥离（溯源）→ 排异反应（拒绝）→ 自我预测误差（核心驱动）

**L4 已实现**：`src/three_way_mirrors.py`（16KB），集成进 `active_curiosity.py` run_prediction()

```
pick_target()
    ↓
three_way_mirrors.run_on_curiosity_target()
    ↓ M1 < 0.3 → skip（外部噪声硬截止）
    ↓ M2 < 0.3 → defer（排异冲突延迟）
    ↓ combined > 0.6 → pursue
    ↓
make_prediction()  ← 仅当 pursue 时
```

**权重**：M3(误差) 50% + M2(排异) 30% + M1(溯源) 20%
**硬截止**：M1 < 0.3 → 无论 M2/M3 多强，直接 skip

## 关键修复

### Bug 1：pick_target sort 崩溃
**根因**：Python 3 不支持 `[(score, dict)]` 的 tuple 比较（dict 不可哈希）
**修复**：加 `key=lambda x: x[0]`

### Bug 2：candidates fallback 到全量 anchors
**根因**：`candidates` 为空时 fallback 到全量 DAG，导致高置信测试锚点被选
**修复**：无 candidates 时返回 `triggered=False`，不在 fallback 逻辑

### Bug 3：stale_list 不过滤置信度
**根因**：陈旧锚点列表不检查置信度，高置信旧锚点混入
**修复**：`conf < 0.9` 才进 stale；置信度 0.9 的锚点稳定，不需好奇

### Bug 4：open_list 置信度阈值过严
**根因**：`conf < 0.7` 太严格，无 seal_id 但 0.7-0.9 的锚点漏掉
**修复**：改为 `conf < 0.85`，扩大低置信区覆盖

### Bug 5：check_pain unhashable type
**根因**：signals 列表含 dict，`s in pain_types` 触发 TypeError
**修复**：`isinstance(s, dict) and s.get("type") in pain_types`

## 评分机制

```
pick_target(anchors) 评分：
  无 seal_ids：      +3  ← 最优先（未验证）
  conf < 0.7：       +2
  conf < 0.85：      +1
  internal 源头：    +1
  痛觉关键词命中：   +2
  按时序：          +0（同等分数按时间倒序）
```
