## §1 可简化项（降冗余、降维护负担）

### 1.1 备份命名规范统一（P-now）
**痛点**：今晚备份文件名不统一，grep 回滚锚点费劲：
`metabolic_pipeline.py.20260817.bak` / `.20260826.impl.bak` / `.20260827.impl2.bak` / `GOVERNANCE.md.orphan_sop.bak` / `.qianxun_review.bak` / `.ai_exec_bak`。

**建议**：锁定单一样式 `原文件名.YYYYMMDD.bak`（或 `原文件名.v{n}.bak`），禁止 `.impl`/`.orphan_sop`/`.ai_exec` 等语义后缀。GOVERNANCE §5 已规定单通道 `backup/`，补一条"命名格式强制"，使回滚可一行 grep。

### 1.2 §6 验收标准与 §9.1 契约表去重（P-soon）
**痛点**：§6（量化验收）与 §9.1（机器可读契约表）都挂 file_lint，内容重叠，存在双源漂移风险（正是我们今晚反复修的"混合病"）。

**建议**：§6 改为"指向 §9.1 + 阶段 CHECKPOINT 的结果汇总"，§9.1 保留为唯一契约真源。不重写，仅把 §6 降级为索引，消除双源。

### 1.3 edit 卫生清单（P-soon）
**痛点**：今晚多次 edit 因 oldText 匹配 2 处 / 含 pager 注记 `[1 more lines...]` / 实际文件为 `seal_index.json` 非 `seal_index` 而原子失败整批回滚，造成重复劳动。

**建议**：在 SOP §2 补一条"edit 前必读真实文件尾段、oldText 取足上下文唯一块"，降低原子回滚重做率。纯流程纪律，不动硬约束。

## §2 可合并 / 可自动化项（提效，不降安全）

### 2.1 Python 调用封装（P-now，工具链）
**痛点**：今晚反复踩 `$py` 变量跨 exec 新 shell 被清空、`.py` 被 PowerShell 当文档"无法在管道中间运行文档"、控制台 GBK `UnicodeEncodeError` 乱码干扰判断。

**建议**：建 `_agent_memory/runpy.ps1` 固定封装（强制 `python` 显式调用 + `sys.stdout.reconfigure(encoding='utf-8')` + `PYTHONIOENCODING=utf-8`），所有验证脚本统一走封装。消除跨 shell 变量丢失与编码乱码两类 footgun。

### 2.2 file_lint 强制门禁自动化（P-now）
**痛点**：§9.1 写"每次治理动作后执行"，但今晚是手动零散跑（P2 后、P4 后），有漏跑风险。

**建议**：把 file_lint 接成"批量移动脚本末尾自动调用"，exit≠0 即中止后续批次并触发 §9.3。从"人工记得跑"升级为"流程强制跑"。

### 2.3 孤儿审阅 §2.5 半自动（P-soon）
**痛点**：§2.5 四步（分组/查验/标记/写入）里"分组（按前缀）"和"标记（文件头加印章）"是机械动作，今晚 40 个脚本手动逐组读+标，耗时但规律性强。

**建议**：写 `src/_quarantine_review.py`——自动按前缀分组、自动在文件头注入 `[已审阅-日期-孤儿诊断脚本-可清]` 印章，**仅"查验(inspect)判定命运"留给 AI 汇报**。人类审阅负担降 60%，且印章格式标准化（顺带解决 1.1 的命名/标记一致性）。

### 2.4 @语义锚点作为跟踪债项（P-later，已知债）
**现状**：裸名+移动改引用已验证零断链（P1 152 文件），@锚点列为"不急"。
**建议**：不现在做，但在 GOVERNANCE §3.1 / TODO_MASTER 留一条跟踪项，避免永久遗忘。扩展 `secure_vault/index.json` 为文档引用注册表的方案已成型（见 SOP §3），未来外协接入时再启。
