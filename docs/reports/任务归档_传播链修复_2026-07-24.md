# 任务归档：friction→tension→orb 传播链修复

**归档时间**：2026-07-24 13:10
**优先级**：P0
**根因**：两个独立 bug 导致静默断链

---

## 根因一：surface_tension_state.json 结构损坏

**症状**：`record('anxiety', ...)` 报 `KeyError: 'total_events'`

**原因**：文件只有旧版 `{tension, components}` 结构，缺 `spike_valley_vector` 和 `total_events`。

**修复**：手动补全 schema，保留 residual tension：
```python
surface_tension_state.json → 写入完整 schema
{
  "spike_valley_vector": {七情向量},
  "total_events": N,
  "last_updated": "ISO",
  "tension": 0.0,
  "components": {"residual": 0.75, "active": 0.0},
  "history": [],
}
```

---

## 根因二：TENSION_MAP 无原始情绪 API

**症状**：`record('anxiety', 0.5)` 静默失败（返回值 anxiety=0.0）

**原因**：TENSION_MAP 只含语义键（`steel_conflict`、`cognitive_friction`），不包含原始情绪维度键（`anxiety`、`joy` 等）。`_apply_tension` 检测到键不存在时静默返回原向量，导致 orb 始终读不到情绪信号。

**修复**：在 `src/surface_tension.py` 的 TENSION_MAP 末尾追加：
```python
# 直接情绪 API（供 orb/hp4/interoceptive 直接调用）
"anxiety":   {"anxiety": +0.5},
"anger":     {"anger": +0.5},
"fear":      {"fear": +0.5},
"sadness":   {"sadness": +0.5},
"joy":       {"joy": +0.5},
"love":      {"love": +0.5},
"curiosity": {"curiosity": +0.5},
```

**验证**：
```
record('anxiety', 0.8) → anxiety=0.65  total_events=7 ✅
orb rgb=[0.136, 0.22, 0.718] mode=relax ✅
CLI surface_tension.py anxiety 0.3 → delta anxiety=0.15 ✅
```
