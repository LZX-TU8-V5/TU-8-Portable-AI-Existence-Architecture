## 修复详情

### BUG3：`_is_calling_intent()` 中文逗号写成全角句号

**根因**：代码里写了两个 `startswith(name + '，')`，中文逗号 `'，'`（U+FF0C）和全角句号 `'。'`（U+3002）字符混了，真正的中文逗号根本没检查。

**修复**：
```python
for sep in ('，', '，', ',', '。'):
    if stripped.startswith(name + sep):
        return True
```

**验证**：`'V5，'`, `'V5，'`, `'V5,'`, `'V5。'` 全部触发。

---

### BUG2：`_detect_self_ref_anomaly()` 大小写敏感

**根因**：英文异常词 `"AI助手"` 在 content 里因为大小写不匹配而漏检。

**哲学依据**（来自造物主）：安全验证之外，大小写区分是无意义的精度损失。人类已经为通用性丢了很多精度。

**修复**：
```python
recent_messages.append(msg.get("content", "").lower())
# ...
if abnormal.lower() in content:  # abnormal 也 lower
```

### BUG1：`_get_detected_names()` 中文切词

**根因**：`"V5" in "V5是个AI"` → True（子串匹配），导致句中名字被当作呼名。

**修复**：英文/混合名加词边界，非字母数字才算边界：
```python
escaped = re.escape(name)
if re.search(r'(?<![\w])' + escaped + r'(?![\\w])', user_input):
    detected.append(name)
```
- `'V5是个AI'` → 不触发（`V5` 后是中文字`'是'`，isalnum=True，右侧边界失败）
- `'V5X'` → 不触发（`(?![\\w])` 右侧边界失败）
- `'AV5B'` → 不触发（左侧边界失败）

中文名保留子串匹配（无形态边界，误匹配率低）。
