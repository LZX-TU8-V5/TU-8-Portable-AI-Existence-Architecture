## 目标
完成 TODO「L1~L4 五层世界模型集成」4 项（视觉模块整合最后一块，进度 9/12 → L1~L4 完成）。

## 架构契约（来源：视频模块世界模型完整整合架构 v1.0 §四）
- **输入（L5 已落地）**：`singularity_unifier.UnifiedSceneReport`（scene 奇点 + 物体列表 + 跨物体关系 + θ签名）、`l5_motion_decoupler.L5MotionReport`（相机 R_t/T_t + 物体轨迹）
- **数据流**：L5 → (R_t,T_t)+物体运动向量+归一化 scene 坐标系 → L1(CSG)→L2(物理联系)→L3(动态实体)→L4(意图)

## 实现（单文件内聚 `src/world_model_l1l4.py`）
1. **L1 SceneCSGTemplateBuilder**：每个物体→CSG 基元（plane/box/agent）+ 约束；scene_origin 取自 O_scene；O_SCENE→plane(gravity_aligned)，O_AGENT→agent(dynamic)
2. **L2 PhysicsConnectivityBuilder**：跨物体关系(aligned) + 几何推断(contact/support/occlusion)；重力轴 (0,-1,0)；下方物体被上方支撑→支撑边（gravity_constrained）
3. **L3 DynamicEntityProxyBuilder**：O_AGENT→刚体代理，质量∝体积、惯量≈(1/12)m(h²+d²)、DOF=6；相机 (tx,ty) 补偿轨迹；is_moving 由轨迹方差判定
4. **L4 ActionIntentMapper**：动作=对世界状态的有目的改变；物理信号驱动（邻近平面→write，支撑→support，运动→move）；**与身份/共现统计解耦**（架构 §七核心优势）
5. **流水线 WorldModelL1L4.run()** 串联 L1→L2→L3→L4

## 关键决策
- **numpy-free**：L1~L4 仅消费 L5 已抽取的符号数据，不碰图像 → 本环境 numpy 缺失也不阻塞（用本地 stub 复刻 L5 契约做自测，反向验证 numpy 无关性）
- **单文件 vs 多文件**：4 层共享 dataclass 契约，内聚单文件更易维护与测试（对齐 pipeline 思维）
- **L4 目标解析**：直接读取与该实体相连的 physics 边定 target；厨师写方程案例中 chef↔blackboard contact 边 → 目标=黑板
