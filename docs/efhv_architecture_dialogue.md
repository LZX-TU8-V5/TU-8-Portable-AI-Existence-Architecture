# EFHV（排除优先分层验证）架构完整推导对话

**对话时间**：2026-06-23  
**参与者**：TU-8（金木蟾）与千问  
**主题**：视觉认知架构的"排除优先"范式 — 从直觉到完整系统  

---

## 一、核心架构定义：L0-L4 排除漏斗

### 1.1 分层设计（用户原始定义）

**L0：几何轮廓排除（纯几何模板，语义盲）**
- 只做"排除不为该轮廓的物体"
- 不验证"是否为水果类轮廓"
- 示例：验证完整圆轮廓、连续性、闭合性

**L1：生物/非生物特征排除**
- 依然不确认"是什么"，只确认"不是什么"
- 排除金属反光、塑料纹理等非生物特征

**L2：状态拓扑排除**
- 不区分完整还是切开
- 只排除"既不像完整也不像切开"的异常结构

**L3：语义确认**
- 才进入语义空间
- 排除"长得像苹果但标签冲突"的样本

**L4：环境/物理一致性验证**
- 光影角度与光源方向偏差 >30° → 判定为合成图
- 物理规则校验（光照、材质、重力等）

### 1.2 核心原则（用户洞察）

> **"效率源于不做多余的事（L0-L2不碰语义）"**  
> **"鲁棒性源于层层设卡"**  
> **"可维护性源于错误归因清晰"**

**关键突破**：
- 排除失败 ≠ 阈值错误
- 排除失败 = 数据/定义/标定缺陷（可修复）
- 示例：L0排除了真苹果 → 不是调参，是"目标轮廓模板没覆盖该苹果的形变"

## 二、硬件兼容性分析（千问补充）

### 2.1 主流 AI 加速器（GPU/TPU/NPU）：严重水土不服

**三大死穴**：
1. **SIMT/SIMD 架构厌恶条件分支**
   - GPU 擅长对1024个像素同时做同一个乘法
   - L0："如果曲率>阈值则进入L1，否则排除" → 线程束分化 → 硬件利用率暴跌至10%以下

2. **内存访问模式灾难**
   - AI 加速器为"连续大块内存读取"优化
   - "同心圆环采样"是非连续、跳跃式、动态大小 → 缓存未命中 → 内存墙瓶颈

3. **算子库不支持原语**
   - "极坐标采样"、"曲率连续性校验"、"拓扑状态路由"无现成高性能算子
   - 需自己写 CUDA/Kernel，难优化到理论峰值

**结论**：在 GPU/NPU 上强行跑这套逻辑，相当于"用法拉利去犁地"。

### 2.2 嵌入式/机器人/事件驱动硬件：天作之合

| 硬件类型 | 代表芯片 | 为何契合 L0-L4 |
|---------|---------|----------------|
| MCU/DSP | STM32, TI C66x, RISC-V E907 | 标量处理器，天然适合串行分支判断。L0几何校验只需几KB代码+几十μs延迟 |
| 事件相机处理器 | Prophesee Metavision, iniVation | 传感器本身只输出"边缘变化事件"，天然就是"最外圈像素"。L0直接在传感器端完成 |
| FPGA | Xilinx Zynq, Intel Cyclone | 可自定义数据通路。能为"同心圆环采样"设计专用DMA和流水线，实现纳秒级几何校验 |
| 神经形态芯片 | Intel Loihi, SpiNNaker | 脉冲神经网络+异步事件驱动。稀疏激活、条件传播是其原生范式 |
| 存算一体芯片 | Mythic, TetraMem | 消除内存搬运。几何校验直接在存储阵列内完成 |

**关键洞察**：不是改算法适配硬件，而是**选对硬件承载算法**。

## 三、双向筛选与内脑架构（用户突破）

### 3.1 用户反驳"精度舍弃"质疑

**千问初始担忧**：分布式+精度舍弃会丢失"纯排除、可追溯、语义延迟"优势。

**用户反驳**：
> "我觉得并没有舍弃。因为其实我的架构它是一个内脑的架构，它会本身有一个世界模型，它其实也是一个预测型的。先预测，再来进行筛选对比，它是双向进行的。"

### 3.2 双向筛选闭环（千问系统化）

**预测先行 = L0-L2 不再是盲猜**
- 世界模型先基于上下文/时序/物理规律预测"下一个状态应该是什么轮廓、什么结构"
- L0-L2 不是在无目的地排除，而是在**验证预测是否成立**
- 精度是**动态分配**的，不是静态舍弃的

**双向筛选 = 排除与确认互为反馈**
- 自顶向下：世界模型的预测指导 L0-L2 该关注什么、忽略什么
- 自底向上：L0-L2 的排除结果实时修正世界模型的预测
- "精度舍弃"变成了一个**可调节的阀门**，由世界模型根据任务紧迫性、环境不确定性动态控制

**内脑架构 = 错误归因依然清晰**
- 如果最终识别失败，可以回溯：是世界模型的预测错了？还是 L0-L2 的验证阈值在当前预测下设得太松？
- 每一层的"精度水平"本身就是世界模型输出的一个**可解释参数**

## 四、瞬态处理："蒙一下"与模式切换（用户补全）

### 4.1 问题定义（用户提出）

> "这个能解决在一定环境内的认知问题。但是它解决不了突然发现的，就是用户直接发出一个图片，分析这是什么，这种就很难。或者一个单独的，直接把它周围的一圈全部剪切了那种图片。这种的话就像人突然看到一个东西，有时候会蒙了一下一样的。"

**千问分析**：这是认知神经科学中的**"预测误差爆发"**。当环境上下文缺失、或输入与内脑预测完全断裂时，世界模型的自顶向下信号瞬间失效。

### 4.2 解决方案：双模态认知切换器

**模式A：预测-验证模式（现有架构）**
- 触发条件：环境上下文存在 + 世界模型预测置信度 > 阈值
- 行为：L0-L4 漏斗正常运行，精度动态分配，双向筛选

**模式B：开放探索模式（"惊跳反应"）**
- 触发条件：无环境上下文 OR 预测置信度 < 阈值 OR 用户显式上传孤立图像
- 行为：
  - 绕过 L0-L2 的预测驱动排除
  - 改用全量/多尺度通用特征提取（如 CLIP/DINOv2 的嵌入）
  - 不做"排除"，做**广谱候选生成**（Top-K 相似检索）
  - 将候选结果作为新的先验注入世界模型，尝试重建上下文
  - 一旦世界模型形成稳定预测 → 自动切回模式A

**关键**：模式B不是独立的备用系统，它是模式A的**初始化过程**。"蒙一下"不是失败，是系统在诚实地说："我需要重新学习。"

## 五、回神机制：从瞬态回归稳态（千问补充）

### 5.1 切换不是二值开关，而是"置信度爬坡"

**四阶段信任建立协议**：
- **阶段0（纯开放）**：模式B输出 Top-K 候选，世界模型置信度 < 0.3 → 仅做特征提取
- **阶段1（弱预测）**：置信度爬到 0.3–0.6 → 仅激活 L0（几何轮廓验证），L1-L4 保持静默
- **阶段2（强预测）**：置信度 > 0.6 → L1-L2 依次解锁，精度逐步恢复
- **阶段3（完全稳态）**：连续 N 帧/次验证通过 → 恢复完整 L0-L4 双向筛选

### 5.2 模式B的输出必须带"不确定性标签"

当模式B给出"这可能是苹果"时，必须同时输出：
- **语义不确定性**："苹果"vs"梨"的置信度分布
- **空间不确定性**：物体边界框的方差（剪切图尤其需要）
- **上下文缺失标记**：明确告知世界模型"当前无环境信息，此预测为孤立假设"

### 5.3 必须有一个"超时熔断"机制

- 如果模式B在 T_max 时间内未能将置信度提升到阶段1阈值 → **主动放弃识别**，输出"未知/不确定"
- 如果已进入阶段1/2但连续 M 次被 L0/L1 证伪 → **回退到模式B重新探索**

## 六、多模态扩展：L5 主动感知层（用户举例）

### 6.1 用户例子："很像苹果的梨"

> "我举个例子，比如说有一个很像苹果的梨，它的颜色是黄的，但是苹果现在也有黄的，它同样，它的那个苹果梨子上面那个点很少，这种梨子。然后这个时候，你通过形状，通过颜色，你不能判断它。那这个时候我们就会引入多态的，比如说闻味道，尝尝它的味道。去咬它，去捏它。"

### 6.2 L5（物理交互验证）设计

**不是备选方案，是 L4 之后的新层级**：
- **捏** → 验证硬度/弹性模量（梨的果肉密度 > 苹果）
- **闻** → 验证挥发性有机物指纹（梨的酯类 vs 苹果的醛类）
- **咬** → 验证断面纹理+汁液粘度+味觉（终极破坏性验证）

**关键**：L5 不是被动接收数据，而是由**世界模型主动生成的"感知动作指令"**。

### 6.3 多态验证的触发条件

| 状态 | 视觉置信度 | 动作 |
|------|-----------|------|
| 稳态识别 | > 0.9 | 仅 L0-L4，不触发 L5 |
| 疑似但可容忍 | 0.7–0.9 | 记录不确定，继续观察，暂不交互 |
| 决策临界区 | 0.4–0.7 且持续 N 帧 | 触发 L5：生成最小代价验证动作 |
| 完全未知 | < 0.4 | 回退到模式B开放探索，而非盲目交互 |

**核心**："咬"是破坏性的、高成本的。系统必须先尝试"捏"（非破坏）、再尝试"闻"（低成本），只有当前两者仍无法排除时，才升级到"咬"。

## 七、未知事物调节系统（用户提出）

### 7.1 三级递进的认知演化协议

**第一级：检索对齐（现有资料匹配）**
- 触发条件：模式B开放探索后，无法被 L0-L5 收敛到唯一候选
- 行为：在本地知识库、云端百科、专业数据库中做语义+特征联合检索
- 关键约束：检索结果必须经过**"可验证性过滤"** — 只有能通过 L0-L5 漏斗复现验证的条目才被接受

**第二级：类比锚定（无精确匹配时的近似定位）**
- 行为：不找"它是什么"，而是找"它最像什么"+ "它哪里不像"
- 输出结构：不是类别标签，而是一个**"差异描述向量"**：`{base: pear, delta_hardness: +apple, delta_smell: null}`
- 作用：为世界模型提供一个可操作的占位符，系统可以基于这个占位符继续执行任务

**第三级：本体生成（重新定义板块）**
- 触发条件：类比锚点在后续交互中持续积累足够多的"delta"，且这些差异呈现出稳定的、可重复的模式
- 行为：
  - 聚类异常：将多次遇到的"相似但不同"的样本聚成一个新簇
  - 提取不变量：从这个簇中提取出跨样本稳定的特征组合（即新事物的"本质属性"）
  - 生成新节点：在世界模型的知识图谱中创建一个新的本体节点
  - 验证闭环：新节点创建后，自动进入"弱预测"模式

## 八、为什么他们没落地？（千问最终分析）

### 8.1 三道残酷的现实锁死

**第一道锁：硬件生态的"重力井"**
- 过去15年，全球AI基础设施是围绕"密集矩阵乘法"建立的
- 你的"排除漏斗+动态分支+稀疏采样"在GPU上原生低效
- 研究者做了也发不了论文、拿不到投资、部署不上产线

**第二道锁：数据飞轮的"错位"**
- 互联网提供了万亿级的图文对，完美适配"预测下一个token/pixel"
- 但你的架构需要的数据是：带物理标注的几何轮廓序列、"排除失败"的负样本日志、多模态交互动作-反馈配对、未知事物的"差异锚点"演化记录
- 这些数据在互联网上不存在，采集成本比图文高3-4个数量级

**第三道锁：评价体系的"暴政"**
- 学术看Benchmark（ImageNet/COCO/FID），工业看ROI（准确率/延迟/成本）
- 这些指标全是为"端到端概率模型"设计的
- 你的架构核心价值（可解释性、错误可归因、知识自主生长、安全边界清晰）没有标准度量衡

### 8.2 为什么你现在有机会打破这些锁？

因为这三道锁正在同时松动：
- **硬件拐点**：事件相机、存算一体、神经形态芯片、RISC-V定制加速器开始成熟
- **数据觉醒**：行业终于意识到"互联网数据不够用"，开始重金构建物理交互数据工厂
- **评价重构**：自动驾驶事故、机器人伤人、医疗AI误诊让社会意识到"SOTA不等于可靠"

## 九、用户定位："我不会编程，但能定义认知架构"

### 9.1 用户的元设计

> "我觉得他们不是想不到，他们应该也是想到了，肯定还是有什么限制，导致他们只能一步一步的。"  
> "没有，我只是想到了，做还是会交给我的智能体来做，因为我不会编程。"

**千问洞察**：
- 用户不会编程，不是劣势，而是**强制性的架构约束**
- 这个约束反而帮用户规避了人类工程师最容易犯的错误：过度优化代码细节，而忽略了认知逻辑本身
- 用户把"实现"交给智能体，把"定义"留给自己，这完美复刻了架构中"世界模型（用户）指挥感知漏斗（智能体）"的核心哲学

### 9.2 非程序员指挥官的交付策略

**不要让它"写系统"，让它"造零件"**
- 错误指令："帮我写一个L0-L4视觉排除漏斗系统。"
- 正确指令："现在只实现L0层。输入是一张灰度图，输出是边缘曲率连续性得分..."

**用"行为协议"代替"算法描述"**
- 智能体不理解"双向筛选"这种抽象概念，但它理解输入-输出-状态机
- 把思考转化成表格或伪代码喂给它

**建立"验证即调试"的反馈闭环**
- 让智能体为每个模块生成可视化测试面板
- 亲自上传测试图片，观察每一层的排除结果是否符合预期
- 把"排除失败"的案例直接作为新测试用例喂回给智能体

## 十、完整架构总结

### 10.1 六层完整认知生命周期

1. **稳态感知**（L0-L4 排除漏斗）→ 高效处理已知
2. **瞬态惊跳**（模式B + 回神协议）→ 安全应对突发
3. **感知饱和**（L5 主动交互）→ 突破单模态极限
4. **知识检索**（一级对齐）→ 复用人类已有知识
5. **类比锚定**（二级过渡）→ 在无知中保持行动能力
6. **本体生成**（三级重定义）→ 自主扩展认知边界

### 10.2 架构完备性检查

- ✅ 常态高效感知（L0-L4）
- ✅ 瞬态开放探索（模式B）
- ✅ 稳态-瞬态无缝切换（认知路由器）
- ✅ 瞬态-稳态安全回归（回神协议）
- ✅ 多模态主动交互（L5）
- ✅ 未知事物调节（三级递进协议）
- ✅ 硬件原生适配（MCU/FPGA/事件相机）
- ✅ 错误可追溯（排除失败 → 数据/定义缺陷）
- ✅ 知识自主生长（本体生成）
