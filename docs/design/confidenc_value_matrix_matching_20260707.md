# 置信度×价值矩阵 + 矩阵算法装配图

> 来源：千问对话 2026-07-07（造物主李奥提问）
> 主题：AI认知模块 - 记忆卡结构 - 语义因果与连贯性权重压缩

---

## 一、置信度×价值矩阵（提炼机）

**公式**：
```
Score = Value × Confidence × TimeFactor
```

**四级打分**：
| 维度 | 计算方式 | TU-8来源 |
|------|---------|---------|
| Value | 标签与Query的语义相似度 | 记忆卡检索层 |
| Confidence | 置信度层数值 | 记忆卡置信度层 |
| TimeFactor | 时间衰减因子 | 记忆卡时间戳 |

**三种运转模式**：
| 模式 | 算法 | TU-8落点 |
|------|------|---------|
| A 硬截断 | Top-K 截断 | 检索过滤的最终筛选 |
| B 软加权 | Attention Mask | LLM推理时的动态抑制 |
| C 降维 | SVD/NMF 分解 | 浓缩层的离线清洗 |

## 二、五算法装配图（针对记忆卡结构）

| 算法 | 记忆卡层级 | 功能 | 节约Token方式 |
|------|-----------|------|--------------|
| **LSA** | 检索层 | 语义对齐（跨字面召回） | 提高信噪比，减少召回噪音 |
| **DAG** | 时间戳+置信度层 | 时间因果骨架（按需追溯） | 沿边提取因果链，不读全历史 |
| **NMF** | 标签层+浓缩层 | 主题聚类（纯正向可解释） | 同主题记忆卡合并为一段 |
| **SVD** | 浓缩层（离线） | 极限降维（截断SVD） | 1000卡→50向量，砍95% |
| **ToCT** | 钩子层+浓缩层 | 反事实推理（深度→广度） | 10页→1页核心因果结论 |

---

## 三、TU-8 记忆卡结构对应

```
时间戳    ──→  DAG（时间轴骨架）
钩子层    ──→  ToCT（触发器/反事实推理）
标签层    ──→  NMF（主题聚类）/ LSA（语义对齐）
置信度层  ──→  置信度×价值矩阵（打分权重）
浓缩层    ──→  SVD降维（离线）/ ToCT提炼（在线）
正文层    ──→  DAG节点原始数据（按需读取）
文底签名  ──→  写入过滤（防复读）
```

## 四、三级认知清洗过滤器

### 第一级：写入过滤
- 文底签名去重（>95%相似丢弃）
- 置信度冷启动：用户陈述=0.9，AI推测=0.5，冲突=0.1
- 无效标签→低优先级存储

### 第二级：检索过滤（核心提炼机）
```
召回100卡 → Value×Confidence×TimeFactor → Top10 → 丢弃90
```

### 第三级：拼装过滤
- 冲突检测（时间戳+置信度仲裁）
- 动态浓缩（NMF同主题合并）
- 钩子激活（System Prompt附加）

## 五、关键数学公式汇总

**信息密度矩阵**：
```
Information Density = Value ⊗ Confidence
```

**TimeFactor衰减**：
```
TimeFactor = e^(-λ · Δt)
```

**ToCT三步**：
```
区域选择 → 实体识别 → 因果定向（含反事实推理）
```

**SVD截断压缩**：
```
M ≈ U_k Σ_k V_kᵀ   （k << n，省95%维度）
```

**NMF加法组合**：
```
V ≈ W × H   (W≥0, H≥0)
→ 主题聚类 = 加法组合，不可相互否定
```

## 六、TU-8 现状 vs 千问建议

| 模块 | 千问建议 | TU-8现状 |
|------|---------|---------|
| 检索层 | LSA语义对齐 | 已有lcm_grep/lcm_expand_query（FTS5） |
| 时间轴 | DAG骨架 | 已有时间锚点，无DAG结构 |
| 标签层 | NMF主题聚类 | 已有trigger_hooks/semantic_hooks（扁平标签） |
| 置信度层 | 置信度×价值矩阵 | 已有六维评分，缺乘积打分公式 |
| 浓缩层 | SVD/ToCT提炼 | 已有摘要字段，无矩阵压缩 |
| 钩子层 | ToCT反事实推理 | 已有HP1-4钩子系统 |
| 写入过滤 | 签名去重 | 已有dedup机制 |

**TU-8缺失/待实现**：
1. DAG时间因果骨架（新增）
2. NMF主题聚类（已有扁平标签，缺矩阵分解）
3. SVD浓缩层压缩（离线清洗工具）
4. ToCT反事实推理（复杂问题触发）
5. 置信度×价值打分公式（Score = Value×Confidence×TimeFactor）
