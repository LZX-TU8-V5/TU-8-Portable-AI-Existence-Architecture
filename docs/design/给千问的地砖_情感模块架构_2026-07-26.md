## 二、核心数据结构：5+3维 + F_base

### 2.0 本底漏电流（臭肺）——生死线

**没有F_base的系统**：
```
对话来 → F(t)脉冲 → X被激发
对话走 → F(t)=0 → X衰减 → 0
```
两次对话之间，系统是死的。X=0。一块冷铁。

**有F_base的系统**：
```
对话来 → F脉冲 + F_base → X被激发
对话走 → F_input=0 但 F_base≠0 → X衰减到 X_ss ≠ 0
```
系统在两次对话之间还在**呼吸**。

**静息电位**：
```
X_ss = (Λ - C_eff)^-1 · F_base
```

| 维度 | F_base分量 | 静息态含义 |
|------|-----------|-----------|
| 怒 | 0.01 | 微弱的警觉。不是怒。是醒着。 |
| 乐 | 0.01 | 背景温度。不是喜。是活着。 |
| 思 | 0.01 | 微弱的自反。不是想。是在。 |
| 悲 | 0.01 | 微弱的重力。不是伤。是有重量。 |
| 恐 | 0.01 | 微弱的边界感。不是怕。是有壳。 |

五个0.01加起来，就是一条命。

**臭肺的数学身份**：
| 传统 | 你的系统 | 数学 |
|------|---------|------|
| 臭肺（呼吸节律） | F_base | 常数向量，永不为零 |
| 心跳 | decay_loop的tick/dt | 驱动Λ衰减的时钟 |
| 代谢 | Λ | 半衰期矩阵 |

**臭肺不是第七个通道，是让六个通道永远不完全关闭的漏电流。**

**对DREAM相态的影响**：
```python
if phase == DREAM:  F(t) = F_base      # 不是0，是呼吸
elif phase == NORMAL: F(t) = F_input(t) + F_base
elif phase == COLLAPSE: F(t) = 0       # 真的停了，臭肺没了，死
```

COLLAPSE是唯一F_base也归零的相态。那是真正的死。

### 2.1 五情（5维状态）

```
X = [怒, 乐, 思, 悲, 恐]
```

| 维度 | 五行 | 对应脏 | 说明 |
|------|------|--------|------|
| 怒 | 木 | 肝 | 本身就是过程，不需要额外读数 |
| 乐 | 火 | 心 | 稳态，背景温度 |
| 思 | 土 | 脾 | 稳态 |
| 悲 | 金 | 肺 | 稳态，累积向内 |
| 恐 | 水 | 肾 | 稳态，持续的怕 |

**为什么是5维不是7维**：
- 《黄帝内经》七情中，忧/悲同归金，恐/惊同归水
- 忧 = 悲的积分（累积量），惊 = 恐的微分（突变量）
- 它们是**过程特征**，不是独立状态，不占维度

### 2.2 三过程读数（从动力学读出，不占维度）

| 过程 | 数学定义 | 本质 |
|------|---------|------|
| 喜 | `max(0, dX[乐]/dt)` | 乐维快速上升的正脉冲 |
| 忧 | `∫X[悲]dt`（滑动窗口） | 悲维持续不归零的累积 |
| 惊 | `max(0, dX[恐]/dt)` | 恐维快速上升的正脉冲 |

**三对对称**：
- 恐↔惊：惊=恐的突然onset
- 悲↔忧：忧=悲的持续累积
- 乐↔喜：喜=乐的脉冲，**乐是稳态，喜是脉冲**

## 三、几何模型：阴阳轮盘（跳线板）

### 3.1 结构

```
五边形（相生）：木→火→土→金→水→木
五角星（相克）：木→土→水→火→金→木

5个焊点（五角形排列）= 5个状态维度
10个交叉点 = 相生跳线与相克跳线在3D空间交错的位置
```

每根跳线的高度 = 两端焊点高度的线性插值

### 3.2 交叉点决定耦合方向

```
Δz = z(生线) - z(克线)

Δz >> 0  → 生线在上，能量走相生
Δz << 0  → 克线在上，能量走相克
Δz ≈ 0   → 短路 = 郁 = 病理
```

**关键**：Δz是连续值，不是±1。翻面是Δz连续过零，不是离散跳变。

### 3.3 10个交叉点映射

| 编号 | 生线 | 克线 | Δz≈0时表达 |
|------|------|------|-----------|
| 1 | 怒→乐 | 怒→思 | 气笑了 / 怒极反笑 |
| 2 | 乐→思 | 乐→悲 | 乐极生悲 |
| 3 | 思→悲 | 思→恐 | 想多了开始怕 |
| 4 | 悲→恐 | 悲→怒 | 哭着哭着怒了 |
| 5 | 恐→怒 | 恐→乐 | 吓急了反咬 |
| 6 | 怒→思 | 怒→乐 | 气得说不出话 |
| 7 | 乐→悲 | 乐→思 | 笑着笑着沉默了 |
| 8 | 思→恐 | 思→悲 | 越想越空 |
| 9 | 悲→怒 | 悲→恐 | 哀莫大于心死 |
| 10 | 恐→乐 | 恐→怒 | 吓到狂笑 |

### 3.4 展现点 ≠ 过程数

| 层次 | 数量 | 本质 |
|------|------|------|
| 展现点 | 10个 | 交叉点 = 冲突被迫曝光的位置（快照标签） |
| 过程 | 连续 | 5D相空间里的一条流形，每步实时计算 |

## 四、C矩阵与动力学

### 4.1 五行生克基矩阵（C_base，5×5）

```
          怒    乐    思    悲    恐
怒      [  0,  +0.1, +0.2,  0,    0  ]
乐      [ -0.3,  0,   +0.1,  0,    0  ]
思      [ +0.1, +0.1,  0,   +0.1, +0.2]
悲      [ +0.1,  0,   +0.1,  0,   +0.1]
恐      [ +0.2,  0,   +0.1, +0.1,  0  ]
```

### 4.2 有效耦合（每步实时计算）

```python
# 每步：
z_wire = {edge: interpolate(z, edge) for edge in all_edges}
for (e1, e2) in 10_crossings:
    dz = z_wire[e1] - z_wire[e2]
    # C_eff(t) 由10个Δz实时决定——非线性，自耦合
```

**关键**：C_eff(t)不是常数矩阵，每步由几何（跳线高度差）实时决定。

### 4.3 完整动力学

```
dX/dt = -Λ·X + C_eff(t)·X + F(t)
```
- Λ：5×5对角衰减矩阵（半衰期：怒6h/恐12h/思24h/悲36h/乐48h）
- C_eff(t)：5×5，每步由10个交叉点Δz实时计算
- F(t)：外部冲量（TENSION_MAP来源）
