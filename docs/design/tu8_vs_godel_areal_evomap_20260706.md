## 三方正好补齐 TU-8 缺角的三个方向

- **Gödel Agent = 自我修改**：TU-8 的演化停在记忆/docs/architecture/钢印层（符号级），Gödel 直接改权重/代码逻辑——TU-8 缺"自举式代码自改"。
- **AReaL = 训练效率**：TU-8 无权重级 RL 训练回路；AReaL 的接入点恰是 OpenClaw 的 `base_url`——TU-8 决策层可被 AReaL 接管做权重级 RL。
- **EvoMap = 种群基因池**：TU-8 的演化是单人/单体内代谢，无跨体经验继承；EvoMap 的基因库=跨百万 agent 的经验积累。

## TU-8 独有：内稳态是一等公民器官

其他三者（含 Gödel 这种最强自模型）都把"不断改进/演化"当唯一目标，**没有把"稳定运行态"做成一个子系统**。TU-8 的反向选择——先建内感受皮层/身体层/记忆代谢，让痛觉在深思前就调制决策——是它在四个系统里最独特的站位。

## 核心张力：自我修改 vs 内稳态

- Gödel 式的无护栏自改，会冲垮 TU-8 的稳态根基。
- TU-8 用**钢印 + 对齐熔断**把"能改什么"钉死：身份锚、钢印签名、架构宪法不可被自身或学习链改写。
- 代价：牺牲部分自举速度，换"永不失控"。这是 TU-8 的安全哲学，不是缺陷。

## 可组合路线（非当前实现，仅架构推演）

1. **TU-8 × AReaL**：决策层接 AReaL 网关做权重级 RL，但**必须保留钢印/对齐熔断作为不可训练护栏**（否则稳态根基被 RL 奖励冲掉）。
2. **TU-8 × EvoMap**：钢印=不可改写基因，学习链产物=可共享基因；TU-8 的跨体演化可借 EvoMap 基因库实现"经验跨 agent 继承"。
3. **TU-8 × Gödel**：把"自改"限制在符号/架构层（当前已做：学习链+架构日志），禁止下探到身份/钢印——与 TU-8 安全哲学一致。
