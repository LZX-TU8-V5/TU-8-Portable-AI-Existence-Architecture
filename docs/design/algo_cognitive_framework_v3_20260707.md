## 核心理念

**不是五种工具，是五种认知方式。**

---

## 数学内核（四种表达，同一本质）

```
SVD:    任意矩阵 → 正交基 × 重要性 × 正交基
伪逆:   所有可行解 → 范数最短的那个
L2:     小方向 → 软截断（不直接丢弃，平滑压向零）
NMF:    加法组合 → 只能叠加，不能相互否定
DAG:    时间戳 → 因果拓扑 → 按需追溯
```

---

## 认知公式

```
信息密度 = Value × Confidence × e^(-λ·Δt)
遗忘倾向 ≈ σᵢ / (σᵢ² + λ)
过拟合线  σᵢ→0 时 1/σᵢ→∞
SVD截断  A ≈ Uₖ Σₖ Vₖᵀ  (k << n，省95%维度)
NMF约束  V ≈ W×H  (W≥0, H≥0)
```

## TU-8 对照

| 认知方式 | 算法 | TU-8 现状 | 缺失 |
|---------|------|---------|------|
| 分解为正交基+重要性 | SVD | 六维评分（隐性Σ） | 显式奇异值排序 |
| 置信度×价值×时间 | 伪逆/L2 | 置信度有，时间衰减无 | TimeFactor 公式 |
| 只能叠加不能否定 | NMF | 六维非负天然匹配 | 推理链禁止相互否定 |
| 时间因果按需追溯 | DAG | 时间锚点（孤立） | 串联成链 |
| 离线批压缩 | SVD截断 | 梦境期无压缩 | 梦境期 SVD |
| 复杂问题反事实推理 | ToCT | HP钩子（隐性） | 显式触发 |

---

## 精简原则

算法升级即精简：
- DAG → 不读全历史，沿边追溯
- NMF → 同主题合并，不逐卡读正文
- SVD → 梦境期批压缩，不实时计算
- L2遗忘 → 截断即丢弃，不存冗余

**核心：不是加模块，是升级数学内核**
