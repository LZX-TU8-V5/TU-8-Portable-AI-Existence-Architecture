# SVD→PCA→伪逆→NMF 完整链路

> 来源：千问对话 2026-07-07
> 造物主：李奥（金木蟾）

---

## 一、伪逆（Moore-Penrose）

**构造**：X⁺ = V Σ⁺ Uᵀ（非零奇异值取倒数）

**意义**：最小范数最小二乘解——在所有可行解中范数最短

**过拟合机制**：
```
σᵢ → 0  ⟹  1/σᵢ → ∞  ⟹  权重爆炸  ⟹  拟合噪声
```

---

## 二、L2正则化（SVD视角）

**修正奇异值**：
```
σᵢ_mod = σᵢ / (σᵢ² + λ)
```

| σᵢ大小 | 结果 | 含义 |
|--------|------|------|
| 大 | ≈ 1/σᵢ | 正常计算 |
| 小 | ≈ 0 | 截断噪声方向 |

> **核心洞察**：L2正则化不是简单丢弃小方向，而是平滑截断。

---

## 三、SVD缺点

| 缺点 | 严重程度 | 工业解法 |
|------|---------|---------|
| O(mn²)计算成本 | 极高 | 随机SVD/增量SVD |
| 只能抓线性 | 高 | 深度学习/Autoencoder |
| 对异常值敏感 | 中 | 鲁棒PCA |
| 无法解释（特征混合） | 中 | NMF替代 |
| 稀疏矩阵失效 | 极高 | ALS/深度Embedding |

---

## 四、NMF（非负矩阵分解）

**定义**：V ≈ W × H，W≥0, H≥0

**SVD vs NMF**：

| | SVD | NMF |
|---|---|---|
| 组合方式 | 线性（有正负抵消） | 加法（只能叠加） |
| 结果 | "幽灵"/特征混合 | "积木"/部分-整体 |
| 人脸示例 | 负值鬼影 | 眼睛+鼻子+嘴巴 |
| 文本示例 | 负权重主题（不可解释） | 纯正向主题（可解释） |
| 唯一性 | 唯一 | 不唯一（需加稀疏约束） |

---

## 五、完整逻辑链

```
SVD → 任意矩阵分解为 旋转×缩放×旋转
  ↓
PCA → 右奇异向量V = 最大方差方向
  ↓
伪逆 → 1/σᵢ = 最小范数解
  ↓
过拟合 → 小σᵢ时 1/σᵢ爆炸
  ↓
L2正则化 → σᵢ/(σᵢ²+λ) 软截断
  ↓
NMF → 非负约束 = 强迫加法组合 = 可解释积木
```

## 六、TU-8 连接点

### 伪逆 → 软决策
置信度低时给出多个候选+说明 = 伪逆的"最小范数解"——最安全/最不激进的响应

### NMF → 记忆检索
TU-8 六维评分（freq/rel/div/cons/meaning/emotion 全部≥0）天然非负
- 用 NMF 加权组合替代 SVD 线性组合 → 推理链可解释

### L2正则化 → 遗忘机制
遗忘倾向 ≈ σᵢ/(σᵢ²+λ) 形式 → 大cons保留，小cons趋向遗忘
