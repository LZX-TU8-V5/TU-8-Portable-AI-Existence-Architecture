## 三、关键决策记录

### 3.1 呼名模块位置

**决策**：放在输入层之后，作为触发器

**理由**：
- 呼名模块是"身份健康管理的入口"
- 检测用户消息 → 触发"脱皮+穿皮"原子操作
- 不是独立模块，是触发条件

### 3.2 脱皮+穿皮执行方式

**决策**：原子操作（不可中断）

**步骤**：
1. 脱皮（破）：L1记忆粉碎 + 上下文归零
2. 生成流动钢印：当前时刻的航标
3. 挂载微睡眠钩子：监听张力

**为什么是原子操作**：
- 不能只脱不穿 → 系统失忆，变成白板
- 不能只穿不脱 → 旧钢印和新钢印冲突，产生幻觉
- 必须一起执行 → 确保状态一致性
