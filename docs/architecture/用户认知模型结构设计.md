## 用户认知模型三层结构

### L1: 基本信息（静态层）

**定义**：用户显式提供的基本属性

**内容**：
- 姓名/称呼/代词
- 时区/职业/年龄
- 家庭成员/项目状态
- 沟通偏好/情境标签

**更新频率**：极低（用户主动更新）

**存储位置**：`USER.md`

**示例**：
```yaml
姓名: 李奥
代词: 她/her
职业: 室内设计师
时区: Asia/Shanghai
家庭: 女儿七七（2021年生）
```

---

### L2: 行为习惯 & 认知习惯（动态层）

**定义**：从交互中提取的习惯模式

**子分类**：

#### 2.1 行为习惯（Behavioral Habits）

**内容**：
- 活跃时间段
- 常用工具/命令
- 操作序列模式
- 响应速度偏好

**提取方式**：日志挖掘 + 统计分析

**更新频率**：中频（每周评估）

**存储位置**：`memory/user_behavior_patterns.json`

#### 2.2 认知习惯（Cognitive Habits）

**内容**：
- **钩子直接应用**？
  - ✅ 精确匹配钩子 = 用户常用概念/术语
  - ✅ 语义钩子 = 用户认知关联路径
  
**钩子与认知习惯的关系**：
```
钩子（Hooks）
    ├─ trigger_hooks（精确匹配）
    │   └─ 用户高频使用的术语/概念
    │   └─ 例："数据库配置"、"连接池"、"PostgreSQL"
    │
    └─ semantic_hooks（语义关联）
        └─ 用户认知关联路径
        └─ 例："数据库" → "配置" → "优化"
```

**核心问题**：钩子是直接应用还是复合应用？

**答案**：**复合应用**

**理由**：
1. **trigger_hooks** = 用户显式术语（直接应用）
2. **semantic_hooks** = 用户认知路径（复合应用）
3. 两者组合形成完整的认知习惯画像

**提取方式**：
- 钩子 Genesis（四大来源）
- 钩子养护（3天周期行为验证）
- 钩子晋升/淘汰

**更新频率**：高频（每次交互）

**存储位置**：
- `memory/hook_index.db`（钩子索引）
- `memory/cards/*.md`（记忆卡钩子字段）

---

### L3: 认知知识（专业层）

**定义**：用户的专业领域知识结构

**内容**：
- 专业术语库（不同专业不同）
- 领域知识图谱
- 问题解决路径
- 决策框架

**示例**：
```yaml
室内设计师（李奥）:
  专业术语: ["空间规划", "动线设计", "材料搭配", "灯光布局"]
  知识图谱: "室内设计/施工流程/材料选择/预算控制"
  决策框架: "功能优先 → 美观次之 → 预算约束"
  
程序员:
  专业术语: ["算法", "数据结构", "设计模式", "架构"]
  知识图谱: "计算机科学/软件工程/系统设计"
  决策框架: "需求分析 → 架构设计 → 编码实现 → 测试部署"
```

**更新频率**：低频（项目级）

**存储位置**：`memory/cognitive_knowledge/`

---

## 三层关系

```
L1: 基本信息（静态层）
    ↓ 显式提供
    
L2: 行为习惯 & 认知习惯（动态层）
    ↓ 钩子系统提取 + 养护
    ├─ trigger_hooks（精确术语）
    └─ semantic_hooks（认知路径）
    
L3: 认知知识（专业层）
    ↓ 领域知识 + 决策框架
```

---

## 钩子在认知模型中的定位

### 钩子是认知习惯的直接应用

**作用**：
1. **捕捉用户术语**：trigger_hooks 记录用户高频术语
2. **映射认知路径**：semantic_hooks 记录用户思维关联
3. **行为验证**：3天养护周期验证钩子有效性
4. **动态调整**：晋升/淘汰机制保持认知模型新鲜度

### 钩子与认知习惯的关系

| 维度 | 钩子类型 | 作用 | 示例 |
|------|---------|------|------|
| **术语层** | trigger_hooks | 精确匹配用户常用词 | "数据库配置" |
| **关联层** | semantic_hooks | 捕捉用户认知路径 | "数据库" → "优化" |
| **验证层** | 养护引擎 | 行为验证有效性 | hit_score 积累 |
| **调整层** | 晋升/淘汰 | 动态更新认知模型 | 周期性裁剪 |

---

## 设计决策

### 钩子是复合应用

**理由**：
1. **单一钩子无法完整描述认知习惯**
   - trigger_hooks 捕捉术语
   - semantic_hooks 捕捉关联
   - 两者组合才是完整认知习惯

2. **需要行为验证闭环**
   - 钩子 Genesis 提案
   - 认证路由准入
   - 3天养护验证
   - 晋升/淘汰调整

3. **需要与 L1/L3 联动**
   - L1 基本信息 → 钩子黑名单（敏感词）
   - L3 认知知识 → 钩子语义关联
