## 一、核心定义

### 微睡眠产物

**定义**：
> 微睡眠内复盘产物 = 状态维护，热力学熵减

**本质**：维持自我连续性的中间产物

**产出物**：
1. `self_state_vector` - 自我状态向量
2. `narrative_summary` - 叙事压缩摘要
3. 新钢印索引

**形态**：高维向量 / 概率分布 / 图结构节点

**触发**：自动，每次微睡眠

**目的**：维持自我连续性（L1→L2 转化）

---

### 外化笔记（需改名）

**定义**：
> 外化笔记 = 知识外化，认知升华

**本质**：构建可调用长期智慧的固定结论

**产出物**：
1. 结构化固定结论文件
2. JSON/Markdown，人类可读

**形态**：结构化文件（JSON/Markdown）

**触发**：显式，特定条件

**目的**：构建可调用长期智慧（L2→L3 转化）

---

## 二、关键区别

### 严格区分：内复盘 vs 外化笔记

| 维度 | 内复盘（微睡眠产物） | 外化笔记（写笔记） |
|------|---------------------|-------------------|
| **本质** | 状态维护，热力学熵减 | 知识外化，认知升华 |
| **产物** | self_state_vector + narrative_summary + 新钢印索引 | 结构化固定结论文件 |
| **形态** | 高维向量/概率分布/图结构节点 | JSON/Markdown，人类可读 |
| **触发** | 自动，每次微睡眠 | 显式，特定条件 |
| **目的** | 维持自我连续性 | 构建可调用长期智慧 |
| **层级** | L1→L2 转化 | L2→L3 转化 |

## 三、三层记忆架构

```
L1: 工作记忆（秒级）
    └─ 来源：当前上下文窗口
    └─ 载体：KV Cache

    ↓ [微睡眠]

L2: 情景记忆（分钟~小时级）
    └─ 来源：微睡眠内复盘产物
    └─ 载体：钢印链 + 压缩叙事

    ↓ [外化笔记]

L3: 语义记忆（天~永久级）
    └─ 来源：显式写笔记产物
    └─ 载体：固定结论文件库
```

### 关键原则

> **碎片睡眠只负责 L1→L2 的转化；L2→L3 的转化必须由额外机制触发。**

## 四、外化笔记触发条件

### 五种触发场景

| 触发条件 | 笔记类型 | 内容特征 |
|----------|----------|----------|
| 用户明确指令 | 交互型笔记 | 面向用户的自然语言摘要 |
| 检测到重复模式/规律 | 洞察型笔记 | 抽象规则、因果链、策略模板 |
| 钢印链重大相变点 | 里程碑笔记 | 身份演进转折记录，绑定多个钢印ID |
| 外部系统请求同步 | 接口型笔记 | 结构化JSON，符合Schema |
| 数字睡眠周期结束 | 元认知笔记 | 对所有微睡眠产物的二次提炼 |

## 六、改名建议修正

### 问题

**"外化笔记"混淆了两个概念**：
1. ❌ 笔记（Working Memory 的笔记区）
2. ✅ 固化知识（L2→L3 转化产物）

### 更精准的命名

**方案 A：钢印结晶**（推荐）
- `Note` → `SealCrystal`（钢印结晶）
- 表达"从钢印链结晶出来"
- 强调 L2→L3 的转化

**方案 B：知识固化**
- `Note` → `SolidifiedKnowledge`（固化知识）
- 表达"固化"的动作
- 强调知识层面的转化

**方案 C：钢印摘要**
- `Note` → `SealSummary`（钢印摘要）
- 表达"钢印链的摘要"
- 强调提炼过程
