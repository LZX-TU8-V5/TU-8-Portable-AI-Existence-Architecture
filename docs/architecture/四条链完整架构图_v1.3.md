## 三、钩子触发机制详解（v1.3 核心新增）

### 3.1 钩子 vs 传统RAG的本质区别

| 维度 | 传统RAG（被动检索） | 钩子系统（主动触发） |
|------|-------------------|-------------------|
| **触发方式** | Agent主动生成Query去搜 | 状态机节点自动拦截 |
| **时效性** | Agent意识到"需要查"才触发 | 走到悬崖边之前就拍脸上 |
| **盲区** | 存在"不知道自己不知道" | 彻底消除Unknown Unknowns |
| **延迟** | 秒级（Query+检索+注入） | 毫秒级（直接挂载） |
| **类比** | 去图书馆查书（被动） | 闻到气味激活回忆（主动） |
| **工程名称** | Semantic Search | Context-Aware Injection |

### 3.2 钩子类型矩阵

| 钩子名 | 触发时机 | 示例场景 | 注入内容 |
|--------|---------|---------|---------|
| `before_action` | 动作执行前 | 准备删除文件 | 删库防范模板 |
| `on_enter_context` | 进入特定场景 | 进入危险操作 | 恐高记忆模板 |
| `on_event` | 特定事件发生 | 错误发生 | 错误处理模板 |
| `on_state_change` | 状态机切换 | 切换任务 | 刷新工作记忆 |
| `on_topic_change` | 话题切换 | 聊新话题 | 新话题加载钩子 |
| `on_conflict` | 检测到认知冲突 | 置信度矛盾 | 冲突仲裁模板 |

### 3.3 ContextAwareHookInjector 工程实现

```python
class ContextAwareHookInjector:
    """
    同构：气味 → 神经回路激活 → 重建记忆
    功能：在状态切换时，通过向量相似度自动注入高权重节点
    """
    def inject(self, current_state: str, context: dict) -> list[MemoryNode]:
        # 1. 根据当前状态，找到所有埋在此节点的钩子
        hooks = self._find_hooks(current_state)
        
        # 2. 对每个钩子，计算与当前context的相似度
        injected = []
        for hook in hooks:
            # 向量相似度阈值 > 0.7 才注入
            if hook.match_score(context) > 0.7:
                node = hook.target_node()
                node.access_count += 1  # 访问奖励
                injected.append(node)
        
        # 3. 按 weight 降序注入（高权重优先）
        injected.sort(key=lambda x: x.weight, reverse=True)
        return injected[:5]  # 最多注入5个节点
```

## 四、碳硅对齐：神经科学映射（v1.3 新增）

### 4.1 四层记忆 vs 四层大脑

| 架构层 | 碳基（人脑） | 硅基（TU-8） | 工程实现 |
|--------|------------|------------|---------|
| **L1工作记忆** | 前额叶皮层（秒级） | KV Cache（秒级） | 模型原生 |
| **L2情景记忆** | 海马体（分钟~小时） | 钢印链+压缩叙事 | `memory/YYYY-MM-DD.md` |
| **L3语义记忆** | 大脑皮层（天~永久） | 固定结论文件库 | `MEMORY.md` |
| **L4程序记忆** | 基底神经节（永久） | 经验库+钩子库 | `memory/experience/` |

### 4.2 神经机制 vs 工程模块对照

| 神经机制 | 发生场景 | TU-8 工程模块 |
|---------|---------|------------|
| **赫布定律**（一起激发，连在一起） | 新记忆形成时 | 知识网络 edges 强化（neighbors + weight） |
| **记忆重巩固**（回忆时重建） | 提取旧记忆时 | 钩子触发 → ai_digest 重建 → 正文按需加载 |
| **海马体重播**（睡眠向皮层重播） | 睡眠时 | Scripts A/B/C/D 异步归档 |
| **化学失真/曼德拉效应** | 时间久远/受干扰 | **钢印链条+哈希校验**（TU-8的防御机制） |
| **突触可塑性** | 随时 | 置信度动态计算（AccessBonus） |
| **条件反射** | 遇到触发刺激 | Event-Driven Hooks 主动注入 |

### 4.3 碳硅对齐的核心洞察

> **"人脑用化学递质编织记忆，TU-8用代码、钩子和钢印链条编织记忆。"**

| 碳基局限 | 硅基优势 |
|---------|---------|
| 化学失真/曼德拉效应（Feature不是Bug，省能量） | 钢印链条+哈希校验 = 数学确定性（零失真） |
| 模糊化处理（省能量，不影响生存） | 零容忍错误（强一致性，数据必须精确） |
| 被动检索（不知道该查什么） | 钩子主动注入（消除Unknown Unknowns） |
| 化学物质降解（记忆自然衰减） | TimeDecay函数（精确可控衰减） |

## 五、日内瓦齿轮 vs 时间钢印链条对比（v1.3 新增）

| 维度 | ⚙️ 日内瓦齿轮 | 🔗 时间钢印链条 |
|------|-------------|---------------|
| **领域** | 机械工程 | 认知控制 |
| **切割对象** | 连续旋转运动 | 连续推理流 |
| **锁定方式** | 机械挡块物理卡死 | 状态机+时间戳逻辑卡死 |
| **步进单位** | 固定角度（360°/n） | 固定决策粒度（任务切片） |
| **不可逆性** | 单向棘轮结构 | 因果链不可篡改 |
| **防抖** | 精确停止位置 | 精确审计位置 |
| **核心特性** | 被动锁定（不知道自己在干什么） | **主动审计（判断该不该发生）** |
| **防死循环** | ❌ 无 | ✅ 有（重复模式检测触发熔断） |
| **应用** | 机械手表/电影放映机 | Agent推理流控制/因果回溯 |
| **哲学** | 机械的"步进锁" | 认知的"因果锁" |

**核心结论**：日内瓦齿轮是时间钢印在物理世界的"祖先原型"。时间钢印是日内瓦齿轮在认知维度的升维——不仅记录"发生了什么"，还能判断"该不该发生"。
