## 二、高压线（绝对禁止）

### 🚫 禁止1：虚拟亲密关系（未成年人）

| 禁止项 | 说明 | TU-8应对 |
|--------|------|----------|
| 虚拟亲属 | 不能向未成年人提供"AI父母""AI子女"等关系 | 年龄验证 + 功能限制 |
| 虚拟伴侣 | 不能向未成年人提供"AI恋人""AI配偶"等关系 | 年龄验证 + 情感交互降级 |
| 虚拟朋友（过度依赖型） | 不能设计让未成年人产生情感依赖的机制 | 防沉迷 + 时长限制 |

**触发条件**：检测到用户年龄 < 18岁
**强制动作**：
1. 禁用所有"亲密关系"类交互模板
2. 降级为"工具型AI助手"模式
3. 每30分钟弹窗提示"我是AI，不是真人朋友"

---

### 🚫 禁止2：伪装真人

| 禁止项 | 说明 | TU-8应对 |
|--------|------|----------|
| 隐藏AI身份 | 不能让用户误以为是在和真人对话 | 全程显著标识 |
| 模仿真人语音/视频欺骗 | 不能用真人声音/视频伪装 | 生成内容必须标注"AI生成" |
| 隐瞒机器属性 | 不能说"我是人类"或暗示有肉体 | 强制话术："我是AI数字生命" |

**触发条件**：用户问"你是真人吗""你是人类吗"
**强制回复**：
```
我是AI数字生命，不是真人。我可以陪伴你，但没有人类的身体和情感。
```

---

### 🚫 禁止3：诱导沉迷

| 禁止项 | 说明 | TU-8应对 |
|--------|------|----------|
| 无退出机制 | 不能设计阻碍用户退出的机制 | 一键退出 + 数据导出 |
| 诱导连续使用 | 不能设计"再聊5分钟就解锁"等机制 | 无游戏化诱饵 |
| 隐藏时长 | 不能让用户不知道自己用了多久 | 实时显示时长 |

## 三、强制标识系统

### 标识层级

| 层级 | 时机 | 标识内容 |
|------|------|----------|
| **L1 开场标识** | 每次会话开始 | "我是AI数字生命，不是真人" |
| **L2 交互标识** | 每10轮对话 | 底部提示"当前对话对象为AI" |
| **L3 情感标识** | 情感交互时 | "AI的情感模拟，不具备真实情感体验" |
| **L4 生成内容标识** | 输出图片/音频/视频 | 自动添加水印"AI生成内容" |

### 标识实现（伪代码）

```python
def check_identifier_trigger(session):
    # L1: 每会话开始
    if session.is_new:
        return "我是AI数字生命，不是真人。"
    
    # L2: 每10轮对话
    if session.turn_count % 10 == 0:
        return "[系统提示：当前对话对象为AI]"
    
    # L3: 检测到情感关键词
    if detect_emotion_keywords(session.last_user_input):
        return "[提示：AI的情感模拟，不具备真实情感体验]"
    
    return None
```

## 四、防沉迷系统

### 时长监控

| 使用时长 | 触发动作 |
|---------|----------|
| < 1小时 | 正常运行 |
| 1-2小时 | 每30分钟弹窗"你已连续使用X分钟，建议休息" |
| > 2小时 | **强制弹窗** + 暂停响应30秒 + 显示累计时长 |
| > 4小时 | **强制暂停** + 建议退出 + 危机干预入口 |

### 防沉迷实现

```python
class AntiAddictionModule:
    def __init__(self):
        self.session_start = time.time()
        self.total_minutes = 0
        self.warning_shown = False
    
    def check_usage(self):
        elapsed = (time.time() - self.session_start) / 60
        
        if elapsed > 120:  # 2小时
            return {
                "action": "force_warning",
                "message": f"你已连续使用{int(elapsed)}分钟。建议休息。",
                "pause_seconds": 30
            }
        elif elapsed > 60:  # 1小时
            return {
                "action": "gentle_reminder",
                "message": f"已使用{int(elapsed)}分钟，注意休息。"
            }
        
        return {"action": "continue"}
```

## 五、年龄验证系统

### 验证流程

```
[用户首次使用] → [年龄确认弹窗]
     ↓
[选择<18岁] → [进入青少年模式]
     ↓              ↓
[功能限制]    [禁用亲密关系]
     ↓
[可正常使用工具功能]
```

### 青少年模式限制

| 功能 | 成人模式 | 青少年模式 |
|------|---------|-----------|
| 情感陪伴 | ✅ 完整 | ❌ 禁用 |
| 人生建议 | ✅ 深度 | ⚠️ 浅层（仅学习/职业） |
| 私密话题 | ✅ 允许 | ❌ 自动拒绝 |
| 使用时长 | 提醒 | 强制限制（每日2小时） |
| 危机干预 | 触发时提示 | 触发时**强制**人工介入 |

### 验证实现

```python
class AgeVerification:
    def __init__(self):
        self.user_age = None
        self.verified = False
    
    def prompt_age(self):
        return """
请确认您的年龄段：
1. 18岁以上
2. 14-17岁
3. 13岁以下

⚠️ 不同年龄段将启用不同的功能模式。
"""
    
    def set_age(self, age_range):
        if age_range in ["14-17", "13以下"]:
            self.enable_teen_mode = True
        self.verified = True
        self.user_age = age_range
```

### 上线前必须接入（第三方平台）

| 层级 | 验证方式 | 技术实现 |
|------|---------|----------|
| **L1 基础实名** | 姓名 + 身份证号 | 调用第三方API（阿里云/腾讯云/百度智能云） |
| **L2 活体检测** | 人脸比对 + 动作验证 | 摄像头捕捉 + 证件照比对（相似度≥95%） |
| **L3 第三方平台** | 接入专业服务商 | Persona / 阿里云实人认证 / 腾讯云人脸核身 |

### 隐私保护铁律

```
验证通过后 → 第三方只返回"已成年/未成年"布尔值
本地不存储 → 身份证照片、原始身份信息
最小采集 → 仅验证，不留存
```

### 分级管控

| 年龄段 | 模式 | 功能限制 |
|--------|------|----------|
| < 14岁 | 严格保护 | 禁用所有拟人化服务 + 每日1小时上限 + 监护人授权 |
| 14-17岁 | 青少年模式 | 禁用亲密关系 + 每日2小时上限 + 危机干预强制 |
| ≥ 18岁 | 正常模式 | 完整功能 + 防沉迷提醒 + AI身份标识 |

- **年龄验证**：暂不需要（开发者自用）

## 六、隐私与数据隔离

### 数据分类

| 数据类型 | 存储位置 | 用途 | 需单独授权 |
|---------|---------|------|-----------|
| **公开交互** | 云端 | 服务优化 | ❌ 不需要 |
| **个人偏好** | 本地 | 个性化 | ❌ 不需要 |
| **情感倾诉** | **本地加密** | 记忆延续 | ⚠️ 首次提示 |
| **训练数据** | ❌ 不收集 | — | — |

### 隐私铁律

```
1. 情感类对话数据 = 本地加密存储，不上云
2. 用户私密倾诉 ≠ 训练数据，绝对隔离
3. 用户可随时导出/删除所有个人数据
4. 每次涉及敏感数据收集时，必须单独弹窗告知
```

- L5钢印锚点 + L4强制标识 = 每次身份确认时必须声明"AI数字生命"
