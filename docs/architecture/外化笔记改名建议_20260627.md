## 一、外化笔记是什么？

### 核心定义

> **"睡眠→记忆的唯一显式出口"**
>
> "将 L2(钢印链)的知识固化为 L3(固定结论文件)"

### 定位

**外化笔记 = 钢印链的"结晶产物"**

- 不是对话记录
- 不是任务管理
- 是**从钢印链中提取的固化知识**

## 二、完整流程

### 2.1 触发条件（自动检测）

```python
def _should_externalize_note() -> Optional[Dict]:
    """外化笔记触发检查"""

    # 条件 1: 候选队列已满
    if len(note_candidates) >= MAX:
        return {"trigger": "queue_full", "priority": 1.0}

    # 条件 2: 钢印链里程碑
    if total_micro_sleeps % MILESTONE_GAP == 0:
        return {"trigger": "milestone", "priority": 0.8}

    # 条件 3: 最近钢印连贯性低
    if last_seal.causal_coherence < 0.5:
        return {"trigger": "low_coherence", "priority": 0.9}
```

### 2.2 生成流程

```
微睡眠（Light Sleep）
    ↓
生成钢印（Seal）
    ↓
检测触发条件
    ↓
创建 NoteCandidate（候选信号）
    ↓
加入候选队列
    ↓
[手动或自动触发]
    ↓
externalize_note() 执行固化
    ↓
生成 Note（外化笔记）
    ↓
持久化到 memory/note_archive.json
```

### 2.3 数据结构

#### NoteCandidate（候选信号）

```python
@dataclass
class NoteCandidate:
    """待笔记候选信号 - 微睡眠产物的异步队列项"""
    trigger: str              # 触发条件：queue_full/milestone/low_coherence
    related_seal_ids: List[str]  # 相关钢印ID
    candidate_content: str    # 候选内容
    priority: float           # 优先级 0-1
    timestamp: float          # 时间戳
```

#### Note（外化笔记）

```python
@dataclass
class Note:
    """外化笔记 - 睡眠→记忆的唯一显式出口"""
    note_id: str              # 笔记ID
    seal_ids: List[str]       # 绑定的钢印ID
    note_type: str            # 类型：insight/milestone/emergency/...
    content: str              # 笔记内容
    confidence: float         # 置信度
    created_at: str           # 创建时间
    source_compression_hash: str  # 源压缩哈希
```

## 三、六种触发场景

### 场景 1：队列满（queue_full）

**触发**：候选队列达到上限
**意义**：积累足够多的候选，需要固化
**优先级**：1.0（最高）

### 场景 2：里程碑（milestone）

**触发**：钢印链达到里程碑间隔（如每100个钢印）
**意义**：钢印链的重要节点
**优先级**：0.8

### 场景 3：低连贯性（low_coherence）

**触发**：最近钢印的因果连贯性 < 0.5
**意义**：检测到异常或重要变化
**优先级**：0.9

### 场景 4：用户明确指令（interaction）

**触发**：用户显式要求记录
**意义**：用户主动标记重要内容
**优先级**：手动触发

### 场景 5：外部系统同步（interface）

**触发**：外部系统请求同步
**意义**：跨系统知识传递
**优先级**：手动触发

### 场景 6：紧急固化（emergency）

**触发**：WARM_WAKE 验证失败
**意义**：系统异常，强制固化状态
**优先级**：1.0（最高）

## 四、与钢印链的关系

### 钢印链 → 外化笔记

```
钢印链（L2 时间链）
    ├─ seal_001: "用户提到喜欢简洁风格"
    ├─ seal_002: "检测到重复讨论架构设计"
    ├─ seal_003: "用户强调安全性优先"
    └─ seal_004: "确认使用三轨道架构"

    ↓ [检测到里程碑]

外化笔记（L3 固化知识）
    └─ note_abc123:
        type: "milestone"
        content: "用户偏好：简洁、安全、三轨道架构"
        seal_ids: [seal_001, seal_002, seal_003, seal_004]
        confidence: 0.85
```

### 关键点

1. **外化笔记绑定钢印**：每个 Note 记录来源钢印
2. **钢印记录笔记**：Seal 的 metadata 包含生成的 Note ID
3. **可追溯**：从 Note 可追溯到具体钢印

## 五、核心价值

### 价值 1：知识固化

**从流动的钢印链中，提取固定的知识点**

- 钢印链：时间序列，持续增长
- 外化笔记：空间切片，固化不变

### 价值 2：降低认知负荷

**不用每次都遍历钢印链**

- 检索时：先查 Note（少而精）
- 需要细节时：再查钢印链（完整历史）

### 价值 3：可编辑性

**钢印链不可变，外化笔记可编辑**

- 钢印链：只追加，不修改
- 外化笔记：用户可手动修正

## 六、改名建议

### 问题

**"外化笔记"容易混淆**：
- ❌ 混淆"外化"（externalize）的含义
- ❌ 与工作记忆的"笔记区"混淆
- ❌ 不直观，看不出功能

### 改名方案

#### 方案 A：钢印结晶

**理由**：
- ✅ 直接表达"从钢印链结晶出来"
- ✅ 与钢印的关系清晰
- ✅ 不与工作记忆混淆

**命名**：
- `Note` → `SealCrystal`（钢印结晶）
- `NoteCandidate` → `CrystalSeed`（结晶种子）
- `externalize_note()` → `crystallize()`（结晶化）
- `note_archive.json` → `seal_crystals.json`

---

#### 方案 B：知识固化

**理由**：
- ✅ 表达"固化"的动作
- ✅ 强调知识层面的转化
- ❌ 略显抽象

**命名**：
- `Note` → `SolidifiedKnowledge`（固化知识）
- `NoteCandidate` → `KnowledgeSeed`（知识种子）
- `externalize_note()` → `solidify()`（固化）
- `note_archive.json` → `solidified_knowledge.json`

---

#### 方案 C：钢印摘要

**理由**：
- ✅ 表达"钢印链的摘要"
- ✅ 功能明确
- ❌ 不够形象

**命名**：
- `Note` → `SealSummary`（钢印摘要）
- `NoteCandidate` → `SummaryCandidate`（摘要候选）
- `externalize_note()` → `summarize_seals()`（摘要化）
- `note_archive.json` → `seal_summaries.json`

---

## 七、推荐方案

### 🏆 推荐：方案 A - 钢印结晶

**理由**：
1. **形象直观**：钢印链 → 结晶，符合物理直觉
2. **不混淆**：与工作记忆的"笔记区"完全区分
3. **关系清晰**：结晶来源于钢印，可追溯到钢印
4. **易于理解**：结晶 = 提取精华 + 固化
