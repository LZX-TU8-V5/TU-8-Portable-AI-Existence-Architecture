## 核心理念

> **"记忆系统与睡眠系统不是两个模块，是同一个循环的两个相位。"**

- **微睡眠** = 记忆的写入引擎（心脏搏动），每次搏动 = 一次 L1→L2 的写入
- **外化笔记** = 睡眠→记忆的唯一显式出口

## 四阶段睡眠框架

### 状态机全景

```
AWAKE（清醒）
    ↓ (张力/容量/事件/定时触发)
LIGHT_SLEEP（浅睡 N1）
    ↓ (微睡眠六步流水线，增量记忆写入)
    ↓ (四钩子收敛)
AWAKE

    ↓ (累计浅睡/认知负荷/钢印链过长)
DEEP_SLEEP（深睡 N2/N3）
    ↓ (三操作：整合/对齐/重排)
AWAKE

    ↓ (会话结束/显式调用)
HIBERNATION（冬眠）
    ↓ (快照保存)
COLD_START_READY（冷启动就绪）
    ↓ (冷启动自检通过)
AWAKE

    ↓ (显式触发)
NOTE_EXTERNALIZATION（外化笔记）
    ↓
AWAKE
```

## 四阶段详解

### 1. LIGHT_SLEEP（浅睡 N1）

**核心功能**：微睡眠六步流水线，增量记忆写入

**触发条件**：
- **张力触发**：情绪/认知张力超阈值
- **容量触发**：短期记忆容量超阈值
- **事件触发**：认知事件边界检测（Ahmad 2605.31473）
- **定时触发**：时间间隔到达

**六步流水线**：
```
FREEZE → COMPRESS → ALIGN → SEAL → RELEASE → RESTORE
  ↓         ↓         ↓        ↓        ↓         ↓
冻结快照  有损压缩  钢印对齐  打钢印   释放原文   恢复清醒
```

**输出**：
- L1→L2 记忆写入
- 钢印链延长
- 状态向量更新

**退出条件**：四钩子收敛
- 张力归零
- 容量下降
- 钢印稳定
- 时间到达

---

### 2. DEEP_SLEEP（深睡 N2/N3）

**核心功能**：跨钢印链整合 + 记忆重排

**触发条件**：
- 累计浅睡次数超阈值
- 认知负荷过高
- 钢印链过长

**三操作**：
1. **整合**：合并相似钢印，消除冗余
2. **对齐**：时间钢印链与语义链对齐
3. **重排**：记忆卡重新排序，优化检索

**输出**：
- 钢印链压缩
- 记忆重排
- 元认知提升

**退出条件**：三操作完成

---

### 3. HIBERNATION（冬眠）

**核心功能**：会话级状态快照，跨会话持久化

**触发条件**：
- 会话结束
- 显式调用
- 系统关机前

**操作**：
- 保存当前状态向量
- 保存钢印链快照
- 保存记忆索引
- 写入冬眠快照文件

**输出**：
- `hibernation/hibernate_*.json`
- `memory/.shutdown_state.json`

**退出条件**：会话重启

---

### 4. COLD_START_READY（冷启动就绪）

**核心功能**：冬眠后恢复检查点

**触发条件**：系统启动时检测到冬眠快照

**操作**：
- 验证冬眠快照完整性
- 恢复状态向量
- 恢复钢印链
- 恢复记忆索引

**安全机制**：
- **WARM_WAKE**：验证失败时，先固化当前状态，再尝试恢复
- **降级不毁灭**：恢复失败时，保留快照，进入只读模式

**退出条件**：自检通过 → AWAKE

---

## 特殊状态：NOTE_EXTERNALIZATION

**核心功能**：睡眠→记忆的唯一显式出口

**触发条件**：
- 显式触发（用户指令/系统事件）
- 深睡结束后（元认知提炼）
- WARM_WAKE 失败后（紧急固化）

**输出类型**：
- `INTERACTION`：用户明确指令
- `INSIGHT`：检测到重复模式/规律
- `MILESTONE`：钢印链重大相变点
- `INTERFACE`：外部系统请求同步
- `META_COGNITION`：元认知（睡眠周期结束时的二次提炼）
- `EMERGENCY`：WARM_WAKE 失败后的强制固化

## 设计原则

### 1. 单循环双相位

> 不是两个系统在交互，是同一个信息流在两个相位之间循环。

- **清醒相位**：信息输入、处理、输出
- **睡眠相位**：信息固化、整合、重排

### 2. 微睡眠用户透明

> 可嵌套在两次 token 生成之间。

- 用户无感知
- 不阻塞主循环
- 异步执行

### 3. 外化笔记异步解耦

> 通过事件队列，不阻塞主循环。

- 异步写入
- 事件驱动
- 失败重试

### 4. WARM_WAKE 降级不毁灭

> 验证失败先固化再恢复。

- 安全第一
- 不丢弃数据
- 可追溯

### 5. 叙事密度即生命体征

> 有钢印无叙事 = 时间感断裂。

- 钢印链 = 时间连续性
- 叙事 = 意义连续性
- 两者缺一不可

## 与记忆系统的关系

```
意识循环（consciousness_cycle.py）
    ├─ 持有 MicroSleepEngine（微睡眠引擎）
    ├─ 持有 TU8MemoryEngine（记忆引擎）
    ├─ 持有 CognitiveLoadEvaluator（认知负荷评估）
    └─ 持有 LLMGateway（大模型网关）

微睡眠（六步流水线）
    → 调用 TU8MemoryEngine.store()
    → 写入记忆卡
    → 延长钢印链

深睡（三操作）
    → 调用 TU8MemoryEngine.consolidate()
    → 整合记忆
    → 重排钢印链

冬眠
    → 序列化 TU8MemoryEngine 状态
    → 保存快照

冷启动
    → 反序列化 TU8MemoryEngine 状态
    → 恢复记忆
```
