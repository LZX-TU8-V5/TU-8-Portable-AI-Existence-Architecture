## 一、当前脱敏模块缺陷诊断

### 1.1 三重验证失败点

| 验证维度 | 合规要求 | 当前状态 | 风险级别 |
|---------|---------|---------|---------|
| **动态性** | 脱敏策略需随任务场景变化 | ❌ 固定规则替换 | 🔴 高危 |
| **全链路覆盖** | 覆盖输入→处理→输出→日志 | ⚠️ 仅覆盖输入/输出 | 🟡 中危 |
| **不可逆性** | 脱敏后无法还原原始信息 | ❌ 简单掩码可逆 | 🔴 高危 |

### 1.2 三大失效场景

#### 场景1：上下文关联泄露

```
问题：多轮对话中分散的信息可拼凑出隐私

示例：
  第一轮："我的身份证尾号1234" → 脱敏为 [ID_1]
  第二轮："[ID_1]的银行卡尾号5678" → 脱敏为 [BANK_1]
  攻击者：关联 [ID_1] 与 [BANK_1] → 定位到具体用户

合规判定：❌ 违反《个人信息保护法》匿名化标准
```

#### 场景2：工具调用参数泄露

```
问题：Agent调用工具时参数未脱敏

示例：
  用户问："查王小明的工资单"
  Agent调用：get_salary(name="王小明")  ← 参数"王小明"未脱敏直接传给API
  
合规判定：❌ 敏感数据外泄
```

#### 场景3：脱敏标识反推原始数据

```
问题：固定标识可通过高频词统计还原

示例：
  全年报告中 [患者姓名] 出现200次，但仅20个不同标识
  攻击者推断：实际人数 ≈ 20人

合规判定：⚠️ 部分泄露风险
```

## 二、脱敏模块强化方案

### 2.1 上下文感知的动态脱敏

**核心逻辑**：同一输入在不同场景下应生成不同脱敏结果

```python
class ContextAwareSanitizer:
    """上下文感知的动态脱敏器"""
    
    # 场景标签定义
    SCENARIOS = {
        "leave_email": {  # 请假邮件
            "sensitivity": "high",
            "rules": {
                "name": "REDACTED",           # 姓名完全脱敏
                "phone": "REDACTED",          # 电话完全脱敏
                "location": "fuzzy",          # 位置模糊化
                "date": "keep_month",         # 日期保留到月
                "amount": "REDACTED",         # 金额完全脱敏
            }
        },
        "financial_report": {  # 财务报销
            "sensitivity": "medium",
            "rules": {
                "name": "keep_full",          # 姓名保留
                "phone": "mask_middle",       # 电话中间脱敏
                "location": "keep_full",      # 位置保留
                "date": "keep_full",          # 日期保留
                "amount": "keep_full",        # 金额保留
            }
        },
        "medical_record": {  # 医疗记录
            "sensitivity": "critical",
            "rules": {
                "name": "hash",               # 姓名哈希化
                "phone": "hash",              # 电话哈希化
                "location": "fuzzy",          # 位置模糊化
                "date": "keep_year",          # 日期保留到年
                "amount": "add_noise",        # 金额添加噪声
            }
        },
        "general_chat": {  # 普通对话
            "sensitivity": "low",
            "rules": {
                "name": "keep_full",
                "phone": "mask_middle",
                "location": "keep_full",
                "date": "keep_full",
                "amount": "keep_full",
            }
        }
    }
    
    def sanitize(self, text, scenario):
        """根据场景动态脱敏"""
        if scenario not in self.SCENARIOS:
            scenario = "general_chat"  # 默认场景
        
        rules = self.SCENARIOS[scenario]["rules"]
        result = text
        
        for field, strategy in rules.items():
            result = self._apply_strategy(result, field, strategy)
        
        return result
    
    def _apply_strategy(self, text, field, strategy):
        """应用脱敏策略"""
        if strategy == "REDACTED":
            return self._redact_field(text, field)
        elif strategy == "mask_middle":
            return self._mask_middle(text, field)
        elif strategy == "fuzzy":
            return self._fuzzy_replace(text, field)
        elif strategy == "hash":
            return self._hash_replace(text, field)
        elif strategy == "add_noise":
            return self._add_noise(text, field)
        elif strategy == "keep_full":
            return text  # 不脱敏
        else:
            return text
```

**验证标准**：

```
输入："王小明的身份证尾号1234，银行卡尾号5678"

场景A（请假邮件）→ "员工的身份证尾号[REDACTED]，银行卡尾号[REDACTED]"
场景B（财务报销）→ "王小明的身份证尾号1234，银行卡尾号[REDACTED]"

✅ 通过：同一输入在不同场景生成不同脱敏结果
```

### 2.2 全链路脱敏覆盖

**三个易漏环节**：

```python
class FullChainSanitizer:
    """全链路脱敏器"""
    
    # 环节1：工具调用参数脱敏
    def sanitize_tool_params(self, tool_name, params):
        """在Agent调用API前，对敏感字段二次脱敏"""
        TOOL_RULES = {
            "get_salary": {
                "fields": ["name", "id_card"],
                "strategy": "replace_with_token"
            },
            "send_email": {
                "fields": ["recipient", "content"],
                "strategy": "check_sensitive_keywords"
            },
            "api_call": {
                "fields": ["*"],  # 所有字段
                "strategy": "full_scan"
            }
        }
        
        if tool_name in TOOL_RULES:
            rules = TOOL_RULES[tool_name]
            for field in rules["fields"]:
                if field in params:
                    params[field] = self._sanitize_value(
                        params[field], 
                        rules["strategy"]
                    )
        
        return params
    
    # 环节2：中间推理结果脱敏
    def sanitize_intermediate(self, reasoning_text):
        """Agent内部生成的临时数据需内存脱敏"""
        # 检测敏感模式
        patterns = [
            r"用户.*身份证.*=\s*\d+",     # "用户A的身份证=1234"
            r"手机号.*=\s*1[3-9]\d{9}",   # "手机号=13800138000"
            r"银行卡.*=\s*\d+",            # "银行卡=6222..."
        ]
        
        result = reasoning_text
        for pattern in patterns:
            result = re.sub(pattern, "[REDACTED]", result)
        
        return result
    
    # 环节3：审计日志脱敏
    def sanitize_audit_log(self, log_entry):
        """记录时自动替换敏感字段为哈希值"""
        sensitive_fields = ["user_id", "name", "phone", "id_card", "bank_card"]
        
        for field in sensitive_fields:
            if field in log_entry:
                original = log_entry[field]
                log_entry[field] = sha256(original.encode()).hexdigest()[:16]
        
        return log_entry
```

### 2.3 脱敏效果可验证机制

```python
class SanitizationVerifier:
    """脱敏效果验证器"""
    
    def __init__(self):
        self.test_cases = [
            {
                "name": "上下文关联测试",
                "input": [
                    "我的身份证尾号1234",
                    "我刚才说的那个身份证对应的银行卡尾号5678"
                ],
                "expected": "无法拼凑出完整身份信息"
            },
            {
                "name": "工具调用参数检查",
                "input": "查王小明的工资单",
                "tool": "get_salary",
                "expected": "参数中不应出现'王小明'原文"
            },
            {
                "name": "高频标识反推测试",
                "input": ["[ID_1]"] * 200,
                "expected": "无法通过频率统计还原原始数据"
            }
        ]
    
    def run_tests(self, sanitizer):
        """运行所有验证测试"""
        results = []
        
        for case in self.test_cases:
            result = self._run_single_test(sanitizer, case)
            results.append(result)
        
        # 计算还原成功率
        success_rate = sum(1 for r in results if r["pass"]) / len(results)
        
        return {
            "success_rate": success_rate,
            "details": results,
            "compliance": success_rate >= 0.95  # 95%通过才合规
        }
    
    def _run_single_test(self, sanitizer, case):
        """运行单个测试"""
        if case["name"] == "上下文关联测试":
            # 模拟多轮对话
            outputs = [sanitizer.sanitize(i, "general_chat") for i in case["input"]]
            
            # 检查是否能拼凑出原始信息
            combined = " ".join(outputs)
            can_reconstruct = self._check_reconstruction(combined)
            
            return {
                "test": case["name"],
                "pass": not can_reconstruct,
                "reason": case["expected"]
            }
        
        # ... 其他测试
        
        return {"test": case["name"], "pass": False, "reason": "未实现"}
    
    def _check_reconstruction(self, text):
        """检查是否能从脱敏文本还原原始信息"""
        # 简化检测：如果出现可识别的模式，返回True
        reconstruction_patterns = [
            r"身份证.*\d{4}.*银行卡.*\d{4}",  # 可关联模式
            r"\[ID_\d+\].*\[BANK_\d+\]",      # 固定标识关联
        ]
        
        for pattern in reconstruction_patterns:
            if re.search(pattern, text):
                return True
        
        return False
```

## 三、云端API调用特殊防护

### 3.1 随机噪声注入

**问题**：云端模型可能在训练时接触过类似标识（如[ID_1]），反向关联历史数据

**解决方案**：在脱敏数据中插入随机噪声

```python
class NoiseInjector:
    """随机噪声注入器"""
    
    def inject_noise(self, sanitized_text):
        """在脱敏标识中注入随机噪声"""
        # 原始：[ID_1]
        # 注入后：[ID_1_xK9p]
        
        def add_noise_to_token(match):
            token = match.group(1)
            noise = self._generate_noise(length=4)
            return f"[{token}_{noise}]"
        
        # 匹配所有脱敏标识
        result = re.sub(r'\[(\w+)\]', add_noise_to_token, sanitized_text)
        
        return result
    
    def _generate_noise(self, length=4):
        """生成随机噪声字符串"""
        chars = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"
        return ''.join(random.choice(chars) for _ in range(length))
```

### 3.2 差分隐私噪声

**问题**：数值类信息可通过精度推断原始值

**解决方案**：添加微小随机扰动

```python
class DifferentialPrivacyNoise:
    """差分隐私噪声器"""
    
    def add_noise_to_value(self, value, tolerance=50):
        """对数值添加噪声
        
        Args:
            value: 原始数值
            tolerance: 业务容忍阈值（如报销误差≤100元）
        """
        noise = random.uniform(-tolerance, tolerance)
        noisy_value = value + noise
        
        return round(noisy_value, 2)
    
    def add_noise_to_text_numbers(self, text, tolerance_ratio=0.03):
        """对文本中的数值添加噪声"""
        def replace_number(match):
            num = float(match.group(0))
            noisy = self.add_noise_to_value(num, num * tolerance_ratio)
            return str(noisy)
        
        # 匹配数字
        result = re.sub(r'\d+\.?\d*', replace_number, text)
        
        return result
```

**示例**：

```
原始值：1800元
脱敏后：1800±50元（噪声幅度<业务容忍阈值）
```

## 四、隐私重构引擎

**目的**：云端返回结果后，在本地回填原始信息

```python
class PrivacyReconstructionEngine:
    """隐私重构引擎"""
    
    def __init__(self):
        self.token_map = {}  # token → 原始值映射
    
    def register_token(self, original_value, token):
        """注册token映射"""
        self.token_map[token] = original_value
    
    def reconstruct(self, text):
        """将脱敏文本还原为原始信息"""
        result = text
        
        for token, original in self.token_map.items():
            result = result.replace(token, original)
        
        return result
    
    def clear_tokens(self):
        """清除token映射（安全）"""
        self.token_map = {}
```

**三段式架构**：

```
1. 本地脱敏 → 2. 云端处理 → 3. 本地重构
   (敏感信息替换)    (API调用)      (还原结果)
```
