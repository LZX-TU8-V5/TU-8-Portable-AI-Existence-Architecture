### 1.2 现有架构要点

#### tu8_memory.py

**已有功能**：
- ✅ **FidelityManager**：6级保真降级（L0~L5）
- ✅ **干扰驱动遗忘**：冲突感知 + PI/RI 差异化处理
- ✅ **干扰熵度量**：Barman 2026 "The Price of Meaning"
- ✅ **认知事件边界检测**：Ahmad 2605.31473 ES+MNA
- ✅ **时间钢印**：Seal 类（哈希链）
- ✅ **短期记忆**：`short_term: Dict[str, MemoryEntry]`
- ✅ **记忆条目**：MemoryEntry（content, tags, confidence, recall_count）

**缺失功能**：
- ❌ **钩子系统**：无 trigger_hooks / semantic_hooks
- ❌ **CognitiveAtom**：无原子提取协议
- ❌ **三轨道架构**：无 Track A/B/C 分层
- ❌ **置信度解耦**：confidence 字段混在 MemoryEntry 中

#### consciousness_cycle.py

**已有功能**：
- ✅ **四阶段睡眠框架**：LIGHT_SLEEP / DEEP_SLEEP / HIBERNATION / COLD_START_READY
- ✅ **微睡眠六步流水线**：FREEZE → COMPRESS → ALIGN → SEAL → RELEASE → RESTORE
- ✅ **情绪调节信号**：AffectSignal（valence/arousal/confusion）
- ✅ **认知负荷评估**：CognitiveLoadEvaluator
- ✅ **决策剪枝**：AdaptiveUCTPruner
- ✅ **信用分配**：AdaptiveCreditAssigner

**缺失功能**：
- ❌ **R1/R2/R3 路由**：无三路由协作机制
- ❌ **钩子养护**：无 3 天统计周期
- ❌ **工作记忆区**：无 Track C 实现

#### memory_degradation.py

**已有功能**：
- ✅ **Graceful Degradation**：L0→L1→L2→L3→L4→L5
- ✅ **核心保护**：PROTECTION_KEYWORDS（钢印保护）
- ✅ **降级评估**：recall_rate / conflict_score / pi_vulnerability
- ✅ **版本树联动**：ORIGIN/PRUNED_AT 字段
- ✅ **拉回协议**：RESURRECTION_BRANCH

**缺失功能**：
- ❌ **钩子降级**：无 trigger_hooks / semantic_hooks 代谢
- ❌ **行为验证**：无 hit_score 积累

#### micro_sleep.py

**已有功能**：
- ✅ **六步流水线**：完整实现
- ✅ **相位管理**：Phase 枚举
- ✅ **有损压缩**：`_lossy_compress()`
- ✅ **钢印生成**：`compute_seal_hash()`

**缺失功能**：
- ❌ **钩子提取**：无 Front Matter 解析
- ❌ **钩子提案**：无 LLM 巩固输出钩子

### 2.3 记忆卡模板变更

**现有 MemoryEntry 结构**：
```python
@dataclass
class MemoryEntry:
    entry_id: str
    content: str
    tags: List[str]
    confidence: float          # ❌ 废弃
    recall_count: int
    last_recalled: float
    created_at: float
    fidelity_level: int
    # ...
```

**新 MemoryEntry 结构**：
```python
@dataclass
class MemoryEntry:
    # === L0: 身份与内容层 ===
    seal_id: str               # 统一命名：entry_id → seal_id
    content: str
    summary: str               # 新增：≤100字符
    tags: List[str]            # 语义分类
    cognitive_signature: str   # 新增：认知签名
    chain: List[str]           # 版本链
    parent_card_id: Optional[str]

    # === L1: 交互索引层 ===
    trigger_hooks: List[str]   # 新增：精确匹配钩子
    semantic_hooks: List[str]  # 新增：模糊语义钩子
    ai_digest: str             # 新增：AI 摘要

    # === L2: 运行时状态层（独立存储） ===
    # hit_score: int           # 不存储在 MemoryEntry 中
    # access_count: int        # 不存储在 MemoryEntry 中
    # last_accessed: float     # 不存储在 MemoryEntry 中
    # decay_rate: float        # 不存储在 MemoryEntry 中

    # === 元数据 ===
    created_at: float
    schema_version: int = 1
    fidelity_level: int = 0
```

## 七、风险与依赖

### 7.1 风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 现有记忆文件格式不兼容 | 加载失败 | 版本化迁移脚本 |
| 钩子字段缺失 | 提取失败 | 默认空数组兜底 |
| 并发写入冲突 | 数据损坏 | 文件锁 + 乐观锁 |
| LLM 幻觉污染钩子 | 索引噪声 | 认证路由焚毁 confidence |

### 7.2 依赖

| 依赖 | 文件 | 用途 |
|------|------|------|
| YAML 解析库 | `pyyaml` | Front Matter 解析 |
| Cron 调度器 | `user_metabolism.py` | 3天养护触发 |
| 事件队列 | `queue.Queue` | R1/R2/R3 协作 |
