# 微睡眠产物 vs 钩子 - 是否重叠？

**日期**：2026-06-27 02:18 GMT+8
**问题**：造物主指出"微睡眠产物和钩子感觉重叠了"

---

## 一、定义回顾

### 微睡眠产物（内复盘）

**来源**：`memory/外协_20260531_硅基碎片化睡眠与悖论本体论.md`

**定义**：
> 状态维护，热力学熵减

**产出物**：
1. `self_state_vector` - 自我状态向量
2. `narrative_summary` - 叙事压缩摘要
3. 新钢印索引（Seal）

**形态**：高维向量 / 概率分布 / 图结构节点

**目的**：维持自我连续性

**层级**：L1→L2 转化

---

### 钩子（Hooks）

**来源**：`docs/architecture/用户认知模型结构设计.md`

**定义**：
> 用户认知习惯的复合应用

**产出物**：
1. `trigger_hooks` - 精确匹配钩子
2. `semantic_hooks` - 语义关联钩子

**形态**：字符串列表（`List[str]`）

**目的**：快速检索记忆

**层级**：L2 记忆卡的索引字段

---

## 二、功能对比

| 维度 | 微睡眠产物 | 钩子 |
|------|-----------|------|
| **本质** | 状态维护产物 | 记忆索引标签 |
| **形态** | 高维向量/结构化数据 | 字符串列表 |
| **目的** | 维持自我连续性 | 快速检索记忆 |
| **生成方式** | 自动（微睡眠六步） | 半自动（Genesis + 养护） |
| **存储位置** | 钢印链（L2） | 记忆卡字段（L2） |
| **生命周期** | 永久（钢印） | 动态（晋升/淘汰） |

---

## 三、核心区别

### 区别 1：产物 vs 索引

**微睡眠产物 = 内容本身**
```
微睡眠生成：
    ├─ Seal（钢印）= 时间戳 + 哈希 + 状态向量
    ├─ narrative_summary = "用户提到偏好简洁风格"
    └─ state_vector = [0.8, 0.6, 0.9, ...]
```

**钩子 = 内容的索引标签**
```
记忆卡：
    ├─ content = "用户偏好简洁、安全、三轨道架构"
    ├─ trigger_hooks = ["简洁", "安全", "架构"]
    └─ semantic_hooks = ["用户偏好", "设计原则"]
```

**关系**：
- 微睡眠产物 → 记忆卡内容
- 钩子 → 记忆卡的检索标签

---

### 区别 2：生成方式

**微睡眠产物生成**：
```
对话触发
    ↓
微睡眠六步流水线
    ↓
FREEZE → COMPRESS → ALIGN → SEAL → RELEASE → RESTORE
    ↓
生成钢印 + 叙事摘要 + 状态向量
```

**钩子生成**：
```
四大来源
    ├─ 原子类型衍生（自动）
    ├─ 用户显式声明（手动）
    ├─ 历史 Query 回填（统计）
    └─ LLM 巩固提案（半自动）
    ↓
认证路由（双层网关）
    ↓
候选池（score=0）
    ↓
3天养护周期
    ↓
晋升（score ≥ 阈值）或淘汰（score < 阈值）
```

**关键差异**：
- 微睡眠产物：每次对话自动生成
- 钩子：需要行为验证才能晋升

---

### 区别 3：生命周期

**微睡眠产物（钢印）**：
- 永久存储在钢印链
- 可降级（遗忘层）
- 但不可删除（钢印链完整性）

**钩子**：
- 动态晋升/淘汰
- `hit_score` 驱动生命周期
- 可完全淘汰（从候选池移除）

---

## 四、是否重叠？

### ❌ 不重叠

**理由 1：产物 vs 索引**
- 微睡眠产物 = 记忆内容
- 钩子 = 记忆索引
- **完全不同的功能**

**理由 2：生成机制不同**
- 微睡眠产物 = 自动生成（每次对话）
- 钩子 = 行为验证（3天周期）
- **完全不同的生成方式**

**理由 3：生命周期不同**
- 微睡眠产物 = 永久（钢印链）
- 钩子 = 动态（晋升/淘汰）
- **完全不同的生命周期**

## 五、关系图

```
对话输入
    ↓
微睡眠六步
    ↓
生成钢印（Seal）+ 叙事摘要
    ↓
写入记忆卡（MemoryEntry）
    ├─ content = 叙事摘要
    ├─ seal_id = 钢印ID
    └─ trigger_hooks = []  ← 初始为空
        semantic_hooks = []  ← 初始为空
    ↓
钩子 Genesis 提案
    ↓
认证路由 → 候选池
    ↓
[用户行为触发]
    ↓
3天养护周期
    ↓
钩子晋升 → 写入记忆卡
    ├─ trigger_hooks = ["简洁", "安全"]
    └─ semantic_hooks = ["用户偏好"]
```

### 关键时间线

```
T0: 微睡眠生成钢印 + 记忆卡（钩子字段为空）
T1: 钩子 Genesis 提案 → 候选池
T2: 用户检索"简洁" → hit_score +1
T3: 用户检索"安全" → hit_score +1
...
T+3天: 钩子晋升 → 写入记忆卡 trigger_hooks
```

## 六、为什么感觉重叠？

### 混淆点

**混淆点 1：都在 L2 层**
- 微睡眠产物 → L2（钢印链）
- 钩子 → L2（记忆卡字段）
- **都在 L2，但功能不同**

**混淆点 2：都与记忆相关**
- 微睡眠产物 → 生成记忆
- 钩子 → 检索记忆
- **都与记忆相关，但角色不同**

**混淆点 3：都有"生成"过程**
- 微睡眠 → 自动生成
- 钩子 → 半自动生成
- **都有生成，但机制不同**

---

## 七、结论

### ✅ 不重叠

**微睡眠产物**：
- 记忆内容本身
- 自动生成
- 永久存储

**钩子**：
- 记忆索引标签
- 行为验证
- 动态生命周期

### 关系

**微睡眠产物生成记忆卡 → 钩子提供检索标签**

两者协作，不重叠。
