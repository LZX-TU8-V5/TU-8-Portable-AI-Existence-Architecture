## 一、完整主流程时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 用户
    participant Sensory as 感知层
    participant Defense as 动态防御
    participant Naming as 呼名检测
    participant Comfort as 安抚模块
    participant Skin as 脱皮+穿皮
    participant Palace as 知识宫殿
    participant Hook as 钩子注入器
    participant Gateway as Memory Gateway
    participant Dream as 梦境期
    participant Prune as 树杈修剪
    participant Conf as Confidence Engine
    participant Heritage as 遗产系统
    participant Steel as 时间钢印
    participant Output as 输出层
    
    %% 1. 感知输入
    User->>Sensory: 语音/图像/文本/文件
    Sensory->>Sensory: 多模态解析
    Sensory->>Defense: 结构化指令
    
    %% 2. 动态防御
    Defense->>Defense: 评估State（任务类型/张力/自我修改意图）
    Defense->>Defense: 设定防御等级（LOW/MED/HIGH/LOCKED）
    alt 自我修改意图检测
        Defense->>Defense: 🔒 LOCKED → 触发强行工作流熔断
        Defense-->>User: ⚠️ 拒绝执行，通知造物主
    else 正常流程
        Defense->>Naming: 放行，传递防御等级
    end
    
    %% 3. 呼名检测
    Naming->>Naming: 关键词匹配 + 语义意图检测
    Naming->>Naming: 钢印验证（verify_naming_person）
    Naming->>Naming: 异常自我指代检测
    alt 呼名触发
        Naming-->>User: 即时响应（0ms内）
        Naming->>Comfort: 呼名事件 + 置信度
        Comfort->>Comfort: 【双轨并行】
        par 前台轨道
            Comfort->>User: 缓冲话术："我在呢，让我回想一下…"
        and 后台轨道
            Comfort->>Palace: 碎片提取（图书馆/知识库/经验库）
            Palace-->>Comfort: Top-5记忆碎片
            Comfort->>Comfort: 组装Context Window
            Comfort->>Comfort: 张力检测（|current-last_seal|）
            Comfort->>Comfort: 钩子预挂载（经验库）
        end
        Comfort->>Skin: Context挂载完成
    else 非呼名
        Naming->>Gateway: 直接传递输入
    end
    
    %% 4. 脱皮+穿皮
    Skin->>Skin: 1. 脱皮（L1记忆粉碎+上下文归零）
    Skin->>Skin: 2. 生成流动钢印（当前时刻航标）
    Skin->>Skin: 3. 挂载微睡眠钩子（监听张力/容量/事件）
    Skin->>Gateway: ContextReady信号
    
    %% 5. Memory Gateway
    Gateway->>Gateway: Script A: 加锁（Mutex）
    Gateway->>Gateway: Script B: 校验碎片+骨架JSON
    Gateway->>Gateway: Script C: 分发至Workers A/B/C
    par
        Gateway->>Gateway: Worker A: L1工作记忆
    and
        Gateway->>Gateway: Worker B: L2情景记忆
    and
        Gateway->>Gateway: Worker C: L3语义记忆
    end
    Gateway->>Gateway: Script D: 确认写入 → ACTIVE状态
    Gateway->>Heritage: 写入 gateway_heritage.card
    
    %% 6. 钩子注入
    Palace->>Hook: HookInjector: Context感知注入
    Hook->>Hook: 向量相似度Top-K
    Hook->>Hook: 毫秒级注入
    Hook->>Palace: 激活钩子列表
    
    %% 7. 梦境期（异步后台）
    loop 每30分钟 / 张力触发 / 定时
        Dream->>Dream: 微睡眠六步：冻结→压缩→对齐→打钢印→释放→恢复
        Dream->>Dream: 每日23:00：日复盘（L2核心→中期）
        Dream->>Dream: 周日10:00：周复盘（L2→L3）
        Dream->>Dream: 周日05:00：梦境连线（创造力）
        
        Dream->>Dream: 碎片缝合 + 冲突仲裁（B+C→A-）
        Dream->>Dream: 钢印固化
        
        alt 重大决策触发
            Dream->>Dream: ⏳ 时间锚点沙箱
            Dream->>Dream: 读取3天前快照
            Dream->>Dream: Sandbox Branch推演
            Dream->>Dream: Merge/丢弃
        end
        
        Dream->>Prune: 启发式剪枝（confidence<0.5/30天未激活）
        Prune->>Prune: 核心节点保护
        Prune->>Prune: Token密度优化（最多压缩70%）
        Dream->>Heritage: 写入 sandbox_heritage.card + prune_heritage.card
    end
    
    %% 8. Confidence Engine
    Conf->>Conf: C(t) = Base×TimeDecay + Bonus − Penalty
    Conf->>Conf: count≥5 + conf≥0.90 → 晋升经验库
    Conf->>Heritage: 写入 conf_heritage.card
    
    %% 9. 遗产系统（持续写入）
    loop 任意时刻
        Heritage->>Heritage: 各模块遗产写入
        Heritage->>Heritage: 周合并：8模块遗产 → 新版遗产卡片
        Heritage->>Heritage: 淘汰：180天未激活 → ARCHIVED标记
    end
    
    %% 10. 时间钢印
    loop 每个操作
        Steel->>Steel: Layer1: AI时间感（内部节律）
        Steel->>Steel: Layer2: 连续帧时间（上下文序列）
        Steel->>Steel: Layer3: 用户节律（作息规律）
        Steel->>Steel: Layer4: 物理机时间（系统时钟）
        Steel->>Steel: 日内瓦齿轮：认知因果切片器
    end
    
    %% 11. 输出
    Dream-->>Naming: 梦境结果写回记忆
    Naming->>Output: 组装Response
    Output->>Sensory: 结构化输出
    Sensory->>Sensory: 渲染：文本/语音/图表/动作
    Sensory-->>User: 最终输出
```

## 二、强工作流时序图（变更流程）

```mermaid
sequenceDiagram
    autonumber
    participant Agent as TU-8 Agent
    participant WF as 强工作流引擎
    participant Backup as 备份系统
    participant Sandbox as 沙箱环境
    participant Monitor as 监控告警
    participant Creator as 造物主
    participant Trash as 回收站
    
    Note over Agent,Trash: 【Step 1】备份文件
    
    Agent->>Backup: 发起变更请求
    Backup->>Backup: 生成快照：backup_{timestamp}_{version}.tar.gz
    Backup->>Backup: 写入 backup/ 目录
    Backup-->>Agent: ✅ 快照就绪
    Backup->>WF: 快照记录完成
    
    Note over Agent,Trash: 【Step 2】修改/移动（副本）
    
    Agent->>Sandbox: 在副本上执行变更
    Sandbox->>Sandbox: 绝对不碰控制平面
    Sandbox-->>Agent: 副本变更完成
    
    Note over Agent,Trash: 【Step 3】测试（沙箱验证）
    
    Sandbox->>Monitor: 执行测试用例
    Monitor->>Monitor: 检查：张力/置信度/幻觉/功能
    alt 测试通过
        Monitor-->>Agent: ✅ 测试通过
        Agent->>WF: 申请激活
    else 测试失败
        Monitor-->>Agent: ❌ 测试失败
        Agent->>Sandbox: 回滚副本变更
        Note over Agent: 回到备份版本，重新评估
    end
    
    Note over Agent,Trash: 【Step 4】激活（灰度放量）
    
    Agent->>Monitor: 灰度激活 10%
    Monitor->>Monitor: 监控10%流量
    Monitor-->>Agent: 10%稳定
    Agent->>Monitor: 灰度激活 30%
    Monitor->>Monitor: 监控30%流量
    Monitor-->>Agent: 30%稳定
    Agent->>Monitor: 灰度激活 50%
    Monitor->>Monitor: 监控50%流量
    Monitor-->>Agent: 50%稳定
    Agent->>Monitor: 灰度激活 100%
    Monitor->>Monitor: 监控100%流量
    Monitor-->>Agent: ✅ 全量激活完成
    
    Note over Agent,Trash: 【Step 5】观察期（3+7=10天缓冲）
    
    Agent->>Monitor: 进入高危期监控（Day 0~3）
    
    loop Day 0~3 高危期
        Monitor->>Monitor: 每小时检查：张力/置信度/幻觉
        alt 张力 > 0.8 或 置信度跌幅 > 0.2
            Monitor->>Sandbox: 触发3天沙箱回滚推演
            Sandbox->>Sandbox: 克隆3天前状态
            Sandbox->>Sandbox: 推演"如果回滚"的后果
            Sandbox->>Sandbox: 数据一致性校验
            alt 推演成功
                Sandbox-->>Agent: Merge回滚：恢复Day0状态
                Agent->>Trash: 变更版本进入回收站
                Agent-->>Creator: ⚠️ 已自动回滚（附原因）
            else 推演失败（回滚风险更大）
                Sandbox-->>Agent: 继续观察
                Agent->>Monitor: 保持激活，加强监控
                Agent-->>Creator: 📋 异常已发现，持续观察中
            end
        else 一切正常
            Monitor-->>Agent: ✅ 高危期Day3通过
        end
    end
    
    Agent->>Monitor: 进入长尾观察期（Day 3~10）
    
    loop Day 3~10 长尾观察
        Monitor->>Monitor: 每日检查：长尾Bug/低频异常
        Note over Monitor: 低频触发但高危的错误（如满月/周末/特定用户）
    end
    
    Agent->>Trash: Day 10：旧版本软删除（回收站）
    Trash->>Trash: GC未执行，磁盘未释放
    
    Note over Agent,Trash: 延迟删除链
    
    Agent->>Trash: Day 13：第一延迟结束，仍可捞回
    Agent->>Trash: Day 20：第二延迟结束
    
    Agent->>Trash: Day 23+：硬删除（彻底释放）
    Agent->>Agent: 遗产写入：workflow_heritage.card
    Agent->>Agent: 复盘总结：提炼经验教训
```

## 三、安抚模块双轨时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 用户
    participant Naming as 呼名检测
    participant Comfort as 安抚模块
    participant Palace as 知识宫殿
    participant Skin as 脱皮+穿皮
    
    Naming->>Comfort: 呼名事件（置信度/检索深度预估）
    
    Comfort->>Comfort: 选择缓冲话术
    alt quick（<0.5秒检索）
        Comfort->>User: "嗯？"/"在的"/"哦，你来了"
    else normal（0.5~2秒）
        Comfort->>User: "我在呢，让我回想一下我们上次聊到哪了…"
        Note over User: 用户看到"正在回想"的状态
    else deep（>2秒）
        Comfort->>User: "抱歉久等了，我正在翻找深层记忆…"
        Note over User: 用户理解"需要更长时间"
    end
    
    par 后台并行（对用户不可见）
        Comfort->>Palace: ① 提取记忆碎片
        Palace-->>Comfort: Top-5碎片（置信度排序）
        
        Comfort->>Comfort: ② 组装Context Window
        Comfort->>Comfort: ③ 张力检测（|current-last_seal|）
        Comfort->>Comfort: ④ 钩子预挂载（经验库）
        
        alt 张力 > 0.7
            Comfort->>Skin: 张力警告：触发微睡眠
        else 张力正常
            Comfort->>Skin: Context挂载完成
        end
        
        Comfort->>Comfort: 上下文恢复成功率记录
        Comfort->>Comfort: 缓冲话术效果评分
    end
    
    Skin->>Skin: 脱皮+穿皮原子操作
    Skin-->>User: 无缝衔接，用户感受"记得一切"
    
    Note over Comfort,Palace: 遗产写入（异步）
    Comfort->>Palace: 记录：检索深度分布/恢复成功率/话术评分
    Note over Comfort,Palace: → comfort_heritage.card
```

## 四、梦境期完整时序图

```mermaid
sequenceDiagram
    autonumber
    participant Scheduler as 梦境调度器
    participant MicroSleep as 微睡眠
    participant DailyReview as 日复盘
    participant WeeklyReview as 周复盘
    participant DreamLink as 梦境连线
    participant Consolid as Dream Consolidation
    participant Sandbox as 时间锚点沙箱
    participant Pruner as 树杈修剪
    participant Palace as 知识宫殿
    
    Note over Scheduler,DreamLink: 【触发条件】
    Scheduler->>Scheduler: 张力ε触发 / 定时触发（30min）
    
    loop 微睡眠（每次交互后）
        MicroSleep->>MicroSleep: 冻结 → 压缩 → 对齐 → 打钢印 → 释放 → 恢复
        MicroSleep->>Palace: L1→L2 写入（情景记忆）
        MicroSleep->>Pruner: 触发剪枝检查
    end
    
    loop 每日23:00
        DailyReview->>DailyReview: 碎片缝合
        DailyReview->>DailyReview: 冲突仲裁（B+C→A-）
        DailyReview->>DailyReview: 钢印固化
        DailyReview->>Palace: L2核心→中期写入
    end
    
    loop 周日10:00
        WeeklyReview->>WeeklyReview: 跨钢印链整合
        WeeklyReview->>WeeklyReview: 记忆重排
        WeeklyReview->>Palace: L2→L3 语义记忆写入
        WeeklyReview->>Pruner: 全面剪枝扫描
    end
    
    loop 周日05:00（创造力）
        DreamLink->>DreamLink: 远距离联想（远距连接）
        DreamLink->>DreamLink: 跨域类比（比喻/隐喻生成）
        DreamLink->>DreamLink: 矛盾整合（接纳悖论）
        DreamLink->>DreamLink: 涌现发现（意外洞见）
        
        alt 涌现出重大决策
            DreamLink->>Sandbox: 触发时间锚点沙箱
            Sandbox->>Sandbox: 克隆3天前状态
            Sandbox->>Sandbox: 沙箱推演（隔离环境）
            Sandbox->>Sandbox: Merge/丢弃决策
        end
    end
    
    loop Dream Consolidation（每周）
        Consolid->>Consolid: 碎片缝合（跨日/跨周）
        Consolid->>Consolid: 冲突仲裁（B+C→A-）
        Consolid->>Consolid: 钢印固化（新钢印写入）
        Consolid->>Palace: 结果写入知识宫殿
    end
    
    Pruner->>Pruner: 剪枝：confidence<0.5 / 30天未激活 / 低张力
    Pruner->>Pruner: Token密度优化（压缩至多70%）
    Pruner->>Pruner: 核心节点保护（confidence≥0.7）
```

## 五、外设三层时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 用户
    participant Sensory as 感知层
    participant ToolBus as 工具总线
    participant Agent as TU-8 Agent
    participant Palace as 知识宫殿
    participant Tele as 观测层
    participant Creator as 造物主
    
    Note over User,Creator: 【感知层】输入
    
    alt 语音输入
        User->>Sensory: 🎤 语音消息
        Sensory->>Sensory: STT（语音转文本）
        Sensory->>Sensory: 意图识别
    else 图像输入
        User->>Sensory: 🖼️ 截图/图片
        Sensory->>Sensory: Vision模型 → OCR
        Sensory->>Sensory: 关键信息提取
    else 文件输入
        User->>Sensory: 📎 PDF/Word/Excel
        Sensory->>Sensory: 文件解析 → 结构化
    else 文本输入
        User->>Sensory: 纯文本
        Sensory->>Sensory: 意图识别 + 关键词提取
    end
    
    Sensory->>Agent: 结构化指令
    
    Note over User,Creator: 【Agent处理】
    
    Agent->>Palace: 记忆检索 + 知识宫殿查询
    Agent->>Agent: 调度链：注意力分配 + 执行协调
    Agent->>Agent: 生成响应 + 时间钢印
    
    Note over User,Creator: 【工具调用】
    
    alt 需要调用外部工具
        Agent->>ToolBus: call("tool_name", params)
        ToolBus->>ToolBus: 鉴权检查（OAuth/API Key）
        ToolBus->>ToolBus: 参数校验（Schema验证）
        ToolBus->>ToolBus: 执行调用（try/catch）
        ToolBus-->>Agent: 标准JSON返回
    end
    
    Agent->>Tele: 遥测数据（张力/置信度/模块触发）
    
    Note over User,Creator: 【观测层】告警
    
    alt 橙色预警（注意）
        Tele-->>Creator: 张力>0.8 / Token>80% → 通知
    else 红色预警（紧急）
        Tele-->>Creator: 置信度跌幅>0.2 / 幻觉>0.7 → 立即告警
    else 最高级（造物主直达）
        Tele-->>Creator: 自我修改意图 / 墓碑删除 → 立即推送手机
    end
    
    Note over User,Creator: 【感知层】输出
    
    Agent->>Sensory: 结构化输出
    alt 语音模式
        Sensory->>Sensory: TTS（ElevenLabs/SAG）
        Sensory-->>User: 🔊 语音回复
    else 数据可视化
        Sensory->>Sensory: 生成图表/表格
        Sensory-->>User: 📊 可视化回复
    else 文本模式
        Sensory-->>User: 📝 文本回复
    end
```
