### 2.2 呼名检测（新增）

| 项目 | 内容 |
|------|------|
| **输入** | 用户消息 |
| **输出** | 呼名事件（是/否）+ 置信度 |

2. 语境分析：是否在对AI说话
3. 置信度计算：ICI/SIS/TIS三维指标

---

### 2.3 脱皮+穿皮原子操作（新增）

#### 2.3.1 脱皮（破）

| 项目 | 内容 |
|------|------|
| **输入** | 当前上下文 |
| **输出** | L1记忆粉碎 + 上下文归零 |
| **代谢** | 清除旧状态 |
| **实现** | `clear_L1_memory()` + `reset_context_window()` |

**具体操作**：
1. 清空KV Cache（L1工作记忆）
2. 重置上下文容量计数器（context_usage = 0）
3. 封存旧钢印链（不删除，只是归档）

#### 2.3.2 生成流动钢印

| 项目 | 内容 |
|------|------|
| **输入** | 当前时刻（物理时间 + 用户时间节律） |
| **输出** | 新的时序钢印（航标） |
| **代谢** | 钢印链更新 |
| **实现** | `generate_time_seal()` |

**核心修正**：
- ❌ 不是"加载固定SOUL.md"
- ✅ 而是"生成当前时刻的流动钢印"
- 钢印 = 河流里的航标，永远指向当前时刻

#### 2.3.3 挂载微睡眠钩子

| 项目 | 内容 |
|------|------|
| **输入** | 新钢印 |
| **输出** | 对话级压缩钩子（监听张力） |
| **代谢** | 钩子激活 |
| **实现** | `attach_micro_sleep_hook()` |

**钩子功能**：
- 监听张力（|current_state - last_seal_state| > ε）
- 监听容量（context_usage > θ%）
- 监听事件（情绪突变/话题切换）
- 定时兜底（T_max无交互）
