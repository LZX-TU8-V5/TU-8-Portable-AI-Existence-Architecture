## 二、感知层详解

### 2.1 输入解析（Agent的五官）

| 模态 | 输入 | 处理流程 | 输出 |
|------|------|---------|------|
| **语音** | 用户说话 | STT（语音转文本）→ 意图识别 | 结构化文本 + 意图标签 |
| **图像/截图** | 用户发图 | Vision模型 → OCR → 关键信息提取 | 描述文本 + 关键实体 |
| **文件** | PDF/Word/Excel | 解析 → 结构化提取 → 去噪 | 结构化内容块 |
| **链接** | URL | 抓取 → 解析 → 摘要 | 内容摘要 + 关键摘录 |
| **文本** | 直接输入 | 意图识别 → 关键词提取 | 结构化指令 |

### 2.2 输出渲染

| 输出类型 | 触发条件 | 渲染方式 |
|---------|---------|---------|
| **文本** | 默认 | 纯文本输出 |
| **语音** | 语音模式开启 / 讲故事 | TTS（ElevenLabs/SAG） |
| **图表** | 数据分析结果 | 自动生成表格/折线图/饼图 |
| **代码** | 编程任务 | 语法高亮 + 代码块 |
| **文件** | 文件生成任务 | 自动下载链接 |
| **操作** | API调用/系统操作 | 格式化执行结果 |

## 三、工具总线详解

### 3.1 标准协议

```yaml
# 工具接入协议（每个工具必须遵守）
tool_protocol:
  name: "tool_name"           # 工具唯一标识
  version: "1.0"               # 协议版本
  params_schema: JSONSchema     # 参数格式
  auth_type: OAuth/APIKey/None  # 鉴权方式
  return_type: JSON/Text/File   # 返回格式
  timeout_ms: 30000             # 超时设置
  degrade: "graceful"           # 降级策略
```

### 3.2 可插拔工具集

| 工具 | 用途 | 鉴权 |
|------|------|------|
| 📧 邮件 | 发送/读取/搜索邮件 | OAuth |
| 📅 日历 | 读写日程/设置提醒 | OAuth |
| 🔍 搜索 | 网络搜索/内容抓取 | API Key |
| 📁 文件 | 读写本地/云端文件 | OAuth |
| 🌐 API | 调用外部REST API | API Key |
| 💻 代码 | 执行代码/终端命令 | SSH Token |

### 3.3 调度链调用示例

```python
# 调度链只需发指令，不需要知道工具细节
tool_bus.call("send_email", {
    "to": "user@example.com",
    "subject": "会议提醒",
    "body": "明天上午10点开会"
})
# Tool Bus自动完成：
# 1. 鉴权检查（OAuth token有效？）
# 2. 参数校验（格式符合schema？）
# 3. 调用执行（try/catch）
# 4. 结果返回（JSON标准化）
# 5. 日志记录（遥测面板可见）
```

## 四、观测层详解

### 4.1 遥测面板指标

| 指标 | 正常值 | 告警阈值 | 严重阈值 |
|------|-------|---------|---------|
| **健康度** | 80~100 | <70 警告 | <50 红色 |
| **Token消耗（日）** | <50%配额 | >80% 警告 | >95% 红色 |
| **张力值** | 0.3~0.6 | >0.8 警告 | >0.9 红色 |
| **置信度（日跌幅）** | <0.05 | >0.15 警告 | >0.2 红色 |
| **安抚触发频率** | 正常分布 | 突然飙升3倍 | 持续异常 |
| **防御拦截率** | <5% | >15% 警告 | >30% 红色 |
| **幻觉指标** | <0.2 | >0.5 警告 | >0.7 红色 |
| **自我修改意图** | 0次 | 任何次数 → 立即告警 | - |

### 4.2 预警机制

```
【橙色预警（注意）】
  · 张力 > 0.8
  · Token消耗 > 80%
  · 置信度日跌幅 > 0.15
  · 动作：发通知给造物主，建议查看

【红色预警（紧急）】
  · 张力 > 0.9
  · 置信度日跌幅 > 0.2
  · 幻觉指标 > 0.7
  · 动作：立即通知 + Agent自动进入安全模式

【最高级预警（造物主直达）】
  · 检测到自我修改意图
  · 检测到墓碑节点删除尝试
  · 检测到强行工作流熔断触发
  · 动作：立即推送造物主手机 + Agent冻结
```

## 六、架构哲学总结

| 原则 | 说明 |
|------|------|
| **内核绝对克制** | 核心逻辑不可动，像DNA一样稳定 |
| **外设极度灵活** | 感知/工具/观测三件套插件化，随场景插拔 |
| **边界极度清晰** | 内核与外设严格隔离，外设故障不传染内核 |
| **黑盒变白盒** | 所有状态可观测，造物主拥有上帝之眼 |
| **变更有序** | 强工作流保证任何修改都是灰度的、可回滚的 |
| **遗产永生** | 每个模块运行经验可积累、可继承 |
| **商业层暂缓** | 等代码落地+客户付费，再加计费插件 |

## 十三、代谢链增强：异常洞察抢救通道

**幻觉 vs 高价值异常预测**：
- 幻觉：凭空、无根、越延展越离谱
- 异常洞察：低概率但有内部自洽结构，追问3次后仍保持自洽

**三重过滤门**：自洽性 → 可追问性 → 下游密度

**修正舍弃公式**：置信度 × 可追问深度 × 下游结构密度
- 低置信度 × 高追问 × 高密度 = 异常洞察 → 7-Day Curiosity Hold抢救通道

**核心钢印**：「真正的洞察不是高置信度的，是低概率但高密度的。舍弃机制必须为异常留一条复活通道。」
