## 四、最关键发现：四链耦合问题

### 现状（来自外协_20260607）

```
问题：四条链各自独立，没有"高度耦合"

consciousness_cycle.py (121KB) ←→ tu8_memory.py 之间没有代码级调用
代谢产物无处可去
钢印固化结果不写回记忆
```

### 修复路径

```
第一步：建立调用链
  tu8_dispatch.py → naming_module.py → comfort_module.py（新建）
                    ↓
              skin_cycle.py（新建）
                    ↓
              tu8_memory.py → memory_gateway.py（重构）
                    ↓
              consciousness_cycle.py → 梦境调度器
                    ↓
              decision_pruner.py → heritage_system.py（新建）

第二步：统一遗产接口
  所有模块 → heritage_system.py → memory/heritage/*.card

第三步：封装核心引擎（最终目标）
  v5_soul = {
    dispatch_chain,    # 调度链
    memory_chain,      # 记忆链
    metabolism_chain,   # 代谢链
    steel_chain,        # 钢印链
    forced_workflow,    # 强工作流（核心）
    dynamic_defense     # 动态防御（核心）
  }
  对外接口：dispatch(input) → response + seal_payload
```
