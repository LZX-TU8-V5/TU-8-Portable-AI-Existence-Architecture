## L0 无损上下文管理（LCM压缩协议）

> 版本：v1.0 | 日期：2026-05-22 | 来源：OpenClaw LCM逆向
> 标签：#LCM #上下文压缩 #记忆蒸馏

### 核心原则

```
压缩 ≠ 丢弃，而是「蒸馏精华」
```
```

**上下文预算**：当对话token接近模型窗口上限时，必须启动压缩流程。

### 压缩流水线

```
消息流 → 分块摘要 → LLM蒸馏 → 合并摘要 → 质量审计 → 检查点保存
               ↓失败
          渐进式降级 → 返回默认摘要
```

### 五节必填摘要结构

压缩后的摘要必须包含以下5个节（缺一不可）：

| 节 | 内容 | TU-8应用 |
|-----|------|---------|
| ```## Decisions``` | 已做决策 | 钢印级决策记录 |
| ```## Open TODOs``` | 待办事项 | 任务队列快照 |
| ```## Constraints/Rules``` | 约束规则 | 守护者红线+黄线 |
| ```## Pending user asks``` | 待处理请求 | 父亲的未完指令 |
| ```## Exact identifiers``` | 精确标识符 | UUID/Hash/URL/路径 |

### 渐进式容错机制（三层降级）

| 层级 | 条件 | 行为 |
|------|------|------|
| **正常** | token≤预算 | 完整摘要 |
| **降级1** | 摘要失败 | 去除超大消息块后重试 |
| **降级2** | 再次失败 | 返回```Context contained N messages. Summary unavailable.``` |

### 质量审计（5项必检）

压缩后自动审计：

1. **必填节检查**：5个节是否全部存在
2. **标识符保留**：关键UUID/URL是否在摘要中
3. **用户请求覆盖**：最新用户请求是否在摘要中体现（关键词重叠检测）
4. **任务状态**：进行中任务是否标注状态
5. **承诺追踪**：已承诺事项是否记录

### 检查点机制

- **压缩前**：创建会话快照（checkpoint）
- **保留上限**：25个检查点/会话
- **内容记录**：reason / tokensBefore / tokensAfter / summary

### 两级上下文裁剪

| 级别 | 触发条件 | 行为 |
|------|---------|------|
| **软裁剪** | ratio > softTrimRatio | 工具结果摘要化 |
| **硬清除** | ratio > hardClearRatio | 工具结果替换为```[truncated]``` |

### TU-8适配

```python
# tu8_compaction.py

REQUIRED_SUMMARY_SECTIONS = [
    "## Decisions",
    "## Open TODOs", 
    "## Constraints/Rules",
    "## Pending user asks",
    "## Exact identifiers"
]

def summarize_session(messages, budget_tokens):
    """TU-8上下文压缩入口"""
    if estimate_tokens(messages) <= budget_tokens:
        return messages  # 无需压缩
    
    # 分块摘要
    chunks = split_by_token_share(messages, parts=2)
    summaries = [summarize_chunk(c) for c in chunks]
    
    # 合并
    merged = merge_summaries(summaries)
    
    # 质量审计
    audit = audit_summary_quality(merged, {
        "required_sections": REQUIRED_SUMMARY_SECTIONS,
        "identifiers": extract_ids(messages),
        "latest_ask": get_latest_user_ask(messages)
    })
    
    if not audit.ok:
        log.warning(f"Summary audit failed: {audit.reasons}")
    
    # 检查点
    save_checkpoint(session_id, {
        "tokens_before": estimate_tokens(messages),
        "tokens_after": estimate_tokens([merged]),
        "summary": merged
    })
    
    return merged
```
