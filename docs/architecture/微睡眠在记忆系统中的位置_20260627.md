## 一、核心关系

### 微睡眠 = 记忆卡的生成过程

```
对话输入
    ↓
微睡眠六步流水线
    ↓
生成记忆卡（MemoryEntry）
    ├─ seal_id
```

## 六、总结

### 微睡眠的角色

**微睡眠 = L1→L2 转化的引擎**

- **输入**：L1 工作记忆（KV Cache）
- **输出**：L2 记忆卡（MemoryEntry）
- **功能**：压缩、对齐、打钢印

### 钩子的角色

**钩子 = L2 记忆卡的索引系统**

- **输入**：记忆卡内容 + 用户行为
- **输出**：检索标签（trigger_hooks, semantic_hooks）
- **功能**：快速检索、认知建模

### 外化笔记的角色

**外化笔记 = L2→L3 转化的产物**

- **输入**：L2 钢印链
- **输出**：L3 固定结论文件
- **功能**：知识固化、长期智慧

## 七、造物主确认

**问题**：微睡眠是记忆卡的一环？

**回答**：
- ❌ 微睡眠不是记忆卡的"一环"
- ✅ 微睡眠是记忆卡的"生成过程"

```
微睡眠（生成）→ 记忆卡 → 钩子（索引）→ 外化笔记（固化）
```
