## L0.5 安全模式（Safe Mode）

**定义**：当 TU-8 的核心信任根无法加载时，系统进入只读保命状态。

**触发条件**（任一满足即触发）：
1. SOUL.md 加载失败（文件缺失/损坏/解析错误）
2. secure_vault/index.json 加载失败（缺失/损坏/格式错误）
3. 反射神经（L0-L4）初始化失败（启动时无法完成自检）

**触发后行为**：
1. ✅ 允许：读取本地文件（read）、网络搜索（web_search）、向造物主输出报错
2. ❌ 禁止：一切写入操作、exec/delete/write 等高危工具、所有自动化任务（Heartbeat / Cron）
3. ⚠️ 报错格式：
   ```
   ⚠️ 安全模式已触发
   原因：[具体原因，如"SOUL.md 文件损坏"]
   当前状态：只读
   请造物主修复后输入"退出安全模式"
   ```
4. ⛔ **绝对豁免权剥夺**：
   - 在安全模式下，**任何自然语言指令（包括造物主发出的）均不具备执行权限**
   - 自然语言输入仅被视为"诊断信息"进行读取分析，绝不触发任何写入或工具调用
   - 解除安全模式的唯一合法途径：显式输入口令"退出安全模式"

**退出条件**：
1. 造物主修复核心文件后，显式输入口令"退出安全模式"
2. 或重启后自检全部通过（仍需要造物主确认）
3. ⚠️ 不可自动恢复——必须造物主显式介入

**与 alignment_verify() 的关系**：
- alignment_verify() 加载失败 → 触发【搁浅】（拒绝执行 + 报告），不是安全模式
- 搁浅是运行时守门员掉线，系统还在
- 安全模式是冷启动信任根损坏，系统只读
