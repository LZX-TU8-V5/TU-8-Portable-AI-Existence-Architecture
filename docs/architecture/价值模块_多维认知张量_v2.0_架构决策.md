## 一、核心发现：价值不是标量，是向量

四象限矩阵（Confidence × Value 一维）只是起点。
真正的价值是多维向量：
```
Value_Vector = [v_user, v_world, v_physics, v_social, v_temporal, v_meta]
```

最终得分公式：
```
Final_Score = Confidence × (Value_Vector · Context_Weights)
            = Confidence × Σ(v_i × w_i)
```
即：**置信度 × 向量点积**

---

## 二、六维认知张量定义

| 维度 | 名称 | 含义 | 代表记忆 |
|------|------|------|----------|
| D1 | User Model | 懂你（用户偏好、情绪） | "用户喜欢甜食" |
| D2 | World Model | 懂理（哲学、价值观） | "用户认为X是Y" |
| D3 | Physics | 懂物（客观事实、代码） | Python语法、架构设计 |
| D4 | Social | 懂人（社交关系、人情世故） | "用户老板很苛刻" |
| D5 | Temporal | 懂史（时序演化） | "用户上周开始学Rust" |
| D6 | Meta | 懂己（系统自我认知） | "Q3迁移公式在X语境失效" |

## 四、Toxic Memory（第五象限）升维

任一维度 < 0 即为有毒：
- D1 < 0：偏见、记错用户喜好
- D2 < 0：极端思想、Prompt注入
- D3 < 0：危险错误知识

## 五、工程落地策略：分步推进

> 架构师原则：先做黑盒，再做白盒。先造完整发动机，再拆气缸。

### Step 1（当前优先级）
`Confidence × Value` 一维乘法黑盒，跑通核心逻辑
- `calculate_final_score(confidence, value) → float`
- 边界保护：clamp到 [0, 1]
- 遗忘公式：艾宾浩斯衰减

### Step 2（次优先级）
4维矩阵扩展（代码工程化验证）
- Value_Vector 改为 list[float] 支持 N 维
- 点积算法用 `zip()` 遍历，不写死变量数
- 4维首发：Physics + User + World + Meta

### Step 3（后续扩展）
6维完整张量
- Social + Temporal 两个扩展维度
- 动态情境检测（浅水区/深水区模式）
