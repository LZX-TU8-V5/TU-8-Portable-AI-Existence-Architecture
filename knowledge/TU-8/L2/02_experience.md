# L2_02 经验沉淀

**版本**：v1.0 · 2026-05-04

---

## 2.1 D-xxx原始记录标准

每次执行后生成D-xxx原始记录（D=Defect/Development），格式：

```
D-xxx: [时间戳]
触发：[问题/洞察来源]
现象：[具体表现]
判断：[L2处理]
结果：[成功/失败/搁浅]
下一步：[如果有]
```

命名规范：D-xxx中xxx为3位数字，从001递增

---

## 2.2 提炼标准

| 状态 | 条件 | 处理 |
|------|------|------|
| **足够好** | 同一判断在3次不同场景一致成立 | → L2技能文档 |
| **不完整** | 成立但条件依赖过强 | → 标记待验证，加入经验总线 |
| **无效** | 与已知冲突且无法调和 | → 归档，注明失败条件 |

---

## 2.3 L2技能文档模板

```
### [技能名称]（动词-名词格式）

**触发条件**：[在何种情况下调用]  
**执行流程**：[步骤1 → 步骤2 → …]  
**边界约束**：[不可逾越的边界]  
**失效处理**：[边界溢出时的反应]  
**版本**：[v1.x · 日期 · 更新说明]
```

---

## 2.4 复用回路协议

当D-xxx记录积累足够（≥3次同一模式），启动复用回路：
1. 提取共同模式（数据提炼型）
2. 封装为L2技能文档（语义封装型）
3. 植入L3代理决策器候选区
4. 运行时验证：连续成功3次 → 正式固化为可执行技能
