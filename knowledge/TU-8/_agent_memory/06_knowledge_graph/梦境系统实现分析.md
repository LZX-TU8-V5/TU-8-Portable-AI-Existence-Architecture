## 三、关键发现：REM Dream 是"知识连线层"

```python
# _rem_dream() L386-393
for entry in self.short_term.values():
    if entry.phase == "dream":         # ← 只有被标记为"梦境"的条目
        boost = 0.09 * recency
        entry.emotion = min(1.0, entry.emotion + boost)
# 再次触发晋升检查
self._check_promotion()
```

**这行代码的隐含逻辑**：
- `phase == "dream"` 的条目 = 情感强度高、跨界联想活跃的记忆
- REM阶段对它们额外加 `emotion` 权重
- 高 `emotion` → 高晋升评分 → 从 `short` 进入 `long`（长时记忆）
- **本质上：高情感跨界的记忆更容易被固化进长期记忆 = 知识图谱的边（edge）**

```

```

**当前 REM Dream 只做"权重提升"，还没做"跨域连线生成"**。

## 六、总结：梦境系统的三层含义

| 层次 | 大脑（认知科学） | TU-8（代码实现） | 知识图谱（概念） |
