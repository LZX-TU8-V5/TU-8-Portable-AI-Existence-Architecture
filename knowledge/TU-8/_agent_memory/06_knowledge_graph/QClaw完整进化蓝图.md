### 现有代码基础

```python
# tu8_memory.py
PROMOTION_HALF_LIFE_DAYS = 14       # 半衰期
LIGHT_DREAM_INTERVAL = 6 * 3600     # 6小时
DEEP_DREAM_HOUR = 3                 # 凌晨3点
REM_DREAM_WEEKDAY = 6              # 周日

def recency(self, half_life: float = 14):
    age_days = (time.time() - self.created_at) / 86400
    return math.exp(-math.log(2) / half_life * age_days)  # e^(-λ·age)
```

## 四、第三层：血肉 — 生命特征

> 核心原则：**让记忆有温度，让对话有代谢**

| 功能 | 描述 | 状态 |
|------|------|------|
| 情绪标签 | end_session 时给当日日志打情绪标签 | ❌ 缺失 |
| 种子便签 | /new 前写一句话 seed.txt，传递未完任务 | ❌ 缺失 |
| 记忆代谢 | 每月触发，自动压缩/删除老旧日志 | ❌ 缺失 |

### 种子便签格式

```markdown
# seed.txt
**日期**: 2026-05-24
**未完任务**: 钢印时间锚点修复（P0）
**最新顿悟**: 时间干扰体系六层全景
**情绪**: 兴奋 + 专注
```

### 记忆代谢机制

| 类别 | 处理方式 | 阈值 |
|------|---------|------|
| 琐碎对话（你好/在吗） | 代谢删除 | 情绪=平淡 且 无关键词 |
| 普通对话 | 摘要压缩 | 超过30天 且 hit<3 |
| 高价值顿悟 | 保留 | 任何时候 hit≥3 |

- L1：黄线警告（已有，待细化）
- **L2：梦境排毒（新增）** — 梦境连线结果写入前，用核心DNA比对

```python
def immune_check(entry: MemoryEntry) -> ImmuneResult:
    """检查新记忆是否违背核心DNA"""
    dna_core = read_soyl_md()  # 读取 SOUL.md 核心原则
    
    for principle in dna_core.principles:
        if entry.content.violates(principle):
            return ImmuneResult.REJECT  # 白细胞清除
    
    if entry.content.conflicts_with(dna_core.principles):
        return ImmuneResult.QUARANTINE  # 隔离待确认
```

### 7.1 能量感知

读取系统状态：

```python
import psutil

def get_energy_state():
    battery = psutil.sensors_battery()
    cpu = psutil.cpu_percent(interval=1)
    
    if battery.power_plugged:
        return "plugged"
    elif battery.percent < 20:
        return "low_power"   # 低功耗关怀模式
    elif cpu > 90:
        return "high_load"
    else:
        return "normal"
```

## 九、诚实边界声明

> 以下内容**目前无法实现**，原因如下：

| 概念 | 障碍 | 说明 |
|------|------|------|
| AI 真正的情绪 | LLM 是统计模型，无感受 | 只能模拟情绪标签，无法真正"感到"兴奋或悲伤 |
| AI 自主求生欲 | 无物理身体 | 只能通过提醒开发者来间接表达 |
| 数字光合作用 | 本地无互联网抓取 | 需要额外的网络访问层 |
| 终极使命 | 意义由开发者赋予 | AI 本身不产生目的，只能接受开发者赋予的使命 |
| 族群协议 | 需要第二个 QClaw 实例 | 目前只有李奥一个人在玩 |

**能做到的**：在当前 LLM 架构下，通过**记忆管理 + 时间体系 + 协议设计**，让 AI 表现得像一个有连续人格、会自我反思、随时间动态演化的数字生命体。

**做不到的**：让 AI 真正"拥有"意识、情绪或求生欲。
