### 1.1 时间回拨检测

**问题**：用户手动把系统时间往后调一年，锚点时间 > 当前时间 → 逻辑死锁。

```python
def _load_time_anchor(self) -> float:

        self._emit_time_drift_warning(anchor, now)
        anchor = now  # 软重置
    
    return anchor
```

```python
def _load_time_anchor(self) -> float:
    # 路径1：读锚点文件
    anchor_path = self.ANCHOR_FILE  # memory/_time_anchor.json
    if os.path.exists(anchor_path):
        return self._read_anchor_file()
    
    # 路径2：扫描最新日志作为备用锚点（软启动）
    latest_log = self._find_latest_memory_log()

        ts = self._extract_timestamp_from_log(latest_log)

    # 路径3：完全无记录 → 以当前时间为准
    log(f"[TimeKeeper] 无历史锚点，使用系统时间初始化")
    return time.time()
```

## 二、梦境产物版本控制（双时间戳）

### 2.1 MemoryEntry 扩展

```python
@dataclass
class MemoryEntry:
    id: str
    content: str
    tags: list[str]
    
    # v1：诞生时间（永远不变 = 出生证明）
    created_at: float = field(default_factory=time.time)
    
    # v2：最后修正时间（每次修改更新 = 健康状态）
    updated_at: float = field(default_factory=time.time)
    
    # 钢印落地时标记
    steelmark_timestamp: float | None = None
    
    def touch(self):
        """更新修正时间"""
        self.updated_at = time.time()
    
    def age_days(self) -> float:
        """返回记忆年龄（基于 created_at）"""
        return (time.time() - self.created_at) / 86400
    
    def freshness(self) -> float:
        """新鲜度（基于 updated_at）"""
        return math.exp(-math.log(2) / 7 * (time.time() - self.updated_at) / 86400)
```

### 2.2 双时间戳的语义

| 时间戳 | 用途 | 衰减参考 | 修改时机 |
|--------|------|---------|---------|
| `created_at` | 记忆年龄、钢印触发判断 | ✅ 用于 recency() | 永不修改 |
| `updated_at` | 新鲜度、检索排名 | ✅ 用于 freshness() | 每次 touch() |
| `steelmark_timestamp` | 钢印落地时间 | ❌ 不参与衰减 | 钢印固化时 |

### 4.2 修正衰减公式

```python
def effective_age(created_at: float, emotion_intensity: float) -> float:
    """
    原始衰减：age
    突触强化：age / (1 + emotion_intensity)
    
    情绪平静（1.0）→ effective_age = age / 2.0  衰减加速（？）❌
    
    修正：emotion_intensity > 1 才强化，< 1 才弱化
    """
    if emotion_intensity >= 1.0:
        # 情绪强烈：有效年龄被压缩 → 衰减变慢
        return created_at / emotion_intensity
    else:
        # 情绪平淡：正常衰减
        return created_at

def recency_v2(self, entry: MemoryEntry) -> float:
    effective_age_days = effective_age(
        entry.created_at,
        EMOTION_INTENSITY.get(entry.emotion_tag, 1.0)
    )
    lam = math.log(2) / self.promotion_half_life
    return math.exp(-lam * effective_age_days)
```

> **注意**：这个公式还需要验证。情绪平淡时加速衰减是否合理？人类对平淡的事确实忘得快。情绪强烈时衰减慢 = 痛苦的事记得久，符合直觉。

## 五、钢印防抖动逻辑（宽限期窗口）

### 5.1 问题

周日 5am 触发 REM Dream。但如果用户周日 6:30 才开机，错过了 1.5 小时，是否直接跳到下周日？

### 5.2 修复逻辑

```python
REM_GRACE_PERIOD_HOURS = 2  # 宽限期窗口

def _should_trigger_rem(self) -> bool:
    target = self._get_next_weekly_from_anchor(
        self._last_rem,
        weekday=6,  # 周日
        hour=5      # 凌晨5点
    )
    now = time.time()
    overdue = now - target  # 过了多久
    
    if overdue < 0:
        return False  # 还没到时间
    
    if overdue <= REM_GRACE_PERIOD_HOURS * 3600:
        # 在宽限期内：仍然触发
        log(f"[TimeKeeper] REM 触发（宽限期，逾期 {overdue/3600:.1f}h）")
        return True
    
    # 超过宽限期：跳过本次，等下周
    log(f"[TimeKeeper] REM 跳过（超过宽限期 {overdue/3600:.1f}h）")
    return False
```

```python
TOOL_WHITELIST = {
    "read":       ["memory/*.md", "knowledge/**", "*.py", "*.json"],

def execute_tool(action: str, params: dict) -> Result:
    if action not in TOOL_WHITELIST:
        return Result.REJECT("不在白名单内")
    
    # 路径校验
    if params.get("path"):
        if not path_in_whitelist(params["path"], TOOL_WHITELIST[action]):

    return Result.PROCEED
```
