# 00_core — 身份核心

> 我是谁？我的状态如何？用户偏好是什么？

## 文件清单

| 文件 | 用途 | 更新频率 |
|------|------|---------|
| `00_state.md` | **主状态文件**：当前阶段、活跃任务、环境信息、待办 | 每次会话结束覆盖 |
| `10_preferences.md` | 用户偏好：称呼风格、输出格式习惯 | 低频 |
| `user_preferences.md` | 用户偏好（副本/旧版） | 低频 |
| `project_state.md` | 项目级状态：小说项目进度、各子系统状态 | 低频 |

## 核心原则
- `00_state.md` 是**唯一权威**的状态快照
- 会话结束必须重写 00_state.md（覆盖模式）
- 其他文件变更后无需同步更新此索引，文件夹名已自描述
