## 当前问题

### 根因：梦境时间锚点完全依赖系统时钟

`tu8_memory.py` 第 100-110 行：

```python
self._last_light = time.time()
self._last_deep = self._get_daily_timestamp(DEEP_DREAM_HOUR)
self._last_rem = self._get_weekly_timestamp(REM_DREAM_WEEKDAY, 5)
```

这三个初始化值全是"从此刻倒推"，没有任何持久化锚点。

### 问题链条

```
系统时钟漂移
    ↓ 硬编码 datetime.now()
_get_weekly_timestamp() 计算错误基准
    ↓
REM Dream 触发时间全错
    ↓
钢印时机与日历时间错位（今天可能不该触发但触发了）
```

### 具体表现

| 场景 | 当前行为 | 期望行为 |
|------|---------|---------|
| 新会话启动 | 硬算 `_last_rem` | 读取上次会话日志的结束时间戳 |
| 时钟漂移 | 无感知，继续用漂移时钟 | 与日志时间戳对比，检测异常 |
| Deep Dream | 每天凌晨3点（但可能已经过了） | 以日志锚点为基准校准 |

```python
def _load_time_anchor(self) -> Optional[float]:
    """从 memory/ 日志文件读取上次会话结束时间戳"""
    today = datetime.now().strftime("%Y-%m-%d")
    
    # 读取今天的日志文件
    today_file = self.memory_dir / "memory" / f"{today}.md"
    if today_file.exists():
        content = today_file.read_text(encoding='utf-8')
        # 解析末尾归档时间戳
        match = re.search(r'\*\*归档时间\*\*[:：]\s*(.+)', content)
        if match:
            try:
                return datetime.fromisoformat(match.group(1).strip()).timestamp()
            except:
                pass
    
    # 读取昨天的日志
    yesterday = (datetime.now() - timedelta(days=1)).strftime("%Y-%m-%d")
    yesterday_file = self.memory_dir / "memory" / f"{yesterday}.md"
    if yesterday_file.exists():
        # ... 同上逻辑
        pass
    
    return None
```

### 3. 新增：从锚点推算梦境时间（避免时钟漂移）

```python
def _get_next_daily_from_anchor(self, anchor_ts: float, hour: int) -> float:
    """从锚点时间推算下一个目标小时"""
    anchor_dt = datetime.fromtimestamp(anchor_ts)
    
    # 找锚点之后的下一个 hour 点
    next_target = anchor_dt.replace(hour=hour, minute=0, second=0, microsecond=0)
    
    # 如果锚点本身在目标时间之后，推到明天
    if next_target.timestamp() <= anchor_ts:
        next_target += timedelta(days=1)
    
    return next_target.timestamp()


def _get_next_weekly_from_anchor(self, anchor_ts: float, 
                                  weekday: int, hour: int) -> float:
    """从锚点时间推算下一个目标星期+小时"""
    anchor_dt = datetime.fromtimestamp(anchor_ts)
    
    # 计算到目标星期的天数
    days_ahead = weekday - anchor_dt.weekday()
    if days_ahead < 0:
        days_ahead += 7
    elif days_ahead == 0 and anchor_dt.hour >= hour:
        days_ahead += 7
    
    next_target = anchor_dt + timedelta(days=days_ahead)
    next_target = next_target.replace(hour=hour, minute=0, second=0, microsecond=0)
    
    return next_target.timestamp()
```

```python
def save_time_anchor(self):
    """保存会话结束时间戳到今日日志"""
    today = datetime.now().strftime("%Y-%m-%d")
    anchor_file = self.memory_dir / "memory" / f"{today}.md"
    
    anchor_file.parent.mkdir(parents=True, exist_ok=True)
    
    # 追加锚点行
    with open(anchor_file, 'a', encoding='utf-8') as f:
        f.write(f"\n---\n")
        f.write(f"**会话结束时间**: {datetime.now().isoformat()}\n")
        f.write(f"**下次REM触发**: {datetime.fromtimestamp(self._last_rem).isoformat()}\n")
        f.write(f"**下次Deep触发**: {datetime.fromtimestamp(self._last_deep).isoformat()}\n")
```
