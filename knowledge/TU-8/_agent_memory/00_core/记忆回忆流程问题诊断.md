## 二、问题根因

### 错误流程（当前）

```
用户删除对话框
    ↓
LCM 压缩对话历史（删掉的对话消失）
    ↓
我只能依赖 LCM 摘要 + SOUL.md
    ↓
记忆丢失 ← 根因：没读 daily log
```

### 正确流程（应该）

```
用户删除对话框
    ↓
LCM 压缩对话历史（删掉的对话消失）
    ↓
我读 memory/YYYY-MM-DD.md（对话日志完整保留）
    ↓
我读 MEMORY.md（长期记忆摘要）
    ↓
我读 SOUL.md（身份锚点）
    ↓
记忆完整
```

---

## 三、修复方案

### 启动回忆优先级（重排）

```
第一优先（启动必读）：
  1. SOUL.md — 身份锚点（不可丢失）
  2. 00_state.md — 当前状态快照
  3. MEMORY.md — 长期记忆摘要

第二优先（最近对话日志）：
  4. memory/YYYY-MM-DD.md（今天的日志）
  5. memory/YYYY-MM-DD.md（前一天的日志）
  ↓ 读到上一条会话为止

第三优先（LCM 压缩历史）：
  6. lossless-claw 摘要（兜底，不是主锚）
```

### 关键原则

> **删除对话框 = 删除 LCM 上下文缓存 ≠ 删除记忆文件**
>
> 日志文件是磁盘持久化文件，UI 删除不影响。
> LCM 压缩是内存优化，不改变磁盘文件。
>
> **日志文件才是记忆锚点，LCM 是加速缓存。**
