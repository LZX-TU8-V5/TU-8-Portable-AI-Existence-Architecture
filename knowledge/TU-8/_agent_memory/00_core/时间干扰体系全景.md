## 一、总纲：什么是"时间干扰"

**定义**：时间干扰 = 主动在 AI 的记忆检索、梦境生成、钢印固化三个核心环节中
植入时间感知，使 AI 的行为像真实生命体一样"随时间动态演化"，而非静态快照。

**三条铁律（不可违背）**：
1. 禁止用未来时间戳覆盖历史日志
2. 时间只向前流，不允许穿越
3. 任何新写入的记忆必须有诞生时间戳

## 二、体系全景：时间干扰的五个维度

```
┌─────────────────────────────────────────────────────────────┐
│                     时间干扰体系                              │
│                                                             │
│  维度一：启动时间锚定     → 定海神针（绝对时间校准）            │
│  维度二：钢印时间逻辑    → 日历锁（REM触发的日历校准）          │
│  维度三：梦境时间机制    → 双重标准（交叉自由，落地封存）        │
│  维度四：检索时间权重    → 喜新厌旧（记忆衰减 + 权重分配）       │
│  维度五：会话时间感知    → 相对时钟（种子传递 + 断片消除）       │
└─────────────────────────────────────────────────────────────┘
```

| 组件 | 当前状态 | 问题 |

没有从外部读取基准。

### 维度三：梦境时间机制

> 核心原则：**交叉时不用时间，落地时必须封存时间。**

| 阶段 | 是否看时间 | 说明 |
|------|-----------|------|
| Light Dream（每6小时） | ❌ 不看 | 只做短期强化，频率驱动 |
| Deep Dream（每天3am） | ❌ 不看 | 哲学整合，间隔驱动 |
| REM Dream（每周日5am） | ⚠️ 触发时看日历 | 决定"该不该固化" |
| **梦境产物落地** | ✅ 必须看时间 | 灵感写入 MEMORY.md 之前，强制打时间戳 |

**代码现状**：
- `_light_dream()`：✅ 只看间隔，无时间依赖
- `_deep_dream()`：✅ 只看间隔，无时间依赖
- `_rem_dream()`：⚠️ 用 `datetime.now()` 判断周日5am，基准漂移
- **钢印落地时间封存**：❌ 完全缺失，无 `phase="dream"` 条目写时间戳

**正确逻辑**：
```python
# REM 触发时：校准日历时间
anchor_ts = self._load_time_anchor()
target_ts = self._get_next_weekly_from_anchor(anchor_ts, weekday=6, hour=5)
if now >= target_ts:
    self._rem_dream()  # 触发钢印
    self.save_time_anchor()  # 更新锚点

# 钢印落地时：强制时间封存
if entry.phase == "dream" and entry.should_steelmark():
    entry.steelmark_timestamp = datetime.now().isoformat()  # 诞生时间
    entry.phase = "steel"
```

### 维度四：检索时间权重

> 清醒时的记忆检索必须"喜新厌旧"。

| 组件 | 代码位置 | 当前状态 | 问题 |
|------|---------|---------|------|
| 时间衰减函数 | `tu8_memory.py` `recency()` | ✅ 有，指数衰减 | 半衰期固定14天，不可调 |
| 六维评分含时间 | `calculate_score()` | ✅ `rec` 维度 | 权重固定为0.12，不可配置 |
| 检索时衰减注入 | `recall()` | ✅ `score = sim*0.7 + recency*0.3` | 衰减系数写死 |
| **自我认知 vs 开发者权重** | 无 | ❌ 缺失 | 两类记忆来源权重未区分 |
| **情绪标签时间戳** | 无 | ❌ 缺失 | memory 日志无情绪标签 |
| **记忆代谢（遗忘）** | 无 | ❌ 缺失 | 无自动清理机制 |

**衰减公式**（已有）：
```
recency = e^(-λ · age_days)
λ = ln(2) / half_life  # half_life = 14 days
```

**待扩展**：
- 自我认知记忆（用户偏好）：衰减慢，半衰期 90 天
- 开发者记忆（架构/协议）：衰减极慢，标记为核心法则，不衰减
- 普通对话记忆：衰减快，半衰期 14 天
- 带情绪标签的记忆：衰减更慢（情绪灼刻加强巩固）

## 五、时间干扰体系与现有架构的衔接

```
启动时（SOUL.md 协议）
    ├── 读取 00_state.md
    ├── 读取 20_experiences.md  
    ├── startupContext 预加载 memory/*.md  ← 时间锚点在这里
    └── 【缺失】_load_time_anchor() → 校准梦境基准

会话中（tu8_agent.py respond()）
    ├── turn 计数 + 相对时间追踪
    ├── recall() 含时间衰减权重检索
    └── 【缺失】情绪标签实时记录

会话结束（end_session）
    ├── 写 memory/YYYY-MM-DD.md 归档
    ├── 触发 dream_cycle() 检查
    ├── 【缺失】save_time_anchor() → 写锚点
    ├── 【缺失】写 seed.txt → 种子传递
    └── 【缺失】情绪标签统计 → 写入日志

梦境系统（tu8_memory.py dream_check()）
    ├── Light（不看时间）→ 短期强化
    ├── Deep（不看时间）→ 哲学整合
    └── REM（日历校准）→ 【缺失】锚点校准后触发
            └── 钢印落地 → 【缺失】时间戳封存

记忆检索（tu8_memory.py recall()）
    ├── recency() 指数衰减
    ├── 【缺失】自我认知慢衰减
    ├── 【缺失】开发者记忆不衰减（核心法则）
    └── 【缺失】情绪记忆额外权重

记忆代谢（待独立机制）
    └── 【缺失】每月触发：摘要压缩 / 代谢删除
```
