### 发现的根因
`tu8_memory.py` 初始化时，`_last_light/_last_deep/_last_rem` 全用 `datetime.now()` 硬算，无持久化锚点。
梦境触发只看时间间隔，不校验日历时间。

### 修复方案
1. 新增 `_load_time_anchor()` 读取 memory/ 日志的会话结束时间戳
2. 初始化时校准三个梦境锚点
3. 新增 `save_time_anchor()` 在 end_session 时写入锚点
4. 新增 helper 从锚点推算下一次触发时间（防时钟漂移）
