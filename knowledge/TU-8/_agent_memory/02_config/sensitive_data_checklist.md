## 六、"去敏后的行为信号"定义（L4 协议落地）

根据 L4_协作.md，云端应只看到：

| 信号类型 | 具体内容 | 示例 |
|---------|---------|------|
| 任务类型 | 泛化后的任务分类 | `[FILE_OP]`、`[CODE_GEN]`、`[DEBUG]` |
| 成功/失败 | 二进制结果 | `SUCCESS` / `FAILURE` |
| 搁浅状态 | 是否触发 L0 红线 | `STRANDED` / `NORMAL` |
| 资源消耗 | 相对值，非绝对值 | `LOW_COST` / `HIGH_COST` |

**禁止发送给云端的内容：**
- ❌ 具体文件路径
- ❌ 锚点 JSON 内容
- ❌ L0~L5 具体规则
- ❌ 用户真实信息
- ❌ 成本绝对值
