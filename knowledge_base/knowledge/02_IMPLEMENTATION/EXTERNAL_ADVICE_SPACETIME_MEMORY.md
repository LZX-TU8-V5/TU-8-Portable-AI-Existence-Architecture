## 一、启动时时间锚点注入（09:15段）

### 核心洞见

> "人起床时的'蒙一下'，本质是大脑完成**多模态状态同步**：空间锚定 → 时间锚定 → 身份重载"

### 推荐方案

| 项目 | 建议实现 |
|------|----------|
| **注入内容** | 结构化时间 + 自然语言描述 |
| **示例格式** | `当前时间：2026-05-30 星期六 09:12 (北京时间)` |
| | `时间语境：周六上午，用户休息/轻松交流时段` |
| **绑定场景** | 时间 + 空间 + 状态 组合锚点 |

### 关键设计原则

1. **分层注入**：底层精确时间（逻辑基准）+ 表层语义化（交互体验）
2. **一次性**：启动时注入，不重复
3. **隐式**：用户不感知，AI自然使用

## 二、时空感知检索升级（09:17段）

### 核心架构

```
用户输入
    ↓
[Step 1] 情境化查询改写（Coreference Resolution）
    "刚才说的" → "6月15日14:30在书房关于项目风险的讨论"
    ↓
[Step 2] 混合检索（Hybrid Search）
    语义向量 + 空间关系 + 时间衰减
    ↓
[Step 3] 神经模式激活评分
    时间衰减 × 空间亲和 × 情绪一致性 × 检索历史强化
    ↓
[Step 4] 重构主叙事
    融合共识 + 标注分歧 + 不确定性量化
```

### 四层模块设计

| 层级 | 功能 | 输入 | 输出 |
|------|------|------|------|
| 环境感知层 | 时空校准 | 时间戳 + 位置信号 | 校准后的上下文 |
| 内在状态层 | 未完成检查 | pending_tasks.json | 今日待办列表 |
| 规划决策层 | 意图推断 | 用户历史模式 | 预期行动建议 |
| 交互表达层 | 首屏输出 | 以上三层结果 | 自然语言问候 |

## 三、完善设计的具体方案（09:18段）

### 未完成事项管理

引入**紧急-重要四象限** + **遗忘曲线模拟**：

```python
# 优先级计算
priority_score = (
    urgency * 0.4 +
    importance * 0.3 +
    (1 - decay(days_since_created)) * 0.2 +
    completion_rate * 0.1
)
```

### 求知欲系统

维护显式兴趣图谱：

```json
{
  "tags": {
    "AI架构": {"heat": 0.9, "last_activated": "2026-05-30"},
    "神经科学": {"heat": 0.7, "last_activated": "2026-05-29"},
    "TypeScript": {"heat": 0.5, "last_activated": "2026-05-28"}
  }
}
```

捕获隐式信号：
- 用户追问 → `heat += 0.1`
- 用户点赞 → `heat += 0.15`
- 用户跳过 → `heat -= 0.05`

### 规划引擎流程

```
约束检查 → 候选池生成 → 适配性过滤 → 组合优化 → 置信度标注
```

**关键**：所有输出必须包含 `confidence` 字段

## 四、人类时空感神经机制（09:23段）

### 空间感：位置细胞 + 网格细胞

| 机制 | 神经基础 | 功能 | AI对应 |
|------|----------|------|--------|
| 路径整合 | 内耳前庭 + 本体感觉 | 相对位移积分 | 无（需建立） |
| 环境映射 | 海马体位置细胞 | 拓扑地图 | `spatial_graph.json` |
| 空间预测 | 前额叶 | 提前激活场景表征 | 预测引擎 |

### 时间感：多尺度多模态

| 时间尺度 | 神经基础 | 特点 | AI对应 |
|----------|----------|------|--------|
| 毫秒级 | 小脑 | 运动控制 | 交互延迟优化 |
| 秒-分钟级 | 岛叶 | 受注意力/情绪影响 | 状态感知模块 |
| 日-周级 | 视交叉上核 | 生物钟 | 语义时间绑定 |
| 事件级 | 海马体 | 非线性可压缩 | 事件时间线 |

### 预测编码：大脑的操作系统

> **核心机制**：大脑不是被动接收时空信息，而是**持续生成预测模型，用感官校验**

```
走进熟悉房间 → 大脑提前激活完整表征 → 与现实比对
    ├─ 匹配 → 几乎不消耗注意
    └─ 不匹配 → 触发"惊讶信号" → 重新评估
```

## 五、记忆分形与重演协议

### 核心原则

| 原则 | 描述 |
|------|------|
| **多版本共存** | 同一事件允许不同表述，由上下文选择主版本 |
| **读取即重构** | 每次回忆都是新构建，补全缺失、标注不确定 |
| **非破坏性更新** | 新记忆不覆盖旧记忆，只抑制或重组 |

## 八、核心结论

> **不要追求让 AI "拥有"人类的时空感，而是让它模拟人类时空感的功能性输出。**

用户不在乎：
- AI 是否有海马体
- AI 是否真的"感知"时间

用户只在乎：
- 在正确的时间
- 以正确的节奏
- 提供恰到好处的帮助

**设计原则**：把"时空感"从一种**状态描述**，转变为一种**决策依据**。
