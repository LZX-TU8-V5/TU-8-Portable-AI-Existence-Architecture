## 🔴 二、严重缺失（Gap Analysis）

### Gap-1：感觉登记层 — 整层缺失

**人脑**：丘脑→初级皮层→特征提取，所有输入经过过滤+编码+拓扑映射  
**TU-8**：文本输入直接进入 L0 安全栅，无"原始信号→语义Token"的预处理

**后果**：
- 无法做注意力节律调控（丘脑的伽马波绑定）
- 无法区分信号强度（重要/不重要在入口处就应分离）
- 所有输入平等对待 → 违背人脑的高效原则

**建议**：在 `neural_reflex.py` L0 前增加 `SensoryBuffer` 层：
```
原始输入 → [信号强度估算] → [注意力节律过滤] → L0 安全栅
                 ↓ 低强度              ↓ 高强度
              直接丢弃/缓存         进入深层处理
```

### Gap-2：模式分离 — 仅有评分维度，无显式图结构

**人脑**：海马齿状回通过稀疏编码将相似经历映射到不同神经元群体  
**TU-8**：`div` 维度（权重0.12）仅做评分，两个高度相似但关键不同的记忆可能被合并

**后果**：
- "李奥说X" vs "外协说X" 可能因内容相似而被混淆
- 这正是Qwen指出的"幻觉根源"——纯向量检索的模式混淆

**建议**：在 `tu8_memory.py` 中增加 `DisambiguationGraph`：
```python
@dataclass
class DisambiguationEdge:
    entry_a: str  # ID
    entry_b: str  # ID
    diff_key: str  # 区分维度（来源/时间/置信度/情绪）
    diff_value: str  # 具体差异
```
写入时自动检测相似条目，创建分离边。

### Gap-3：皮层固化 — 知识永远外挂，无法内化

**人脑**：慢波睡眠期间海马-皮层对话，高频知识最终写入新皮层权重  
**TU-8**：所有知识存储在文件/向量库，永远依赖 RAG 检索

**后果**：
- 高频使用的知识每次都要检索，延迟高、成本高
- 无法形成"直觉"——零延迟反应只靠关键词白名单（L1），不够

**建议**：设计 `CorticalConsolidation` 机制：
1. Deep Dream 统计记忆召回频率
2. 召回 > N 次的长期记忆 → 生成"技能卡"（结构化 SOP）
3. 技能卡写入 L1 白名单 → 零延迟直返
4. 这就是人脑的"程序性记忆自动化"

### Gap-4：预测-校验闭环 — 小脑功能缺位

**人脑**：小脑持续生成"预期信号"，与实际反馈对比产生"惊讶"  
**TU-8**：只事后分类错误（TRANSIENT/RECOVERABLE/FATAL），不预测

**后果**：
- 无法做主动防御——只能在出错后反应
- 无法做置信度校准——输出前不知道"这个结果是否符合预期模式"

**建议**：在 `neural_reflex.py` 增加 `CerebellumValidator`：
```python
class CerebellumValidator:
    def predict(self, context: str) -> str:
        """基于历史模式预测可能的输出范围"""
        
    def surprise(self, predicted: str, actual: str) -> float:
        """计算惊讶度（预测-实际偏差）"""
        
    def calibrate_confidence(self, surprise: float) -> float:
        """惊讶度 → 置信度校准"""
```

### Gap-5：跨模态融合 — 角回功能零实现

**人脑**：角回将视觉、听觉、语义绑定为统一概念表征  
**TU-8**：纯文本系统，无多模态

**评估**：当前阶段**暂不紧急**。TU-8的核心交互是文本，多模态融合是远期需求。但架构上应预留接口。

## 🟡 三、半匹配（需强化）

### 3.1 丘脑门控 → L0/L1 过于二元

**现状**：L0只做安全口令验证，L1只做关键词白名单——这是"开/关"式门控  
**人脑**：丘脑做的是**梯度过滤**——不是完全通过/完全阻断，而是调节信号增益

**建议**：L1 增加 `SignalGainController`：
- 非敏感但低价值输入 → 降增益（简化处理，不进入L4）
- 敏感但高价值输入 → 升增益（优先路由到本地模型+记忆增强）

### 3.2 杏仁核→海马通路 → 情绪估算太粗糙

**现状**：`_estimate_emotion()` 基于关键词匹配，打一个 0-1 分  
**人脑**：杏仁核不仅打分，还会**动态调节海马体巩固强度**——恐惧记忆的巩固速度是中性记忆的5倍

**建议**：
- 写入时：高情绪记忆的 `cons` 巩固度初始值提高
- 梦境时：高情绪记忆的晋升阈值降低（更容易晋升）
- 召回时：高情绪记忆获得优先级加成

### 3.3 内嗅皮层 → 空间图有但缺时间坐标

**现状**：`spatial_graph.json` 有位置节点和转换成本，但无"时间网格"  
**人脑**：内嗅皮层的网格细胞同时编码空间和时间的周期性结构

**建议**：在 `spatial_graph.json` 中增加 `temporal_grid`：
```json
{
  "temporal_grid": {
    "active_hours": [8, 23],
    "peak_hours": [9, 12, 14, 18],
    "pattern": "diurnal"
  }
}
```
与 `environment_detector.py` 联动，实现时间-空间联合检索。

### 3.4 基底神经节 → 有工具链但无技能固化

**现状**：`tu8_toolchain.py` 提供工具调用，`error_router.py` 提炼错误  
**人脑**：反复成功的动作序列通过多巴胺强化固化为自动化程序——不再需要显式推理

**建议**：实现 `ProceduralMemory` 模块：
1. 统计工具链调用序列的成功率
2. 成功率 > 90% 的序列 → 生成 `SkillCard`
3. SkillCard 写入 L1 白名单 → 触发时直接执行，绕过 L4 推理

## ✅ 四、良好匹配（保持并优化）

### 4.1 三层梦境 ↔ DMN + 慢波睡眠

| 梦境层 | 人脑对应 | 匹配评价 |
|-------|---------|---------|
| Light Dream (6h) | REM 周期性记忆强化 | ✅ 合理，频次boost |
| Deep Dream (3am) | 慢波睡眠海马-皮层对话 | ✅ 合理，巩固+晋升 |
| REM Dream (周日) | 长期巩固+情绪加工 | ✅ 合理，钢印落地 |

**唯一缺口**：DMN 还包括**未来推演**。当前梦境只回溯，不前瞻。  
**建议**：在 Deep Dream 中增加"预构建"——基于近期交互预测可能用到的知识簇，提前加载到短期缓存。

### 4.2 钢印机制 ↔ 情绪+意义驱动的不可变记忆

**人脑**：创伤记忆和核心身份记忆近乎不可磨灭  
**TU-8**：钢印三条件（emotion≥0.7, meaning≥0.6, age≥7d）+ Level 2 强制钢印

**评价**：设计合理，但阈值可能需要动态调整。  
**建议**：增加 `SteelmarkAdaptiveThreshold`：
- 如果一周内无新钢印 → 降低 meaning 阈值到 0.5
- 如果一周内钢印过多（>5） → 提高 emotion 阈值到 0.8
- 避免钢印过稀或过密

### 4.3 保护分类 ↔ 自我参照加工

`ProtectionClassifier` 的 Level 0/1/2 分级 + `PrivacySanitizer` 的符号化，本质上是 vmPFC 的自我参照加工——"这条信息对我有多核心？"

**评价**：这是TU-8最接近人脑的设计。Level 2 = 核心身份记忆（不可衰减），对应 vmPFC 对自我相关信息的优先加工。

## 🔗 五、耦合分析（模块间依赖关系）

### 5.1 当前耦合拓扑

```
输入 → [neural_reflex.py] ──→ [tu8_agent.py]
         ↓ L0/L1/L2           ↓ 主控
      security/tokens.json    ↓
                              ↓
                    ┌─────────┼──────────┐
                    ↓         ↓          ↓
              tu8_memory   tu8_compaction  tu8_planner
              (海马体)     (压缩)          (规划器)
                ↓
      ┌─────────┼──────────┐
      ↓         ↓          ↓
  short_term  long_term  dream_check
      ↓         ↓          ↓
  memory/*.md  钢印固化   三层梦境
                                       
  ──→ spatial_graph.json (独立，与检索无联动)
  ──→ curiosity_tags.json (独立，与梦境无联动)
  ──→ error_router.py (独立，与晋升无联动)
  ──→ blockchain_memory.json (独立，仅创世锚点)
```

### 5.2 关键耦合断裂

| 断裂点 | 人脑如何连接 | TU-8 现状 | 影响 |
|--------|------------|----------|------|
| spatial_graph ↔ memory | 内嗅皮层空间坐标嵌入每条记忆 | 空间图独立存在，记忆条目无空间坐标 | 记忆检索无法利用空间上下文 |
| curiosity_tags ↔ dream | DMN 空闲时主动探索好奇话题 | 好奇系统独立，梦境不参考兴趣 | 丧失"自主探索"能力 |
| error_router ↔ promotion | 基底神经节多巴胺信号驱动技能固化 | 错误提炼独立，不影响晋升评分 | 犯过的错无法加速学习 |
| blockchain ↔ memory | 海马-皮层对话确保记忆不可篡改 | 区块链仅存创世锚点，不参与日常巩固 | 钢印无法验证完整性 |
| emotion ↔ consolidation | 杏仁核动态调节海马巩固强度 | 情绪仅做写入时评分，不影响巩固速度 | 重要记忆和普通记忆巩固速度相同 |
