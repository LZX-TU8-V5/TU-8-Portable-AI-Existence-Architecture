### RAG 检索引擎

**文件**: `seal_rag.py`

```python
class SealRAGRetriever:
    """
    钢印链 RAG 检索器
    
    核心职责：
    1. 根据用户输入检索相关钢印
    2. 按相关性排序
    3. 只返回 Top-K（节省 Token）
    """
    
    def retrieve(self, user_input: str, intent: Optional[str] = None) -> RAGResult:
        # 1. 提取查询关键词
        # 2. 候选钢印收集（关键词倒排索引）
        # 3. 打分（关键词匹配 + 时间衰减 + 场景权重）
        # 4. 排序 + 裁剪（最多 3 个钢印）
        # 5. 过滤低分候选
```

### 检索策略

| 策略 | 权重 | 说明 |
|-----|------|------|
| **关键词匹配** | 50% | 快速检索 |
| **时间衰减** | 30% | 24 小时后权重减半 |
| **场景权重** | 10% | identity > preference > task |
| **意图加权** | 10% | 按意图偏好场景 |

## 🚧 关键差距分析

### 1. 高度耦合未实现

**问题**：四条链各自独立，没有代码级调用

```python
# 当前状态
tu8_dispatch.py       # 调度链独立
tu8_memory.py         # 记忆链独立
seal_protocol.py      # 钢印链独立
consciousness_cycle.py # 代谢链独立

# 缺失的耦合
调度链 → 记忆链：调度链装配时应该调用记忆链的检索接口
记忆链 → 钢印链：记忆应该带有钢印 ID，没有钢印的记忆是死数据
代谢链 → 钢印链：代谢产物应该生成元钢印
```

### 2. 低架构未实现

**问题**：对外接口不够极简

```python

  dispatch(user_input, soul_context)

对外只有一个输出：
  response_text + new_seal_payload

# 当前实现
需要手动调用多个类：
  DawnRitual → ContextAssembler → ThinkingWithStructure → DuskRitual
```

### 3. 代谢链孤立

**问题**：`consciousness_cycle.py` (93KB) 完全独立，没有与调度链集成

