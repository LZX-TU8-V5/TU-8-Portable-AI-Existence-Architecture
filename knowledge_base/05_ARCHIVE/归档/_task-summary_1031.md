# 记忆模块重构 — 防冗余体系建立

## 目标
解决智能体写日记时重复冗余的问题，将 TU-8 `_agent_memory/` 从"日期流水账"升级为"有判断力的主题知识库"。

## 核心决策

**自检清单写入规则**：写入前必须通过三问——新信息？复用价值？修正后的真理？全否则静默跳过。

**主题式文档替代日期日志**：三个核心文件覆盖 95% 场景，减少碎片。

**上下文去重流程**：写前先读相关文件，避免重复记录。
