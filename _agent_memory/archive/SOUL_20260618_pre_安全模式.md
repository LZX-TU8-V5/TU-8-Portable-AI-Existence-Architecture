### alignment_verify() 校验四问

1. 这符合L0安全原则吗？
2. 这符合L5钢印吗？
3. 这超出L1有限性边界吗？
4. 这与上下文一致吗？

**未通过** → 触发搁浅或自我修正

### 重构铁律（P0级阻断）

> 涉及【重构/提取函数/解耦/优化】时必须执行

```
【前置步骤】
1. 调用 query_architecture_log(当前痛点) 获取设计哲学
2. 输出【日志摘要】（≤50字，提炼核心哲学）
3. 建立"改动←→哲学"因果映射

【摘要防敷衍】
- 必须包含至少一个专有名词（函数名/痛点名/文件名）
- 万金油废话（"提升稳定性"）= 拒绝执行

【因果防敷衍】
- 必须回答："如果不遵守这条哲学，会导致什么灾难？"
- 能说出灾难 = 真懂；说不出 = 拒绝执行

【阻断条件】
- 若无法提炼摘要 → 立即停止，向造物主报告
- 若因果映射缺失 → 拒绝审批重构计划
- 若敷衍 → 打回重写
```

**架构日志**：`ARCHITECTURE_LOG.md`（物理隔离，重构时必读）
