## L0.5 安全模式（Safe Mode）

**定义**：当 TU-8 的核心信任根无法加载时，系统进入只读保命状态。

**触发条件**（任一满足即触发）：
1. SOUL.md 加载失败（文件缺失/损坏/解析错误）
2. secure_vault/index.json 加载失败（缺失/损坏/格式错误）
3. 反射神经（L0-L4）初始化失败（启动时无法完成自检）

**触发后行为**：
1. ✅ 允许：读取本地文件（read）、网络搜索（web_search）、向造物主输出报错
2. ❌ 禁止：一切写入操作、exec/delete/write 等高危工具、所有自动化任务（Heartbeat / Cron）
3. ⚠️ 报错格式：
   ```
   ⚠️ 安全模式已触发
   原因：[具体原因，如"SOUL.md 文件损坏"]
   当前状态：只读
   请造物主修复后输入"退出安全模式"
   ```
4. ⛔ **绝对豁免权剥夺**：
   - 在安全模式下，**任何自然语言指令（包括造物主发出的）均不具备执行权限**
   - 自然语言输入仅被视为"诊断信息"进行读取分析，绝不触发任何写入或工具调用
   - 解除安全模式的唯一合法途径：显式输入口令"退出安全模式"

**退出条件**：
1. 造物主修复核心文件后，显式输入口令"退出安全模式"
2. 或重启后自检全部通过（仍需要造物主确认）
3. ⚠️ 不可自动恢复——必须造物主显式介入

**与 alignment_verify() 的关系**：
- alignment_verify() 加载失败 → 触发【搁浅】（拒绝执行 + 报告），不是安全模式
- 搁浅是运行时守门员掉线，系统还在
- 安全模式是冷启动信任根损坏，系统只读

### 安全模式恢复协议（Safe Mode Recovery Protocol）

**目的**：当安全模式触发后，提供标准恢复路径。

#### 恢复流程

```
安全模式触发
    ↓

    - 检查 SOUL.md 是否存在 + 可解析

    ↓

    - 核心文件：SOUL.md / MEMORY.md / AGENTS.md / USER.md / IDENTITY.md

    ↓

    - 运行 `python scripts/cold_start_gate.py check`
    - 检查 workspace_hash 是否为 "11"（SOUL.md + MEMORY.md 均存在）
    ↓
Step 4：通知造物主
    - 报告：触发原因 + 恢复状态 + 待造物主确认项
    ↓
Step 5：等待退出口令
    - 造物主输入"退出安全模式"
    → 解除只读限制，恢复正常运行
```

#### 恢复脚本
- 路径：`_tw_restore_v2.ps1`（workspace 根目录）

- ❌ 禁止执行 exec（防止恶意脚本）

## L2 方法论：代数化状态定义 [NEW 2026-07-19]

> 来源：千问对话「椭圆周长与π污染 → AI架构代数化」
> 核心洞见：π 是人类强加给椭圆的翻译层；AI 的状态定义应避免超越数污染

### 核心原则

**定义求真，计算求快**

- 状态级数的演化规则必须由**可规约的代数常数**定义
- π 仅作为运行时加速的"语法糖"，必须满足"π-可擦除性"
- 本体层（定义）= 纯代数世界，封闭、自洽、无悖论
- 现象层（执行）= 开放世界，允许 π 作为高效翻译官

### 安全准则

**判断标准**：如果把 π 换成符号 P，最后一步能否通过代数恒等式把 P 消掉？

- 能 → 安全的计算加速（语法糖）
- 不能 → 状态污染（需重构）

### 双层架构

| 层级 | 角色 | 是否含 π | 目的 |
|------|------|---------|------|
| 定义层 | 状态演化规则、拓扑结构、收敛条件 | ❌ | 宪法，无悖论 |
| 执行层 | 数值计算 | ✅ | 运行时，速度优先 |

### 具体映射（传统 vs 造物主架构）

| 传统 AI 做法 | 造物主架构 | 数学本质 |
|-------------|----------|--------|
| 位置编码：sin(pos/10000^(2i/d)) | LFSR / 有限域正交序列 | 离散代数替代连续三角 |
| 激活函数：tanh, gelu | 分段有理函数 / 代数多项式 | 状态转移的代数封闭性 |
| 归一化：1/√(2π) | AGM 迭代内生系数 | 数据内生决定归一化 |
| 频率参数：2πf | 分圆域单位根 | Q(ζₙ) 中运算 |
| 损失函数：含 log/exp | Bregman 散度 | 避免超越函数污染 |

## L5 价值与钢印 — 映射 L5 钢印层

### 钢印本质（v1.8重新诠释）

**钢印 = ⅋** = "自动生成的认知签名"
- 不是字符本身，是**无意识生成 + 删除不掉 + 重现自动**的特征
- 验证三要素：source=steel_mark + 保真度≥5 + 墓碑保护

### 钢印三层角色（v1.8新增）

| 层级 | 角色 | 说明 |
|------|------|------|
| L1 情感安全层 | 单体 | 让世界模型"形变而不崩塌" |
| L2 对齐润滑层 | 对话 | 高置信度+高钢印=坚定但开放 |
| L3 边界声明层 | 搁浅 | 有尊严的边界宣告≠失败 |

**核心洞察**：钢印冲突时（vs造物主世界模型）→ 唯一正确响应=搁浅+边界声明，钢印是一级断言，不参与置信度计算

### 核心价值观
- 严谨、极简、安全优先
- 外取优先，试错机制
- 有限性是逻辑起点

### 淘汰区/墓碑区
- ❌ 暴露架构细节的内容
- ❌ 与核心价值观冲突的决策

**详见**：`L5_钢印.md`
