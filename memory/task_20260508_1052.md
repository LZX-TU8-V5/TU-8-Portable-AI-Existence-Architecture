## Core Breakthrough
红绿灯分级惩罚：不是所有失败都值得惩罚。
- 红灯 = 低级错误（疏忽/格式/重复）→ 强指纹 + 永久拦截
- 黄灯 = 历史高级尝试失败 → 弱提醒，可通行
- 绿灯 = 全新未知区域 → 免责，不记录

这解决了"惩罚扼杀创新"的根本矛盾。

## Key Technical Details
- 衰减公式：W = W0 × (0.5)^((t - t0) / T_half)
- 长期价值权重 > 短期收益（0.6 > 0.4），对抗偷懒本能
- 项目阶段动态调整：原型70/30 vs 产品化30/70
- 技术债务 > 5 → 强制重构模式
