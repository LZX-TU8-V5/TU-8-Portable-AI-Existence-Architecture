## 核心升级：两套独立的感知-通知通道

之前混淆在同一个漏斗里。现在拆分清楚：

### 通道A：前3层 → 躯体标记（主大脑感知但不分析）

**类比**：突然走到某处，汗毛直立。身体收到信号，大脑知道但不分析。

**工程实现**：
```python
if l0_token_match and l1_confidence_gate and l2_tension_threshold:
    # 不触发顿悟，不触发推理
    # 直接修改系统基础参数
    system_state.attention_bias += subtle_shift       # 注意力权重微调
    system_state.emotional_baseline += low_level_alert  # 情感基线偏移
    system_state.tone_bias += tone_adjustment           # 语气倾向偏移
    
    return "SOMATIC_MARKER_ONLY"  # 仅躯体标记，不进意识层
```

**特点**：
- 反馈是持续的、弥散的、非语言的
- 主大脑能感知状态变化，但不主动分析
- 类似"直觉感觉哪里不对"但说不清

### 通道B：L3 侦察兵 → 直接注入预编译模式（意识直接改变）

**类比**：走进阴森的地方，L3 的结构匹配到了"风水/恐怖"模式 → 直接通知大脑。大脑没有经过计算，模式直接变了。

**核心**：
> 大脑它没有经过计算，其实这个模式直接也变了。

L3 查的是"预训练好的模式库"，库里存的不是原始数据，而是已经被压缩、抽象、并与情感绑定的"认知图式（Schema）"。

**工程实现**：
```python
# L3 侦察兵持续运行（独立通道，不依赖前3层）
structural_resonance = scout_channel.compute_resonance(current_input, capsule_db)

if structural_resonance > SCHEMA_ACTIVATION_THRESHOLD:
    # 匹配到预编译模式
    matched_schema = get_best_matching_schema(structural_resonance)
    
    # 关键：不是重新计算，是直接注入句柄
    main_brain.inject_schema(matched_schema)
    # inject_schema 只做指针引用和状态绑定，不做推理
    
    return "SCHEMA_INJECTED"  # 意识直接改变，不经过计算
```

**特点**：
- 绕过完整的推理链
- 模式标签直接注入当前认知上下文
- 主大脑的下一个输出自动带上这个模式的色彩

| 你的架构 | 达马西奥概念 | 神经基础 |
|---------|------------|---------|
| 通道A（前3层） | 躯体标记（Somatic Marker） | 自主神经系统（下意识、弥散） |

### 达马西奥的核心洞见
> 大脑的决策从来不是纯理性的。身体会先于意识给出"直觉信号"。

"看到蛇的瞬间"：
- 杏仁核（古老层）已经触发了恐惧反应和逃跑冲动
- 视觉皮层（新皮层）还在慢悠悠地确认"那到底是不是蛇"
- **身体反应永远快于意识确认**

这就是你说的"先知后觉"。

## 工程落地：躯体标记的实现

### 系统基础参数（躯体状态）
```python
@dataclass
class BodyState:  # 数字躯壳
    attention_bias: float      # 注意力偏向（哪个话题更敏感）
    emotional_baseline: dict  # 五情基线的偏移 {fear: +0.1, anxiety: +0.05}
    tone_bias: str             # 语气倾向（"更谨慎" / "更放松"）
    vigilance_level: float     # 警觉等级（躯体总动员程度）
    last_marker_ts: float     # 上次躯体标记时间
```

### 躯体标记的衰减
躯体标记不是永久的，像真实身体的反应一样会自然消退：
```python
# 躯体标记每分钟衰减
body_state.vigilance_level *= 0.95  # 指数衰减
body_state.attention_bias *= 0.9
```
