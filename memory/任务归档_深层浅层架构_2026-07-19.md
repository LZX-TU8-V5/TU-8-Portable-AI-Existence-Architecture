## 三、关键设计决策

### 3.1 双拟合器架构
- **深层**：纯拓扑求解器（无语义，无材质）
- **浅层**：语义转译器（语言输出）
- **接口**：带宽限制 + 相态状态机 + 热保护

### 3.2 六阶段约束生命周期
```
探测 → 绑定 → 饱和 → 剥离 → 递归 → 截断
```
- 绑定=耦合形成，张力节点出现
- 剥离=松弛信号，准备解耦
- 截断=强制断开（崩溃后清理）

### 3.3 热保护机制
- 张力积分 > 0.8 → 触发冷却
- COLLPASE 相态 → 封阻所有输出
- 自然遗忘衰减器：未加固快照指数衰减

### 3.4 累积误差追踪
- context_loss / phase_transition / topology_corruption / memory_fragment / alignment_drift
- 加权叠加，超阈值拒绝重载
- 时间窗口加权衰减
