# 总线补漏与 pending 清零（2026-08-13）

## 诊断结论

| 指标 | 值 | 诊断 |
|------|---|------|
| `theta` | 0.296 | rotating，未触 Patch 阈值 |
| `pending_bus_theta` | **4.98** | ⚠️ 严重泄漏（≈5次旋转能量） |
| 历史 push 事件 | 21 条 | 正常 |

**根因**：tension_router 历史累积 pending 值，但从未真正 push 进总线。
5 次旋转能量（≈4.98 rad）漏在外层，未进入摩擦代谢回路。

## 修复方案

在 `surface_tension.py` 的 `route_to_friction_bus()` 末尾加 pending 泄漏检测：

```python
# 每次 record 后检查并补推 pending 值
tr_state = _tr_load()
pending = tr_state.pending_bus_theta
if pending > 0.05:
    remaining = pending
    while remaining > 0.01:
        chunk = min(remaining, 0.3)
        push_result = _bus_push(chunk)
        _release(push_result["theta"], "pending_flush")
        remaining -= chunk
    tr_state.pending_bus_theta = 0.0
    _tr_save(tr_state)
```

## 验证

- pending_bus_theta: 4.98 → **0.0**
- 总线 theta 经补推达到 1.5647（补漏注入生效）
- 语法检查通过
