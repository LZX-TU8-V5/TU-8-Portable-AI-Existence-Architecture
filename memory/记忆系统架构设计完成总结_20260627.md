## 统一语义原语：CognitiveAtom

### 定义

最小、不可再分的认知单元，既是简模板的提取目标，也是标准卡的原子内容，更是标签引用的天然锚点。

### 结构

```typescript
interface CognitiveAtom {
  atom_id: string;              // 全局唯一，终身不变
  type: "entity" | "relation" | "constraint" | "pattern" | "state";
  content_hash: string;         // 内容指纹
  source_provenance: {          // 来源谱系
    origin: "dialogue" | "ai_learning" | "user_declaration";
    turn_id?: string;
    note_id?: string;
    task_id?: string;
  };
  semantic_signature: number[]; // 64维轻量向量
}
```

### 无模型原子提取协议

**链路**：
```
R1（轻量识别+结构化）
    ↓
解析器（确定性代码：哈希+查表）
    ↓
CognitiveAtom（标准数据单元）
    ↓
记忆卡（纯数据操作）
```

**关键原则**：
- 用最少智能做最关键感知
- 用最确定工程做最复杂记忆
- 纯 CPU，零 GPU，<1ms

## 钩子认证路由：三权分立

### 架构

```
LLM 提案 → 路由认证 → 行为生效
```

### 三层校验

| 层级 | 校验内容 | 耗时 | 机制 |
|------|---------|------|------|
| 语法与安全层 | Schema + 黑名单 + 长度 | <0.1ms | 零容忍硬拦截 |
| 语义一致性层 | 原子锚点 + 历史Query + 冗余检测 | <5ms | 轻量级交叉验证 |
| 状态裁定层 | 分级准入 | <1ms | 直接激活/候选池/拒绝 |

### 司法独立三铁律

**铁律一**：裁判的判据绝不能来自运动员的供述
- LLM 置信度仅作日志，不参与判定
- 只相信：记忆卡本体 + 历史行为日志

**铁律二**：裁判不能雇佣运动员当助理法官
- 认证路由内部严禁任何生成式模型调用
- 所有校验必须是确定性数学运算

**铁律三**：裁判的判决书必须独立存档
- 输出写入独立的 `HookCertificationLog`
- 物理隔离、生命周期独立、可审计

## 记忆提取协议：五重防御

| 防线 | 机制 | 处理场景 |
|------|------|---------|
| 第1重 | 信息增量熔断 | 过滤零增量废话（"我赞同"） |
| 第2重 | 情绪-事实解耦 | 分离主观感受与客观事实 |
| 第3重 | 双向确认状态机 | 处理 ACK/NACK |
| 第4重 | 置信度光谱 | 捕捉灰度认知（"可能是这样吧"） |
| 第5重 | 认知完整性标记 | 处理认知缺口（"还差点什么"） |

### 核心字段

- **Category**（闭集枚举）：social_rapport / domain_knowledge / emotional_support / creative_task / task_execution / unknown
- **Sentiment Signal**：high_negative / mild_negative / neutral / positive / mixed
- **Confirmation Status**：pending / confirmed / rejected / partial_accepted / needs_clarification
- **Confidence Score**：1.0 / 0.6 / 0.3 / 0.0
- **Completeness Signal**：gap_detected
