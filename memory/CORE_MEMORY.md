## 技术宪法（最终版 v6.0）

**十六字宪法**：
> 底层同源，上层异构；各自为政，交叉为证。

1. **参数准确性**：来自物理感受，而非人类反编译
2. **计算机母语**：数学公式 + 0/1，而非自然语言
3. **LLM 边界**：翻译官 + 证伪器 + 审问员，而非认知主体
4. **核心安全原则**：LLM 找相同，物理锚点保正确
5. **认知坐标系**：纵轴（1+1=2）= 确定性 = 本地算法独占；横轴（男人+女人）= 模糊性 = LLM 主导；原点 = 锚点+审问 = 安全协作
6. **三层剥离宪法**：物理层 / 数字层 / 语义层正交，各层独立存储、独立输出
7. **状态机绑定协议**：LLM 是处理器，状态机是内存与时钟
8. **验证标准**：公式残差 < 阈值，而非"人眼觉得对"
9. **五条铁律（防 LLM 化）**：
   - 禁止模糊匹配 / 向量检索 / 语义相似度
   - 全量知识库禁止作为状态机上下文
   - 转移条件必须是布尔表达式，不依赖 LLM 输出
