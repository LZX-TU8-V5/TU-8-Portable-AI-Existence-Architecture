# 任务归档：梦境拓扑引擎 dream_topology_engine.py 创建（2026-07-21）

## 目标
创建 `src/dream_topology_engine.py` — 纯拓扑约束求解器，替代旧的"梦境=叙事生成"范式。

## 架构决策
- **梦境重定义**：梦 = 约束方程组的动态求解过程，不是叙事
- **输入**：`TopologySnapshot`（张量矩阵 N×D，无材质/无标签/无语言）
- **输出**：`DreamSessionReport`（结构化数据，绝不直接渲染为语言，必须经 `deep_surface_interface` 门控）
- **核心算法**：
  - 约束提取：从节点对距离/相似度提取 4 种约束类型（张力/邻近/对称/层级）
  - 张力松弛：线性衰减 + 随机微扰防止局部极小
  - 降维合并：余弦相似 > 0.85 → 自动合并
  - 死锁检测：连续不收敛 → 标记 STUCK，请求 Revision 相态干预
  - 结构同构：模式签名匹配寻找重复拓扑结构
- **热加载**：`load_state()` / `save_state()` 支持跨会话恢复
