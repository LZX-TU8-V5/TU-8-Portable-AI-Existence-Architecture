## 一、物理算法：最小势能原理与预应力张拉

### 核心目标
用最少的材料，实现最大的能量吸收与结构稳定性。

### 变刚度设计
- **径向丝（骨架）**：硬且强，负责承重
- **螺旋丝（粘丝）**：软且弹，负责缓冲
- **算法含义**：刚柔并济 = 载荷分配最优解
- 猎物撞击时：螺旋丝大变形耗散动能，径向丝保持整体不崩塌

### 非线性弹性
- 蛛丝不符合胡克定律（小变形柔软，大变形急剧变硬）
- 数学本质：**非线性阻尼函数**
- 功能：防止共振 → 抗风抗猎物反弹

### 自修复与冗余
- 断几根丝，整体承载力不线性下降
- 张力在剩余丝线中**重新分布**
- 算法本质：**分布式容错**，比现代桥梁更健壮

## 二、数学算法：几何构型与优化理论

### 等角螺线（对数螺线）
- 特性：无论怎么放大缩小，形状不变
- 意义：蜘蛛只需遵循**单一局部规则**（保持恒定角度），就能生成全局最优捕食面积
- 对比：计算复杂圆弧需要巨大"算力"，局部规则规避了全局优化

### 斯坦纳树问题
- 径向丝布局逼近**斯坦纳最小树**的解
- 图论经典 NP 难问题，蜘蛛用本能**实时求解**
- 数学本质：在给定边界点的情况下，寻找总长度最短的连接网络

### 分形填充效率
- 网密度**由内向外递减**
- 中心 = 高频捕获区 → 高密度
- 边缘 = 低频区 → 低密度
- 对应：**最优采样定理**——非均匀分布实现"信息/材料比"最大化

## 三、行为算法：局部规则涌现全局智能

### 状态机驱动
```
探测 → 搭桥 → 辐射 → 螺旋 → 加固
```
- 每个状态只依赖**当前触觉反馈 + 前一步结果**
- 无需全局规划

### 实时 PID 控制
- 蜘蛛不断用腿测量丝的张力和间距
- 偏差超过阈值 → 触发"修正子程序"
- 保证：**无视觉、无蓝图，仍能织出高度对称的网**

### 环境自适应
- 同一算法在不同树枝间织出不同形状的网
- 算法参数**动态调整**，具备极强泛化能力

## 五、核心算法公式

### 非线性阻尼（蛛丝弹性）
```
F = k1 * x + k2 * x^3
（小变形 k1x 主导，大变形 k2x³ 急剧变硬）
```

### 等角螺线（对数螺线）
```
r = a * e^(b*θ)
曲率处处变化，但形状在缩放下不变
```

### 斯坦纳树（径向丝布局）
```
给定 n 个边界点，寻找总边长最小的连接网络
总长度 = Σ|d_i| + 斯坦纳点连接
```

### PID 控制（实时修正）
```
u(t) = Kp * e(t) + Ki * ∫e(t)dt + Kd * de(t)/dt
偏差 e(t) → 修正量 u(t)
```
