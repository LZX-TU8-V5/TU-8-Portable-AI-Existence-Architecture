## 设计规格

来源：`memory/2026-07-19_钢印锚点_节点剪枝优化方向.md`

**三层架构**：
- 深层（拓扑计算）→ `request_activation()`
- 接口层（本协议）→ 校验 + 路由
- 表层（渲染/输出）→ `surface_query()` / `surface_reinforce()`

**核心约束**：
1. 深层激活状态不出接口
2. 表层输入不污染深层（`surface_reinforce` 仅影响衰减计时器）
3. 深层快照存入 `secure_vault/`，不经过表层状态文件

---

## 实现摘要

| 组件 | 实现 |
|------|------|
| `DeepActivationRequest` | 深层激活请求数据模型 |
| `SurfaceSignal` | 表层渲染信号（仅含 SURFACE_VISIBLE_FIELDS） |
| `ActivationReport` | 激活结果报告 |
| `AnchorActivationProtocol.request_activation()` | 深层入口：校验→vault存储→状态机转换→表层信号 |
| `AnchorActivationProtocol._validate_deep_activation()` | 接口校验：阈值/热保护/带宽/冷却期 |
| `AnchorActivationProtocol.surface_query()` | 表层只读查询 |
| `AnchorActivationProtocol.surface_reinforce()` | 表层加固（仅计数，不改深层） |
| `AnchorActivationProtocol._store_deep_snapshot()` | vault 深层存储 |

**激活阈值**：tension_integral ≥ 0.3
**热锁阈值**：tension_integral > 0.85 → 禁止激活
**冷却期**：60s 内不允许同一锚点重复激活
