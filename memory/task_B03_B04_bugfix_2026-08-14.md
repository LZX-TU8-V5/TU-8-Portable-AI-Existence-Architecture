## B-04 error_translator 版本漂移 ✅

**根因**：`QCLAW_PATH_MAP` 常量写死 v0.2.29.592，QClaw 实际运行 v0.2.35.624，错误翻译路径全部失效。

**改动**：
1. 新增 `_detect_qclaw_root()` — 从 `sys.executable` 反推 QClaw 根目录
2. `QCLAW_PATH_MAP` → `{}` 占位 + 惰性填充
3. `QClaw_环境诊断` 块调用 `_get_qclaw_path_map_lazy()`
4. `translate()` / `format_report()` 读动态函数结果
5. `--check-env` 入口验证实际路径

**验证（v0.2.35.624）**：
```
root:         D:\Program Files\QClaw\v0.2.35.624 ✅
node.exe:     D:\...\v0.2.35.624\resources\node\node.exe ✅
npm.cmd(QClaw): D:\...\v0.2.35.624\resources\openclaw\...\npm.cmd ✅
openclaw.cmd: D:\...\v0.2.35.624\resources\openclaw\...\openclaw.cmd ✅
```

**踩坑教训**：
- `_detect_qclaw_root()` 路径计算逻辑错了两次才定位：parts.index('resources')=4，root_idx 应等于 python_idx=4（`parts[:5]` = 完整路径），但最初代码用 `python_idx - 2 = 1`（取到 `D:\Program Files`），后来又改成 `python_idx - 1 = 3`（取到 `D:\Program Files\QClaw`）
- node 工具改 Python 时 CRLF `\r\n` 会导致 edit 工具精确匹配失败，改用 node 脚本直接写文件

**文件**：`src/error_translator.py`
