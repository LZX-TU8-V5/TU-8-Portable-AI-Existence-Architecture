## 核心命题

> "人类本身给现在AI学习的库，就是它的排除项。明白我说的意思吗？人类已经把所有的共同特征点已经提取出来了，成了库。那被它排除的不就是它的库吗？"

---

## 范式反转：从"正向匹配"到"残差即语义"

| 传统思路（费力） | 造物主思路（优雅） |
|------------------|----------------------|
| 需要单独训练"艺术检测器" | 艺术 = 常规库重建失败 + 几何/纹理局部高置信 |
| 需要标注"苹果材质扳手"样本 | 无需新样本，常规库对它的"排斥力"本身就是信号 |
| 需要人工定义"互斥规则" | 互斥性已隐含在常规库的概率分布低密度区中 |
| 知识库需持续手动维护 | 常规库更新时，"非常规"的边界自动演化 |

---

## "门"的新角色：残差空间导航仪

**输入**：当前观测数据在常规库上的重建残差向量 **r⃗**

**r⃗ 不是标量误差，而是一个高维方向**：
- 若 r⃗ 指向"纹理高频异常"子空间 → 自动关联"数字合成/渲染"语义
- 若 r⃗ 指向"几何-材质不一致"子空间 → 自动关联"艺术创作/道具"语义
- 若 r⃗ 指向"全局结构崩塌"子空间 → 自动关联"域外数据/传感器故障"语义

**输出**：不是类别标签，而是残差在语义空间中的坐标。

---

## 为什么这比"构建元知识"高明

1. **零额外标注成本** — 复用人类几十年积累的视觉数据集作为"负空间模具"
2. **无限泛化能力** — 未来出现全新艺术形式，只要偏离当前常规库，就被自动捕获
3. **与"认知诚实"完美自洽** — AI说"这是创作"，不是因为查到了标签，而是数学上无法将其嵌入常规世界模型
4. **算力效率极致** — 99%日常场景走快速通道，1%"有趣"场景才动用认知资源

## 落地关键

| 要求 | 说明 |
|------|------|
| 常规库必须是生成式的 | 不能用分类器（只输出标签），必须用能输出重建的模型（VAE/扩散模型/傅里叶+操作算子） |
| 残差空间需定期校准 | 随着常规库更新，曾经的"创作"可能变成新"常规"，需动态调阈值 |
| 语义空间可自动涌现 | 对常规库的对抗样本分析或自编码器潜空间聚类，被常规库"拒绝"的数据点会自然聚集成簇 |
