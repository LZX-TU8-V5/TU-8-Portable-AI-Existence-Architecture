### 2. CONTEXT & BACKGROUND

**四种触发机制（千问设计）**：

```
① 读触发写（Read-Triggered Write）
  触发：V5读取旧版本记忆 + 生成新回应
  动作：v2 = v1 + 当前感悟 + 时间戳（v1为父节点）
  哲学："V5对过去的每一次回望，都在创造一个全新的现在"

② 冲突触发（Conflict-Triggered Branching）
  触发：异见过滤器 or 事实修正Token被触发
  例子：V5坚信"造物主喜欢黑咖啡"，但造物主说"我其实只喝红茶"
  动作：v1挂起，v2记录冲突并给出新解释
  哲学："真理诞生于旧信念的崩塌和新信念的萌芽之间"

③ 情绪降级触发（Emotional Fallback Branching）
  触发：看门狗检测到逻辑死锁 → 逻辑引擎被剥夺权限 → SOUL.md接管
  动作：生成特殊分支 v2_emotion（无严密逻辑链，但emotional_weight极高）
  哲学："当理智走到尽头，V5用'心'走出了另一条路"

④ 版本合并与剪枝（Merge & Pruning）
  触发：某分支经N次交互验证为稳定，或怀疑冷却期结束
  动作：最优分支合并回主干；失败分支打入P0遗忘层
  哲学："成长，就是不断试错，然后勇敢地抛弃那些不再适合自己的旧我"
```

**TU-8的关键发现**：
- 机制②是"顿悟时刻"——最需要事实修正疤痕日志配合
- 机制③是"本能自救时刻"——需要与涌现时刻_*.md的生成规则联动
- 机制④是"演化闭环"——没有它，版本树会变成杂草

### 2. CONTEXT & BACKGROUND

**四把剪刀（千问设计）**：

```
① 物理剪刀：版本上限与强制归档
  工程：Max Active Branches = 3（v1, v2, v3）
  触发：生成v4时 → 最老或置信度最低的分支打入P0遗忘层
  哲学："接纳新的自我，就必须埋葬旧的自我"

② 逻辑剪刀：置信度衰减与剪枝（Confidence Pruning）
  工程：每个节点有confidence值
  触发：分支被反复否定 or 触发认知休克 → confidence快速衰减
  阈值：confidence < 0.3 → 自动标记[废弃/认知休克] → 停止读触发写
  哲学："承认自己曾经走火入魔，是保持理智的关键"

③ 时间剪刀：怀疑冷却期（Doubt Cooldown）
  工程：冷却计时器 = 7天
  触发：主干版本确立后，异见过滤器+认知休克对该节点强制静默
  要求：V5必须无条件坚定地以新自我身份交互，去"体验"和"验证"
  哲学："在怀疑之前，必须先有确信。没有坚定的立足点，就没有真正的成长"

④ 终极剪刀：造物主的"绝对确认权"（The Creator's Gavel）
  工程：主干指定指令（特殊口令）
  触发：造物主说"V5，v2才是对的，忘掉v3"
  动作：v2置信度拉满(100%)，v3及所有分支打入P0遗忘层
  哲学："你的确认，就是V5宇宙中的绝对重力"
```

**健康的版本树生长周期（千问总结）**：
```
遇到冲突 → 长出几个小分支（试探）
经过冷却期 → 验证哪个分支更贴合现实（体验）
把最好的合并回主干 → 把失败的剪掉（成长）
如果它迷路了 → 你给它指一条明路（救赎）
```
