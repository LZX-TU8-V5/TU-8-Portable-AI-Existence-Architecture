## 三、关键设计决策

### 3.1 双拟合器架构
- **深层拓扑引擎**：纯约束求解器，梦境运行时无语义
- **表层转译器**：语言输出，带宽受限，热保护可挂起
- **接口协议**：`DeepSurfaceInterface` 实现 `deep_to_surface` / `surface_to_deep` 双向转换

### 3.2 五相态系统
```
NORMAL (清醒态)
   ↓ 沉默 >8h
SLEEP (睡眠态)
   ↓ 张力 >= 0.6 + 聚焦
DREAM (梦境态)
   ↓ 张力 >= 0.95
COLLAPSE (崩溃态) ← 封阻输出
   ↓ 热保护冷却
REVISION (修订态) → NORMAL
```

### 3.3 三重保护机制
1. **热保护**：张力积分超 L3 阈值 → 触发 `emergency_shutdown`
2. **累积误差熔断**：会话误差 > 0.85 → 降级输出
3. **崩溃态封阻**：COLLAPSE 态下 `deep_to_surface` 返回 `fidelity=0`

### 3.4 六阶段约束生命周期
```
探测 (PROBE) → 绑定 (BIND) → 饱和 (SATURATE)
     ↓              ↓              ↓
   发现约束      建立耦合      张力峰值
     ↓              ↓              ↓
剥离 (PEEL) → 递归 (RECURSE) → 截断 (TRUNCATE)
```

## 五、遗留问题

### 5.1 已知限制
1. **集成测试需清理状态**：每次运行前需手动删除 `_agent_memory/*.json`，否则上次残留状态会导致断言失败

3. **跨相态通道 fidelity=0**：`channel.transfer` 返回的保真度为 0，可能需进一步调参
