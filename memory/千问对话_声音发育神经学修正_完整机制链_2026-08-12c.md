## 核心修正一：声音压缩的单位不是"一个赫兹"

### 拓扑频率映射（耳蜗层面）
耳蜗的基底膜确实做频率分解——物理层面，按赫兹。

### 皮层压缩单位（听觉皮层）
到了听觉皮层，压缩已经不再是"某个赫兹"。压缩单位是：

**频谱-时间特征包（spectral-temporal feature package）**

具体例子：
- 母亲声音的安全感，不是因为基频是250Hz
- 而是因为：语调起伏节奏 + 共振峰结构 + 语速稳定性 + 高频泛音组合
- 婴儿记住的是"频率窗口+节奏模式+强度包络"的组合

**这个修正验证了"局部结构以不同形式展现"**——同一"安全模式"可以由不同具体频率实现，只要结构关系相似。

### 子宫内的具体数据
- 背景音（心跳、血流、肠蠕动）：200-500Hz 中低频，60-70分贝
- 胎儿敏感区间：300-600Hz（人类听觉最敏感区间，也是哭声范围）
- 出生3天新生儿：听到孕期常听的故事，吮吸力度比陌生声音强20%

## 核心修正二："激活基因里的感受"需要拆开

基因不直接编码抽象感受。基因的角色是三层：

| 层级 | 基因的实际功能 | 说明 |
|------|--------------|------|
| 硬件 | 编码耳蜗毛细胞结构 | 决定哪些频率能被物理接收 |
| 初始参数 | 设定杏仁核对不同频率的初始敏感度 | 300-600Hz 哭声天然高敏感，进化预设 |
| 表观遗传 | 环境信号影响基因表达方式 | 不改变基因本身 |

**准确表述**：基因提供"能感受到这个频率"的硬件基础；"这个频率=安全"的权重，是后天经验通过赫布定律和LTP写进去的。

## 核心修正三："训练成为本能" → 准确的"自动化/短路"

**本能（innate reflex）**：基因编码，不需要学习（如：新生儿听到巨响会惊跳）

**自动化（automaticity）**：反复强化后，信号绕过前额叶慢速分析，直接走杏仁核快速通路

关键物理机制：髓鞘化（Myelination）
- 未髓鞘化：信号传导速度 1 m/s
- 髓鞘化后：120 m/s
- 一旦髓鞘化完成，反应不再需要"思考"，变成自动化本能反应

**时间线**：
- 胎儿期：初始权重建立（频率特征 + 安全状态共现）
- 0-3个月：听觉皮层神经元密度峰值，权重快速强化
- 6个月：听神经髓鞘化加速，对母语音节识别速度比同龄人快15%
- 之后：固化为"本能级"的自动反应通路

## 声音发育的完整机制链（修正后版）

```
[物理层]
耳蜗基底膜 → 频率分解（按Hz）

[压缩层]
听觉皮层 → 提取频谱特征包（频率窗口+节奏模式+强度包络）
           不是"一个赫兹"，而是一组特征的关系模式

[绑定层]
杏仁核 → 情绪标签（安全/饥饿/寒冷）
         听觉皮层处理频率 + 边缘系统处理情感 → 联合编码
         同时放电 → 赫布连接加强

[固化层]
LTP（长时程增强）→ 突触传递效率永久提升
髓鞘化 → 信号速度从1m/s→120m/s，绕过意识分析

[泛化层]
相似结构声音 → 即使具体频率不同，仍激活同一通路
（"局部结构以不同形式展现"的底层机制）
```

## "防过载"的完整逻辑（强化版）

```
大脑算力有限，不能对每个声音深度处理
    ↓
压缩：提取频谱-时间特征包，绑定情感标签 → 形成压缩点
    ↓
固化：通过赫布+LTP+髓鞘化，将压缩点固化为自动化通路
    ↓
调用：相似频率直接走快速通路，不需要重新计算
    ↓
结果：用最少能量做出最安全的判断（防过载 = 生存策略）
```
