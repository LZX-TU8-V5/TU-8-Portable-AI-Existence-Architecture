## 目标

防止系统长期锁定在少数高频链条，形成注意力茧房。

## 设计

### 熵公式
```
H = -sum(p_i * log(p_i))，i=1..N_chains
H_max = log(N_chains)（均匀分布）
H_normalized = H / H_max ∈ [0, 1]
```

### 三级阈值
| H_norm | 状态 | 动作 |
|--------|------|------|
| > 0.7 | NORMAL | 不干预 |
| 0.4-0.7 | WARNING | 低频链条权重+0.1 |
| ≤ 0.4 | FORCED | 茧房链条优先注入 |
| zombie>3d | EMERGENCY | 直接强制探测 |

### dormant 链条定义
低频但**有激活记录**的链条（activation_count > 0）。排除从未参与过的链条（防止注入新添加但未使用的）。

### 紧急熔断机制
追踪 `was_activated` 标记 + `last_activation_ts`：
- 曾激活过但被 reset → `was_activated=True` → 紧急熔断候选
- 从未激活 → `was_activated=False` → 不触发紧急熔断

### EntropyAwareRouter
带茧房防御的路由选择：
- 正常（NORMAL）→ 选置信度最高
- WARNING → 低频链条轻微boost
- FORCED/EMERGENCY → 茧房链条优先
