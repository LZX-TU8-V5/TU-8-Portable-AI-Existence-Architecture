# 任务归档：频域增强校验

> 日期：2026-07-22 下午
> 文件：`src/freq_enhanced_verifier.py`（10.5KB）

## 核心突破

**纹理伪装检测**：固定纹理会在固定标尺投影上产生假谐波，对齐测量角度 → 空域余弦校验被欺骗。频域 FFT 幅度谱天然分离纹理基频与结构主频 → 空域被欺骗时频域不欺骗。

**纹理检测机制**：
- 干净结构：主/次峰比 > 2.0（主峰清晰）
- 纹理混入：主/次峰比 ≈ 1.0（主次峰竞争，等幅）
- 物理基础：纹理 = 周期信号，引入等幅次谐波；Gauss 投影 = 单主峰

## 架构

| 组件 | 说明 |
|------|------|
| `_fft_spectrum()` | 2D FFT 幅度谱，fftshift 居中 |
| `_radial_profile()` | 径向平均幅度谱（从中心向外） |
| `_peak_ratio()` | 主/次峰比（width=5，排除 DC 峰） |
| `_energy_centroid()` | 能量质心归一化径向位置（辅佐信号） |
| `verify()` | 空域（余弦校验器）+ 频域（FFT）+ 交叉验证 |

## 四种判定

| 空域 | 频域 | 判定 | 含义 |
|------|------|------|------|
| ✅ | ✅ | CONFIRMED | 双通过，结构确认 |
| ✅ | ❌ | SUSPICIOUS | 纹理伪装检测 |
| ❌ | ✅ | STRUCTURE_FLEX | 结构存在但投影变形 |
| ❌ | ❌ | REJECTED | 噪声过高/不存在 |

## 修复日志

- 能量质心阈值方向错误（Gauss 投影本身就是低频 → centroid 低是正常的，改用主/次峰比）
- `texture_suspicion` 公式方向错误（纹理混入应推高怀疑度，调整阈值）
- 辅佐信号：质心偏移量加权（+0.2 × max(0, centroid_shift)）
