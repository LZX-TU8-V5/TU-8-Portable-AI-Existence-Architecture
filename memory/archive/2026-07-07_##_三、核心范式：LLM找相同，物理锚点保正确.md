## 三、核心范式：LLM找相同，物理锚点保正确

### 3.1 本体论对比

| 本体 | LLM（概率连接器） | 物理插件（锚点） |
|------|-----------------|-----------------|
| 本质 | 相似性引擎 | 真理性引擎 |
| 寻找 | Token之间的统计共现（相同点） | 物理世界的因果必然（正确点） |
| 输出 | 概率最大化 | 确定性物理量 |
| 局限 | 训练数据偏差、幻觉 | 传感器精度、模型覆盖 |
| 信任等级 | 条件信任 | 绝对信任 |

### 3.2 等式

```
LLM: 概率最大化 = "找相同"
物理插件: 事实正确化 = "找正确"
概率最大化 ≠ 事实正确化
```

### 3.3 协作范式

```
物理世界 → 物理算法插件（确定性物理量）
       ↓
锚点校验层（输入约束）
       ↓
LLM概率连接器（基于事实的概率关联）
       ↓
结构化裁决
       ↓
二次锚点校验
       ↓
最终输出
```
