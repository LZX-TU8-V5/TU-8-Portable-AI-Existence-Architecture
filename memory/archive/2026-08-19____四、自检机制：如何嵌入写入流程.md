## 四、自检机制：如何嵌入写入流程

千问建议：
> 不要仅用L0做后处理，应作为损失函数嵌入网络。

**TU-8 应用**：

当前流程：
```
对话发生 → 记忆写入 → [无验证] → 存储
```

改进流程：
```
对话发生 → 提取候选记忆 → L0梯度验证 → 通过则写入 / 不通过则标记冲突
```

**L0梯度在认知领域的定义**：
- 梯度 = 新信息与已有知识的差异
- L0 = 显著差异的数量
- 平滑 = 新知识与已有知识一致
- 边缘 = 新知识与已有知识冲突

**验证指标**：
- GSR（梯度稀疏比）过低 → 新信息全是噪声，忽略
- GSR 过高 → 新信息全是冲突，需人工确认
- GSR 适中 → 有价值的知识更新，写入
