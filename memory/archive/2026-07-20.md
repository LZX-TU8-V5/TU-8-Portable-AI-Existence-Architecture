**闭环机制**：

- 动态分配：简单物体跳过慢通路；高需求才完整启动

**认知映射**：背侧流（快/动作）vs 腹侧流（慢/识别）= System 1 vs System 2

### 中轴切片-正方形铺砌升维法（千问对话③）

详见 `千问对话_中轴切片正方形铺砌升维法_慢通路底层几何_2026-07-20.md`

**慢通路底层几何原理**：
```
2D物体轮廓 → 中轴变换 → 连续骨架线
    ↓ 切片生成
骨架切片族 → 正方形参数域（U=骨架长度，V=切片宽度）
    ↓ 2D FFT
频域编码（频率=曲率，相位=法向）
    ↑ 锚点边界条件
能量最小化曲面提升 → 精确3D物体
```

**三个数学本质**：
- 中轴变换 = 降维（2D→1D骨架+半径函数）
- 正方形铺砌 = 规则化（不规则形状→规则网格）
- 能量最小化 = 插值（锚点约束下光滑重建）

**快→慢锚点**：快通路锚点 = PDE边界条件；快通路方向 = 初始提升方向
