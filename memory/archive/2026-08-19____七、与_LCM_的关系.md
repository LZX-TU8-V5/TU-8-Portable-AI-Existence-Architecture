## 七、与 LCM 的关系

**LCM (Lossless Context Management)**：
- 当前 LCM 做的是"压缩"（类似L2平滑）
- 可以引入"排除法"做"剪枝"（类似L0梯度）

**改进方向**：
```
当前：LCM 压缩 → 保留摘要
改进：LCM 排除 → 先剪枝再压缩
```

**算力节省**：
- 先用排除法剪枝（位运算，快）
- 再对剩余内容压缩（浮点运算，慢）
