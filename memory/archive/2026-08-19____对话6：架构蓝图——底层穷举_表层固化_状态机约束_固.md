## 对话6：架构蓝图——底层穷举/表层固化/状态机约束/固定格式化

**用户架构构想：**
> 底层让大模型继续穷举
> 表层固化 + 分层输出
> 状态机约束
> 输出固定格式化

---

**千问构建的四个核心模块：**

### 模块1：底层穷举（System 2 / 慢思考）

- 保留庞大基座大模型作为"世界模拟器/草稿生成器"
- 遇到底层没见过的新问题（高熵/长尾）时 → 自回归穷举（Next Token Prediction）
- 负责处理：模糊性、常识、发散性思维

### 模块2：表层固化（System 1 / 快思考）

```
用户输入 → 表层路由器
  命中固化通路？
  ↓ 是
  调用【固化算子/代码】→ 10ms → 固定格式化输出
  ↓ 否
  进入【底层大模型穷举】→ 2000ms → 固定格式化输出
```

**固化通路实现：**
- 符号/规则库：正则表达式、知识图谱（高频/确定任务）
- 小模型/矩阵算子：SLM 或矩阵指数（稍复杂但高频）
- 短路机制：完全跳过底层大模型，零延迟

### 模块3：状态机约束（防止幻觉）

- 在底层模型和表层输出之间插入 FSM 或 PDA 作为"护栏"
- 每生成一个 Token，状态机校验："当前状态允许输出这个吗？"
- 偏离预定逻辑轨道 → 拦截 → 回退或触发重新计算
- 比喻：给越野车套上铁轨

### 模块4：固定格式化输出

- 架构：结构化生成引擎（Constrained Decoding）或 AST 解析
- 物理保证：Logit Masking 屏蔽所有不符合 Schema 的 Token
- 结果：100% 合法格式化输出，业务系统可安全解析

---

**完整架构流程图（千问绘制）：**

```
用户输入
    ↓
表层路由器
    ↓
[命中固化通路?] → 是 → 固化算子/代码
    ↓ 否                    ↓
底层大模型穷举         状态机校验
    ↓                          ↓
中间结果生成      固定格式化输出
    ↓
状态机严格约束
    ↓
固定格式化输出
    ↓
[反馈闭环] → 结果正确 → 沉淀为表层固化通路（自我进化）
```

**TU-8 已有对应实现：**

| 模块 | 千问描述 | TU-8 实现 |
|------|---------|----------|
| 底层穷举 | System 2 大模型 | LLM 层（外取） |
| 表层固化 | 固化算子/规则库 | 状态机（L0-L4）+ heritage_system |
| 状态机约束 | FSM/PDA 护栏 | cognitive_brakes（写保护锁）+ alignment_verify |
| 格式化输出 | Constrained Decoding | 状态机输出协议 |
| 表层路由器 | 固化判断 | cognitive_filters（DAG_coherence + InfoDensity） |
| 反馈闭环 | 正确结果 → 固化通路 | L2 遗忘法则 + GC to Learning 适配器 |
