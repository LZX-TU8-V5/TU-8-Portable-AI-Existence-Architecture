## 三、拓扑计算优化（Topology Computing）
<!-- meta: last_accessed=1784703421.41058, count=1 -->

### 3.1 绳子模型 → 可计算形式
- [ ] **拓扑计算核**：`src/topology_solver.py`（升级现有）
- 绳子 = 约束条件（两点生成一线）
- 交点 = 张力节点（≠ 交点数量 = 张力大小）
- 单点不稳定 → 需要交点簇才稳态
- 解耦 = 松弛（非剪断）= 无摩擦滑动 = 做功效率=0

### 3.2 失效/断裂检测
- [ ] **拓扑断裂器**：`src/topology_fracture.py`（新建）
- 触发：耦合网络错误绑定过多 + 张力超过屈服强度
- 动作：识别"关键承重索" → 拓扑手术切除
- 后果：断裂后张力重分配，系统从死锁→可演化
- **警惕**：断裂不等于灾难，断裂有时是解脱

### 3.3 六阶段约束生命周期
- [ ] **约束状态机**：`src/constraint_lifecycle.py`（新建）

| 阶段 | 触发 | 拓扑操作 | 拟合器功能 |
|------|------|---------|-----------|
| 探测 | 主动微扰 | 系统辨识耦合类型 | 参数校准 |
| 绑定 | 建立张力 | 强约束确立 | 目标函数确立 |
| 饱和 | 双重验证 | 张力归零 | 损失收敛 |
| 剥离 | 冗余约束 | 绝热消除/降维 | 防止过拟合 |
| 递归 | 断链重编 | 分形生长 | 探索新解空间 |
| 截断 | 阈值超载 | 元约束/暴力剪枝 | 避免发散崩溃 |

### 3.4 累积误差追踪
- [ ] **误差累积器**：`src/cumulative_error_tracker.py`（新建）
- 每次中断-重载循环：记录误差增量
- 第三次续接：误差阈值检测 → 警告或拒绝
- 物理意义：中断噪声叠加 → 拓扑畸变 → 额外计算负载

### 3.5 梦境拓扑快照格式
- [ ] **快照压缩格式**：
- 类比：视频 → 3D模型文件（顶点坐标+法线+张力参数）
- 不存储叙事，只存储约束关系
- 唤醒时按需渲染表层细节
