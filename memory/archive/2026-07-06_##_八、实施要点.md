## 八、实施要点

### 8.1 标签层级化

**上下文状态标签树**：
```
L1: {任务相关, 任务无关} ← 互斥
    ├── L2(任务相关): {高优先, 中优先, 低优先}
    └── L2(任务无关): {闲聊, 噪声, 广告}
```

### 8.2 阈值标定

**方法**：
- 用历史对话数据统计各维度的分布
- 取 μ-3σ 作为排除边界

### 8.3 日志记录

**记录排除路径**：
```
[L1: 相关性✅] → [L2: 时效性✅] → [L3: 冗余性❌] → 终止
```

**用途**：后续优化排除顺序和阈值

### 8.4 兜底机制

**当所有路径都被排除**：
- 标记"未知/新类别"
- 保存原始数据
- 作为未来扩展的种子样本
