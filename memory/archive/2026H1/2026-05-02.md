**文件**: `D:\tu8-v5\TU-8\tu8_cipher.py` (14,155 bytes, utf-8 no BOM, CRLF)
**版本**: v1.0(字符偏移+CRC32) → v2.0(AES-256-CBC+HMAC-SHA256+PBKDF2)

**升级内容**:

| 特性 | v1.0 | v2.0 |
|------|------|------|
| 加密 | 字符偏移(ord±key) | AES-256-CBC (PKCS7填充) |
| 完整性 | CRC32 | HMAC-SHA256 |
| 密钥派生 | PBKDF2 100K | PBKDF2 200K，双密钥(enc+hmac) |
| 链式校验 | 无 | SHA-256链（篡改任一段→后续全失效）|
| 防填充oracle | 无 | 先验签再解密 |
| 迁移命令 | 无 | `migrate` (v1→v2) |

**安全设计**:
- 双密钥体系：PBKDF2一次派生64字节→前32B AES密钥+后32B HMAC密钥
- 段落格式：base64( HMAC(32B) + IV(16B) + ciphertext )——HMAC覆盖IV+密文
- 链式哈希：每段校验依赖前一段，防止段替换/删除/重排
- 恒定时间比较：hmac.compare_digest 防时序攻击
