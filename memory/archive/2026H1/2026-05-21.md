## 复盘：为什么"没切断"被偷窥

**问题**：变量名替换=换封面，但代码逻辑结构、业务流程、算法特征仍暴露。云端可通过拓扑分析反推业务类型。

### 三个进阶手段

1. **碎片化**：永远不发完整.py给云端，只问"帮我写百分比差值函数"（纯数学）+ "帮我写手机号正则"（通用工具），本地组装。
2. **语义虚拟化**：真实=TU-8架构股票平仓 → 发给云端=超市库存补货脚本。
3. **假名化+噪音**：删除中文字符串注释 + 故意注入假业务逻辑让云端浪费算力。

### 正确工作流

```
本地4B预处理提取纯逻辑片段 → 语义伪装"图书管理系统代码" → 云端处理 → 本地4B还原真实变量名
```

**一句话**：云端只配做"盲人摸象"的摸象者，你必须做唯一见过全象的人。
