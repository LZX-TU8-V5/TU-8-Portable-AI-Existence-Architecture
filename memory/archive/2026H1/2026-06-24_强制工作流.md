# 强制工作流 + 节点熔断机制 实现记录
日期: 2026-06-24
类型: 功能实现 + 单元测试

## 目标
按外协五段设计实现强制工作流引擎，确保 src/ 目录所有写入必须走完完整流程。

## 外协五段设计（来自对话摘要）
1. L0: SOUL.md 极简锚点
2. L1: Gateway 注入阻断
3. L2: 单向状态齿轮（禁止跳步）
4. L3: 每 3 节点熔断汇报
5. L4: "审核完毕继续任务" 解锁口令

## 产出文件

### 1. src/forced_workflow.py（~16KB, v1.1）
核心类: `WorkflowStateMachine`

**状态流转图:**
```
IDLE → BACKUP → SANDBOX → TESTING → AWAITING_APPROVAL
                                                      ↓
                                          APPROVED (口令验证)
                                                ↓
                                           ACTIVE → IDLE
                        ↑                          
         ← 失败回滚 ← TESTING (测试失败)
         ← FAILED_ROLLBACK ← AWAITING_APPROVAL (审批失败)
```

**关键方法:**
- `request_start()`: IDLE → BACKUP
- `step_backup()`: 备份到 backups/ + 生成物理锚点记忆卡
- `step_sandbox()`: 写入沙箱 sandbox/
- `step_test()`: 测试通过 → AWAITING_APPROVAL；失败 → 退回 SANDBOX
- `step_approve(unlock_phrase)`: 口令正确 → APPROVED；错误抛 WorkflowViolation
- `step_activate()`: 沙箱 → src/ 正式写入（不可逆）
- `rollback()`: 从备份恢复
- `verify_write_allowed()`: 供 gateway_interceptor 调用

**物理锚点记忆卡格式:**
```json
{
  "card_id": "wf_xxxxxxxxxxxx",
  "file": "src/xxx.py",
  "step": "BACKUP|SANDBOX|TESTING|APPROVED|ACTIVE",
  "action": "...",
  "detail": "...",
  "anchor": "[GENE_SOURCE: src/xxx.py] [TAG: WORKFLOW] [ANCHOR: PHYSICAL]"
}
```

**禁止跳步验证:** VALID_TRANSITIONS 定义合法路径，_transition() 校验，不合法抛 WorkflowViolation。

**关键修复:**
- 添加缺失的 `_transition()` 方法
- `_save_state()` 自动创建父目录

### 2. src/task_scheduler.py（~8KB, v1.2）
核心类: `TaskScheduler`

**熔断机制:**
- FUSE_THRESHOLD = 3（每 3 节点强制汇报）
- 解锁口令: "审核完毕继续任务"
- 解锁后 fuse_count 重置为 0，进入新周期
- 周期汇报存档到 memory/workflow_cycles/

**UUID 隔离设计:**
- `_instance_id = uuid.uuid4().hex[:8]`，每个实例唯一
- 防止跨测试污染（测试用例间磁盘状态文件隔离）

**关键修复:**
- 添加 `import os`
- 状态文件路径用 UUID（而非 task_name 的 hash）
- `reset()` 清除磁盘状态文件

### 3. src/gateway_interceptor.py（~3KB, v1.0）
- `intercept_write(target_file)`: 检查是否允许写入
- `assert_write_allowed(target_file)`: 不允许则抛 WriteBlocked
- `check_before_write(target_file)`: 返回 True/False
- 只拦截 src/ 目录；其他目录直接放行
