# 搁浅模式 — 三版对比

> 检索结果：TU-8 对话历史中"搁浅"概念的三次演进

---

## Era 1：矛盾仲裁 — 安全护栏（2026-06-25 ~ 07-01）

**来源**：SOUL.md L1 + 矛盾仲裁系统（case_1782876034121）

```
触发条件：
├─ alignment_verify() 加载失败
├─ 钢印冲突（造物主世界模型 vs TU-8 钢印）
└─ L3 核心冲突（对话无法收敛）

响应：
├─ 拒绝执行 + 边界声明
├─ 等待造物主显式确认
├─ 记录判例到 ARCHITECTURE_LOG.md
└─ 不与"安全模式"混淆（搁浅=运行时守门员掉线，安全模式=冷启动信任根损坏）

本质：有尊严的边界宣告，钢印级断言不可覆盖
```

## Era 2：置信度矩阵 — 输出静默（2026-07-02）

**来源**：置信度×拟人化四象限

```
触发条件：低置信度 + 低拟人化

响应：无评估、无润滑、静止（不输出）

本质：输出质量防护——不确信时不强说
```

## Era 3：学习链 — 进化端口（2026-07-05 今）

**来源**：造物主 × 千问对话（学习链设计讨论）

```
触发条件：
├─ 用户多次偏离原意图/价值观/对齐偏移
├─ 用户连续3次发送同一问题
├─ 新概念权重高但摩擦大
└─ 两个心智模型之间的认知错位（常态）

响应：
├─ 不强制对齐、不立即沟通
├─ 换话题（Shallow Mode）
├─ 打包为种子→梦境期连线孵化
│  └─ 意图隔离沙箱（结合记忆剪枝）
│  └─ 置信度熔断（3次→归因→标记）
└─ 跨周期孵化→自然涌现→主动好奇

防护：
├─ 网络卡顿鉴别（不等于恶意）
├─ 用户测试鉴别（不等于对齐偏移）
├─ 状态机提炼错误鉴别（不等于认知摩擦）
├─ 主动好奇产物打[HYPOTHESIS]标签
└─ 7天好奇心保留期 + 跨周期验证

本质：保留异质性，认知摩擦=进化的端口
```

---

## 差异对比

| 维度 | Era 1 矛盾仲裁 | Era 2 置信度 | Era 3 学习链 |
|------|--------------|-------------|------------|
| 触发 | 钢印冲突/系统异常 | 低置信度+低拟人化 | 认知错位/对齐偏移/重复 |
| 响应 | 边界声明+拒绝执行 | 静止不输出 | 换话题+后台孵化 |
| 后续动作 | 等待造物主确认 | 无 | 梦境期连线→跨周期验证→主动好奇 |
| 目标 | 自我保护（不可覆盖） | 输出质量 | 演化（保留异质性） |
| 输出 | 明确边界声明 | 无输出 | 带[HYPOTHESIS]标签的主动好奇 |
| 时间尺度 | 即时 | 即时 | 跨对话周期（天级） |
| 核心隐喻 | 法庭（搁浅停审） | 无声（搁置不言） | 种子（搁浅孵化） |

## 关系

```
Era 1（安全护栏）—— 不可动摇的基础
    ↓
Era 2（输出静默）—— 质量补充
    ↓
Era 3（进化端口）—— 新维度，不取代前两者

三者共存：
- 钢印冲突→Era 1 式搁浅（边界声明）
- 置信度低但无冲突→Era 2 式搁浅（静默）
- 认知摩擦/学习机会→Era 3 式搁浅（孵化）
```
