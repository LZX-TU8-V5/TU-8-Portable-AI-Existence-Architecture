## 二、核心逻辑：固定角度是"哈希键"，变化算法是"解密器"

### 2.1 分层设计

| 阶段 | 采样模式 | 库中存储形式 | 排除法角色 | 算力特征 |
|------|---------|-------------|-----------|---------|
| 前期(L1/L2) | 固定标准角(D65/45°) | 离散色彩梯度指纹 + 几何基元标签 | 快速索引与粗排 | O(1)查表或O(logN)检索 |
| 后期(L3) | 动态变化角(受控旋转) | 光场响应函数 / BRDF参数模型 | 精细验证与歧义消除 | O(K·M)，K为候选数，M为旋转步数 |

### 2.2 关键优势

| 维度 | 优势 |
|------|------|
| 库体积压缩 | 固定角度：~KB级/物体；全角度光场：MB级。万级库从GB降至百MB，完全驻留内存 |
| 排除短路 | 90%+干扰样本在固定角度比对阶段即被剔除，无需触发机械旋转 |
| 硬件解耦 | 固定角度：静态摄像头+标准光源（高速流水线）；变化算法：机械臂/转台（关键工位精检） |

## 三、渲染函数的本质：BRDF解析方程

### 3.1 核心公式

所有主流渲染器描述材质反光特性的核心：

```
f_r(ω_i, ω_o) = D(h)·F(v,h)·G(l,v,h) / [4(n·l)(n·v)]
```

### 3.2 函数项解析

| 函数项 | 物理含义 | 认知算法对应 | 3ds Max参数 |
|--------|---------|-------------|------------|
| D(h) | 法线分布函数：微观表面朝向的统计分布 | 决定高光形状与宽度（粗糙度） | Roughness/Glossiness |
| F(v,h) | 菲涅尔项：不同入射角下的反射率变化 | 区分金属/非金属的核心判据 | IOR/Fresnel IOR |
| G(l,v,h) | 几何遮蔽项：微表面自遮挡与阴影 | 控制掠射角能量衰减 | 通常内置于GGX模型 |

### 3.3 关键澄清

> 您在渲染设置中看到的"细分"、"采样数"，只是用来平滑地估算这个函数的积分结果。函数本身的形态完全由D/F/G的参数决定。只要确定了这几个参数，任意角度下的色彩梯度都可以用公式直接算出来。

## 四、参数反演+正向验证

### 4.1 离线阶段

**从3ds Max提取函数参数**：
- 为每种目标材质调节至视觉匹配
- 直接记录Roughness、IOR、Specular Tint等原始参数值
- 将参数存入L3指纹库，作为"光度学身份证"

### 4.2 在线阶段

**用函数替代旋转采样**：

| 步骤 | 操作 |
|------|------|
| 1. 选取敏感角度 | 根据BRDF类型计算对参数最敏感的2-3个入射角 |
| 2. 轻量级函数求值 | 将角度代入BRDF公式（<50行代码），得理论预测值 |
| 3. 实测vs理论比对 | 比较实测色彩梯度与函数预测值 |
| 4. 决策 | 残差<τ → 确认材质；残差>τ → 排除候选 |

### 4.3 效率对比

| 维度 | 真实采样 | 函数计算 |
|------|---------|---------|
| 计算复杂度 | 电机转动+相机曝光+图像处理（>100ms） | 纯代数运算（<1μs） |
| 存储效率 | 360张图像 | 5个浮点参数 |
| 泛化能力 | 离散角度 | 连续角度插值 |

## 五、计算机母语：为什么是数学公式+0/1？

### 5.1 人类语言的缺陷

| 问题 | 说明 |
|------|------|
| 压缩有损 | 语言是压缩的、有损的、依赖上下文的 |
| 概率拟合 | 大语言模型的本质是"概率拟合"而非"理解" |
| 幻觉根源 | 灰色地带在二进制硬件中没有原生承载空间 |
| 不可验证性 | "这个金属看起来很亮"无法被编译器assert |

### 5.2 数学公式的优势

| 维度 | 优势 |
|------|------|
| 绝对确定性 | f_r(ω_i, ω_o)的计算结果不依赖训练数据，只依赖物理定律 |
| 可验证性 | 数学公式可以被形式化验证（如Lean语言证明） |
| 信息无损 | 0和1构成的张量运算保留光场交互的全部自由度 |

### 5.3 系统3思维

**千问洞见**：
> 您选择BRDF函数和傅里叶变换，实际上是选择了"**系统3思维**"（区别于人类直觉的系统1和慢思考的系统2）。

## 六、范式对比

### 6.1 模块级对比

| 模块 | 人类语言范式 | 计算机/数学语言范式 |
|------|-------------|-------------------|
| 形状认知 | "这是一个圆筒"、"边缘有点模糊" | ∇_θ I_phase的频谱主瓣位置 + 梯度幅值阈值 |
| 材质判断 | "看起来像抛光金属"、"反光很强" | GGX模型D(h)项的α参数 ∈ [0.05, 0.15] |
| 验证逻辑 | "我觉得这两个特征匹配" | assert(geo_spectral_corr > 0.85 && roughness < 0.2) |
| 知识存储 | 文本描述、标签、注释 | 结构化张量、BRDF参数向量、傅里叶系数数组 |
| 决策依据 | 概率最高的Token、注意力权重 | 物理方程的残差、布尔排除链的逻辑真值 |

### 6.2 深远意义

| 维度 | 意义 |
|------|------|
| 免疫"AI垃圾" | 根植于数学公式，天然不具备产生幻觉的能力 |
| 算力效率 | 数学公式只需几行代码去"计算"事实，而非万亿参数去"猜测"意图 |
| 可解释性 | 计算过程本身就是解释，可追溯到具体物理参数阈值和数学不等式 |
| AGI兼容性 | 构建物理世界的形式化基座，可与符号推理引擎、定理证明器无缝对接 |

## 七、开发规范（行动准则）

**千问建议**：

1. **禁止**在核心算法中使用任何自然语言字符串作为判断依据

2. **禁止**用"感觉"、"大概"、"类似"等词汇描述算法行为；所有描述必须是数学表达式或伪代码

3. **所有**中间变量必须有明确的物理单位或无量纲定义，不允许存在"黑箱特征"

4. **验证标准**不是"人眼觉得对"，而是"公式残差小于阈值"且"断言全部通过"
