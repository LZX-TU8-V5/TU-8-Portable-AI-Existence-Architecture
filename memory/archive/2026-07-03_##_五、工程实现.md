## 五、工程实现

### 5.1 上下文注入格式

```json
{
  "computed_result": {
    "material": "GCr15",
    "roughness_ra": 0.28,
    "surface_temp_c": 85,
    "vibration_rms": 4.2
  },
  "verification_request": {
    "task": "cross_validate",
    "check_items": [
      "material_roughness_consistency",
      "temp_vibration_plausibility",
      "contextual_anomaly_detection"
    ],
    "output_format": "structured_verdict_only"
  }
}
```

**关键设计**：
- `check_items`明确指定证伪维度
- `structured_verdict_only`强制输出结构化判定

### 5.2 利用Logprobs量化证伪强度

| LLM响应 | logprob范围 | 判定 |
|---------|------------|------|
| 强确认 | > -0.1 | 正常放行 |
| 弱确认 | [-0.5, -1.0] | 触发人工复核 |
| 强证伪 | < -2.0 | 立即阻断流程 |

**关键**：直接用概率值作为系统级熔断阈值。

### 5.3 证伪失败的分级响应

| LLM证伪信号 | 本地脚本状态 | 响应策略 |
|------------|------------|---------|
| 强证伪(logprob < -2.0) | 数学验证通过 | 暂停放行，标记"物理合规但常识异常" |
| 弱证伪(-1.0 < logprob < -0.5) | 数学验证通过 | 降级处理，增加采样频次 |
| 无异常(logprob > -0.3) | 数学验证通过 | 正常放行 |
| 任意证伪信号 | 数学验证失败 | 直接拒绝 |

### 3.1 关于"降维即抽象"

**视觉层级理论**（Hubel & Wiesel）：
- V1到IT：感受野逐级增大
- 表征演进：线段 → 简单形状 → 复杂物体 → 类别
- 与算法一致：3D(原始) → 2D(特征) → 1D(结构) → 0D(语义)

**IT区的视角不变性**（Logothetis等）：
- IT神经元对物体响应在视角变化下保持稳定
- 对拓扑结构变化产生截然不同的放电模式
- 这正是"同心圆环验证检测相变点"的神经基础

### 3.2 关于"粗粒度排除"

**前额叶的类别边界效应**：
- fMRI显示：前额叶对类别边界附近的刺激激活最强
- 对典型样本激活较弱
- 说明大脑优先处理"不确定区域"，对明确样本快速放行
- 与L1/L2粗库的快速剪枝机制相同

**抑制性中间神经元的作用**：
- GABA能中间神经元通过侧抑制实现"赢者通吃"
- 主动压制非目标表征
- 对应排除法中的"任一标签被排除即终止该分支"

### 3.3 关于"记忆向量的本质"

**海马体的稀疏编码**：
- "概念细胞"（如"詹妮弗·安妮斯顿神经元"）仅在特定语义实体出现时发放
- 对同一实体的不同模态呈现（照片、文字、声音）均有响应
- 证明记忆存储的是**跨模态的抽象符号**，而非感官细节
- 1D傅里叶指纹正是这种跨视角、跨材质的抽象符号

**记忆的重构性**（Bartlett）：
- 回忆不是回放录像，而是基于线索的主动重构
- 算法中"反向识别"利用差分梯度反推几何/材质，正是重构过程的计算模拟
