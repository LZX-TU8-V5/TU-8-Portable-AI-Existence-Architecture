### 第六段：SNN核心公式（LIF神经元模型）

**膜电位微分方程**：
```
τ_m · dV(t)/dt = -(V(t) - V_rest) + R · I(t)
```

**发放条件**：V(t) ≥ V_th → 发放脉冲S(t)=1，重置V(t)=V_reset

**伪代码**：
```python
def lif_neuron_update(V_current, I_input, V_rest, R, tau, V_threshold, dt):
    dv = (-(V_current - V_rest) + R * I_input) / tau
    V_new = V_current + dv * dt
    spike = 0
    if V_new >= V_threshold:
        spike = 1
        V_new = V_rest
    return V_new, spike
```

### 第七段：CIM核心公式

**单点乘法（欧姆定律）**：I_ij = V_i × G_ij

**阵列求和（基尔霍夫电流定律）**：I_out_j = Σ(V_i × G_ij)

**核心逻辑**：乘法通过电压×电导瞬间完成，加法通过电流汇聚自然实现。矩阵向量乘法复杂度从O(N²)降为O(1)。

### 第八段：突触可塑性公式（STDP）

**权重改变量**：Δw 取决于前后神经元发放时间差Δt

- Δt > 0（前先放，后后放）→ 权重增强（LTP）
- Δt < 0（后先放，前后放）→ 权重减弱（LTD）

**伪代码**：
```python
def stdp_learning(pre_spike_time, post_spike_time, current_weight):
    delta_t = post_spike_time - pre_spike_time
    if delta_t > 0:
        weight_change = A_plus * exp(-delta_t / tau_plus)
    else:
        weight_change = -A_minus * exp(delta_t / tau_minus)
    return current_weight + weight_change
```
