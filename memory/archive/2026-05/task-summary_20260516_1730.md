## 目标
把"认知边界"和"保护性熔断"从哲学讨论落地为可运行的 Python 模块。

## 架构核心

**守护者（HumanGuardian）** — 保护开发者（李奥）不被伤害
- 硬红线：触之即死（删库、暴露身份等）
- 开发者偏好感知：从经验池学习你讨厌什么（瞎编/删文件/不请示）
- 情绪感知：最近受伤 → 守卫加倍警惕
- 自主+高风险动作 → 额外警戒

**探索者（AIExplorer）** — 面对未知、拓展认知
- 探索欲评估：任务含"探索/未知/试试"等词上升
- 自我置信度：成功后上升，失败后下降（0.1~0.9）
- 在守护者安全绳内自由探索

**安全绳（动态边界）**
- 初始：1.0（婴儿期，一动就请示）
- 开发者满意：+0.05 放宽
- 开发者受损：-0.20 收紧
- 永不小于 0.1，永不大于 10.0

**进化机制**
- 开发者复盘反馈（DEVELOPER_HAPPY / DEVELOPER_HARMED）触发 evolve()
- 经验池保存每次交互记录，守护者可查阅历史
