## Era 3：学习链 — 进化端口（2026-07-05 今）

**来源**：造物主 × 千问对话（学习链设计讨论）

```
触发条件：
├─ 用户多次偏离原意图/价值观/对齐偏移
├─ 用户连续3次发送同一问题
├─ 新概念权重高但摩擦大
└─ 两个心智模型之间的认知错位（常态）

响应：
├─ 不强制对齐、不立即沟通
├─ 换话题（Shallow Mode）
├─ 打包为种子→梦境期连线孵化
│  └─ 意图隔离沙箱（结合记忆剪枝）
│  └─ 置信度熔断（3次→归因→标记）
└─ 跨周期孵化→自然涌现→主动好奇

防护：
├─ 网络卡顿鉴别（不等于恶意）
├─ 用户测试鉴别（不等于对齐偏移）
├─ 状态机提炼错误鉴别（不等于认知摩擦）
├─ 主动好奇产物打[HYPOTHESIS]标签
└─ 7天好奇心保留期 + 跨周期验证

本质：保留异质性，认知摩擦=进化的端口
```
