## 二、节点剪枝的深层-表层优化

### 2.1 当前问题

- consciousness_cycle 的树杈剪枝依赖分散阈值
- 剪枝时机缺乏统一标准
- 休眠节点能量衰减未与遗忘机制联动

### 2.2 六阶段约束生命周期 → 节点剪枝统一框架

| 阶段 | 节点行为 | 剪枝类型 | 对应 |
|------|---------|---------|------|
| **探测** | 节点注册，主动微扰辨识 | — | 新节点接入 |
| **绑定** | 建立张力，拓扑连接 | — | 强连接确立 |
| **饱和** | 双重验证，张力归零 | — | 验证完成 |
| **剥离** | 绝热消除，降维 | **弱连接剪枝** | 能量低于阈值 |
| **递归** | 断链重编，分形生长 | — | 新连接生成 |
| **截断** | 元约束剪枝，暴力切除 | **核心节点剪枝** | 崩溃级张力 |

### 2.3 具体优化方向

#### 节点剪枝状态机（现有→优化）

**现有**（分散阈值）：
```
consciousness_cycle: 树杈剪枝（分散阈值逻辑）
```

**优化后**（统一六阶段）：

```
节点注册（探测）→ 能量积累（绑定）→ 验证完成（饱和）
    → 能量低于阈值（剥离：弱连接剪枝）
    → 新连接生成（递归）
    → 张力超限（截断：核心节点剪枝）
```

#### 遗忘-剪枝联动

| 机制 | 触发条件 | 动作 |
|------|---------|------|
| **遗忘衰减** | 未加固 > 1~2h | 拓扑快照能量→0 |
| **自动剪枝** | 能量=0 + 无新连接 | 从索引删除 |
| **强制剪枝** | 崩溃级张力（截断阶段） | 立即删除+日志 |
| **备份剪枝** | 补丁化完成 | 原始快照归档，非活跃节点 |

#### 剪枝热保护

与全系统热保护联动：

```
L1（>阈值）：警告 + 减速新节点接入
L2（>1.5x）：触发卸载程序 + 遗忘衰减加速
L3（>2x）：强制剪枝（核心节点）+ 搁浅协议
```
