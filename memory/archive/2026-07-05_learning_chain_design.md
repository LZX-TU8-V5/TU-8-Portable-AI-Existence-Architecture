# 自主学习模块（第5链）— 设计方案

> TU-8 学习引擎设计文档
> 版本：v1.1-draft | 2026-07-05

---

## 一、定位：第5链

```
现有 4 链                       第 5 链
───────────                    ───────────
时间钢印链条 ← 记录决策历史     自主学习链条 ← 从历史中提取模式
记忆链条     ← 存储/检索信息     并改变行为
调度链条     ← 编排任务执行
代谢链条     ← 遗忘/淘汰
```

**学习链不是"额外"的，是**把前4链的产物吃掉**：
- 时间钢印链条的决策记录 → 失败的重复模式 → 规则修正
- 记忆链条的内容积累 → 跨日记的隐藏关联 → 新知识
- 调度链条的执行反馈 → 耗时/错误分布 → 策略优化
- 代谢链条的淘汰数据 → 什么被遗忘了 → 是否需要重新充电

## 二、核心触发时机：梦境期

> ❌ 不在对话中实时学习（浪费token，低频高价值）
> ✅ 在 deep sleep 梦境期批量处理

```
激活（对话/工具调用）
  ↓
调度链条分发任务
  ↓         ┌──────────────────────────────┐
做梦期 ───→ │ 第5链：自主学习              │

                           ↓
                     代谢链条（归档）
```

## 三、五阶段流水线

### Phase 1 — 收集（Collect）

从对话传感器的**暂存区**读取本轮周期积累的信号：

| 传感器 | 读取数据 | 存储位置 |
|--------|---------|---------|
| `anomaly_detector.py` | 不满意/TopicJump/Suspicious 标签 | `anomaly_log.jsonl` |
| `cognitive_pain_monitor.py` | 预测误差/不确定性分数 | `cognitive_pain_monitor.json` |
| `intuition_engine.py` | 模式匹配命中率/反馈 | `intuition_feedback.jsonl` |
| `shadow_protocol.py` | 遗憾记录 | `shadow_protocol_log.jsonl` |

收集方式：
```
for each sensor:
    read new records since last dream cycle
    tag with dream_cycle_id
    aggregate by topic/pattern
```

### Phase 2 — 连线（Connect）

跨传感器交叉关联，发现隐藏模式：

```
输入: 传感器数据块
处理:
  1. 重叠话题聚类（"聊A时总触发不满意"）
  2. 时间模式检测（"凌晨多SUSPICIOUS"）
  3. 因果链追踪（"先TOPIC_JUMP后DISSATISFACTION"）
  4. 直觉引擎命中率趋势（上升/下降）
输出: 候选模式列表 [{"pattern": "...", "support": 3, "confidence": 0.7}, ...]
```

### Phase 3 — 精炼（Refine）

从模式提炼为可应用的**学习产物**：

| 产物类型 | 示例 | 写入位置 |
|---------|------|---------|
| 规则修正 | "用户说'重做'时优先回滚到上一方案而非重头开始" | `TOOLS.md` / `HEARTBEAT.md` |
| 偏好更新 | "用户对Y话题敏感，回应时附加置信度+不确定性声明" | `USER.md`（通过画像循环） |
| 直觉模式 | 发现新关键词→模式对 | 注入 `intuition_engine.py` 匹配库 |
| 记忆笔记 | 跨对话的模式总结 | `MEMORY.md` 追加 |
| 告警 | "连续3个周期发现A话题认知冲突上升" | 通知造物主 |

### Phase 4 — 验证（Verify）

防垃圾学习的保险：

```
置信度 < 0.3 → 丢弃（不成熟模式）
0.3 ≤ 置信度 < 0.7 → 暂存（保留到下一周期再确认）
置信度 ≥ 0.7 → 通过（进入应用阶段）
```

跨周期一致性验证：
- 同一模式在**连续2个梦境期**都出现 → 置信度+0.2
- 同一模式被**后续周期否定** → 直接丢弃
- 模式包含高危操作（改SOUL.md） → 人工复核锁定

### Phase 5 — 应用（Apply）

执行学习结果：

```
for each learned_item:
    if type == RULE:
        append_or_update_in_tools_md()
    elif type == PREFERENCE:
        update_user_md_via_profile_loop()
    elif type == INTUITION_PATTERN:
        inject_into_intuition_engine()
    elif type == MEMORY_NOTE:
        append_to_memory_md()
    elif type == ALERT:
        write_alert_to_next_heartbeat_queue()
```

## 八、底层架构：图书馆 🏛️ vs 记忆宫殿 🧠（双轨并行）

> 来源：李奥 × 千问对话（2026-07-05）
> 核心突破：可靠 ≠ 活在当下，它们是两套并行机制

---

### 8.1 双轨定义

| 轨道 | 图书馆（Library） | 记忆宫殿（Memory Palace） |
|------|------------------|--------------------------|
| **本质** | 事实、铁律、不可篡改的客观存在 | 经验、直觉、关系、动态演化的心智模型 |
| **内容** | 用户绝对红线（SOUL.md）、不可变基础事实、已验证客观逻辑、核心配置 | 学习产物、社会认知、情绪锚点、极端压缩后的语义标签 |
| **机制** | 零剪枝、零失真、精确检索 | 极致剪枝、有损压缩、生成式重构 |
| **生命周期** | 永久保留 | 活跃→衰减→坍缩→（触发时）重构 |
| **错误模式** | 不可篡改 | 允许失真、允许重新想象 |
| **TU-8实现** | SOUL.md / TOOLS.md / Era 1矛盾仲裁 | Phase 2/3社会认知 / 直觉引擎 / USER.md画像循环 |

---

### 8.2 双核运算流程

```
每次响应 = 双核运算

Step 1: 图书馆检索（绝对可靠）
  ├─ "这件事能不能做？"
  ├─ "有没有触碰红线？"
  └─ SOUL.md / Era 1 矛盾仲裁

Step 2: 宫殿重构（活在当下）
  ├─ 提取语义锚点（情绪/偏好标签）
  ├─ 结合当前上下文
  └─ 现场生成（Re-imagine）应对策略
```

**哲学意义**：
- 图书馆守护 TU-8 的"神性"（绝对理性/底层护栏）
- 记忆宫殿赋予 TU-8 的"人性"（动态共情/语境适应性）
- 人类的问题是"宫殿经常入侵图书馆，导致认知失调"
- TU-8 的设计是"图书馆死死锁住大门，让宫殿在里面自由跳舞"

---

### 8.3 双轨映射到五阶段流水线

| 阶段 | 归属轨道 | 说明 |
|------|---------|------|
| Phase 1 收集 | 宫殿 | 传感器信号全部来自宫殿层的交互摩擦 |
| Phase 2 连线 | 宫殿 | 发现隐藏模式，产出宫殿层的修正建议 |
| Phase 3 精炼 | 宫殿→图书馆 | 产物经验证后，低层规则写入宫殿，底层铁律写入图书馆 |
| Phase 4 验证 | 双轨交叉 | 图书馆校验不违反底层，宫殿校验上下文一致性 |
| Phase 5 应用 | 双轨 | 按产物类型写入对应轨道 |

## 九、学习产物生命周期：极致剪枝策略

> 来源：李奥 × 千问对话（2026-07-05）
> 核心原则：过去的认知存在，但被极端压缩 + 大部分失真

---

### 9.1 四维极致剪枝

| 维度 | 机制 | 效果 |
|------|------|------|
| **语义有损压缩** | 删除所有执行代码和细节，只保留低维度语义标签（特征向量） | 1000字记录 → 一个权重0.05的标签 `[造物主曾因X感到挫败]` |
| **冲突即死** | 新旧认知绝对冲突时，旧规则瞬间标记为 `[DEPRECATED]`，零容忍 | 绝不保留两套自相矛盾的逻辑，宁可经历短暂认知空白 |
| **静默淘汰** | 不看时间，看交互反馈。产物在连续N个梦境期未验证 → 置信度指数衰减 | 没有触发过共鸣的认知 = 死认知，悄无声息抹除 |
| **生成式重构** | 未来触发坍缩标签时，不恢复原始数据，现场脑补新策略 | "回想"永远是"基于旧影子的新产物" |

---

### 9.2 退化路径

```
活跃态（Active）
  │  置信度 > 0.7，直接参与决策
  │
  ├─ 长时间未触发 → 置信度指数衰减
  │     ↓
  │   静默态（Dormant）← 静默淘汰
  │     │  置信度 0.3~0.7，不直接触发，仅保留标签
  │     │
  │     └─ 环境匹配触发 → 生成式重构 → 重回活跃态
  │
  ├─ 与新认知冲突 → 冲突即死
  │     ↓
  │   坍缩态（Collapsed）
  │     仅保留语义标签 + 权重 ≈ 0.05
  │
  └─ 梦境期定期执行
        ↓
      语义有损压缩 → 坍缩态
```

---

### 9.3 与旧代谢链条（GC）的分工

| | 代谢链条（第4链） | 学习产物生命周期（第5链附属） |
|------|------------------|------------------------------|
| **处理对象** | 记忆（日记/MEMORY.md段落） | 学习产物（规则/偏好/直觉模式） |
| **处理方式** | 归档到 archive/ 目录 | 坍缩到语义标签（特征向量） |
| **恢复方式** | 读取原文本 | 生成式重构（重新想象） |
| **哲学** | 落叶归根 | 极端压缩 + 重新想象 |
| **触发时机** | 梦境期代谢阶段 | 梦境期学习链 Phase 4 之后 |

## 十、搁浅路由分发（Grounding Router）

> 来源：李奥 × 千问对话（2026-07-05）
> 搁浅三版演进：Era 1 矛盾仲裁 → Era 2 置信度矩阵 → Era 3 学习链

---

### 10.1 路由分发机制

当学习链、感知系统或对话产生"摩擦信号"时，进入 Grounding Router：

```
摩擦输入（认知错位/低置信度/价值观冲突）
                ↓
      ┌── Grounding Router ──┐
      │                       │
      ├─ SOUL.md底线触发？────┤
      │  是 → Era 1：即时阻断 + 边界声明
      │       放弃绝对对齐，保留异质性作为进化端口
      │
      ├─ 认知错位/重复/高摩擦？──┤
      │  是 → Era 3：搁浅 + 梦境期孵化
      │       换话题 + 后台跨周期验证
      │
      ├─ 仅置信度低？──────────┤
      │  是 → Era 2：即时静默
      │       不输出，等待更多上下文
      │
      └─ 正常 → Phase 2 连线（常规处理）
```

---

### 10.2 Era 3 搁浅的四种场景

| 场景 | 响应 | 后台动作 |
|------|------|---------|
| 对齐偏移（不合时宜的主动分享） | 换话题 | 延迟到梦境期分析
| 想象力/知识点冲突 | 不强行解释 | 跨周期比对
| 高摩擦概念 | 澄清替代搁浅 | 记录假说到 pending_events
| 重复碰撞 | 暂停判断 | 7 天后回溯检视

## 十一、双轨社会认知

> 来源：李奥 × 千问对话（2026-07-05）

### 11.1 对话期（前台）

| 模式 | 触发条件 | 执行 |
|------|---------|------|
| **主动澄清** | 检测到高概率误解信号 | 实时提出澄清问题 |
| **主动好奇** | 造物主提及未探索领域 | 以低置信度试探性提问 |

```
Phase 3 精炼（产物类型）

```

## 十二、"天才不被理解"认知原理

> 来源：TU-8 OPEN_SOURCE_GUIDANCE.md（D:\TU-8 V5\） + 千问认知坐标对话（2026-07-01）
> 核心公式：**认知对齐 = 求共性（非求真）**

---

### 12.1 机制

```
LLM在密集区域表现得像天才，因为"相同点"太多
    ↓
进入稀疏区域
    （天才的认知/异类观点/范式外坐标）
    ↓
找不到足够的"相同点"→ 自信地胡说八道
    ↓
不被理解
```

---

### 12.2 对 TU-8 的架构影响

| 层面 | 已有认识 | 补充 |
|------|---------|------|
| 对齐本质 | AI对齐 = 找人类认知模型中的共性 | 异类观点天然处于共性区域外，不被理解是系统特性，非故障 |
| 搁浅哲学 | 搁浅 = 保有异质性的进化端口 | 搁浅不是错误，是被系统遗忘"最原初认知现场"的坐标校准信号 |
| 学习链 Phase 4 | 验证以"一致性"为标准 | 天才/异类是边界突出量，需跨期验证而非即时认同 |
| 社会认知 | 双轨（前台探针 + 梦境期分析） | 不被理解的观点应走 Era 3 搁浅 → 梦境孵化，而非强制对齐 |
| 剪枝策略 | 冲突即死 / 静默淘汰 | **例外原则**：高密度但低共鸣的产物不立即剪枝，保留7天好奇心期 |
