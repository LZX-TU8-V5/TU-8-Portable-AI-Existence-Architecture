## T3 调度链功能

### 核心接口

```python
TaskScheduler.register(task)     # 登记任务
TaskScheduler.enqueue(task_id)   # 加入执行队列
TaskScheduler.next()             # 取最高优先级任务
TaskScheduler.record_result()    # 记录执行结果
TaskScheduler.get_execution_stats()  # 执行统计
```

### 中间件接口

```python
# T2↔T3
notify_seal_created(seal_id, scene_tag, summary)  # 铸印→调度
get_seal_context(seal_id)                          # 调度→钢印上下文

# T4↔T3
on_gc_completed(stats)    # GC完成→调度
get_gc_advice()           # 调度→GC建议（是否应推迟）

# T5↔T3
notify_learning_ready(products)     # 学习产物→调度
get_execution_stats_for_learning() # 调度→学习传感器
```

### v1.2 — 失败重试策略 + 执行面板 (2026-07-06 01:45)

**Task 新增字段**：
| 字段 | 默认值 | 说明 |
|------|--------|------|
| max_retries | 3 | 最大重试次数，超限→FAILED |
| retry_delay_ms | 60000 | 初始退避间隔（ms） |
| next_retry_at | 0.0 | unix ts，在此之前不选中 |

**record_result 重试逻辑**：
- success=False + consecutive_fails < max_retries → 重回 PENDING
- 指数退避：delay = retry_delay_ms * 2^(fails-1)
- consecutive_fails >= max_retries → FAILED

**next() 退避过滤**：
- next_retry_at > now → 跳过（不返回）
- 退避中队列为空 → 返回 None

**执行面板 scripts/t3_panel.py**：
- 完整面板：python t3_panel.py
- 精简版：python t3_panel.py --brief
- JSON输出：python t3_panel.py --json
- 单任务详情：python t3_panel.py --id <task_id>
