# 2026-07-25 下午核查：系统骨架架构问题

## Q1：HP4 心跳串行阻塞

- **串行阻塞，无超时**：`_execute_heartbeat_actions()` 顺序调用 `_trigger_active_curiosity` → `_trigger_self_probe` → `_trigger_anomaly_detector` → `_trigger_intrinsic_reward` → `_trigger_lambda_tuner` → `_record_surface_tension` → `_trigger_batch_confidence` → `_trigger_cognitive_friction`。无 threading/async，无单个函数超时机制。
- **慢函数拖心跳**：`_trigger_active_curiosity()` 在 idle<0.5h 时提前 return（30s 间隔 → 几乎每次 return），实际计算成本低。但一旦触发（idle≥0.5h），内调 `decide_action()` 可能含 LLM 调用，无超时。
- **HP4 内无 timeout wrapper**：所有 `_trigger_*` 函数无任何超时保护。
- **最坏情况**：`_trigger_self_probe()` → `self_probe.probe()` → 若含 LLM 调用，挂起 → HP4 心跳整体卡死直到 LLM 返回/超时。
