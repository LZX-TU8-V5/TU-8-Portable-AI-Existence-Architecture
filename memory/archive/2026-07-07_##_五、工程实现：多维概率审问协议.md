## 五、工程实现：多维概率审问协议

### 5.1 标准化多模态证据包

```json
{
  "evidence_package": {
    "visual": {
      "material_candidate": "GCr15",
      "roughness_ra": 0.28,
      "color_gradient_anomaly": false,
      "confidence": 0.96
    },
    "tactile": {
      "friction_coefficient": 0.12,
      "vibration_damping_ratio": 0.85,
      "surface_temp_c": 42,
      "compliance_mm_n": 0.002
    },
    "context": {
      "process_stage": "final_inspection",
      "expected_material": "GCr15_bearing",
      "ambient_humidity_rh": 75
    }
  },
  "interrogation_task": {
    "mode": "cross_modal_consistency_check",
    "output_schema": {
      "verdict": "enum[consistent, suspicious, contradictory]",
      "suspicion_type": "string?",
      "recommended_action": "enum[pass, re-sense, escalate, clean]"
    }
  }
}
```

### 5.2 利用Logprobs实现分级审问

| LLM响应 | logprob范围 | 判定 | 行动 |
|---------|------------|------|------|
| 一致(Consistent) | > 0.8 | 自动放行 | 生成报告 |
| 可疑(Suspicious) | 0.4-0.8 | 输出具体怀疑类型 | 针对性复测 |
| 矛盾(Contradictory) | > 0.6 | 立即停机 | 保存数据，人工介入 |
| 不确定性过高 | 均 < -1.5 | 信息不足 | 主动请求补充采样 |

### 5.3 审问结果的闭环反馈

```
视觉+触觉并行采集
       ↓
本地数学计算
       ↓
多模态证据包
       ↓
LLM概率审问
       ├──→ Consistent → 放行 + 生成报告
       ├──→ Suspicious → 定向补采指定模态
       ├──→ Contradictory → 停机 + 人工介入
       └──→ Uncertain → 主动请求新采样策略
```
