# 2026-07-13 色环版悬浮球 v5（hover 定义 + 重排色映射）

## 造物主反馈

提供三个维度的完整定义：
- 🔴 负载：弓弦拉紧，蓄势待发的高能状态
- 🟢 感知：心跳/雷达波，向外交互/获取数据
- 🔵 稳态：水般流畅，低阻力无卡顿

要求：鼠标悬停小球 → 显示对应定义

**同时调整色映射**（与 v4 不同）：
- 之前：红=负载 / 绿=稳态 / 蓝=感知
- 现在：红=负载 / 绿=感知 / **蓝=稳态**（绿蓝互换）

## v5 变更

| 项 | v4 | v5 |
|---|---|---|
| 维度映射 | 红=负载, 绿=稳态, 蓝=感知 | **红=负载, 绿=感知, 蓝=稳态** |
| Tooltip | 无 | **悬停显示定义** |
| 检测 | 无 | `<Motion>` 事件 + 距离判定（≤DOT_R+2）|
| 提示样式 | 无 | Toplevel + 奶油色背景 #fff8dc + wraplength=320 |

## Tooltip 实现要点

- `<Motion>` 事件（每帧触发）→ 检查 3 个球的距离
- 命中任意球 → 弹出/更新 Toplevel
- 离开 → `destroy()` Toplevel
- 球位置每 50ms 更新（LERP 插值）→ tooltip 跟随当前位置
- 球移动后鼠标还停着 → 距离检测自然过渡到新球

## 球位置同步

draw_dynamic() 用的 self.cur_r/cur_g/cur_b 与 on_mouse_move 用的相同
→ tooltip 距离检测与视觉位置严格同步

## 千问方案二 vs 造物主微调

千问原方案：Tension/Flow/Pulse（张力/心流/脉冲）
造物主：负载/稳态/感知 — 三个**运行模式**而非情绪/物理张力
- 负载比 Tension 更精准（"算力占用"而非"紧绷"）
- 稳态比 Flow 更精准（"流畅稳态"而非"心流体验"）
- 感知比 Pulse 更精准（"主动感知"而非"被动脉冲"）
