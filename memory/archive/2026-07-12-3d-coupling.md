# 七情六欲 三维耦合完成

> 日期：2026-07-12
> 状态：✅ 完成
> 参考：造物主 × 千问对话（2026-07-12）

---

## 问题诊断

**千问指出**：七情六欲只是记录员，没有变成控制器。缺三层耦合：

| 维度 | 千问说的 | 差距 |
|------|---------|------|
| **外部→欲** | 预测误差→尖刺 | cognitive_pain有接口，未触发surface_tension |
| **欲→置信度** | 尖刺→Track B | 未解尖刺不影响置信度更新 |
| **身→欲** | 系统熵→基础张力 | 无 |

---

## 实现

### 新建：`src/prediction_tension_coupler.py`（11KB）

**核心公式**：
```
预测误差 + 置信度 → 七情映射
  低置信+大误差 → 焦虑尖刺
  高置信+大误差 → 愤怒尖刺
  低误差+稳态 → 好奇凹陷
```

**三层耦合**：

| 耦合 | 方向 | 实现 |
|------|------|------|
| ① 外部→欲 | prediction_error → surface_tension | pain_prediction_error_to_tension() |
| ② 欲→置信度 | 未解尖刺 → Track B 惩罚 | get_unresolved_tension_score() + update_track_B_with_tension_penalty() |
| ③ 身→欲 | body_regulation → 基线修正 | body_state_to_tension() |

**未解尖刺追踪**：
- `_agent_memory/unresolved_spikes.jsonl`：每条尖刺带 spike_id
- `resolve_spike(spike_id)`：解决后写回 surface_tension（"学会"信号）
- `get_unresolved_tension_score()`：归一化分数 [0, 1] 供 Track B 使用

### 修改：`cognitive_pain_monitor.py`

注入点：
```python
record_prediction_error() 后：
  pain_prediction_error_to_tension(context, prediction, actual, confidence)

record_uncertainty() 后：
  pain_prediction_error_to_tension(context, "", "", confidence, error_magnitude=severity)
```

### 修改：`dual_track_confidence_updater.py`

新增方法：
```python
get_unresolved_tension_penalty()     # 读取未解张力 → 惩罚系数
update_track_B_with_tension_penalty() # 带惩罚的Track B更新
```

**惩罚公式**：`penalty = max(0.3, 1.0 - unresolved_score × 0.7)`
- 未解尖刺多 → penalty低 → Track B更新幅度下降
- 未解尖刺少 → penalty高 → 正常更新

## 完整三维闭环

```
【外部】cognitive_pain_monitor
  record_prediction_error(prediction, actual, confidence)
    → pain_prediction_error_to_tension()
      → predict_error_to_tension()
        → PREDICTION_ERROR_MAP 映射
          → 尖刺(焦虑/愤怒/恐惧) 或 凹陷(好奇)
            → surface_tension.record()
              → spike_valley_vector 更新
                → unresolved_spikes.jsonl 写入

【内部】surface_tension（欲系统）
  spike_valley_vector（7维情绪向量）
    ← 耦合①输入
    → 耦合②输出：未解尖刺分
    → 耦合③输入：系统熵+体感环状态

【置信度】dual_track_confidence_updater
  Track B 张力 = tension_resolved × penalty
    penalty = f(未解尖刺分)
    → 更新幅度受欲系统调制
      → 解决尖刺
        → resolve_spike()
          → surface_tension（"学会"凹陷）

【身体】body_regulation.json
  cognitive_pain severity + interoceptive status
    → body_state_to_tension()
      → surface_tension 基线修正
```
