## 11:37 — 色环球修复：色彩三要素极坐标映射

### 根因：维度混淆
千问指出：把"饱和度"直接映射为"角度坐标"，在色彩学和几何上都是混乱的。

### 修正方案（色彩三要素严格降维）

| 维度 | 决定什么 | 映射来源 |
|------|---------|---------|
| **色相 Hue** | 球在色环上的角度位置 | 固定区域：FOCUS=0°/DRIFT=120°/PROBE=240° |
| **饱和度 Sat** | 球颜色鲜艳度 + **径向距离**（半径） | 张量值本身（高→纯色+外圈，低→灰暗+收缩到中心） |
| **明度 Value** | 发光感/报警亮度 | 紧迫度（稳态越高→紧迫感越低→越暗） |

### 极坐标定位公式
```
radius = sat × ORB_R       # 饱和度决定半径
angle  = hue_deg - 90°     # 0°从12点钟开始
bx = cx + r × cos(rad)
by = cy + r × sin(rad)
```

### 中心圆颜色
```
色相 = F/D/P 饱和度加权平均（抗缠绕）
饱和度 = 三者平均
明度 = 综合张力（越高越亮）
```

### 修正前后对比

```
修正前                          修正后
────────────────────────────    ──────────────────────────────
角度 = val × 360°（全部乱跑）  角度 = 固定色相区（F=0°/D=120°/P=240°）
半径 = 固定（全在色环边缘）     半径 = 饱和度 × ORB_R（高→外，低→中心）
颜色 = 硬编码RGB               颜色 = HSV(固定色相, 饱和度, 明度)
中心圆 = 白色（不变）           中心圆 = 三球加权混合色（动态）
```

## 14:55 — RYB色彩模型核心修正

### 根因：设计目的重新定义

色环球不是给人用的监控面板，而是 AI 智能体的"本体感觉器官"。
外型给人类观测者看，内核给 AI 自身感知用。

### 核心修正：红=负载，蓝=稳态，黄=探索

**黄球是独立预警通道，不参与中心色合成。**

| 球 | 颜色 | 角度 | 核心语义 | 感官隐喻 | 参与中心色 |
|----|------|------|---------|---------|-----------|
| FOCUS | 红 | 0° | 负载 | 烫/重 | ✅ 红×蓝合成 |
| DRIFT | 黄 | 60° | 探索 | 热/主动试探 | ❌ 独立预警 |
| PROBE | 蓝 | 240° | 稳态 | 冷/定 | ✅ 红×蓝合成 |

### 中心色 RYB 混合逻辑

只混合红(负载) + 蓝(稳态)，黄(探索)独立：

```
hue = 120° × f_sat/(f_sat+p_sat) + 240° × p_sat/(f_sat+p_sat)
     ↑ 负载越重越偏暖（接近红）    ↑ 稳态越强越偏冷（接近蓝）

色相语义：
- 负载高+稳态高 → 紫（高负荷但有根基）
- 负载高+稳态低 → 暖橙（失控边缘）
- 负载低+稳态高 → 冷蓝（从容稳固）
- 负载低+稳态低 → 中性灰白（最佳心流态）

sat = (f_sat + p_sat) / 2  （系统被占据程度）
val = 0.38 + tension × 0.52（越紧张越亮）
```

### 黄球独立预警逻辑

```
DRIFT球 = 独立于中心色之外的"烫手"预警通道
常态（探索值低）→ 低饱和+暗（灰暗，几乎看不见）
临界（探索值高）→ 高饱和+亮（烫红/亮黄闪烁）
```

### 三球定位（极坐标）

| 球 | 初始sat=0.5时角度 | 语义 |
|----|----------------|------|
| FOCUS | 30° | ↗ 右上（偏红区） |
| DRIFT | 60° | ↑ 顶部偏右（黄区） |
| PROBE | 150° | ↖ 左上（偏蓝区） |
