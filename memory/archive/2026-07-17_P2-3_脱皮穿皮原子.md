## 完成内容

### 1. 创建 `src/skin_cycle.py`

将 `tu8_dispatch.py` 中的 DawnRitual 和 DuskRitual 封装为独立 `SkinCycle` 类。

**核心接口**：
```python
from skin_cycle import SkinCycle
skin = SkinCycle()
soul = skin.enter(user_input)        # 穿皮：加载灵魂结构
result = skin.exit(response, soul)  # 脱皮：提取并写回结构变更
state = skin.status()               # 查看当前皮肤循环状态
```

**SoulStructure 属性映射**（修正）：
| 旧属性名 | 正确属性名 |
|---------|-----------|
| soul_hash | seal_chain_hash |
| anchors | active_memories |
| seals | recent_seals |

### 2. 依赖修复
- 安装 pyyaml（DawnRitual 需要 `cognitive_constitution.yaml`）

### 3. 集成到 cron_daemon
```python
"skin_cycle": {
    "path": SRC + "skin_cycle.py",
    "args": ["--enter", "cron_health_check"],
    "output": AGENT + "cron_skin_cycle_last.json",
    "interval": 3600,   # 每小时检查一次灵魂结构
    "desc": "[P2-3] 脱皮+穿皮灵魂结构检查"
}
```

### 4. 状态文件
`_agent_memory/skin_cycle_state.json` 记录：
- total_enter / total_exit
- last_enter.ts / last_exit.ts
- last_soul_hash
- last_write_count
