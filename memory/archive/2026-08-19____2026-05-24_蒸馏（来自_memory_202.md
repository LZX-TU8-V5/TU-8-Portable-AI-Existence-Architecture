### 全局观三层架构（写入SOUL.md）
```
L0: 战略层（人类掌舵）→ 定义目标、设定边界、设计熔断
L1: 战术层（人机协同）→ 关键节点、处理异常、价值判断
L2: 执行层（AI划桨）→ 高效执行、局部优化、反馈数据
```

### 眼镜蛇效应五大规避策略
| 策略 | 含义 | 适用场景 |
|------|------|---------|
| 多维度指标 | 不只看单一数字 | 指标被游戏化时 |
| 第二层思维 | 推演行动的第二层后果 | 政策/激励设计 |
| 小范围试点 | 先小规模验证再推广 | 任何新机制 |
| 独立数据源 | 用外部数据交叉验证 | 避免自我强化 |
| 人在环中 | AI建议+人做决定 | 高风险决策 |

### 眼镜蛇效应典型案例
- 印度眼镜蛇悬赏 → 养蛇领赏 → 蛇患更严重
- 墨西哥限行政策 → 买第二辆车 → 污染更严重
- 日托迟到罚款 → 迟到更多（钱替代了社会规范）

### 开发铁律（来自李奥反馈）

- **动作**：先 `memory_search` 检索已有模块
- **原因**：避免重复造轮子，确保全局最优

> **造物主箴言**："你没有全局观。"——从执行者升级为思考者，每次开发前必须先检索已有模块
