## 接口对比结论

### 两套张力系统：不在同层，可共存

```
文本输入
  ↓
structural_vector.py（新增）→ 提取{动词类型/终点状态/弓形面积}
  ↓
surface_tension.py（现有）→ 计算7维情绪向量 + 张力量值
  ↓
tension_router.py（新增）→ 三轨路由
  ├─ 低张力 → 归档
  ├─ 中张力 → 通道A躯体标记
  └─ 高张力 → friction_bus_euler.py（新增）
                      ↓
               alignment_verify（现有出口）
```

### HP4 L0：可升级，不冲突

| 层 | 现有 | 下午 |
|----|------|------|
| L0 | Jaccard(token) ≥ 0.5 | StructuralVector.match() |
| L1 | Sigmoid(confidence) ∈ (0.2,0.8) | 不变 |
| L2 | ReLU(tension-θ) > 0 | 不变 |
