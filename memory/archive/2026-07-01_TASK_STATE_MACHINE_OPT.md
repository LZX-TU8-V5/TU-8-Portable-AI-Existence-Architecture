## 一、任务目标

将**排除法语义检索**策略集成到 TU-8 的**上下文拼接状态机**中，实现：

1. 用置信度作为排除阈值，剪枝无效状态转移
2. 用位掩码加速状态编码，实现快速排除
3. 用动态剪枝顺序优化计算效率

---

## 二、背景

### 2.1 当前问题

- 上下文拼接采用"正向拼接"逻辑（所有轮次都处理）
- 类似"正向检索"：检查所有特征，算力浪费
- 缺少"排除不可能状态"的机制

### 2.2 千问洞见

> 在多标签交叉场景下，正向检索是加法逻辑 O(N×M)，排除法是减法逻辑 O(N/2^k)。排除法是一种**算力压缩策略**。

### 2.3 跨领域映射

| 视觉领域 | TU-8 领域 |
|---------|----------|
| 语义检索 | 上下文拼接 |
| 多标签交叉物体 | 多轮对话状态 |
| 傅里叶特征阈值 | 置信度阈值 |
| 排除法剪枝 | 状态转移剪枝 |

### 3.5 Phase 5: 与 LCM 集成

**目标**：将排除法集成到 LCM (Lossless Context Management)

**集成方案**：
```
当前流程：
    对话 → LCM 压缩 → 保留摘要

改进流程：
    对话 → 排除法剪枝 → LCM 压缩 → 保留摘要
         （位运算，快）   （浮点运算，慢）
```

**算力优化**：
- 先用排除法剪枝（位运算）
- 再对剩余内容压缩（浮点运算）

**输出**：
- `src/lcm_elimination_integration.py`（LCM 集成模块）
