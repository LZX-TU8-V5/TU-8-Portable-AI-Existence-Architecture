## 二、矩阵算法 × 认知框架

**不是五种工具，是五种认知方式**：

```
SVD     = 认知分解：把经验拆成相互正交的主成分，按重要性排序
         TU-8: 六维评分就是隐性的 SVD，cons/div/meaning = 隐性的 σᵢ

伪逆    = 认知决策：信息不足时，选所有可行解中"最安全/最短"的那个
         TU-8: 置信度低时给多个候选 = 伪逆的最小范数解

L2正则化 = 认知遗忘：小σ方向 = 不重要的/噪声的，直接软截断
         TU-8: 遗忘机制 ≈ σᵢ/(σᵢ²+λ) 形式

NMF     = 认知建构：只能叠加，不能相互否定，子结论只能强化
         TU-8: 六维评分天然非负 → 推理链应禁止相互否定

DAG     = 认知时间：时间戳 → 因果拓扑，按需追溯，不读全历史
         TU-8: 时间锚点是孤立的，需要串联成链
```

**公式汇总**：

```
信息密度  = Value × Confidence × e^(-λ·Δt)
遗忘倾向  ≈ σᵢ / (σᵢ² + λ)
过拟合线  = σᵢ→0 时 1/σᵢ→∞
NMF约束  = W≥0, H≥0（只能加法组合）
SVD截断  = UₖΣₖVₖᵀ  (k << n)
```
