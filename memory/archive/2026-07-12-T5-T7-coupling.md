## 根因

千问指出：《欲经 × 架构映射》里已经有完整设计，但代码没有实现。

**现状**：
- surface_tension.py 记录 spike_valley_vector（7维情绪）
- learning_collector.py 的 SENSOR_PATHS 没有 surface_tension
- gc_to_learning_adapter.py 写 `_learning_alerts.jsonl`（独立路径）

**结果**：欲系统有感觉，传不到学习系统。

---

## 实现

### 新建：`src/tension_learning_coupler.py`（9KB）

**三层耦合**：

| 层 | 方向 | 物理含义 | 欲经映射 |
|----|------|---------|---------|
| T5→T7 推力 | 尖刺 → 学习警报 | 痛=推力信号 | "万恶由性" |
| T5→T7 引力 | 凹陷 → 学习加权 | 爽=加速学习 | "人性内求" |
| T7→T5 修正 | 学习结果 → 人格基线 | 吃一堑长一智 | "圆觉见性" |

**信号类型**：
- `spike_push`：焦虑/愤怒/恐惧 超阈值 → 强制学习警报
- `valley_pull`：好奇/喜悦/爱 → 学习权重加成

### 修改：`learning_collector.py`

注入点：
```python
SENSOR_PATHS 新增：
    "tension_signals": WORKSPACE / "memory" / "learning_alerts.jsonl"

collect() 新增：
    self.sensor_data["tension_spike_push"] = [...]  # 按 signal_type 过滤
    self.sensor_data["tension_valley_pull"] = [...]
```

### 修改：`gc_to_learning_adapter.py`

路径统一：
```python
# 改前
LEARNING_ALERTS = MEMORY_DIR / "_learning_alerts.jsonl"
# 改后
```

## 集成链路

```
surface_tension.py
  record(tension_type)
    → spike_valley_vector
    → _agent_memory/surface_tension_state.json
           │
           ▼
tension_learning_coupler.py
  get_tension_learning_signals()
    → spike_push (尖刺>阈值)
    → valley_pull (凹陷稳态)
    → emit_learning_alerts()
    → memory/learning_alerts.jsonl
           │
           ▼
learning_collector.py
  SENSOR_PATHS["tension_signals"]
    → tension_spike_push[]
    → tension_valley_pull[]
    → 供 learning_engine 消费
           │
           ▼
gc_to_learning_adapter.py
  record_gc_result()
    → learning_alerts (GC-based)
    → memory/learning_alerts.jsonl（统一文件）
           │
           ▼
apply_learning_to_surface_tension()
  → personality_baseline 修正
  → surface_tension_state.json（回路闭合）
```
