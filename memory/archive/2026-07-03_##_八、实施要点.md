## 八、实施要点

### 8.1 标签层级化

**上下文状态标签树**：
```
L1: {任务相关, 任务无关} ← 互斥
    ├── L2(任务相关): {高优先, 中优先, 低优先}
    └── L2(任务无关): {闲聊, 噪声, 广告}
```

### 8.2 阈值标定

**方法**：
- 用历史对话数据统计各维度的分布
- 取 μ-3σ 作为排除边界

### 8.3 日志记录

**记录排除路径**：
```
[L1: 相关性✅] → [L2: 时效性✅] → [L3: 冗余性❌] → 终止
```

**用途**：后续优化排除顺序和阈值

### 8.4 兜底机制

**当所有路径都被排除**：
- 标记"未知/新类别"
- 保存原始数据
- 作为未来扩展的种子样本

千问说：
> 幅度谱编码光照/纹理，相位谱编码几何。实现"几何-纹理"天然解耦。

**映射到认知**：

| 视觉频域 | 认知频域 |
|---------|---------|
| 幅度谱（光照/纹理） | 情绪、语气、表达方式 |
| 相位谱（几何） | 核心语义、事实、逻辑 |

**吸收思路**：
- 在记忆写入时，区分"相位"（核心事实）和"幅度"（情绪色彩）
- 检索时，可以用"相位匹配"找逻辑相关，"幅度匹配"找情绪相似

**但这可能过度复杂化。更实用的思路**：
- 当前 MEMORY.md 和 memory/*.md 已经在做"语义压缩"
- 问题在于：没有区分"什么是噪声"

**L0梯度可以回答这个问题**：
> 噪声 = 梯度小的区域（无认知转折）
> 信号 = 梯度大的区域（有认知转折）
