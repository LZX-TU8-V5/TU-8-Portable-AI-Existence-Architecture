## 三、第二步：绕过atan2的相位旋转

### 3.1 传统做法的致命缺陷

```
α = atan2(v, u)  // 跨越2π时产生数值跳变 → GPU分支 → 黑色裂缝
```

---

### 3.2 架构师的降维打击

> **我们不需要知道"角度"是多少，我们只需要知道旋转后的复数坐标！**

在傅里叶合成中，**相位的加法等价于复平面上单位向量的乘法**。

---

### 3.3 复数旋转因子Z

引入深度调制频率 k（控制嵌套层数），计算基础旋转的正余弦：

```
Cw = cos(θ + k·w)
Sw = sin(θ + k·w)
```

执行复数乘法（将投影坐标(u, v)旋转 θ + kw）：

```
Z_real = u·Cw - v·Sw
Z_imag = u·Sw + v·Cw
```

---

### 3.4 工程意义

| 特性 | 说明 |
|------|------|
| Z 就是 e^(iΔΨ) 的代数等价物 | 天然携带角度θ和深度w的螺旋缠绕信息 |
| 全程运算 | 加减乘除 + 一次sincos |
| if数量 | 0 |
| atan2数量 | 0 |
