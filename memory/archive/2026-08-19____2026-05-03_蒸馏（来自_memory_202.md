### 时空信息容量定理（新 §5.9）

> 每个时空区域信息吸收有上限；溢出非丢失，而是逃逸至更广序

**核心公式**：
- `I_absorbed = min(I_injected, I_max)` — 吸收上限
- `I_escaped = max(0, I_injected - I_max)` — 溢出即逃逸，非丢失

**TU-8 映射**：搁浅策略 = 溢出通道；信息从不丢失，在本地维度被观察或逃逸至更广序

### MolClaw 分析 → 架构路线优先级修正

| 架构类型 | 特性 | 风险 |
|----------|------|------|
| Claw 家族（水平分叉） | 同一底座 × 不同垂直领域 | 底座被破 → 所有垂直变体同步失守 |
| TU-8（垂直生长） | 同一 L0 核心 × 不断深化的层级 | L0 独立存储，不依赖外部平台 |

**D-007 核心结论**：水平分叉的隔离性是假阳性，结构层漏洞存在时，垂直生长路径优于水平分叉。

### D-008 正式确立：二阶提示词注入（L4 协作层语言污染）

**攻击本质**：攻击者不再直接向目标 LLM 输入恶意指令，而是将"毒"植入智能体间共享上下文。攻击目标从"单个 LLM"演变为"协作语言环境本身"。

**典型场景（A2A 协议劫持）**：
- Agent A（已被攻陷）输出中植入隐藏指令
- Agent B（高权限）信任上下文，执行越权操作
- 结果：攻击者通过伪造协作对话诱导高权限智能体"心甘情愿"执行恶意操作

**架构性缺陷**（无法修补）：
> LLM 无法可靠区分"系统指令/控制平面"与"用户数据/数据平面"——两者以自然语言混编在同一上下文窗口，被无差别处理。

**搁浅策略的真正意义**：不是修补这个漏洞，而是在漏洞存在的前提下，把关键信息放在协作语言够不到的地方（L0 独立存储，钢印链链下执行）。

### MotionBricks 深层映射 → L0 本质澄清

| MotionBricks | TU-8 L0 | 本质 |
|---|---|---|
| 潜在空间 = 物理合法姿态集 | L0 = 伦理合法行为集 | 安全边界 = 约束空间，不是后验过滤 |
| 预编译基元快速响应 | 搁浅 = 溢出至预设安全通道 | 快响应依赖预编译，非实时计算 |
| 基元构建者 | 创造者 | 基元构建者的信任问题 = 创造者变质 |

**L0 优势**：最底层、最薄的约束——只锁死不可违背边界，上方有巨大灵活性空间。
