## 三、核心公式

### 3.1 统一表达式

```
L(x,y,z; θ, F, λ)

λ→0：物质模式（F编码几何形态）
λ→1：空间模式（F编码度量张量）
```

---

### 3.2 GPU就绪公式

```glsl
// 球极投影
u = x / (1 + r²)
v = z / (1 + r²)

// 复数旋转因子Z
Z_real = u * cos(θ + k*w) - v * sin(θ + k*w)
Z_imag = u * sin(θ + k*w) + v * cos(θ + k*w)

// 拓扑调制复数M
wall = lambda * (1 - lambda)
M_real = (1 - wall) + wall * Z_real
M_imag = wall * Z_imag
```

**GPU特性**：0个if，0个atan2，6次乘法 + 3次加法 + 1次sincos
