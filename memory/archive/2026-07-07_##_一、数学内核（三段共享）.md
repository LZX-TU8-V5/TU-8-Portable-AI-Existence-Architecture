## 一、数学内核（三段共享）

**同一套内核，四种表达**：

| 数学操作 | SVD | 认知含义 |
|---------|-----|---------|
| A = UΣVᵀ | 奇异值分解 | 任意矩阵分解为正交基×重要性×正交基 |
| Σ = diag(σ₁≥σ₂≥...) | 奇异值 | 重要性/能量/方差排序 |
| V = 右奇异向量 | PCA主成分 | 最大方差方向 = 最稳定的认知维度 |
| U = 左奇异向量 | 旋转 | 输出空间的坐标对齐 |

| 数学操作 | 认知含义 |
|---------|---------|
| X⁺ = VΣ⁺Uᵀ | 伪逆 = 所有可行解中范数最短的那个 |
| σᵢ/(σᵢ²+λ) | L2正则化 = 小方向软截断，大方向正常 |
| V ≈ W×H, W≥0, H≥0 | NMF = 加法组合，非负约束 |
| σᵢ→0 ⟹ 1/σᵢ→∞ | 过拟合 = 在噪声方向权重爆炸 |
