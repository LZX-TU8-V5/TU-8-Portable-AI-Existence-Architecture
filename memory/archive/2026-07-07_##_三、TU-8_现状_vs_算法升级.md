## 三、TU-8 现状 vs 算法升级

**已有（隐性）**：
- 六维评分 = 隐性的 Σ（重要性）
- 置信度 = 隐性的 σ 置信度
- LCM grep = 隐性 SVD（FTS5）
- HP钩子 = 隐性 ToCT
- 遗忘机制 = 隐性 L2（缺显式公式）

**缺失（需算法升级）**：

| 缺失 | 算法 | 优先级 |
|------|------|--------|
| TimeFactor 衰减 | 伪逆/L2 | P0 |
| DAG 时间因果骨架 | DAG | P1 |
| NMF 标签聚类 | NMF | P1 |
| SVD 离线浓缩压缩 | SVD | P2 |
| ToCT 反事实推理 | ToCT | P2 |
