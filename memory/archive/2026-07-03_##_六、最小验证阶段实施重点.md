## 六、最小验证阶段实施重点

### 6.1 层间接口协议

**认知请求包**：
```json
{
  "roi_bbox": [...],
  "coarse_label": "bearing",
  "confidence": 0.65,
  "required_attributes": ["material", "internal_hollow"]
}
```

**规则**：第二层只响应包含`required_attributes`的请求。

### 6.2 物理感受数字化

| 条件 | 量化指标 |
|------|---------|
| 抓稳 | 力传感器读数方差 < τ_force |
| 转速稳定 | 编码器速度波动 < τ_rpm |

**规则**：双条件同时满足，才打开三维傅里叶引擎的数据闸门。

### 6.3 模拟具身验证

**无真实机械臂时**：
- 用转台+夹具模拟"受控旋转"
- 用手持力传感器模拟"抓取确认"
- 验证三维傅里叶引擎在理想物理条件下的认知上限

### 6.4 联合数据集

**记录四元组**：
```
{视觉帧, 物理状态, 旋转序列, 最终标签}
```

**价值**：这是未来训练端到端具身认知模型的黄金数据。
