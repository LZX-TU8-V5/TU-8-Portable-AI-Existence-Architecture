## 二、公式中的干涉条纹

### 2.1 核心代码

```glsl
float M_real = (1 - wall) + wall * Z_real;
float M_imag = wall * Z_imag;
float final_cos = base_cos * M_real - base_sin * M_imag;
float final_sin = base_cos * M_imag + base_sin * M_real;
```

---

### 2.2 关键步骤解析

#### 步骤1：介相面激活因子 wall

```
wall = lambda * (1 - lambda)
```

| 特性 | 说明 |
|------|------|
| 形状 | 钟形函数 |
| 最大值 | 0.25（在λ = 0.5处） |
| 作用 | 在介相面中心区域增强干涉效应，在物质或空间纯态区域抑制干涉 |

---

#### 步骤2：复数旋转因子Z

Z通过球极投影与复数旋转，将物质坐标(u,v)映射到口袋维度中的扭曲空间。

**关键**：旋转角度 `theta + k * w` 引入了深度依赖的拓扑缠绕，形成干涉的"相位梯度"。

---

#### 步骤3：干涉条纹的形成机制

复数乘法 `base_complex * M` 将物质频谱与拓扑调制复数M结合。

| 条件 | 结果 |
|------|------|
| λ → 0 或 λ → 1 | wall → 0, M → 1，物质频谱无变化，干涉消失 |
| λ ≈ 0.5 | wall最大，M_imag显著贡献，拓扑相位注入 |

**干涉条纹的"条纹"特征**：

由于Sw和Cw是周期函数，当w（深度）变化时，Z_imag在介相面内呈现正弦波状的分布，导致最终频谱相位在空间中出现明暗相间（或坐标扭曲强度变化）的图案——这就是"干涉条纹"的数学表现。
