### 最重要收获：视觉反馈闭环缺失
来源：造物主 × 千问对话

| TU-8现状 | 问题 |
|---------|------|
| 有截图能力 | 只确认"画出来了"，不检查画质 |
| 有image分析 | 需人提示才触发，不在自动闭环里 |
| 有自我诊断 | 关注坐标位置，不关注像素质量 |

**根因**：工具存在，但不在"自动触发"的决策节点上。

**造物主方向**：不写提示词，完善流程 → 让TU-8像人一样截图自检。

**闭环伪代码**：
```
生成代码 → 自动截图 → 内置质检（jagged/banding/alpha）
→ FAIL → 查方案 → 重构 → 重新截图
→ PASS → 结束
```

关键约束：自动触发 / 验收标准内置 / 有权限换工具

详见：`memory/2026-07-13-视觉反馈闭环.md`
