## 三、关键概念定义

### 3.1 空间语言

```
空间语言 = 锚点（词汇）+ 角度（语法）+ 傅里叶（词义）
```

| 要素 | 数学对应 | 功能 |
|------|---------|------|
| 锚点 | 局部坐标卡原点 | 拓扑结构的骨架节点 |
| 角度 | 转移函数与联络 | 相邻形态的过渡规则 |
| 傅里叶 | 局部形态基底函数 | 几何频谱特征 |

---

### 3.2 本体论权重λ

```
L(x,y,z; θ, F, λ)

λ→0：物质模式（F编码几何形态）
λ→1：空间模式（F编码度量张量）
```

---

### 3.3 传送门背面

> **传送门的背面，就是你的空间语言在谈论它自己。**
>
> **不是反物质，是纯度量场 / 拓扑势阱。**
