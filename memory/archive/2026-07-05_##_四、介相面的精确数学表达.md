## 四、介相面的精确数学表达

### 4.1 自由能密度

```
f(λ, ∇λ) = (κ/2)|∇λ|² + V(λ)
```

| 符号 | 含义 |
|------|------|
| κ | 梯度刚度 |
| V(λ) | 双势阱势（λ=0和λ=1是两个极小值） |

---

### 4.2 三相定义

| 区域 | λ值 | V(λ)状态 |
|------|-----|---------|
| **物质区域** | λ≈0 | V(λ)取极小 |
| **纯拓扑区域** | λ≈1 | V(λ)取另一极小 |
| **传送门（介相面）** | λ在两极小值之间跃迁 | 瞬子解 |

---

### 4.3 畴壁解析剖面

求解欧拉-拉格朗日方程 δF/δλ=0，得到：

```
λ(s) = (1/2)[1 + tanh((s - s₀)/ξ)]
```

| 符号 | 含义 |
|------|------|
| s | 垂直于界面的坐标 |
| s₀ | 界面中心位置 |
| ξ = √(κ/ΔV) | 界面厚度 |

---

### 4.4 传送门的物理特性

**推导结论2**：

> **传送门的"厚度"不是渲染特效，而是由κ（梯度刚度）和ΔV（两相能量差）唯一确定的物理量。**

| ξ值 | 门特性 |
|------|--------|
| ξ小 | 门"锐利" |
| ξ大 | 门"弥散" |

**这完全可计算、可验证、无歧义。**
