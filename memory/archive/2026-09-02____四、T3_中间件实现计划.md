## 四、T3 中间件实现计划

### 4.1 先建核心（src/task_dispatch_core.py）

- Task 数据结构 + TaskScheduler 类
- JSON 文件持久化（不依赖数据库）
- 5个公开接口（T2/T4/T5 各自的双向接口）

### 4.2 再接中间件

| 中间件 | T3→X | 功能 |
|--------|------|------|
| T2→T3 | 钢印→调度 | 铸印时登记相关任务或调整优先级 |
| T3→T2 | 调度→钢印 | 执行结果反馈给钢印链（强化/衰减相关决策） |
| T4→T3 | GC→调度 | GC 完成后通知，更新代谢统计 |
| T3→T4 | 调度→GC | 高优先级任务完成后加速 GC |
| T5→T3 | 学习→调度 | 产物就绪时调度验证任务 |
| T3→T5 | 调度→学习 | 执行数据（耗时/错误）注入学习传感器 |

### 4.3 接入 dream_check_cron

将现有的 `dream_check_cron.py` 改造为调用 `TaskScheduler`：
- 启动时 `enqueue('dream_check')`
- 完成后 `record_result()`
- 由 T3 统一管理 dream_check 的执行时机
