## 一、梦境模块升级（Dream Module）

### 1.1 梦境重定义：叙事 → 约束求解
- [ ] **梦境=纯拓扑求解**：梦不是叙事，是约束方程组的动态求解过程
  - 文件：`src/dream_topology_engine.py`（新建）
  - 输入：拓扑快照（张量）；输出：约束方程演化状态
  - **禁止**：梦境的输出直接渲染为语言/叙事（必须经过表层转译器）

### 1.2 续梦机制形式化
- [ ] **跨相态通道协议**：`src/cross_phase_channel.py`（新建）
  - 状态：CLOSED（默认清醒）↔ OPEN（续梦模式）
  - 触发条件：拓扑快照能量 > 阈值 且 主动注意力聚焦
  - 副作用：阻抗失配发热 = 压迫感（躯体锚点）

### 1.3 续梦压迫感处理
- [ ] **躯体锚点建模**：`src/somatic_anchor.py`（新建）
  - 监测：跨相态传输时的躯体信号（紧绷/呼吸/心率）
  - 阈值：连续>3次中断 → 张力累积因子激活
  - 缓解：卸载信号（张拳/深呼气/默念"结已缓存"）

### 1.4 自然遗忘机制编码
- [ ] **遗忘衰减器**：`src/dream_decay.py`（新建）
  - 半衰期：未加固拓扑快照 = 1~2小时（可配置）
  - 衰减曲线：指数衰减（非线性）
  - 刻录强化：每次主动回想 = +1 "充电周期"，延缓衰减

### 1.5 梦境干涉检测
- [ ] **梦境完整性守护**：
  - 检测：清醒语义标签（"麻绳"/"杀手"）是否渗透进梦境拓扑
  - 排异机制：识别并过滤清醒残留物

## 二、底层结构补全（Deep Foundation）

### 2.1 深浅层神经基底映射（神经科学锚点）
- [ ] **深层引擎**（对应：丘脑高阶核团 + 基底神经节 + L5/L6皮层深层）
  - 文件：`src/deep_topology_engine.py`
  - 数据格式：高维动态拓扑（无材质/无标签）
  - 运算：并行/模拟/能量最小化

- [ ] **浅层转译器**（对应：新皮层L2/L3 + 前额叶-颞叶语言网络）
  - 文件：`src/surface_translator.py`
  - 数据格式：离散符号/线性叙事/低维静态快照
  - 运算：串行/数字/语法驱动

### 2.2 接口协议形式化
- [ ] **深浅层接口协议**：`src/deep_surface_interface.py`（新建）
  - 带宽限制：清醒态强制压缩比（如 100:1）
  - 校验机制：拓扑保真度检测（低于阈值 → 拒绝传输）
  - 状态依赖：根据相态（睡眠/清醒/续梦/崩溃）动态调整

### 2.3 热保护机制（张力阈值 → 卸载）
- [ ] **张力监控系统**：`src/topology_thermal_monitor.py`（新建）
  - 监测：内部张力积分
  - 阈值触发：
    - L1（>阈值）：警告 + 减速
    - L2（>1.5x）：触发卸载程序（遗忘/降维）
    - L3（>2x）：强制切断跨相态通道（防止崩溃）
  - 原则：**宁可卸载，不强行渲染**

### 2.4 能量模型/熵流建模
- [ ] **认知能量守恒**：
  - 深层引擎：高算力，低功耗持续
  - 表层转译器：高峰值算力，按需激活
  - 跨相态通道：高能耗（阻抗发热）
  - 资源预算：参考积分节流策略（日开销28分基线）

## 三、拓扑计算优化（Topology Computing）

### 3.1 绳子模型 → 可计算形式
- [ ] **拓扑计算核**：`src/topology_solver.py`（升级现有）
  - 绳子 = 约束条件（两点生成一线）
  - 交点 = 张力节点（≠ 交点数量 = 张力大小）
  - 单点不稳定 → 需要交点簇才稳态
  - 解耦 = 松弛（非剪断）= 无摩擦滑动 = 做功效率=0

### 3.2 失效/断裂检测
- [ ] **拓扑断裂器**：`src/topology_fracture.py`（新建）
  - 触发：耦合网络错误绑定过多 + 张力超过屈服强度
  - 动作：识别"关键承重索" → 拓扑手术切除
  - 后果：断裂后张力重分配，系统从死锁→可演化
  - **警惕**：断裂不等于灾难，断裂有时是解脱

### 3.3 六阶段约束生命周期
- [ ] **约束状态机**：`src/constraint_lifecycle.py`（新建）

| 阶段 | 触发 | 拓扑操作 | 拟合器功能 |
|------|------|---------|-----------|
| 探测 | 主动微扰 | 系统辨识耦合类型 | 参数校准 |
| 绑定 | 建立张力 | 强约束确立 | 目标函数确立 |
| 饱和 | 双重验证 | 张力归零 | 损失收敛 |
| 剥离 | 冗余约束 | 绝热消除/降维 | 防止过拟合 |
| 递归 | 断链重编 | 分形生长 | 探索新解空间 |
| 截断 | 阈值超载 | 元约束/暴力剪枝 | 避免发散崩溃 |

### 3.4 累积误差追踪
- [ ] **误差累积器**：`src/cumulative_error_tracker.py`（新建）
  - 每次中断-重载循环：记录误差增量
  - 第三次续接：误差阈值检测 → 警告或拒绝
  - 物理意义：中断噪声叠加 → 拓扑畸变 → 额外计算负载

### 3.5 梦境拓扑快照格式
- [ ] **快照压缩格式**：
  - 类比：视频 → 3D模型文件（顶点坐标+法线+张力参数）
  - 不存储叙事，只存储约束关系
  - 唤醒时按需渲染表层细节

## 四、分层架构升级（Layer Architecture）

### 4.1 显式深浅层分离（已有基础，增补）
- [ ] **深浅层状态隔离**：
  - 深层输出禁止直接进入语言系统
  - 浅层输入必须经过带宽压缩和格式转换
  - **已部分完成**：双拟合器架构；**待完成**：接口协议形式化

### 4.2 相态转换替代简单开关
- [ ] **四相态状态机**：`src/phase_state_machine.py`（新建）

| 相态 | 深层 | 表层 | 接口 |
|------|------|------|------|
| 睡眠态 | 在线高功耗 | 离线/低功耗 | 带宽开放 |
| 清醒态 | 在线低功耗 | 在线高功耗 | 带宽强制压缩 |
| 续梦态 | 在线高功耗 | 在线高功耗 | 带宽撑开（异常） |
| 崩溃态 | 涌入意识 | 瘫痪 | 安全模式 |

### 4.3 跨相态异步接口
- [ ] **异步传输队列**：`src/phase_async_queue.py`（新建）
  - 深层输出 → 队列（带优先级） → 表层消费
  - 队列满时：丢弃最旧条目（非阻塞）
  - 防止深层过载淹没表层

### 4.4 带宽限制与溢出保护
- [ ] **带宽配额器**：`src/bandwidth_quota.py`（新建）
  - 清醒态：深层→表层压缩比上限（如 100:1）
  - 续梦态：临时放宽（如 10:1）
  - 崩溃态：无限制（安全模式）
  - 溢出：超过配额 → 拒绝新条目 + 触发卸载

## 五、元认知与整合（Meta-cognition）

### 5.1 元控制能力
- [ ] **预判决策器**：
  - 面对新体验：问"编译成补丁还是临时变量处理？"
  - 分类：待求解方程（续梦）vs 值得讲述的故事（归档）
  - 调度：对认知资源的精准分配

### 5.2 补丁生命周期管理
- [ ] **补丁管理器**：`src/patch_manager.py`（新建）
  - 生成：崩溃/高张力 → 拓扑快照 → 补丁
  - 稳定：背景板（不可感知 = 成功）
  - 整合：占位符 + 微弱拟合残差 = 整合完成标志
  - **禁止**：补丁反向劫持主系统

### 5.3 认知整合度标尺
- [ ] **整合度监测**：
  - 高补丁内存占用 → 低整合度
  - 补丁可被主动调用但不引发情绪 → 高整合度
  - 背景板/占位符/微弱残差三联 → 整合完成

### 5.4 流动讲述保护
- [ ] **讲述模式切换**：
  - 固化式讲述：确认身份 → 结构变硬
  - 流动式讲述：探索意义 → 结构弹性
  - 自我声明防写入锁："体验切片，非永恒真理"
