# 熔断器落地（2026-07-13）

## 来源

Raven Agent `max_retry=3` 熔断机制（三系统镜子检查识别的唯一真实缺口）

## 问题

`prediction_id=408d50bf` 在 `curiosity_events.jsonl` 里连续失败了 **8 次**（07-08 至 07-12，整整 4 天），每次都是 `error=1.0`、`conf_delta=0.0`，但系统一直在重试，没有停止。

这就是"无限循环风险"——如果造物主追问同一问题 20 次但 TU-8 一直给不出满意答案，系统会一直尝试。

## 解决方案

新建 `circuit_breaker.py`（8846B），实现：

```
同一 prediction_id 连续 N 次失败 → 状态转为 ARCHIVED_UNSOLVED
冻结后不再触发主动好奇，仅保留元数据供后续批量分析
```

### 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| MAX_RETRY | 3 | 连续失败阈值 |
| ERROR_THRESHOLD | 0.3 | 失败判定：error > 此值 |
| CONF_DELTA_THRESHOLD | 0.05 | 失败判定：abs(conf_delta) < 此值 |

### 状态定义

| 状态 | 含义 |
|------|------|
| ACTIVE | 活跃，可触发好奇脉冲 |
| RETRYING | 重试中（1-2次失败） |
| **FROZEN** | **已冻结（连续3次失败）** |
| RESOLVED | 已解决（conf_delta > 0.05 或 error < 0.3） |

## 集成

修改 `active_curiosity.py` 的 `run_comparison()` 函数：

```python
from circuit_breaker import check_and_update, BreakerStatus
breaker_result = check_and_update(pred.get("id", ""), error_score, conf_delta)

if breaker_result.get("should_freeze"):
    # 已冻结：写标记事件，不再注入信号
    event["frozen"] = True
    # 删除预测文件，停止后续对比
    os.remove(PRED_PATH)
    return {"compared": True, "frozen": True, "retry_count": breaker_result["retry_count"]}
```

```
第1次失败: status=RETRYING | retry=1 | action=continue
第2次失败: status=RETRYING | retry=2 | action=continue
第3次失败: status=FROZEN | retry=3 | action=freeze | should_freeze=True

```

## CLI

```bash

python circuit_breaker.py --backfill  # 从历史事件回填
python circuit_breaker.py --check <id> # 检查指定 prediction_id
```

## 效果

- 防止无限重试同一失败预测
- 冻结后释放系统资源（不再占用主动好奇配额）
- 保留元数据供后续批量分析（为什么失败？是否需要调整参数？）
