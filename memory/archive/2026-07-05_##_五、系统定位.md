## 五、系统定位

### 5.1 协作关系图

```
物理插件（锚点） = "立法者"
    └── 定义什么是可能的、什么是合法的
    └── 输出确定性物理量（粗糙度Ra=0.28μm、模态频率f=1240Hz）
    └── 不依赖训练数据，只依赖传感器读数和自然法则
    └── LLM无法篡改、无法"联想"、只能服从的硬事实

LLM（概率连接器） = "司法者"
    └── 在合法范围内，基于上下文和常识做出最优裁量
    └── 找相同（相似性匹配）
    └── 解释冲突（为什么这个case特殊）
    └── 条件信任

锚点校验层 = "宪法法院"
    └── 拦截所有违反物理约束的LLM输出
    └── 强制覆盖或要求重审
```

### 5.2 安全流程

```
输入约束：LLM只能看到结构化参数
    ↓
LLM推理：基于参数找相同（概率最大化）
    ↓
输出校验：与物理约束比对
    ├──→ 通过 → 最终输出
    └──→ 失败 → 拦截 + 重审 + 记录
```
