## 二、核心重构：从"双通道"到"光场统一表征"

### 2.1 视角对比

| 传统分离视角 | 光场统一视角 |
|------------|-------------|
| 几何FTP = 形状信息 | 几何FTP = 光波的相位/振幅调制（由表面法向决定） |
| 色彩梯度 = 材质信息 | 色彩梯度 = 光波的光谱选择性反射率梯度（由BRDF决定） |
| 两路信号后期融合 | 两路信号是同一光场方程的不同分量 |
| 光照是干扰噪声 | 光照是承载信息的载体本身 |

### 2.2 关键推论

**千问洞见**：
> 人眼之所以能通过色彩渐变判断材质，正是因为大脑在无意识中解算了"光如何被该表面调制"。色彩梯度不是材质的属性，而是"**光-材交互事件**"的记录。

## 三、为什么是"色彩梯度"而非"绝对色彩"？

### 3.1 敏感性对比

| 采样维度 | 对材质敏感性 | 对光照鲁棒性 | 排除法价值 |
|---------|------------|------------|-----------|
| 绝对RGB/HSV均值 | 低（易受白平衡、阴影污染） | 极差 | 仅能做最粗材质大类预筛 |
| 色彩空间分布统计 | 中（可区分金属/非金属） | 一般 | L2层辅助排除，需严格光照标定 |
| 色彩梯度幅值/方向 | 高（直接反映表面微结构） | 强（梯度是局部差分） | L3层精细排除核心材质指纹 |
| 色彩-几何梯度相关性 | 极高（材质与结构耦合特征） | 极强 | 交叉验证终极判据 |

### 3.2 核心洞察

> 人眼识别材质时，依赖的从来不是像素的绝对颜色，而是颜色如何随视角、曲率、边缘变化。色彩梯度正是这种"变化率"的数学表达。

**例子**：
- 抛光金属球：色彩梯度集中在高光边缘，过渡锐利
- 哑光塑料球：色彩梯度全域平缓，噪声较高

## 四、工程落地：光场统一表征下的排除法升级

### 4.1 采样层：构建"光谱-空间联合差分张量"

**统一的光场微分算子**：

```
D_unified = [
    ∇_θ I_phase     // 几何调制（相位）
    ∇_θ C_spectral  // 光谱调制（色彩）
    Corr(∇_θ I_phase, ∇_θ C_spectral)  // 光-材耦合项
]
```

**关键点**：
- 三项在同一圈同心圆环上同步计算
- 共享自适应起止点
- **耦合项是关键**：编码"高光位置是否与几何边缘对齐"等光-材交互规律

### 4.2 排除层：用"光场一致性"替代"特征匹配"

**L3层验证逻辑**：

| 材质候选 | 光场一致性要求 |
|---------|---------------|
| 金属 | ∇_θ C_spectral 与 ∇_θ I_phase 高度相关，光谱梯度集中在高频（镜面反射主导） |
| 哑光塑料 | 二者弱相关，光谱梯度全域低频平缓（漫反射主导） |
| 异常/伪造 | 耦合项偏离该类材质的物理先验范围 → 立即排除 |

**算力优势**：一次联合张量比对同时完成几何验证、材质验证、真伪验证三重任务。

## 六、色彩梯度与几何的协同

### 6.1 自适应起止点共享

> 色彩梯度与几何信号共享由傅里叶相位定义的自适应起止点。

### 6.2 额外校验

> 若某圈几何信号闭合但色彩梯度在闭合点处出现突变 → 标记为"接缝/涂装边界" → 触发L3层的"复合材质"分支验证。

**价值**：色彩梯度不仅用于材质分类，还能反向增强几何拓扑的理解（发现隐藏的装配缝）。

**方法**：改变光源色温/方向

**预期结果**：`geo_spectral_coupling_coeff` 比绝对色彩或单独几何梯度更稳定。
