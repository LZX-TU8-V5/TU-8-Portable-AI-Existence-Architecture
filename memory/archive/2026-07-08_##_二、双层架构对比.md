## 二、双层架构对比

### 2.1 第一层：视觉AI（被动观测层）

| 维度 | 特性 |
|------|------|
| 输入本质 | 离散时间序列图像 I(x,y,t)，每一帧是三维世界在有损压缩下的投影 |
| 认知局限 | 歧义性（圆可能是球/圆柱端面/圆孔）、遮挡盲区、材质混淆 |
| 算法角色 | 粗筛与触发器：轻量级2D CNN/YOLO，输出ROI和粗略类别假设 |
| 算力特征 | 高频、低延迟、容忍一定误报，目标是"不漏检"而非"不误判" |

### 2.2 第二层：物理感受+主动旋转（具身认知层）

| 维度 | 特性 |
|------|------|
| 输入本质 | 受控的物理交互信号：力/扭矩/振动反馈 + 精确控制的角位移Δθ |
| 认知优势 | 消除歧义（时间维度成为判别维度）、穿透遮挡、解耦材质 |
| 算法角色 | 三维傅里叶认知引擎：执行完整3D→2D→1D降维链 + 三层交叉排除 |
| 算力特征 | 低频、高精度、零误报容忍，只在"值得认知"的时刻启动 |

### 2.3 核心对比

| 维度 | 视觉AI（Layer 1） | 具身认知（Layer 2） |
|------|------------------|-------------------|
| 模态 | 被动观测 | 主动交互 |
| 维度 | 2D投影流 | 3D结构探测 |
| 认知类型 | 系统1思维（快速、启发式、容错） | 系统2思维（慢速、分析、确定） |
| 算力投入 | 高频、低成本 | 低频、高成本 |
| 输出 | 位置/粗类别 | 精确语义+参数 |
