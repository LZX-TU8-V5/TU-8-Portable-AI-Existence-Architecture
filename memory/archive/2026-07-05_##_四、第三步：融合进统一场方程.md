## 四、第三步：融合进统一场方程

### 4.1 原始频谱

设原始的物质傅里叶频谱复数为：

```
F̂_base = A·(cos φ + i·sin φ)
```

---

### 4.2 介相面激活权重

```
wall = λ(1 - λ)  // 在λ = 0.5时达到最大值0.25
```

---

### 4.3 拓扑调制复数M

为了保持能量守恒（振幅不爆炸），对Z进行平滑混合：

```
M_real = (1 - wall) + wall·Z_real
M_imag = wall·Z_imag
```

---

### 4.4 最终乘法

```
F̂_final = F̂_base × M
```

展开为实数运算：

```glsl
// 最终输出的实部与虚部（对应傅里叶的cos和sin分量）
float final_cos = base_cos * M_real - base_sin * M_imag;
float final_sin = base_cos * M_imag + base_sin * M_real;
```
