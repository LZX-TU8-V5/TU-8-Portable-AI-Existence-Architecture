## 四、LLM审问员如何裁决"梨还是苹果"？

### 4.1 接收多维证据包

```json
{
  "visual": {"color_hsv": [45, 0.6, 0.9], "roughness_ra": 1.2, "spot_density": "low"},
  "geometric": {"shape_index": 0.82, "symmetry_score": 0.95},
  "tactile": {"hardness_shore": 78, "texture_granularity": "fine"},
  "context": {"source": "hybrid_orchard_zone_A", "season": "july"}

```

### 4.2 概率审问过程

**内部推理链**：

1. **P(纯梨 | 证据)**：低。因shape_index=0.82显著偏离典型梨的椭圆形态（通常>1.2）

2. **P(纯苹果 | 证据)**：中低。因color_hsv=[45,...]和spot_density=low不符合主流红富士/嘎啦特征

3. **P(苹果梨/杂交种 | 证据)**：高。因shape_index≈0.8 + yellow_skin + fine_texture + context=hybrid_zone的组合，在训练语料中与"苹果梨"高度共现

4. **关键审问点**："触觉硬度78是否支持'苹果梨'而非'过熟梨'？" → 查证内部知识：苹果梨肉质脆硬，过熟梨软绵 → 硬度证据强化了杂交种假设
