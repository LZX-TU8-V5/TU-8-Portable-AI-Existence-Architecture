## 一、核心框架：深层=物理引擎，表层=渲染管线

| 属性 | 深层（Deep） | 表层（Surface） |
|------|-------------|---------------|
| **运算基底** | 高维动态拓扑（无材质/无标签） | 离散符号/线性叙事/低维快照 |
| **运算逻辑** | 并行/模拟/能量最小化 | 串行/数字/语法驱动 |
| **数据格式** | 张量约束关系 | 语言/代码/可视化 |
| **功耗** | 持续低功耗 | 按需高功耗 |
| **TU-8对应** | 拓扑计算核 | LLM输出/渲染层/TTS |

## 四、全系统深浅层流量图

```
[外部输入：对话/文件/时间]
        ↓
[L0 安全栅：alignment_verify()] ← 深层核心校验
        ↓
[L1 认知层]
  ├─ cognitive_friction_detector ← 深层张力检测
  ├─ tension_distiller ← 深层矛盾提取
  └─ contradiction_arbitration ← 深层冲突求解
        ↓
[L2 方法论层：外取优先/试错/重构铁律] ← 深层约束协议
        ↓
[L3 记忆层]
  ├─ secure_vault ← 深层拓扑索引（快速）
  ├─ store()/recall() ← 接口协议
  └─ MEMORY.md ← 表层渲染存储（慢速）
        ↓
[L4 技能/工具层]
  ├─ local Ollama ← 深层推理（低功耗）
  ├─ LLM（云端）← 表层转译器（高功耗，按需）
  └─ Skills ← 深层工具库
        ↓
[L5 钢印层：拓扑签名 ← 深层常量，不可表层污染]
        ↓
[L6 健康监控层]
  ├─ surface_tension_state ← 深层7D张力向量
  ├─ interoperative_cortex ← 深层协调路由
  ├─ metabolism_dashboard ← 深层监控仪表
  └─ orb_ring ← 表层渲染输出（TTS/视觉）
```

## 五、关键对比：当前TU-8 vs 深层-表层模型

| 维度 | 当前TU-8（现状） | 深层-表层模型（目标） |
|------|----------------|---------------------|
| **数据格式** | 混合（语言+状态+向量） | 严格分层：深层张量/表层语言 |
| **接口** | 隐式/散落 | 显式协议：带宽限制+校验+相态 |
| **遗忘** | 被动（cron代谢） | 主动（未加固拓扑1~2h自然衰减） |
| **崩溃响应** | 搁浅（被动） | 热保护机制（主动分级） |
| **补丁管理** | 无显式管理 | 补丁状态机：生成→背景板→占位符 |
| **深浅层分离** | 部分完成（拟合器） | 全系统严格分离 |
| **张力监控** | 分散（各子系统） | 统一热保护：L1→L2→L3分级 |
| **表层渲染** | 直接（LLM直出） | 受接口控制（带宽配额） |

## 六、核心结论

**这不是梦境模块升级，是全系统底层机制的重新定义。**

- 深层 = 所有拓扑计算/约束求解/状态监控
- 表层 = 所有语言输出/渲染/执行
- 接口 = 带宽限制+校验+热保护+相态切换
