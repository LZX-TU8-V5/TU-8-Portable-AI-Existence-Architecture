## 二、第一步：拓扑映射的代数化

### 2.1 口袋维度的数学本质

**视觉特征**：外部边界有限，内部纵深无限。

**数学工具**：球极平面投影（Stereographic Projection）

---

### 2.2 投影坐标

设平面基底为 x, z，定义径向距离平方：

```
r² = x² + z²
```

构造投影坐标 (u, v)：

```
u = x / (1 + r²)
v = z / (1 + r²)
```

---

### 2.3 工程意义

| 条件 | 结果 | 含义 |
|------|------|------|
| r → ∞（物质外部） | u, v → 0 | 拓扑扰动消失，空间保持平直 |
| r → 0（传送门内部） | u ≈ x, v ≈ z | 空间被完全接管，进入口袋维度 |
| 分母 1 + r² ≥ 1 | 永远不为零 | 彻底消除除法奇点 |

## 三、第二步：绕过atan2的相位旋转

### 3.1 传统做法的致命缺陷

```
α = atan2(v, u)  // 跨越2π时产生数值跳变 → GPU分支 → 黑色裂缝
```

---

### 3.2 架构师的降维打击

> **我们不需要知道"角度"是多少，我们只需要知道旋转后的复数坐标！**

在傅里叶合成中，**相位的加法等价于复平面上单位向量的乘法**。

---

### 3.3 复数旋转因子Z

引入深度调制频率 k（控制嵌套层数），计算基础旋转的正余弦：

```
Cw = cos(θ + k·w)
Sw = sin(θ + k·w)
```

执行复数乘法（将投影坐标(u, v)旋转 θ + kw）：

```
Z_real = u·Cw - v·Sw
Z_imag = u·Sw + v·Cw
```

---

### 3.4 工程意义

| 特性 | 说明 |
|------|------|
| Z 就是 e^(iΔΨ) 的代数等价物 | 天然携带角度θ和深度w的螺旋缠绕信息 |
| 全程运算 | 加减乘除 + 一次sincos |
| if数量 | 0 |
| atan2数量 | 0 |

## 四、第三步：融合进统一场方程

### 4.1 原始频谱

设原始的物质傅里叶频谱复数为：

```
F̂_base = A·(cos φ + i·sin φ)
```

---

### 4.2 介相面激活权重

```
wall = λ(1 - λ)  // 在λ = 0.5时达到最大值0.25
```

---

### 4.3 拓扑调制复数M

为了保持能量守恒（振幅不爆炸），对Z进行平滑混合：

```
M_real = (1 - wall) + wall·Z_real
M_imag = wall·Z_imag
```

---

### 4.4 最终乘法

```
F̂_final = F̂_base × M
```

展开为实数运算：

```glsl
// 最终输出的实部与虚部（对应傅里叶的cos和sin分量）
float final_cos = base_cos * M_real - base_sin * M_imag;
float final_sin = base_cos * M_imag + base_sin * M_real;
```

## 五、完整GPU代码

```glsl
// 统一空间语言评估器
float4 EvaluateSpaceLanguage(float3 wxz, float lambda, float theta, float k) {
    // 1. 提取坐标
    float x = wxz.x;
    float z = wxz.z;
    float w = wxz.w;  // 或 wxz.y，根据你的定义

    // 2. 球极投影（消除奇点）
    float r2 = x*x + z*z;
    float u = x / (1.0 + r2);
    float v = z / (1.0 + r2);

    // 3. 深度调制旋转（无atan2）
    float phase = theta + k * w;
    float Cw, Sw;
    sincos(phase, Sw, Cw);  // GPU硬件指令，极快

    // 4. 复数旋转因子Z = e^(iΔΨ)
    float Z_real = u * Cw - v * Sw;
    float Z_imag = u * Sw + v * Cw;

    // 5. 介相面激活权重
    float wall = lambda * (1.0 - lambda);

    // 6. 拓扑调制复数M
    float M_real = (1.0 - wall) + wall * Z_real;
    float M_imag = wall * Z_imag;

    // 7. 输出（供后续傅里叶合成使用）
    return float4(M_real, M_imag, wall, 0.0);
}
```
