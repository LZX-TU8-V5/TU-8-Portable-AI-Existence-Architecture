## 六、关键公式回顾

```glsl
// 介相面激活因子
float wall = lambda * (1 - lambda);

// 复数旋转因子Z（含拓扑相位）
float Cw = cos(theta + k * w);
float Sw = sin(theta + k * w);
Z_real = u * Cw - v * Sw;
Z_imag = u * Sw + v * Cw;

// 拓扑调制复数M
M_real = (1 - wall) + wall * Z_real;
M_imag = wall * Z_imag;

// 傅里叶合成（干涉叠加）
float final_cos = base_cos * M_real - base_sin * M_imag;
float final_sin = base_cos * M_imag + base_sin * M_real;
```
