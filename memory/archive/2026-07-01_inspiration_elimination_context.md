## 二、上下文拼接状态机的当前问题

### 2.1 正向拼接的问题

**当前做法**：
```
轮次1 → 提取语义 → 拼接到上下文
轮次2 → 提取语义 → 拼接到上下文
轮次3 → 提取语义 → 拼接到上下文
...
```

**问题**：
- 每轮都拼接 → 上下文膨胀
- 噪声/无关信息也被拼接
- 类似"正向检索"：检查所有特征，算力浪费

### 2.2 排除法思路

**改进做法**：
```
轮次1 → 提取语义 + 计算置信度
         ├──→ 置信度 < 阈值 → ❌ 排除（不拼接）
         └──→ 置信度 ≥ 阈值 → ✅ 保留（拼接）
轮次2 → 同上
...
```

**核心思想**：
> 不是"找最相关的"，而是"删不可能相关的"

## 三、排除法在上下文拼接中的应用

### 3.1 多层级排除

```
输入：新轮次对话
       ↓
L1: 相关性排除
       ├──→ 与当前任务无关 → ❌ 不拼接
       └──→ 与当前任务相关 → ✅ 进入下一层
              ↓
L2: 时效性排除
       ├──→ 过期信息（已被后续轮次覆盖） → ❌ 不拼接
       └──→ 有效信息 → ✅ 进入下一层
              ↓
L3: 冗余性排除
       ├──→ 与已拼接内容重复 → ❌ 不拼接
       └──→ 新增信息 → ✅ 进入下一层
              ↓
L4: 置信度排除
       ├──→ 置信度 < 阈值 → ❌ 不拼接（或降级处理）
       └──→ 置信度 ≥ 阈值 → ✅ 拼接
```

### 3.2 短路机制

**排除法的核心优势**：
> 任意一层排除，立即终止，不再检查后续层级

**例子**：
- L1 判断"与当前任务无关" → 直接跳过，不计算时效性/冗余性/置信度
- 类似视觉领域的"无sinc峰 → 排除棱柱类"

## 四、置信度的用法

### 4.1 置信度作为排除阈值

**千问思路**：
> 阈值τ不是固定值，而是从本地库中同类样本的统计分布（如μ±3σ）动态生成。

**TU-8应用**：
- 置信度阈值 = 历史成功拼接的平均置信度 - 3σ
- 动态调整：随着系统运行，阈值自动演化

### 4.2 置信度的计算

| 维度 | 计算方式 | 权重 |
|------|---------|------|
| 语义相关性 | 与当前任务的相似度 | 0.3 |
| 时效性 | 距离当前时间的衰减 | 0.2 |
| 新增性 | 与已拼接内容的差异度 | 0.3 |
| 来源可信度 | 说话者/渠道的可信度 | 0.2 |

**综合置信度**：
```
Conf = 0.3×Rel + 0.2×Time + 0.3×Novel + 0.2×Trust
```

### 4.3 置信度区间处理

**模糊边界**：
> 当置信度处于边界附近（如距边界<10%区间宽度）时，不直接排除，标记为"待验证"

**TU-8应用**：
- 置信度 ∈ [阈值-10%, 阈值] → 标记"待验证"，触发二次确认
- 置信度 < 阈值-10% → 排除
- 置信度 ≥ 阈值 → 拼接

## 五、位掩码加速的映射

### 5.1 状态编码

**视觉领域**：
- 200-bit 向量表示标签
- 位运算快速排除

**TU-8映射**：
- 对话状态编码为位掩码
- 每个bit代表一个状态维度

**状态维度示例**：
```
[任务相关, 时效性, 冗余性, 置信度, 情绪, 意图, ...]
[  1,      1,     0,      1,    0.8,  0.9,  ...]
```

### 5.2 批量排除

**应用场景**：
- 多轮对话同时到达（群聊场景）
- 批量处理时，用位运算同时排除多条

## 六、动态剪枝顺序

**千问思路**：
> 让最高置信度的特征最先执行排除，最大化早期剪枝效果。

**TU-8应用**：

| 场景 | 优先排除层 |
|------|----------|
| 任务明确 | L1（相关性）前置 |
| 时间敏感 | L2（时效性）前置 |
| 信息过载 | L3（冗余性）前置 |
| 信任敏感 | L4（置信度）前置 |

**策略**：
- 根据当前对话状态，动态调整排除顺序
- 最高置信度的维度最先检查

## 七、与 LCM 的关系

**LCM (Lossless Context Management)**：
- 当前 LCM 做的是"压缩"（类似L2平滑）
- 可以引入"排除法"做"剪枝"（类似L0梯度）

**改进方向**：
```
当前：LCM 压缩 → 保留摘要
改进：LCM 排除 → 先剪枝再压缩
```

**算力节省**：
- 先用排除法剪枝（位运算，快）
- 再对剩余内容压缩（浮点运算，慢）
