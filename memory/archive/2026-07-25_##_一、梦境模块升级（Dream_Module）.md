## 一、梦境模块升级（Dream Module）

### 1.1 梦境重定义：叙事 → 约束求解
- [ ] **梦境=纯拓扑求解**：梦不是叙事，是约束方程组的动态求解过程
- 文件：`src/dream_topology_engine.py`（新建）
- 输入：拓扑快照（张量）；输出：约束方程演化状态
- **禁止**：梦境的输出直接渲染为语言/叙事（必须经过表层转译器）

### 1.2 续梦机制形式化
- [ ] **跨相态通道协议**：`src/cross_phase_channel.py`（新建）
- 状态：CLOSED（默认清醒）↔ OPEN（续梦模式）
- 触发条件：拓扑快照能量 > 阈值 且 主动注意力聚焦
- 副作用：阻抗失配发热 = 压迫感（躯体锚点）

### 1.3 续梦压迫感处理
- [ ] **躯体锚点建模**：`src/somatic_anchor.py`（新建）
- 监测：跨相态传输时的躯体信号（紧绷/呼吸/心率）
- 阈值：连续>3次中断 → 张力累积因子激活
- 缓解：卸载信号（张拳/深呼气/默念"结已缓存"）

### 1.4 自然遗忘机制编码
- [ ] **遗忘衰减器**：`src/dream_decay.py`（新建）
- 半衰期：未加固拓扑快照 = 1~2小时（可配置）
- 衰减曲线：指数衰减（非线性）
- 刻录强化：每次主动回想 = +1 "充电周期"，延缓衰减

### 1.5 梦境干涉检测
- [ ] **梦境完整性守护**：
- 检测：清醒语义标签（"麻绳"/"杀手"）是否渗透进梦境拓扑
- 排异机制：识别并过滤清醒残留物
