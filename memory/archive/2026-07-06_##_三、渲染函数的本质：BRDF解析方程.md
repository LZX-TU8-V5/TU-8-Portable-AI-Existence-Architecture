## 三、渲染函数的本质：BRDF解析方程

### 3.1 核心公式

所有主流渲染器描述材质反光特性的核心：

```
f_r(ω_i, ω_o) = D(h)·F(v,h)·G(l,v,h) / [4(n·l)(n·v)]
```

### 3.2 函数项解析

| 函数项 | 物理含义 | 认知算法对应 | 3ds Max参数 |
|--------|---------|-------------|------------|
| D(h) | 法线分布函数：微观表面朝向的统计分布 | 决定高光形状与宽度（粗糙度） | Roughness/Glossiness |
| F(v,h) | 菲涅尔项：不同入射角下的反射率变化 | 区分金属/非金属的核心判据 | IOR/Fresnel IOR |
| G(l,v,h) | 几何遮蔽项：微表面自遮挡与阴影 | 控制掠射角能量衰减 | 通常内置于GGX模型 |

### 3.3 关键澄清

> 您在渲染设置中看到的"细分"、"采样数"，只是用来平滑地估算这个函数的积分结果。函数本身的形态完全由D/F/G的参数决定。只要确定了这几个参数，任意角度下的色彩梯度都可以用公式直接算出来。
