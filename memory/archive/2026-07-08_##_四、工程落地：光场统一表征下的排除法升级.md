## 四、工程落地：光场统一表征下的排除法升级

### 4.1 采样层：构建"光谱-空间联合差分张量"

**统一的光场微分算子**：

```
D_unified = [
    ∇_θ I_phase     // 几何调制（相位）
    ∇_θ C_spectral  // 光谱调制（色彩）
    Corr(∇_θ I_phase, ∇_θ C_spectral)  // 光-材耦合项
]
```

**关键点**：
- 三项在同一圈同心圆环上同步计算
- 共享自适应起止点
- **耦合项是关键**：编码"高光位置是否与几何边缘对齐"等光-材交互规律

### 4.2 排除层：用"光场一致性"替代"特征匹配"

**L3层验证逻辑**：

| 材质候选 | 光场一致性要求 |
|---------|---------------|
| 金属 | ∇_θ C_spectral 与 ∇_θ I_phase 高度相关，光谱梯度集中在高频（镜面反射主导） |
| 哑光塑料 | 二者弱相关，光谱梯度全域低频平缓（漫反射主导） |
| 异常/伪造 | 耦合项偏离该类材质的物理先验范围 → 立即排除 |

**算力优势**：一次联合张量比对同时完成几何验证、材质验证、真伪验证三重任务。
