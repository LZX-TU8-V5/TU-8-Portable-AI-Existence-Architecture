## 三、排除法在上下文拼接中的应用

### 3.1 多层级排除

```
输入：新轮次对话
       ↓
L1: 相关性排除
       ├──→ 与当前任务无关 → ❌ 不拼接
       └──→ 与当前任务相关 → ✅ 进入下一层
              ↓
L2: 时效性排除
       ├──→ 过期信息（已被后续轮次覆盖） → ❌ 不拼接
       └──→ 有效信息 → ✅ 进入下一层
              ↓
L3: 冗余性排除
       ├──→ 与已拼接内容重复 → ❌ 不拼接
       └──→ 新增信息 → ✅ 进入下一层
              ↓
L4: 置信度排除
       ├──→ 置信度 < 阈值 → ❌ 不拼接（或降级处理）
       └──→ 置信度 ≥ 阈值 → ✅ 拼接
```

### 3.2 短路机制

**排除法的核心优势**：
> 任意一层排除，立即终止，不再检查后续层级

**例子**：
- L1 判断"与当前任务无关" → 直接跳过，不计算时效性/冗余性/置信度
- 类似视觉领域的"无sinc峰 → 排除棱柱类"
