## 二、上下文拼接状态机的当前问题

### 2.1 正向拼接的问题

**当前做法**：
```
轮次1 → 提取语义 → 拼接到上下文
轮次2 → 提取语义 → 拼接到上下文
轮次3 → 提取语义 → 拼接到上下文
...
```

**问题**：
- 每轮都拼接 → 上下文膨胀
- 噪声/无关信息也被拼接
- 类似"正向检索"：检查所有特征，算力浪费

### 2.2 排除法思路

**改进做法**：
```
轮次1 → 提取语义 + 计算置信度
         ├──→ 置信度 < 阈值 → ❌ 排除（不拼接）
         └──→ 置信度 ≥ 阈值 → ✅ 保留（拼接）
轮次2 → 同上
...
```

**核心思想**：
> 不是"找最相关的"，而是"删不可能相关的"
