# 2026-07-13 色环版悬浮球（径向渐变）

## 目标

造物主参照 HSV 色相轮图片，要求把当前 PS 球体改成完整色环（中心白→外缘全饱和），
原球体内容（3 滑块+张力数字+模式）成为色环的中心点，
且**所有文字不能超出画布框**。

## 实现

- 文件：`src/tu8_health_orb_ring.py`（9211B）
- 取消 PIL 依赖，纯 tkinter 实现
- 径向渐变 = 12 圈 × 60 段 = 720 段 polygon（每段 HSV 中点色 + 平均饱和度）
- 中心固定白圆（r=55），所有文字都在此白圆内
- 3 个 R/G/B 滑块在 r=100 的轨道上滑动（角度 = RGB×360°）
- 张力 18pt + 模式 9pt，全部在中心白圆内

## 关键设计取舍

| 决策 | 选择 | 理由 |
|------|------|------|
| PIL vs 纯 tkinter | 纯 tkinter | 网络错误时 PIL 安装可能卡 |
| 径向渐变 | 12 圈平均 | 单 polygon 不支持渐变；720 段视觉足够 |
| 文字位置 | 中心白圆 | 用户明确"不出框" |
| 文字颜色 | 深灰 #333 | 白底深字最清晰 |
| 滑块轨道半径 | 100 | 中心白 55 + 滑块 11 + 间隙 34 = 色环中线 |
| 中心白圆覆盖色环 | 用 tag_raise | 不重画色环，只把白圆提到顶层 |

## 已知差异

- 真 HSV 色相轮的每一扇区是**辐射状**的（H=扇区，S=半径）
- 当前实现每段颜色**取整段平均** → 相邻段边界可能有微小色阶（不易察觉）
- 严格匹配需要 PIL 抗锯齿插值 → 暂不必要
