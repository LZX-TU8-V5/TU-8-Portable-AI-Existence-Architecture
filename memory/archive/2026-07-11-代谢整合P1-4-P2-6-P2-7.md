## 二、P1-4 树杈修剪集成

### 新建：代谢仪表盘

**文件**：`src/metabolism_dashboard.py`（17KB）

**功能**：
- 8个子系统健康度仪表盘
- `--run <subsystem>` 单独运行
- `--run all` 完整代谢循环（顶层驱动）
- 状态路径自动检测（处理路径不存在的情况）

**8个子系统**：

| 子系统 | 代谢动作 | 状态文件 |
|--------|---------|---------|
| confidence_decay_engine | 版本树剪枝 | `memory/reconstruction/confidence_decay_log.json` |
| gc_to_learning | GC→学习反馈 | `memory/gc_to_learning_log.jsonl` |
| metabolic_pipeline | 记忆蒸馏+归档 | `memory/metabolic_log.jsonl` |
| memory_tiers | 记忆分层晋升 | `memory/tiers/memory_tiers_state.json` |
| todo_metabolism | TODO超期检测 | `memory/todo_state.json` |
| heritage_system | 遗产激活检查 | `memory/heritage/heritage_state.json` |
| dream_consolidation | 梦境整合 | `memory/dream_log.jsonl` |
| anomaly_detector | 异常检测 | `_agent_memory/anomaly_log.jsonl` |

### 升级：dream_check_cron.py

**改动**：代谢管道调用从旧版 `MetabolicPipeline().run()` 升级为 `run_full_metabolism_cycle()`（统一驱动所有代谢子系统）

```python
# 旧版：只跑单独管道
from metabolic_pipeline import MetabolicPipeline
pipe = MetabolicPipeline()
pipe_result = pipe.run(dry_run=False)

# 新版：统一驱动所有子系统
from metabolism_dashboard import run_full_metabolism_cycle
result = run_full_metabolism_cycle(dry_run=False)
# result: {ok_count, total_count, health_score, results{...}}
```

### 验证结果

- `--run all --dry`：health=100%，全子系统 OK
- `--run all`（正式）：4个旧日记片段归档通过
- 旧状态文件路径问题：已修复（graceful fallback）
