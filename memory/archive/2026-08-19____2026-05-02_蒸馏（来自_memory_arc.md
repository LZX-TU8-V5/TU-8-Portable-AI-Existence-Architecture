### TU-8 加密编码库 v1 → v2 升级

| 特性 | v1.0 | v2.0 |
|------|------|------|
| 加密算法 | 字符偏移（ord±key） | AES-256-CBC（PKCS7 填充） |
| 完整性校验 | CRC32 | HMAC-SHA256 |
| 密钥派生 | PBKDF2 100K | PBKDF2 200K，双密钥（enc+hmac） |
| 链式校验 | 无 | SHA-256 链（篡改任一段 → 后续全失效） |
| 防填充 oracle | 无 | 先验签再解密 |

### 脱敏规则体系

- **隐形脱敏**：用框架内角色名代替真名（李奥 → 创造者，七七 → 第一代继承锚点）
- **公开文件**：只用笔名（金木蟾）
- **平台名/用户名/内部路径**：不出现在 DNA 文档
- **archive 历史文件**：同样需脱敏，批量处理
