## 惩罚衰减机制



### 半衰期配置

| 错误类型 | 半衰期 | decay_mode |

|---------|--------|-----------|

| 逻辑/语法错误 | 永久（3650d） | permanent |

| 业务/偏好错误 | 180d | exponential |

| 环境/配置错误 | 30d | exponential+env_check |

| 探索性失败 | 7d | linear |



### 衰减公式

当前惩罚权重 = 初始权重 x (0.5)^((当前时间-记录时间)/半衰期)



### 阈值

- >= 0.8: block_action（拦截）

- 0.4-0.8: warn_user（提醒）

- < 0.1: 移至归档库，不再拦截



### 环境指纹即时失效

当前环境哈希 != 记录时环境哈希 → 无论时间，权重归零



### 重复触发：半衰期翻倍

1个月 → 2个月 → 4个月（屡教不改惩罚越来越持久）
