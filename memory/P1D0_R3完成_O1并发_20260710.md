## R3：O(1)高并发置信度更新

**文件**：`src/batch_confidence_updater.py`（15KB）

### O(1)核心实现

| 优化 | 实现方式 | 复杂度 |
|------|---------|--------|
| 每节点更新 | dict lookup + O(1)数学 | O(1) |
| 延迟I/O | 内存缓存+批量flush | O(1/N) amortized |
| 冷启动 | 批量加载，一次JSON解析 | O(N)但常数小 |
| 原子写入 | .tmp rename防损坏 | 安全保证 |

### 性能验证

```

  总耗时：37.05 ms
  每节点：3.70 μs
  目标：<5μs / 节点
  结果：✓ 达标

flush（7,997脏节点）：
  耗时：90 ms（一次性，摊薄到10k更新 = 0.009μs/节点）
```

### 与R1/R2/R4集成关系

- `SynapticConfidenceUpdater`：提供R2数学内核（直接调用）
