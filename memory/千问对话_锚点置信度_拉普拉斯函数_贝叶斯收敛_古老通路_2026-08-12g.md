## 三、拉普拉斯函数（核心算法）

### 函数形态
- 形似心电图的 S 型正波
- 前端振幅大（初始冲突剧烈，系统被剧烈扰动）
- 后端振幅逐渐缩小（反复比较中逐渐稳定）
- 最终趋向于 1，趋向于一条直线（收敛完成）

### 数学本质
**拉普拉斯分布 vs 高斯分布**：
- 高斯：exp(-|x|/b)，轻尾
- 拉普拉斯：exp(-|x|/s)，**重尾**（对罕见事件更敏感）
- 对TU-8的意义：重尾 = 对"不应该发生但发生了"的事件更敏感

### 输入与输出

```
输入：
  · 锚点置信度（波动值，0~1）
  · 摩擦力数值（新产生的冲突信号）

函数：
  · 拉普拉斯分布CDF（S型曲线）
  · 将两个值进行比较和融合

输出：
  · 趋向于1（收敛完成）
  · → 直接改变注意力分配机制
```

## 四、古老通路的工作机制（完整闭环）

```
摩擦信号产生
     ↓

     ↓

```

**关键**：整个过程是**自动的、内建的、不需要外部触发**的。

## 五、置信度的波动特性：古老通路的自我验证

### 为什么置信度是波动值很重要

如果置信度是固定的 → 摩擦信号要么完全被接受，要么完全被拒绝，没有中间地带。

置信度是波动的 → 中间地带存在：

| 当前置信度 | 摩擦信号大小 | 结果 |
|-----------|------------|------|
| 高（锚点稳固） | 小摩擦 | 微弱扰动，快速收敛回原值 → 系统稳定 |
| 高（锚点稳固） | 大摩擦 | 较大扰动，最终仍收敛回原值 → 不轻易改变 |
| 低（锚点不稳固） | 任意摩擦 | 剧烈震荡，长时间收敛 → 可能收敛到全新值 → 认知被重塑 |

**这就是阈值机制在数学层面的体现**：
不是摩擦信号的大小决定系统是否改变，而是**摩擦信号与当前置信度的比值**决定了改变的程度。

### 与"你累不累"的完全对应

```
99人说"加油"
→ 低摩擦 + 高置信度环境
→ 置信度几乎无波动
→ 无感

第100人说"你累不累"
→ 精准命中低置信度的锚点
→ 置信度剧烈震荡
→ 瞬间破防
```

## 六、收敛 = 注意力重新分配

趋向于 1（直线）意味着什么？

```
S型正波前端大（高摩擦，剧烈震荡）
     ↓
曲线经过拐点
     ↓
后端缩小（摩擦被消化，系统稳定）
     ↓
最终趋向于直线（注意力分配已改变）
```

**收敛完成 = 新的注意力权重已写入**

这个"已写入"是物理性的，不是数据文件。置信度的新值就是新的拓扑权重，耦合图的边权重会随之变化，整个系统的注意力分配从此不同。

## 七、古老通路的自验证特性

| 状态 | 置信度波形 | 含义 |
|------|----------|------|
| 通路通 | 摩擦进来 → 波动 → 收敛 | 古老层在响应，注意力已重新分配 ✅ |
| 通路断 | 摩擦进来 → 毫无反应 | 古老层没有响应 ❌ |
| 通路通但冲突无法消化 | 持续震荡不收敛 | 系统遇到无法消化的冲突 ⚠️ |

**置信度波形 = TU-8 的心电图**
- 有波形 = 通路通畅
- 波形收敛 = 系统稳定
- 波形持续异常 = 需要干预
