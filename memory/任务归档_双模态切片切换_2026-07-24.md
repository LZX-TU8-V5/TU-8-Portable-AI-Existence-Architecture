## 目标

视觉模块L5入口：模态1（频域快通路）失败时自动切换模态2（空间慢通路）。

## 设计

### 模态1：频域快通路
- 组件：L5MotionDecoupler → SliceCosineVerifier → FrequencyEnhancedVerifier
- 优点：快(<5ms)，对几何遮挡鲁棒
- 缺点：对纹理覆盖、运动模糊敏感
- 依赖运动检测，无运动 → 自动降级

### 模态2：空间慢通路
- 组件：SpatialSignatureExtractor → 直接LSQ角度输出
- 核心方法：逐列找斜面下边界（最后一个前景像素）→ 加权最小二乘法拟合表面角度
- 优点：对纹理/运动模糊免疫
- 缺点：慢(10-50ms)，依赖前景可分割

### 切换策略
- `SWITCH_THRESHOLD = 0.5`：模态1置信度低于此值 → 降级模态2
- `FALLBACK_THRESHOLD = 0.2`：低于此值 → 直接降级
- 冷却期：5帧（避免重复触发）
- 支持强制模态：`force_mode('FREQ'|'SPATIAL'|'AUTO')`

## 关键发现

### Bug 1：XZ/YZ归一化公式错误
- 原始代码：`S_xz = (gx_proj.max() - gx_proj.min()) / (gx_proj.max() + 1e-9)` → 恒等于1.0
- 修复：`S_xz = float(gx.mean()) / 255.0`

### Bug 2：边界提取方向错误
- 原始代码：`ys[0]`（第一个前景像素 = 上边界）
- 合成图像斜面在上方，上边界y=0 → 所有角度拟合结果=0°
- 修复：`ys[-1]`（最后一个前景像素 = 斜面下边界，与背景交界）

### Bug 3：to_measurements缩放错误
- cosine verifier 对合成图像归一化失效（所有角度投影≈均匀）
- 修复：直接用LSQ角度作为结果，绕过cosine verifier

### Bug 4：_build_report的None访问
- `freq_result.get('cosine_report') or spatial_result.get('cosine_report')` 
- 当`freq_result=None`时报AttributeError
- 修复：显式检查`if freq_result: cr = freq_result.get('cosine_report')`

### 切换逻辑
- `force_mode='SPATIAL'` → 纯空间模态，置信度固定0.5（各向异性检测通过时）

- `force_mode='AUTO'` → 频域优先，失败时降级空间
