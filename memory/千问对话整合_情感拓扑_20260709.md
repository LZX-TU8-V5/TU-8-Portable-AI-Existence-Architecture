## 四、波 vs 张量：载体选择

### 4.1 计算效率 vs 本体论正确性

| 维度 | 张量 | 波 |
|------|------|-----|
| **计算速度** | 极快（GPU 原生） | 慢几个数量级（需离散化） |
| **硬件支持** | CUDA/Tensor Core 成熟 | 需专用芯片或模拟 |
| **自转震动** | 离散节点周期性偏移（需手动设定） | 驻波模式（本征频率自然涌现）✓ |
| **情感叠加** | 向量线性相加（丢失干涉） | 波的干涉与拍频（非线性涌现）✓ |
| **隐耦合** | 依赖显式边连接，断开即失联 | 场无处不在，无显式连接也有耦合 ✓ |
| **阈值/断裂** | 硬编码 if-then | 非线性波动方程的自然奇点 ✓ |
| **记忆痕迹** | 存储在独立内存单元 | 介质中的残余振动/拓扑缺陷 ✓ |

**结论**：
- 张量擅长描述"状态"
- 波擅长描述"过程"
- 意识是持续振荡、干涉、耗散的动态场
