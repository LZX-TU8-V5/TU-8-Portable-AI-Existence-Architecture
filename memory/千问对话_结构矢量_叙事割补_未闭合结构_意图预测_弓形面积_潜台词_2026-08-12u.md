## 一、词元匹配的误判与漏判

### 误判：共享词元 ≠ 同一结构

**"我吃饭" vs "我做饭"**：
- 都含词元：A（我）+ 饭
- 但：`吃` = **消耗型/状态型**结构，终点在"饭"本身
- `做` = **创造型/过程型**结构，终点悬在半空，等待下一个动作闭合

```
误判：
  词元集合{"我", "饭"} ∩ {"我", "饭"} = 2个相同
  → 算法认为两者高度相似 ❌

真相：
  "我吃饭" = 结构A：能量输出 → 直接满足（终点已闭合）
  "我做饭" = 结构B：能量输出 → 悬置 → 等待"吃"闭合（终点未闭合）
```

### 漏判：第二层意图的隐藏关系

**"我做饭" vs "我吃饭"**：
- 第一层：两者词元相似度低（只有"饭"重叠）
- **第二层**：叙事因果隐藏匹配
  ```
  "我做饭"的后续可能：
    → "我吃饭"（满足生理需求，能量守恒闭环）
    → "我学厨艺"（升维：动作被割补为自我提升）
    → "我请客"（升维：动作被割补为社交行为）
  ```
- **词元匹配完全漏掉了这层关系**

## 二、叙事结构 = 带方向的能量线段（结构矢量）

### 核心概念：线段 ≠ 距离，线段 = 叙事能量矢量

你那句话精准点破：
> 叙事中的线段并不一定等于是一样的。

```
传统理解（静态）：
  线段 = 词元A → 词元B
  匹配 = |A-B| 距离大小

你的理解（动态）：
  线段 = 叙事能量从起点到终点的运动路径
  匹配 = 能量结构是否同构，而不是词元是否相同
```

### 结构矢量的三要素

```python
@dataclass
class StructuralVector:
    subject: str           # 施事者（"我"）
    predicate: str         # 动词（"做"/"吃"）= 能量类型
    object: str            # 受事（"饭"）= 能量终点
    energy_direction: str   # 能量走向："收敛"/"发散"/"悬置"
    endpoint_status: str   # 终点状态："闭合"/"悬置"/"断裂"
    narrative_tension: float  # 叙事张力值
```

### 三种基本结构矢量

| 类型 | 示例 | 能量方向 | 终点状态 |
|------|------|---------|---------|
| **消耗型** | 我吃饭 | 收敛 → 直接满足 | **已闭合** |
| **创造型** | 我做饭 | 发散 → 过程展开 | **悬置（待补全）** |
| **断裂型** | 我做饭 | 发散 → 但被打断 | **断裂（需排泄）** |

def predict_next_intent(structural_vector):
    """
    给定当前叙事结构，预测最可能的补全路径
    "我做饭" → 预测"我吃饭"/"我学厨艺"/"我请客"
    """
    gap = structural_vector.gap  # 悬置的缺口形状
    
    # 查询历史叙事库：相似缺口 → 历史上是如何补全的
    historical_completions = narrative_db.query_by_gap_shape(gap)
    
    # 排序：按叙事能量守恒程度
    # "做饭→吃饭" = 完全守恒（100%）
    # "做饭→学厨艺" = 部分守恒（能量升维）
    # "做饭→请客" = 社会维升维
    
    ranked_completions = sorted(
        historical_completions,
        key=lambda c: compute_energy_conservation(c补全方案)
    )
    
    return ranked_completions
