- 直接 `python cold_start_engine.py`（`__main__` block）
- 直接 `python environment_detector.py`（`__main__` block）
- 直接 `python -m src.hp1_...`（`__main__` block）

**为什么 QClaw 能跑：** QClaw 启动时 src/ 已入 sys.path，`import src.x` 等效于 `import x`，所以"刚好能用"。

**为什么不修会死：** 
- `cold_start_engine.py` 有 `if __name__ == "__main__"` 自测入口（:1205）
- `environment_detector.py` 有 `if __name__ == "__main__"` 自测入口（:534）
- 独立调试/测试/CLI 调用全部失败
- Hook 注册脚本 `python -m src.hp1_...` 失败

**正确写法：**
```python
# 方式A（推荐）：直接 import
from steel_seal_verifier import get_steel_seal_verifier
# 方式B：相对导入
from . import steel_seal_verifier  # 需要 src/ 下有 __init__.py

## B-04 修复记录（2026-08-14）

**根因：** `QCLAW_PATH_MAP` 常量写死 v0.2.29.592，`translate()` 和 `format_report()` 读这个常量 → QClaw v0.2.35 下路径全部失效。

**改动：**
1. 新增 `_detect_qclaw_root()` — 从 `sys.executable` 反推 QClaw 根目录（`vX.X.X.XXX/resources/python/python.exe` → 上两级）
2. `QCLAW_PATH_MAP` 改为 `{}` 占位 + 惰性填充
3. `get_qclaw_path_map()` / `_get_qclaw_path_map_lazy()` 调用 `_detect_qclaw_root()` 动态构建路径
4. `QClaw_环境诊断` 块改为调用 `_get_qclaw_path_map_lazy()`
5. `translate()` / `format_report()` 读动态函数结果
6. `--check-env` 命令行入口验证实际路径
