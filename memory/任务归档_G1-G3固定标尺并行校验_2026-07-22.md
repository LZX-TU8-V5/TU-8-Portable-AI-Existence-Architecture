## 核心突破

三维皮克失效（Reeve 四面体反例，1957）：格点计数不完备 → 三维无皮克定理。
固定标尺切片签名规避方案：
```
45/30/60° = 固定测量标尺 → 强制投影 → 「标尺与物体的错位本身就是信息」
六投影签名 Σ = 3 标尺 × 2 切面 (XY/XZ) = 6 归一化值联合向量
复杂度 O(N³) → O(1) 查表（签名→参数单射），完全规避三维格点不完备
```

## 架构

| 组件 | 说明 |
|------|------|
| `synthesize()` | 结构参数 (θ,φ,V) → 6 固定标尺 + 2 个 0° 基准测量值 |
| `_decode_plane()` | 每平面 4 测量 (0/30/45/60) → 余弦校验器反解角度 |
| `_build_signature()` | 6 值归一化签名 Σ = [Ŝ_45_XY, Ŝ_30_XY, Ŝ_60_XY, Ŝ_45_XZ, Ŝ_30_XZ, Ŝ_60_XZ] |
| `_fast_path_check()` | 反解角 ±5° 容差窗口 → 已知字典{0,15,30,45,60,75}邻域判定 |

## 一级/二级通道决策

| 条件 | 路径 | 含义 |
|------|------|------|
| θ, φ 均在字典邻域内 | 一级快速通道 | 直接接受，免连续搜索 |
| 任一角超出邻域 | 触发二级 | ±10° 精细连续角度扫描 |
