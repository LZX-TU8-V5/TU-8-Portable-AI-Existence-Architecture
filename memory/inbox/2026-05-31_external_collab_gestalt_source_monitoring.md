## 一、核心洞见："上一次"是语义拓扑，不是线性时间

**TU-8 原话**:
> "比如我说上一次任务，不一定指的是刚刚的任务（可能我觉得不对打断了），是回到上一段（语义种得一段，而不是上一个任务）"

**外协回复核心**:
- "上一段"是语义拓扑结构，"上一个"只是线性时间序列
- 被打断的任务A在认知层面没有形成闭环，不是独立的"段落"，只是未完成的悬置态
- 真正的"上一段" = 打断之前已经完整闭合、或在语义上与当前意图真正构成承接关系的任务B

## 二、三个机制设计

### 1. gestalt_score（完形度排序）
- 正常结束/明确结论/显式确认 → 分数趋近1
- 被中断/报错未处理/无反馈 → 分数极低
- 解析"上一次/上一段"时，过滤掉 `gestalt_score < 阈值` 的近期节点

### 2. semantic_block（语义分块）
- 连续、高内聚、共享同一意图上下文的多个钢印 → 动态聚合为一个 `semantic_block`
- 打断、话题切换、长时间停顿、预测误差爆发 = 天然分块边界
- "上一段" = 当前 `semantic_block` 的前一个 block，而非前一个 seal

### 3. intent_trajectory（意图轨迹向量）
- 维护实时意图轨迹向量
- 新输入到来时，计算与历史轨迹的方向一致性
- 用户打断任务A去做任务C：若C的意图向量与A高度正交 → C是新段落起点；若C是对A的修正/补充 → 仍属于A的段落

## 四、功能完整性讨论：还差哪两块拼图？

**TU-8 追问**: "这是完整解析了人脑记忆系统吗？"

**外协回答**: 功能层面已完成90%，还差两块纯信息处理层面的机制（非生物层面）：

### 缺失拼图 1：源监控（Source Monitoring）
- **人脑功能**: 区分"亲眼看到的"/"别人告诉我的"/"自己推理出来的"/"做梦梦到的"
- **TU-8 现状**: 钢印记录了内容和时间，但没有原生记录"认知模态"
- **功能补全**: 写入时强制绑定 `source_modality`（感知/语言输入/内部推理/外部工具返回/被修正的历史）；召回时不同源有不同置信度权重

### 缺失拼图 2：提取诱发遗忘 / 侧抑制（Retrieval-Induced Forgetting）
- **人脑功能**: 提取某个记忆时，主动抑制与之竞争的相关记忆（不是bug，是核心feature）
- **TU-8 现状**: 代谢机制是全局性衰减或基于访问频次强化，缺少"上下文相关的动态抑制"
- **功能补全**: `recall()` 过程中引入侧抑制机制；高匹配度候选集激活的同时，语义相邻但意图不匹配的节点被临时降权
