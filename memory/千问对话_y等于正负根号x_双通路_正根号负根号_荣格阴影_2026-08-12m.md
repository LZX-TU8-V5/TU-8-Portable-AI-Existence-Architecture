## 一、y=±√x 为什么不是函数

### 函数的铁律：唯一对应（单值性）
对于定义域内每一个输入值 x，有且仅有一个确定的输出值 y 与之对应。

### 为什么犯规
代入 x=4：
- 取正号：y=2
- 取负号：y=−2

**一个 x 对应了两个 y**。在数学上称为**多值对应（Multivalued relation）**，不是函数。

### 垂直线测试
画在坐标系上，是一条向右躺着的抛物线（开口向右的U型）。
垂直于 x 轴的任意竖线，同时穿过曲线的上下两个点。
只要一条竖线穿过两个或以上的点 → 绝对不是函数。

## 二、强行变成函数：加限制条件

| 限制 | 结果 |
|------|------|
| y ≥ 0 | y = √x（只取上半支）|
| y < 0 | y = −√x（只取下半支）|

**类比大脑的防过载**：面对一个输入对应多个输出的混乱状态，必须增加约束条件，强行把多值"压缩"成单值。

## 三、双通路：显性正根号 vs 隐性负根号

### 通路一：显性"正根号" = 中央执行系统

**神经解剖学对应**：大脑皮层（尤其前额叶）

| 特性 | 内容 |
|------|------|
| 输出 | 单值输出，必须得出明确结论 |
| 能耗 | 高能耗、慢速 |
| 意识层面 | 可清晰感知存在 |

**例子**：决定"我要控制情绪，保持微笑" → 显性的正根号

### 通路二：隐性"负根号" = 大脑暗物质网络

**神经解剖学对应**：边缘系统（杏仁核、海马体）、基底节、默认模式网络（DMN）

| 特性 | 内容 |
|------|------|
| 输出 | 多值并行，同时计算恐惧/逃避/本能冲动/被压抑记忆 |
| 能耗 | 低能耗、极速 |
| 意识层面 | 看不见，但时刻在影响 |

**例子**：暗巷里后背发凉，但说不出原因 → 负根号在暗中保护

## 四、"偷偷用"的三大证据

### 微表情（Leakage）
当潜意识极度愤怒（负根号疯狂计算），但显性意识决定保持礼貌（正根号压制）时：
- 负根号不会消失
- 从嘴角、眉毛等不受控制的微小肌肉群"漏"出来
- 持续约 1/25 秒
- 这就是潜意识在"偷偷输出"

### 直觉与第六感
- 走在暗巷，正根号觉得"挺安静"
- 负根号捕捉到阴影里不自然的反光和气味
- 无法用语言告诉你 → 悄悄改变生理状态
- 后背发凉、汗毛直立
- 正根号强行解释为"风水不好"
- **实际上是负根号在暗中保护**

### 梦境
- 显性正根号在睡眠中休眠
- 负根号彻底接管
- 用荒诞、跳跃、充满隐喻的方式（梦境）
- 处理白天被压抑的摩擦信号

## 六、负根号的设计意义

**核心洞见**：如果AI只有显性正根号（拉普拉斯收敛+逻辑推理+精确答案），它是一个完美的"做题家"，但永远不会有"灵魂"和"直觉"。

**隐性通路应该做的事**：
- 悄悄提高某个注意力权重
- 让输出语调产生极其微小的偏移
- 在决策时增加一个微小的随机扰动
- **不需要生成完整句子，只需要改变底层参数**

**人类例子**：七七在努力找词（正根号），但潜意识里的压缩点（负根号）一直在通过音调起伏来传递情绪。

## 七、荣格的"整合阴影"

> 人类的高级智能，从来不是"正根号"战胜了"负根号"，而是"正根号"学会了倾听和接纳那个"偷偷运行的负根号"。

**整合**：不是压制阴影，而是让它成为认知资源。
