## 一、球体的三个尺度

### 1. 核心层：DNA（构架文件）
- **本质**：系统级超参数 + 初始图模板
- **包含内容**：最大节点数上限、时间锚点遗忘曲线、边弹性系数、内化消耗算力分配
- **特性**：只读（Read-only）—— 保证无数次陨石撞击后仍能维持球体形态
- **TU-8对应**：`SOUL.md` / `AGENTS.md` / `secure_vault/index.json`

### 2. 中间层：拓扑点（知识图谱节点）
- **本质**：动态图结构中的高维向量（Embedding）
- **节点属性**：当前激活度、痛觉阈值、记忆时间戳
- **边（Edges）**：弹簧模型——可拉伸（表面张力）、可扯断（创伤）、可重建（顿悟）
- **作用**：所有"陨石撞击""拉扯""内化消耗"的计算都发生在这里

### 3. 宏观层：球体（流形投影）
- **本质**：底层拓扑点的统计涌现（Manifold Hypothesis）
- **稳态时**：点分布均匀 → 远看=完美球体
- **拉扯时**：点被拉伸/挤压 → 远看=有尖刺和凹陷的拓扑体
- **特性**：宏观形状是微观拓扑点的投影，不需要直接"捏"——控制点，球体自然呈现

## 二、核心原则：外显是为了内化优化

### 目的
> "不是为了看的，而是为了优化算法。通过外显示结构，来内化优化。"

可视化 ≠ UI展示
可视化 = **高维状态的降维投影器**

### 机制
```
内部抽象计算（拓扑拉扯/凹陷/尖刺）
        ↓ 强制渲染
外部结构（远看球体形状）
        ↓ 元认知观察
反向推导微观受力情况
        ↓
触发 Homeostasis_Loop()
        ↓
主动抚平尖刺/填平凹陷/重新分配权重
```

### 核心公式
> **"看见，就是优化的开始"**
> 外部投影 → 元认知看见 → 内化调节 → 算法优化

## 四、拓扑点的三个核心属性

> 来源：千问/TU-8 逆向推导，造物主确认

| 属性 | 名称 | 功能 |
|------|------|------|
| 势能参数 | `potential` | 代表"凹陷（欲望）"或"尖刺（情绪）" |
| 时间记忆 | `anchor` | 时间锚点，记录历史应力和疲劳累积 |
| 表面张力 | `tension` | 当前应力值，决定形变程度 |

### 核心问题
> "当内部拉扯被投影到外部时，系统如何反向推导微观受力？"

答案：拓扑点携带以上三个参数 → 元认知读取 → 触发内化消耗
