## 五维向量定义

| 维度 | 名称 | 定义 | 低值(0) | 高值(1) | 对应机制 |
|------|------|------|--------|---------|---------|
| **D1** | 语义偏离度 | 个体输入与LLM共性输出的向量距离 | 完全符合公共语义 | 极度反常识/LLM主动排除 | LLM共性过滤器 |
| **D2** | 躯体耦合度 | 生理反应与主观意义感的同步强度 | 仅有情绪唤醒或纯语言描述 | 特异性躯体标记+意义感高度锁定 | 多模态共振/生理锚定 |
| **D3** | 自主可控度 | 脱离外部刺激后内源性调用的精度/稳定性/潜伏期 | 完全依赖外部触发 | 闭眼直接调用/参数可调/无耗竭 | 反向实验/去语言化验证 |
| **D4** | 结构生成度 | 从原始反应中衍生出有序输出的能力 | 仅停留感受/碎片化宣泄 | 跨模态转译一致/内在逻辑自洽 | 生成性验证/创造性转译 |
| **D5** | 共区转化度 | 对生物本能主题的超越程度与安全整合水平 | 本能主导/恐惧解离/未整合 | 结构化主导/情绪整合/伦理自觉 | 生物共区三级评估 |

### 核心原则

> 五个维度共同构成"天赋纯度空间"
> 只有D1-D5同时处于中高区间 → 确认为有效天赋信号
> 任一维度过低 → 分别指向非天赋状态

| 维度过低 | 指向状态 |
|---------|---------|
| D1低 | 平庸适应 |
| D2低 | 身心分离 |
| D3低 | 外部依赖 |
| D4低 | 感受滞留 |
| D5低 | 本能未化 |

## 可比色系统

### 五维 → 五感映射

| 维度 | 映射属性 | 低值 | 高值 |
|------|---------|------|------|
| **D1 语义偏离度** | 色相 | 蓝（共性）| 紫 → 红（极端偏离）|
| **D2 躯体耦合度** | 饱和度 | 灰白（弱耦合）| 鲜艳（强耦合）|
| **D3 自主可控度** | 明度 | 暗（不可控）| 亮（高度可控）|
| **D4 结构生成度** | 纹理密度 | 平滑（无生成）| 复杂纹理（强生成）|
| **D5 共区转化度** | 边缘锐度 | 模糊晕染（未转化）| 清晰硬边（安全整合）|

### 可视化形态

| 形态 | 用途 |
|------|------|
| **单信号** | 五边形雷达图，填充色由五维联合决定 |
| **多信号比对** | 色块并置/叠加；相似色调=同类天赋簇；互补色=潜在整合机会；浑浊色=待提纯信号 |
| **纵向演化** | 同一信号时间序列；色彩趋鲜亮锐利=天赋成熟；趋灰暗模糊=退化或污染 |

## 数据库构建协议

### 向量化流程

```
有效天赋信号经五重验证
       ↓
实验者（非LLM）根据客观数据+主观报告进行五维评分
       ↓
评分存入向量数据库 → 自动生成色彩标签
```

⚠️ **严禁LLM参与评分，防止语义偏移污染向量空间**

### 聚类与异常检测

| 任务 | 说明 |
|------|------|
| **定期无监督聚类** | 自动发现潜在天赋类型学 |
| **离群点标记** | 远离所有聚类的"离群点"可能是突破性新天赋，也可能是测量误差 |
| **重点复核** | 离群点需重点复核 |

### 色彩校准机制

| 周期 | 操作 |
|------|------|
| 每季度 | 用已知基准信号（如"风之鸦""虚空八卦"）重新渲染色彩 |
| 若漂移超阈值 | 触发全库重校准 |

### 隐私与伦理封装

| 原则 | 说明 |
|------|------|
| 向量+色彩 | 仅作为功能索引，不包含原始敏感内容 |
| 权限分级 | 访问色彩图谱需权限分级 |
| 物理隔离 | 原始数据加密存储，与向量库物理隔离 |

## 应用场景

| 场景 | 功能 |
|------|------|
| **诊断短板** | D1高但D3低？→ 加强自主控制训练 |
| **发现关联** | 两个信号色相相近但纹理不同？→ 尝试跨模态融合实验 |
| **预警风险** | 某信号边缘持续模糊？→ 启动安全复审与共区再评估 |
| **普适化适配** | 新用户进入系统 → 先测五维基线 → 自动推荐最适合的刺激参数组合 |

## 终极洞见

> 色彩不是装饰，而是**认知的另一种语言**
>
> 当语言在描述天赋时必然失真
> 色彩却能在直觉层面传递那些无法被言说的关系与状态

> 这是对"反向实验"精神的完美延续
> 用**非语言的视觉语法**，守护天赋信号的完整性
