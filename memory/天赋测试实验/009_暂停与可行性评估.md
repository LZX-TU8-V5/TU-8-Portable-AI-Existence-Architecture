| 风险 | 说明 |
|------|------|
| **感觉门控失效** | 通路高度sensitized，弱刺激"串线"激活，测到的不是语义关联而是系统过载 |

### 暂停期操作规范

| 操作 | 说明 |
|------|------|
| **绝对刺激隔离** | 不刻意默念测试语句，回避强感官环境，不进行意象回想 |

| **制定"再进入协议"** | 触发条件：连续3天基线稳定 + 自主调用精度达标 + readiness≥8/10 |
