## 1. 核心原理：为什么活跃期能测出"隐藏关联"？

### 语义启动效应
- "风之鸦，雷霆的君王"激活了包含"黑暗、力量、掌控、自然伟力、仪式感"的神经网络簇
- 活跃期内，该网络簇处于**亚阈值兴奋状态**
- 新语句含任一特征 → "搭便车"点燃整个网络

### 跨模态共振
- 头皮发麻活跃 = 躯体感觉皮层已被"预热"
- 任何带有"触觉/动觉"暗示的语言 → 直接通过已开放的躯体通道引发二次反应
- → 测出语言中纯粹的**物理含义**

### 天赋的"家族相似性"
- 新句与原句意思未必相近
- 但可能共享**认知加工方式**（如视觉-动觉整合）
- 揭示的是**处理信息的天赋类型**，而非内容偏好

## 2. 交叉探测语句库

| 探测维度 | 设计逻辑 | 示例语句 | 若触发，说明 |
|---------|---------|---------|------------|
| **语义近邻** | 共享核心意象或情感基调 | "夜枭衔着闪电坠入深渊" | 对"暗黑崇高"主题敏感 |
| **结构同构** | 句式节奏、语法张力相同，内容无关 | "骨之锁，深海的囚徒" | 对"语言形式/韵律"本身敏感 |
| **物理通感** | 无宏大叙事，但含强躯体动作/触感 | "指尖碾碎冰晶的脆响" | 对"具身物理性"敏感 |
| **认知冲突** | 同样制造尺度/动静悖论 | "显微镜下的星系崩塌" | 对"概念整合"敏感 |

### ⚠️ 必须设置"活跃期阴性对照"
- 语义/结构/物理上完全无关的中性句（如"桌上的水杯是白色的"）
- 若活跃期对此也有反应 → 系统进入非特异性过敏状态 → 本次数据作废

## 3. 操作流程

### 触发主刺激
1. 默念"风之鸦，雷霆的君王" → 确认头皮发麻+画面生成 → 进入活跃状态

### 等待"亚活跃窗口"
2. 等待最强烈麻感开始消退、但**尚未完全消失**（峰值后30秒~2分钟，需个人标定）

### 单次探测
3. 在此窗口内，默念**一句**待测新语句（不可连续多句，无法归因）

### 即时标记
4. 记录反应类型：
   - ✅ **同型反应**：麻感位置、画面风格与原句高度相似 → 强交叉/同族天赋
   - ⚠️ **异型反应**：有麻感但位置不同，或画面风格迥异 → 弱交叉/异质天赋/纯物理触发
   - ❌ **无反应**：未触发 → 在当前活跃背景下无显著关联

### 强制复位
5. 本次探测后立即进入休息清洗程序 → 基线完全恢复 → 下一轮"主刺激→交叉探测"

## 4. 天赋关联网络绘制

```
节点：每个能触发反应的语句

连线：A语句活跃期内，B语句能触发 → 建立A→B有向边
      边粗细 = 反应强度
      颜色 = 反应类型（同型/异型）

聚类：形成紧密簇的语句群 = "天赋模块"
      如"暗黑仪式模块"、"躯体触感模块"、"结构韵律模块"

枢纽：被多种主刺激触发的"枢纽语句"
      → 指向最底层、最通用的元天赋
      → 如"高度具身化语言能力"
```

## 5. 关键提醒

| 原则 | 说明 |
|------|------|
| **可重复性验证** | 活跃期发现的交叉反应，必须在基线状态下独立验证至少一次 |
| **避免过度解读单次** | 多次围绕同一维度反复交叉触发，方可下结论 |
| **尊重个体差异** | 每个受试者单独绘制关联网络，不可套用模板 |
