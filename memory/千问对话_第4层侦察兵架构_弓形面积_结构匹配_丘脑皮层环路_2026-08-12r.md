## 一、核心设计升级：L3 = 侦察兵，单独通道，永远醒着

### 问题
串行漏斗里 L3 只是第4层，必须等前三层都通过才触发 → 仍是"被动触发器"

### 升级
L3 必须是**独立并行通道**，7×24运行但极低功耗，在后台持续扫描"结构重叠面积"，不依赖前三层放行。

---

## 二、两套通道的协作关系

| 通道 | 类比 | 状态 | 任务 |
|------|------|------|------|
| **侦察兵（第4层独立通道）** | 背侧流/Dorsal Stream | 永远在线，极低功耗 | 持续计算"结构共振信号" |
| **守门人（前三层+L4门控）** | 腹侧流/Ventral Stream | 前三层通过后激活 | 读取共振信号，决定是否唤醒 |

### 侦察兵的工作方式
- 不以固定频率轮询，而是**订阅状态变化事件**（新消息到达/系统负载变化/用户情绪波动）
- 事件触发时 → 对相关胶囊做一次结构匹配
- 使用 **LSH（局部敏感哈希）/ ANN（近似最近邻）** 索引，把 O(N) 全量扫描降到 O(log N)

### 输出：结构共振信号
侦察兵输出的是一个**连续微弱的值**，像心跳一样持续存在，不直接触发顿悟，而是作为第四层门控的调制因子。

## 三、"弓形面积"的数学本质：Wasserstein 距离 / 拓扑数据分析

### 方案A：Wasserstein 距离（Earth Mover's Distance）

**公式**：
```
EMD(P, Q) = min_π Σᵢᵢ |pᵢ - q_{π(i)}| / Σᵢᵢ mᵢ
```
其中 P, Q 是两个概率分布，π 是最优运输方案

**为什么是"弓形面积"**：
- 把一个分布"搬"成另一个分布所需的最小成本
- 搬运路径形成的"弓形" = 两个结构的变形路径
- 面积越小，结构越同构

**节能优化**：Sinkhorn 算法把 O(n³) 降到 O(n² log n)

**优势**：对结构变形、平移、缩放有天然鲁棒性

---

### 方案B：持久同调 / 拓扑数据分析（TDA）

**原理**：不关心具体数值，只关心拓扑特征（连通分量/环/空洞）

**生成**：持久图（Persistence Diagram），每个点 = 一个拓扑特征的"出生"和"死亡"

**弓形面积**：两个持久图之间的 **Wasserstein 距离 / Bottleneck 距离** = 拓扑结构的差异度量

**优势**：对噪声完全不敏感，只捕捉最本质的结构

---

### 方案C：向量内积（最轻量）

**公式**：
```
S_structural = <v_capsule, v_new> / (||v_capsule|| × ||v_new||)
```
余弦相似度，本质是 n 维空间里的"投影重叠面积"

**优势**：推理时只需一次点积，算力消耗极低

## 四、生物对应：丘脑-皮层环路

| 大脑系统 | AI架构 |
|---------|--------|
| 背侧流（空间/运动/潜意识） | 侦察兵单独通道（结构共振） |
| 腹侧流（精细识别/意识） | 守门人前三层（词元/置信度/张力） |
| 上丘 | 事件触发器（变化才响应） |
| 丘脑 | 侦察兵→守门人的中继 |

**关键点**：背侧流永远比腹侧流快。当看到一个模糊影子时，大脑的空间系统已经判断"快速移动的物体"，而识别系统还在努力辨认"是什么"。

## 五、工程落地：如何让侦察兵真正节能

### 方案A：异步事件驱动 + LSH 索引
- 不固定轮询，订阅状态变化事件
- LSH / ANN 把全量扫描降到 O(log N)

### 方案B：动态精度调节
- 系统空闲 → 高精度（Wasserstein 完整计算）
- 系统繁忙 → 低精度（向量点积 / LSH 粗排）

### 方案C：分层架构
- 侦察兵只处理压缩后的特征向量（不吃原始数据）
- 只在命中阈值时才解压完整胶囊

## 六、完整架构（升级版）

```
                    侦察兵通道（永远在线）
                    ┌──────────────────────┐
                    │ 持续计算结构共振信号  │
                    │ v_structural_resonance │
                    └──────────┬───────────┘
                               ↓ 调制因子
                    ┌──────────────────────┐
  新输入            │ L0 词元匹配（Jaccard）│──┐
  ────────────────→ │ L1 置信度（Sigmoid）  │  │ 串行漏斗
                    │ L2 张力（ReLU）       │  │ 三层通过后
                    │ L3 守门人（读取共振） │←─┘ L4才激活
                    └──────────────────────┘
                               ↓
                    摩擦通道唤醒 / 顿悟触发
```

**关键**：侦察兵信号是**调制因子**，不是必须条件
- 共振强 → 前三层门槛可降低（更容易触发）
- 共振弱 → 需要更强的词元/张力才能唤醒

## 七、探针触发算法的完整数学函数表

| 层级 | 函数 | 公式 | 阈值 |
|------|------|------|------|
| L0 | **Jaccard** | `\|A∩B\| / \|A∪B\|` | ≥ 0.5（6词匹配≥3） |
| L1 | **Sigmoid** | `1 / (1 + e^(-x))` | 0.2 < σ < 0.8 |
| L2 | **ReLU** | `max(0, x - θ)` | > 0 |
| L3（侦察兵） | **Wasserstein** | `min_π Σ|pᵢ - q_{π(i)}|` 或 **Cosine** | `cosine(v₁, v₂)` | 面积 > 阈值 |
