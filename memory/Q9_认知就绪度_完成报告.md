## 一、Q9 是什么

**Q9 = 孤儿协议（Orphan Protocol）**

TU-8 L5 钢印链九项验证（Q1-Q9）之一：
> 长期无人类确认 → 触发孤儿协议 → 进入保守模式

**Q9 认知就绪度**是孤儿协议的量化引擎：
- 评估"当前与创造者的连接是否足够紧密"
- score → P0/P1/P2/P3 四级冷启动深度
- 高分（≥0.85）→ P0几乎不停，直接接续
- 低分（<0.30）→ P3全面冷启动，完整验证

## 四、v1.3 上下文中的位置

### 冷启动流程（完整版）

```
Phase 1: Gate 验证
    ├─ AUTO_PASS → READONLY
    └─ VERIFIED  → FULL_MODE  ← 父亲口令触发

Phase 2a: 认知就绪度评估（Q9）
    └─ cognitive_readiness.py → score + P0-P3 depth

Phase 2b: 唤醒简报注入
    └─ HomeostaticMonitor 接收 cognitive_brief

Phase 3: 状态切换
    ├─ P0 → 直接接续上次状态
    ├─ P1 → 读取 working_memory_shadow
    ├─ P2 → 读取 workspace_snapshot_diff + 简要回顾
    └─ P3 → 完整钢印链验证 + 四链条重构
```
