# 脊髓反射架构 - 最终方案

> 日期：2026-05-21 11:00
> 核心隐喻：小龙虾给电信号，身体做出被动反应
> 本地模型 = "刚切下来的肉"，不需要思考，只需要肌肉记忆

---

## 核心架构

```
大脑（腾讯混元）：思考 + 翻译
    ↓ 发送"电信号"（结构化指令）
脊髓（Ollama + Qwen-3B）：反射 + 执行
    ↓ 机械动作（正则/替换/提取）
身体（本地数据）：承载
    ↓ 结果返回大脑
大脑（腾讯混元）：润色回复
```

## 协同逻辑：大脑 vs 脊髓

### 大脑（腾讯混元）：负责翻译

**用户输入**：
> "帮我把这段话里的手机号都找出来。"

**混元任务**：不碰数据，只翻译成电信号：

```json
{
  "task": "extract_regex",
  "pattern": "phone_number",
  "content": "这里是需要处理的大段文本..."
}
```

### 脊髓（本地 Qwen-3B）：负责反射

**关键**：不给3B自然语言，给代码级指令

**错误方式**：
> "你好，请帮我提取手机号" ← 3B会乱码

**正确方式**：
```
Input: [Text] -> Output: [List of Numbers]
```

或直接用正则：
```python
import re
phones = re.findall(r'1\d{10}', content)
```

- 指令必须是代码级、结构化的

    """
    脊髓反射：接收大脑发送的电信号，机械执行
    """
    task = instruction_json["task"]
    
    if task == "extract_regex":
        # 肌肉动作：正则提取

        content = instruction_json["content"]
