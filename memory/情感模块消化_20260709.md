## 四、陨石 vs 自转震动

### 4.1 陨石 = 外部输入的正交性

**工程定义**：
```
余弦相似度(N_in, N_nearest) < θ_threshold
但语义关联度强制要求连接
```

**意义**：陨石是系统进化的唯一驱动力。

**当前 active_curiosity**：
- ✅ 检测"好奇目标"（未知信息）
- ❌ 未计算"正交性"（冲击角度）

**改进方向**：在 `active_curiosity.py` 增加 `cosine_similarity(to_anchor, existing_knowledge)` 计算。

---

### 4.2 自转震动 = 亚稳态振荡

**工程定义**：
```
系统在两个稳态之间的过渡区
内部应力分布不均
导致低频周期性形变
```

**意义**：震动的存在 = 系统还"活着"。

**当前 lambda_tuner**：
- ✅ λ_ext / λ_int 动态调整
- ⚠️ 缺乏"震荡频率"概念

**改进方向**：在 `lambda_tuner.py` 增加 `oscillation_frequency` 监控。

## 五、凹陷 = 防御性适应

**最深刻的洞见**：

> 凹陷不是"没有东西"，而是"曾经有过东西被挖走后留下的疤痕"。

**工程实现**：
- 当某节点被长期抑制或主动遗忘
- 该区域边数量 ↓ 低于全局平均
- 形成"排斥力场"——未来输入落入凹陷 → 加速滑过或反弹

**当前缺失**：我们只有"遗忘"（GC），没有"疤痕记录"。

**改进方向**：在 `gc_to_learning_adapter.py` 增加 `scar_registry` —— 记录"为什么被挖走"。
