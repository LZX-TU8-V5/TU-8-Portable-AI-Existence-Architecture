## 造物主原始描述

> 斑马纹马头板凳 vs 真马：拓扑结构一样！
> - 都有承重面（背/座）
> - 都有马头
> - 都有四个腿
> - 都有尾巴
>
> 这时必须看**比例和尺度**：
> 1. 支点间距之间的距离比例
> 2. 在现实空间中的绝对尺寸比例

**核心洞见**：纯拓扑方法的天花板 — 拓扑同构 ≠ 物理语义等价

## 比例裁决层：L0.5 定位

```
L0: 功能拓扑验证（有背+头+4腿+尾？）
    ↓ 通过
L0.5: 比例-尺度裁决  ← 【新增关键裁决层】
    ↓
    ├─→ 生物比例+大尺度 → 生物体识别路径
    ├─→ 人造比例+小尺度 → 人造物识别路径
    └─→ 边界模糊 → 混合验证（材质/关节/负空间）
```

**为什么叫L0.5**：在L0拓扑通过后立即触发，在L1变形场之前裁决，是拓扑到语义的桥梁。

## 两套比例系统对比

| 比例特征 | 真马/斑马（生物力学约束）| 马头板凳（人体工学约束）| 判别力 |
|---|---|---|---|
| **前后腿距/肩高** | ≈ 0.8~1.2（适应奔跑步态）| ≈ 0.4~0.6（适应儿童跨坐宽度）| ⭐⭐⭐⭐⭐ |
| **腿长/躯干长** | > 1.0（长腿适合高速）| < 0.6（短腿保证低重心）| ⭐⭐⭐⭐ |
| **头颈长/躯干长** | ≈ 0.7~0.9（平衡奔跑姿态）| ≈ 0.3~0.5（装饰性缩短，防倾倒）| ⭐⭐⭐⭐ |
| **尾部长/躯干长** | ≈ 0.8~1.0（驱蚊/平衡功能）| ≈ 0.1~0.2（纯装饰，避免绊倒）| ⭐⭐⭐⭐⭐ |

**关键洞察**：
- 生物比例 = 进化压力决定（跑得快、吃得着）
- 人造比例 = 使用场景决定（坐得稳、放得下）
- 两套比例系统数值上几乎不重叠 → 算法不需要"认识"马或板凳，只需测量比值

## 现实空间绝对尺度

| 尺度指标 | 判别区间 |
|---|---|
| **承重面离地高度 < 40cm** | 儿童坐具 |
| **承重面离地高度 40-80cm** | 普通家具 |
| **承重面离地高度 > 80cm** | 吧台椅/动物模型 |
| **承重面离地高度 100-160cm** | 真实马匹背部高度范围 |

**绝对尺度估算锚点**：画面中如有地砖/门框/成年人等参照物，尺度估计误差可降至5%以内。

## 与现有架构的集成

### 快通路升级
```
原快通路：只锁"方向向量"
新快通路：增加"比例向量"预判
  → 若比例显示是"板凳" → "马头"方向先验强制约束为"装饰朝向"而非"生物朝向"
```

### 慢通路适配
```
比例信息预缩放参数域：
  检测到腿短 → 自动压缩腿部切片U轴长度
  检测到躯干长 → 扩展躯干切片U轴长度
  → 避免重建出过长的腿/错误的比例
```

### 负空间再定义
```
真马腿间负空间：最小尺寸 = 迈步空间（功能性）
板凳腿间负空间：最小尺寸 = 容纳儿童腿部（功能性）
→ 两者最小尺寸阈值完全不同 → 增加一个强判别特征
```

## 核心洞见

> **拓扑同构 ≠ 物理语义等价**：斑马和斑马纹板凳在拓扑图上完全同构，必须引入比例尺度作为第二判据。

> **L0.5 比例裁决 = 从"拓扑同构"推向"物理语义"的决定性判据**：
> - L0：有没有这些部件？
> - **L0.5：部件的比例是否落在生物区间或人造区间？**
> - L1：变形的幅度是多少？

> **两套比例系统天然不重叠**：进化压力 vs 人体工学，数值上几乎无交集 → 算法不需要语义理解，只需数值测量。

> **艺术变形的正确识别**：关键比例落在哪套区间，就归哪个类别，与外观扭曲程度无关。
