## 造物主原始描述

> 算法分为两种情形：
> 1. **静态图片**：AI识别图片（我们之前讨论的）
> 2. **视频流**：拓扑骨架在旋转

**核心分野**：静态 = "切片推断"，视频 = "轨迹积分"

---

## 两种情形核心对比

| 维度 | 静态图片（单帧）| 旋转视频流（时序）|
|---|---|---|
| **拓扑状态** | 2D投影瞬时快照（可能退化/遮挡）| 3D拓扑在时间轴上的连续展开 |
| **尺度来源** | 环境参照物、透视灭点（间接估计）| 运动视差、自转周期、角速度（直接测量）|
| **负空间可见性** | 固定视角下的局部可见 | 随旋转动态显现/消失，完整拓扑遍历 |
| **功能验证** | 基于先验的假设检验 | 基于物理一致性的轨迹验证 |
| **算法重心** | L-1尺度上下文 + L0拓扑匹配 | 时序拓扑跟踪 + 运动学约束 |
| **本质** | 信息不完整→贝叶斯推断 | 完整信息→轨迹积分 |

---

## 静态图片：重先验、轻计算

| 策略 | 内容 |
|---|---|
| **L-1物理上下文第一** | 30cm vs 1.2m的物理必然性消歧 |
| **多假设并行+几何收敛** | 允许2点/3点/N点多种拓扑切分同时生成候选 |
| **几何一致性裁决** | 投影IoU/负空间合理性/物理约束逐项验证 |
| **频域补全** | 用可见部分FFT外推被遮挡区域（统计先验）|

**本质**：在信息不完整的情况下，用物理常识和几何约束做最优贝叶斯推断

---

## 旋转视频流：轻先验、重时序积分

### 三种黄金信息

| 信息 | 算法利用 | 静态无法实现 |
|---|---|---|
| **自转解尺度** | `v = ωR`，从光流估计ω和v → 直接算出R | 比间接估计精确一个数量级 |
| **拓扑完整性验证** | 逐帧累积拓扑证据；遮挡区域旋转后显现 | 马头凳180°背面=平整座面；真斑马180°背面=脊柱肌肉 |
| **运动学约束** | 惯性矩/质心轨迹/支撑相-摆动相时序 = 生物vs人造区分器 | 动态特征比静态比例更强判别器 |

### 快通路时序升级

```
原快通路：锁"方向向量"
新快通路：锁"拓扑状态时序演化模型"

快通路预测：
  下一帧哪些锚点应该出现？
  负空间应如何变化？
  ↓
  若观测与预测不符 → 立即触发慢通路重初始化
```

## 双模态统一：拓扑作为"时空不变量"

```
静态图片输出：骨架的瞬时实例（带不确定性）
视频流输出：骨架的世界线（时空轨迹）

两者收敛到：同一个"功能-比例-尺度"联合语义空间
```

**互增强机制**：
```
视频流高精度3D拓扑 → 反向标注静态训练数据 → 提升静态模型泛化
静态图庞大先验库 → 冷启动视频流初始假设 → 避免时序跟踪从零漂移
```

| 维度 | 价值 |
|---|---|
| **资源自适应** | 静态图：重先验轻计算；视频流：轻先验重时序积分 |

| **渐进式认知** | 静态图先给初步判断（70%）→ 视频流接入后置信度提升至99% |

## 核心洞见

> **静态是"切片推断"，视频是"轨迹积分"**：
> - 静态：信息不完整，用物理常识+几何约束做贝叶斯推断
> - 视频：信息完整，用运动轨迹做直接验证

> **旋转180°是终极判别器**：
> - 马头凳背面 = 平整座面支撑结构
> - 真斑马背面 = 脊柱和臀部肌肉
> - 这种时序不对称性是静态永远无法获取的黄金判据

> **同一核心表示，不同积分路径**：
> - 参数化拓扑骨架是统一的底层表示
> - 静态输出瞬时实例，视频输出时空轨迹
> - 最终收敛到同一个语义空间
