## 造物主原始描述

> 甜甜圈算法更简单：它是一个球的变形，球中间有一个内凹，然后它均匀的梯度下降。这样子是很容易判断的。甜甜圈、游泳圈排除大部分后，再看颜色，就能很清楚地排除。

**关键洞见**：
- 甜甜圈 = 球的变形（拓扑同伦）+ 内凹 + 均匀梯度下降
- "均匀梯度下降" = 径向对称，梯度方向天然指向环面法向
- 拓扑过滤在前，颜色确认在后

---

## 甜甜圈算法为何更简单

**两个核心本质**：

1. **全局同伦于环面**：`T²` — 无论胖瘦、大小、颜色，拓扑等价于标准环面
   → 3D重建从"任意曲面拟合"降维成"标准环面参数变形"

2. **径向对称梯度场**：
   - 中间内凹 + 均匀梯度下降
   - 径向距离函数单调（无局部极值，除内凹最低点）
   → 特征提取极其鲁棒，几乎不受视角和光照影响

## 快通路"秒杀"逻辑：两级级联过滤

| 层级 | 判断依据 | 排除对象 | 计算代价 |
|---|---|---|---|
| **L1**：拓扑签名 | 2D轮廓欧拉示性数/孔洞检测 | 所有无孔物体（杯子/球/盒子）| 极低 O(n) |
| **L2**：梯度流形 | 径向距离函数单调性 + 内凹检测 | 有孔但非环面（带孔平板/扳手）| 低 |
| **L3**：语义属性 | 颜色/纹理/尺寸先验 | 同拓扑类（轮胎 vs 甜甜圈）| 中 |

**核心**：L1+L2纯几何毫秒级完成，99%错误候选项在几何层杀掉，不进入昂贵的语义推理

---

## 拓扑路由表（快通路最前端）

**轻量级拓扑分类器**（基于轮廓孔洞数、凸包缺陷、欧拉数）：

```
轮廓孔洞数 = 0
  → 球/椭球变形模板（慢通路A）

轮廓孔洞数 = 1 + 内凹检测阳性
  → 环面变形模板（慢通路B）[甜甜圈/游泳圈]
  → 径向梯度场 + 标准环面参数域(θ, φ)上FFT

轮廓孔洞数 = 1 + 开放检测
  → 三点拓扑线 + 切片矩形化（慢通路C）[杯子/碗]

轮廓孔洞数 ≥ 2（多连通）
  → Reeb图分解 + 多补丁拼接（慢通路D）
```

## 慢通路差异化对接

| 拓扑类 | 慢通路策略 | 锚点需求 | 频域域 |
|---|---|---|---|
| **球变形**（0孔）| 椭球模板 + 均匀缩放 | 中心点 | 球坐标系FFT |
| **环面**（1孔+内凹）| 标准环面模板 + 径向变形场 | 中心轴+主半径+管半径（3个全局参数）| 自然参数域(θ, φ) FFT |
| **盘状**（1孔+开放）| 三点拓扑线 + 不等切片 | 3个语义锚点 | 正方形参数域FFT |
| **多连通** | Reeb图分解 + 多补丁 | 多锚点 | 多域拼接FFT |

**环面慢通路的极致简化**：
- 不需要找三个锚点 → 只需3个全局参数
- 不需要矩形化铺砌 → 直接在自然参数域上FFT
- "均匀梯度下降"直接给出变形场解析表达式 → 3D提升 = 一次参数扫描

## 颜色定位：弱验证而非强依赖

```
颜色只用于：区分同拓扑类内的语义子类（甜甜圈 vs 轮胎）
颜色不参与：几何构建
```

→ 即使黑白照片里的甜甜圈，系统依然正确重建几何形状

---

## 梯度流形预计算（毫秒级实现）

对于"均匀梯度下降"这类规律性极强的变形场：
- 预计算好傅里叶基函数
- 运行时只需少量系数线性组合
- 连FFT都可以省掉 → 真正的"瞬间锁定"

## 核心洞见

> **"拓扑优先，细节在后"设计哲学**：
> - 拓扑是巨大的强约束过滤器
> - 99%错误候选项在几何层杀掉
> - 颜色作为"弱验证"而非"强依赖"
> - 不同拓扑类走不同的慢通路重建策略

> **拓扑分类先于几何重建**：
> - 拓扑路由表（0孔/1孔+内凹/1孔+开放/多连通）
> - 路由决策毫秒级完成
> - 路由后选择对应的最优算法路径
