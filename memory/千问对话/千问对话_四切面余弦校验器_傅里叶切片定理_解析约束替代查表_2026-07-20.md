## 一、核心纠正：不是查表，是校验器

> **造物主原话**：不是为了查表。是用来作为切点关系的校验。因为切点关系在固定角度的切面上，始终会维持一个面积变换的梯度，或者说是一个傅里叶变换的公式。

**本质重新定性**：
```
查表（旧误解）：离散映射签名→参数
校验器（真正目的）：连续约束，四点是否共余弦曲线

固定切面 = 采样点（测量4个S值）
校验目标：四个S值是否落在同一个余弦曲线上
  → 落在曲线 = 真实物理结构
  → 偏离曲线 = 虚假信号/噪声/误检
```

## 二、核心公式：余弦约束方程

### 空域形式

```
S(θ) = S_0 · |cos(θ - θ_true)| + ε(θ)

S(θ)      = 角度θ处的皮克面积（实测值）
S_0       = 基准面积（θ=0°时的投影）
θ_true    = 真实斜面角度（未知，不需要知道）
ε(θ)      = 残差（衡量置信度）
```

### 校验协议

```
测量：S(0°), S(30°), S(45°), S(60°)
拟合：四个点是否符合 S(θ) = A|cos(θ-φ)| + B 的形式

通过条件：拟合残差 < ε_threshold
  → 锚点构型合法
  → φ 即为真实斜面角度（副产品，不是目的）

失败条件：残差过大
  → 锚点不共面 / 动态干扰 / 相机未解耦
  → 触发L-0重搜索
```

## 三、理论基础：Radon变换 + 傅里叶切片定理

### Radon变换（拉东变换）

```
R{f}(θ, t) = ∫ f(x, y) ds
           = 二维物体在角度θ处的线积分投影

当f是锚点的格点密度函数时：
R{f}(θ, 0) ∝ S(θ) — 角度θ的投影在中心轴的值 = 该角度的皮克面积
```

### 傅里叶切片定理（本质）

```
F¹{p_θ(t)} = F²{f(x,y)} | line at angle θ

三维物体在任意角度θ切面上的投影的一维傅里叶变换
  = 该物体二维傅里叶频谱中过原点、同角度直线上的值

在离散锚点场景下：
四个固定切面的S值，实质是在θ=0°/30°/45°/60°处采样R{f}函数
校验 = 验证四个采样点是否来自同一个f(x,y)
```

## 四、查表 vs 校验器的本质对比

| 维度 | 查表法（旧） | 解析校验器（新） |
|---|---|---|
| **本质** | 离散映射：签名→参数 | 连续约束：四点共曲线检验 |
| **对未知角度** | 无法处理（表里没有）| ✅ 天然支持（公式对所有θ连续）|
| **误差度量** | 预设容差窗口 | 残差ε连续量化置信度 |
| **计算** | O(1)查表 | O(1)代入公式+残差 |
| **可解释性** | 黑箱匹配 | 白箱物理定律验证 |
| **与L-0关系** | 独立于频域 | **就是L-0频域对齐的数学表达** |
| **对37°/22.5°** | 需扩展字典 | ✅ 无需特殊处理 |

## 五、频域增强版：空域+频域双重校验

```
空域校验：四个S值是否符合余弦曲线
频域校验：四个角度的FFT幅度谱是否与空域余弦一致

两者应给出一致的残差
  → 一致：锚点构型真实
  → 不一致：存在纹理伪装或光照干扰（空域被欺骗，但频域不会）
```

## 六、完整校验流水线

```
L-0锚点提取 → 候选锚点集
    ↓
G0优先级：正交基准S₀校验
    ↓ S₀通过
S_0, S_30, S_45, S_60 四个切面皮克计算
    ↓
余弦约束方程拟合：
  S(θ) = A|cos(θ-φ)| + B
    ↓
残差 ε = Σ(S_实测 - S_拟合)²
    ↓
ε < ε_threshold → VALID（顺便解出φ=真实斜面角度）
ε ≥ ε_threshold → FAIL → 定位失败维度 → L-0重搜索
    ↓（可选）
频域FFT交叉验证
```

## 七、为什么解决了"三维皮克定理"问题

| 传统Ehrhart | 本方案 |
|---|---|
| 在三维格点空间中直接计数 | 降维到二维投影 |
| 需要高阶校正项（面法向量等）| 只需要余弦曲线拟合 |
| 计算复杂度随维度指数增长 | O(1) 四点代入 |
| Reeve四面体=体积不可数 | **四切面余弦校验对任何三维物体都成立** |

**关键洞察**：
```
Reeve四面体的问题 = 体积不可从格点计数直接算得
但 = 体积在任意切面上的投影依然满足傅里叶切片定理

所以：与其数格子算体积，不如用切面投影验证一致性
三维几何约束 → 二维余弦校验
```

## 八、相机运动解耦的天然绑定

```
相机在动：
  四个切面面积同步缩放
  但余弦关系的"形状"不变
  → 校验器天然免疫尺度变化

物体在动：
  四个切面面积的相对关系被破坏
  → 余弦约束方程报错
  → 精确区分"相机在动"vs"世界在动"
```

## 九、核心洞见

> **校验即认知**：不需要知道真实角度θ_true是多少，只需要验证四个测量值是否来自同一个物理结构。

> **余弦=物理定律**：真实三维物体在固定切面上的投影面积，必须严格服从余弦规律。这是物理定律，不是统计相关。

> **副产品=角度解算**：校验通过时顺便解出的φ=θ_true，但这是校验的副产品，不是目的。

> **固定切面=采样点**：不是"用哪个角度的切片"，而是"在四个角度上采样，验证是否共曲线"。

> **残差=置信度**：连续残差值替代硬阈值，可直接驱动注意力权重分配。
