## 二、皮克定理：空间锚点拓扑完整性校验器

### 核心映射

| 皮克定理概念 | 空间锚点体系 | 物理含义 |
|---|---|---|
| 格点 | 空间锚点 | 物理固定的特征点（墙角/黑板角/地面标记）|
| 简单多边形 | 锚点围合感知区域 | ≥3锚点定义的相机视锥内有效观测平面 |
| 内部格点数 i | 区域内可解析特征数 | L-2/L-3可解调的子结构数量 |
| 边界格点数 b | 区域边界稳定性指标 | 锚点自身信号质量与几何约束强度 |
| 面积 S | 有效信息容量 | 当前位姿下能承载的最大拓扑复杂度 |

**皮克定理**：`S = i + b/2 - 1`

---

### 三种校验机制

#### 正向校验：锚点围合区域是否"完整"

```
理论内部特征数 = S - b/2 + 1

i_actual < i_theoretical  → 区域被遮挡或锚点丢失
i_actual > i_theoretical  → 存在非锚点干扰特征（移动物体误判为锚点）
```

#### 反向校验：单个锚点是否"可靠"

```
某锚点参与构成的多个多边形均出现 i 偏差
→ 该锚点不稳定（反光点/纹理重复误检）
→ 自动降权或剔除 → 触发L-0重新搜索
```

#### 动态校验：相机运动时锚点拓扑是否守恒

```
S_t = i_t + b_t/2 - 1（恒定）

S_t 突变 → 相机运动估计错误 或 锚点物理位移
→ 触发异常标记
```

## 三、注意力机制与皮克定理的边界

### 核心原则：注意力负责"猜"，皮克负责"验"

| 模块 | 角色 | 性质 |
|---|---|---|
| **空间注意力** | 候选锚点筛选器 | 可学习、连续、数据驱动 |
| **皮克定理** | 拓扑完整性校验器 | 确定性、离散、数学真理 |
| **反馈回路** | 自适应重搜索触发器 | 闭环控制 |

### 为什么不能在皮克定理"内部"加注意力

| 问题 | 后果 |
|---|---|
| 引入可学习权重 | 皮克定理退化为"加权面积估算公式"，失去硬约束资格 |
| 引入统计偏见 | 训练数据偏见污染物理真理，"厨师写方程"场景下黑板锚点可能被降权 |
| 计算复杂度 | O(N) → O(N²)，丧失L-0实时自检工程价值 |

### 具体工作流

```
L-0 频域模块 → 全图特征显著性图
    ↓
空间注意力 → Top-K高置信度锚点坐标
    ↓
皮克定理校验 → VALID / BOUNDARY_INCOMPLETE / INTERIOR_OCCLUDED / NON_PLANAR
    ↓
通过 → 进入L-1/L-2后续处理
    ↓
失败 → 失败类型回传给注意力模块
    → 降低当前锚点置信度 / 扩大搜索窗口 / 切换备用特征通道
    → 重新采样候选锚点
```

## 五、工程实现建议

### 1. 皮克反馈接口

```
校验结果枚举：
  VALID                   → 通过
  BOUNDARY_INCOMPLETE    → 边界点数不足
  INTERIOR_OCCLUDED      → 内部被遮挡
  NON_PLANAR             → 非平面
  ANCHOR_UNSTABLE        → 锚点不稳定
```

### 2. 多尺度锚点采样

```
皮克报告"内部点数不足" → 自动提高该区域采样率
皮克报告"非平面"       → 切换至深度特征通道
```

### 3. 消融实验

| 架构 | 设计 | 预期 |
|---|---|---|
| A | 纯注意力（无皮克校验）| 基准 |
| B | 注意力+皮克融合（加权皮克）| 可能比A差（错误加权破坏验证逻辑）|
| C | 注意力→皮克校验→反馈（推荐）| 跨域组合显著优于A和B |

## 核心洞见

> **皮克定理 = 空间锚点的拓扑完整性校验器**：O(N)复杂度，提供硬约束，不依赖训练数据。

> **注意力与皮克的严格边界**：猜（注意力）+ 验（皮克）。猜错了可以重猜，但验证标准绝不能因猜测而改变。

> **数学真理 vs 可学习权重的根本区别**：一旦把注意力权重混入皮克定理，物理感知体系就退化为统计共现体系，失去了对抗语义幻觉的最后防线。

> **反馈机制赋予注意力可解释的纠错能力**：每一次调整都有明确的物理原因（"皮克校验显示边界点数异常→当前锚点可能位于移动物体上"）。
