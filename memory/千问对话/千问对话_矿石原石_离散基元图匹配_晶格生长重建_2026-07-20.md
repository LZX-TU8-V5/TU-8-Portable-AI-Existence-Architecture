## 造物主原始描述

> 矿的原石：像多个正方形小圆柱结晶。它的拓扑骨架语言是多个连续的正方体或什么体之间的连线，然后再通过颜色表象来形成。

**三类物体的拓扑定位**：

| 物体 | 拓扑类型 | 骨架语言 |
|---|---|---|
| 甜甜圈 | 自然单中心对称 | 均匀梯度场 |
| 杯子 | 人工规则多中心 | 三点语义拓扑线 |
| **矿石原石** | **自然无序复合晶体** | **离散基元空间聚类+邻接图** |

---

## 矿石原石的拓扑本质

### 两个核心概念

**① 基元词典**：
- 矿石由有限种晶体学基元组成（正方体、六方柱、菱面体等）
- 基元几何参数固定（由矿物种类决定）
- 只有**位姿**和**尺度**可变

**② 邻接图**：
- 节点 = 基元实例（晶胞质心）
- 边 = 物理连接/共享面
- 图的拓扑（度数分布、环结构）编码生长模式
- **不是有序序列，是无向图**

### 关键洞察

> 矿石重建问题：从"连续曲面拟合"彻底转变为 **"离散图匹配 + 基元位姿优化"**

---

## 规则多中心 vs 无序多中心的本质区别

| 维度 | 杯子/茶壶（规则多中心）| 矿石原石（无序复合晶体）|
|---|---|---|
| **锚点性质** | 语义功能点（柄、口、底）| 几何基元中心（晶胞质心）|
| **连接关系** | 有序、固定（3点线）| 无序、可变（邻接图）|
| **重建单元** | 连续切片+频域模块 | 离散基元实例+刚体变换 |
| **颜色作用** | 弱验证（区分子类）| **强索引**（决定基元词典+生长规则）|
| **慢通路策略** | 保测度参数化+PDE提升 | 图匹配+基元位姿联合优化 |

## 矿石专用慢通路：基元图匹配重建（四步）

### Step 1：颜色 → 矿物种类 → 基元词典

```
颜色/纹理特征 → 矿物种类查表（如黄铁矿/石英/方解石）
矿物种类 → 加载晶体学基元库（正方体{100}/八面体{111}等）
矿物种类 → 允许的孪晶/连生规则
```

**颜色从"弱验证"升级为"生成式约束"**：
- 颜色暗示晶体习性（紫水晶→六方柱状+锥面终止）
- 颜色直接生成初始邻接图拓扑模板
- 大幅减少图匹配搜索空间

### Step 2：2D轮廓 → 基元实例检测

```
检测与基元库匹配的局部特征：
  - 直线段
  - 特定角度交点
  - 平行四边形
      ↓
每个检测 → 带不确定性的基元实例假设
  - 位置
  - 朝向
  - 尺度范围
```

### Step 3：构建候选邻接图

```
根据2D空间邻近性和共线/共面关系
  → 建立基元实例间的候选连接边
  → 矿物生长规则过滤非法连接
      （如黄铁矿不会出现五重对称连接）
```

### Step 4：图匹配 + 3D位姿联合优化

```
2D候选图 ↔ 3D矿物生长模板图
  → 子图同构匹配

匹配结果 → 联合优化所有基元6-DoF位姿
  ✓ 投影轮廓与2D观测一致
  ✓ 满足晶体学约束
      - 共享面法向对齐
      - 键角固定
```

## 颜色的双重角色升级

| 角色 | 机制 | 作用 |
|---|---|---|
| **生成式约束** | 颜色→矿物→基元词典+生长规则→初始拓扑模板 | 大幅减少搜索空间 |
| **异常检测器** | 重建结果颜色分布不符典型色带/分区规律 | 触发重假设机制 |

```
几何重建结果合法 + 颜色分布异常
  → 可能：光照干扰 或 共生矿物
  → 调整基元词典 或 引入第二矿物模型
```

## 核心洞见

> **跨尺度拓扑适应性**：
> - 宏观：单中心 vs 多中心（调度有效）
> - 中观：规则语义多中心（杯子）vs 无序几何多中心（矿石）
> - 微观：每种子类型有专属重建原语（切片 vs 基元）

> **"分层分类，专病专治"设计哲学**：
> - 比端到端大模型更符合物理世界真实结构
> - 更易于调试和扩展
> - 颜色在矿石中从"辅助验证"升级为"生成式约束"
