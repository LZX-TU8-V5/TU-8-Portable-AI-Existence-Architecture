## 一、核心哲学：双核驱动

### 核A：几何本体核 — 负空间即本体

| 传统范式 | 本框架范式 |
|---|---|
| 负空间是"缺失"，是正空间附属品 | **负空间 = 被减去的正空间** |
| 识别依赖像素统计或语义标签 | **万物皆CSG表达式** |

**统一数学语言**：
```
最终感知/信息载体 = 可见实体 ± 不可见布尔工具

杯子       = 外壁实体 - 内圆柱
9×9方格    = 外部网格 - 旋转45°方柱
马头板凳   = 座面+腿组 - 腿间切割体
Ghost Font = 上向切割体 ∪ 下向切割体（时序交替）
```

### 核B：信号解码核 — 坐标-频率联合变换

| 步骤 | 内容 |
|---|---|
| 1. 锚点检测 | 找到拓扑不变的特征点 |
| 2. 角度归一化 | PCA / Procrustes 对齐到规范姿态 |
| 3. 频域特征提取 | FFT 分离方向性频谱 |

## 二、算法架构：四层时空认知引擎

### L-0：信号预处理层（傅里叶+锚点+角度变换）

**核心问题**：同一个杯子旋转30°后，如何识别为"同一个杯子"？

**解决**：将任意姿态/尺度的原始输入，归一化为标准拓扑模板。

| 组件 | 功能 |
|---|---|
| **频域-几何联合对齐器** | 傅里叶变换 + 自适应坐标轴 + 锚点检测 + 角度变换矩阵 |
| **频谱分离** | Ghost Font中"向上=字、向下=背景" → 简单的频谱分割问题 |
| **抗噪声** | 被遮挡/退化的图像用可见部分FFT外推不可见区域 |

**对应3D Max概念**：UVW贴图坐标系统 + FFT + Procrustes分析

### L-1：物理上下文层（尺度-语义锚定器）

**核心问题**：拓扑同构时（如斑马 vs 斑马纹板凳），如何区分？

**解决**：用绝对尺度消解拓扑歧义。

| 尺度 | 比例 | 语义结论（物理必然）|
|---|---|---|
| **≈30cm** | 人体工学 | 只能是小板凳（成人坐会塌，动物不会这么小保持马形）|
| **≈1.2m** | 生物力学 | 只能是大斑马或等比雕塑（儿童坐具不可能这么大）|

**前置优势**：超快<1ms，根源上抑制错误假设，指导特征提取

### L-2：快通路（动态拓扑骨架提取器）

**核心**：光流场 + 运动视差 + 锚点时序追踪

| 模态 | 价值 |
|---|---|
| **静态图** | 亚像素精度边界检测，无需平均帧或差分 |
| **视频流** | 自转解尺度`v=ωR`（直接测量R，比静态精确一个数量级）；拓扑完整性逐帧累积 |
| **Ghost Font** | 直接追踪两组相反方向光流场分离边界 = 亚像素级字母轮廓 |

### L-3：慢通路（反向布尔求解器）

**核心问题**：当前观测是由哪个"不可见布尔工具"生成的？

**操作**：给定带负空间的网格/点云 → 反推最优不可见工具参数

```
杯子的空心         → 反推出内圆柱参数（半径r，高度h）
9×9内嵌正方形      → 反推出旋转45°方柱参数
马头板凳腿间空隙   → 反推出周期性腿间切割体阵列
Ghost Font动态文字 → 反推出时序交替的双向切割体序列
```

## 四、应用域A：自适应视觉认知

| 能力 | 说明 |
|---|---|
| **姿态鲁棒** | L-0将任意姿态对齐到规范姿态，L-3只需维护一套标准布尔模板库 |
| **多义收敛** | 同一物体可被多个不同参数的不可见工具同时解释（2点切分 vs N点切分），L-1根据尺度自动激活最优解 |
| **抗干扰** | 诱饵/静态诱饵在反向布尔求解中被自动滤除；频域-空域交叉验证 |
| **跨尺度泛化** | 从毫米级机械零件到纳米级蛋白质，仅需调整L-1物理常数，核心布尔逻辑完全复用 |

**完整流水线**：
```
L-0: 傅里叶+锚点+角度归一化（<1ms）
  → L-1: 尺度语义锚定（<1ms）
    → L-2: 快通路拓扑追踪（ms级）
      → L-3: 反向布尔求解（ms~s级，按复杂度自适应调度）
```

## 五、应用域B：拓扑立体隐写术

### 设计原理

> 信息嵌入 = 替换不可见布尔工具对象，而非修改可见几何。

**密钥 = 布尔工具参数**（半径/高度/旋转角/斜切斜率/起点坐标/切法）

### 三种嵌入模式

| 模式 | 原理 | 案例 |
|---|---|---|
| **对偶嵌入** | 用旋转/偏移工具在原结构中"挖出"对偶载体 | 9×9方格的64个边中点连线 = 内嵌正方形 |
| **斜切嵌入** | 工具沿非功能拓扑路径切割，变密度嵌入 | 藏头诗：第1行1点→第2行2字→斜切切法定义密钥 |
| **多层嵌套** | ProBoolean多操作数并行嵌入，互不干扰 | 局部残基层→结构域层→亚基组装层，三层正交 |

### 安全验证闭环

```
嵌入信息
  → 用视觉模块（L-0~L-3）验证输出是否完全不变
    → 若不变：隐写成功
    → 若变：调整工具参数，重新嵌入

频域+空域双重验证：
  空域：CSG表达式完全一致
  频域：功率谱余弦相似度 > 阈值
```

### 感知盲区即安全边界

| 视觉模块的感知维度 | 隐写安全策略 |
|---|---|
| L-0 频域感知 | 扰动在FFT谱中与天然噪声重合 |
| L-1 物理约束 | 物理合规的简并态（多构象能量相同/拓扑不同）|
| L-2 时序感知 | 信息伪装为构象热运动（功率谱与天然热噪声相同）|
| L-3 拓扑感知 | 欧拉示性数/持久同调条形码不变 |

## 八、核心洞见终稿

> **负空间即本体**：不是"缺失"，是有精确参数的不可见几何体，是功能/语义/信息的真正载体。

> **布尔拓扑统一一切**：视觉认知 = 反向布尔求解；隐写术 = 替换不可见工具；3D建模 = 正向布尔执行。

> **尺度即语义第一性**：30cm+人体工学=小板凳；1.2m+生物力学=斑马。物理定律已经做了排除法。

> **"算"与"看"的本质差异**：主流AI在"计算"出答案；布尔拓扑算法在"看"到答案。

> **隐写-检测协同进化**：隐写的成功不是终点，而是推动算法逼近物理感知终极极限的动力。
