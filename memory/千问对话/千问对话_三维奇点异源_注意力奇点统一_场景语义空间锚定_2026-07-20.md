## 一、核心陷阱：单一物体奇点 ≠ 场景空间奇点

> **造物主原话**：单一物体的3D坐标奇点和场景空间3D奇点不在同一个点。需要注意力调节这些奇点，在统一奇点下才能做共同空间语义转换。

**问题本质**：

```
单一物体（如黑板）的余弦约束方程：
  S(θ)_黑板 → 参考原点 = 黑板自身几何中心/质心
  → 角度θ = 相对于黑板自身坐标系的斜面角度

场景空间的余弦约束方程：
  S(θ)_场景 → 参考原点 = 世界坐标系原点（墙角/地面标记）
  → 角度θ = 相对于世界坐标系的绝对角度

两个方程在不同的奇点上建立
→ 各自计算出的θ_true完全不同
→ 无法做跨物体语义比较
```

---

## 二、为什么这是个陷阱

### 错误场景：相邻物体被误判为不对齐

```
黑板斜撑：θ_黑板 = 45°（自身坐标系）
地面斜坡：θ_地面 = 30°（自身坐标系）
→ 若各自在自身奇点下校验，两者看似完全无关

但在场景统一奇点下：
→ 黑板斜撑相对于世界 = 45°
→ 地面斜坡相对于世界 = 30°
→ 两者存在固定的15°夹角关系
→ 这个夹角关系 = 场景层面的语义信息
```

### 错误场景：跨物体余弦校验失效

```
物体A（咖啡杯）S_A(θ) → 自身奇点O_A
物体B（桌面）S_B(θ) → 自身奇点O_B
→ 直接比较S_A(θ)和S_B(θ)毫无意义
→ 因为参考原点不同

必须先统一到场景奇点O_scene：
  S_A(θ)_scene = S_A(θ) · f(Δ_OA)
  S_B(θ)_scene = S_B(θ) · f(Δ_OB)
  → 然后才能比较scene坐标系下的值
```

## 三、注意力机制在奇点统一中的角色

### 核心功能

```
注意力不只选择"哪个锚点正确"
  → 注意力还负责识别每个物体当前锚定在哪个奇点
  → 学习/计算奇点之间的偏移向量
  → 将所有物体校正到统一场景奇点
```

### 奇点识别

| 信号 | 奇点类型 |
|---|---|
| 墙角/地面标记/黑板角 | 世界空间奇点候选（O_scene）|
| 物体自身几何中心 | 物体局部奇点（O_object）|
| 重心/质心 | 动态物体奇点（O_agent）|

### 奇点偏移计算

```
Δ_O = O_scene - O_object
  = 通过共同锚点反推
  = L-0锚点云中共享特征点

校正公式：
  S_object(θ)_scene = S_object(θ) · cos(Δ_O方向分量) + ε_offset
  或等效地在傅里叶域做相位校正
```

## 四、统一奇点后的语义转换

```
步骤1：奇点识别
  L-0锚点提取 → 识别每个物体锚定在哪个奇点

步骤2：奇点偏移学习
  共同锚点 → 计算Δ_O向量场
  建立奇点偏移查找表

步骤3：统一到场景奇点
  对每个物体的S(θ)在scene坐标系下重计算
  Δ_O校正 = 投影分量修正 + 相位偏移

步骤4：scene级余弦校验
  统一坐标系下的S_scene(θ)才可互相比较
  scene级校验 = scene层面语义信息（物体间夹角/相对关系）

步骤5：跨物体语义提取
  黑板斜撑45° - 地面斜坡30° = 15°夹角（scene语义）
  咖啡杯把手 - 桌面边缘 = 平行（scene语义）
```

## 五、失败模式与检测

| 失败模式 | 表现 | 检测方式 |
|---|---|---|
| 奇点未统一就做比较 | 物体明明共面但余弦校验失败 | 对已知共面物体做scene级校验，应通过 |
| 奇点偏移估计错误 | scene级角度偏差系统性偏离 | 与已知ground truth比较 |
| 多奇点冲突 | 某锚点同时属于两个奇点领域 | 锚点歧义检测 |
| 动态物体奇点漂移 | 物体移动导致Δ_O变化 | 时序奇点跟踪 |

## 核心洞见

> **奇点即语义锚**：每个物体"认为"自己站在原点；scene坐标系需要知道每个物体"真正的"原点在哪里，才能把它们放在同一个空间里对话。

> **余弦校验的适用范围**：单一物体的余弦校验 = 物体自身的几何自洽性验证；scene级余弦校验 = 物体间空间关系的语义验证。两者在不同的奇点下运作。

> **注意力是奇点的"调解者"**：不是只选择锚点，是选择"在哪个奇点的框架下"选择锚点。

> **统一奇点 = 共同空间语义的前提**：不统一奇点，余弦校验只能验证"局部自洽"，无法提取"全局关系"。
