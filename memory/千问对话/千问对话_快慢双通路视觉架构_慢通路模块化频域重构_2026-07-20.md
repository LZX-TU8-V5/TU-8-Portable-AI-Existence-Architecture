## 核心定位

**快通路（SFGAP）**：负责全局姿态的快速收敛与歧义消除
**慢通路（本对话）**：负责高精度的几何重建与细节验证

两者互为表里，构成完整的鲁棒视觉预测系统。

---

## 造物主原始描述（慢通路）

> 它是以三维坐标轴里面所形成的核心的空间锚点，然后空间锚点再形成一个物体的核心的中心点，再用傅里叶再基于。加上角度变量来形成一个一个的小模块，再由小模块拼接而成一个物体。

**核心直觉**：
- 从3D坐标轴 → 空间锚点 → 中心点 → 傅里叶+角度变量小模块 → 拼接成物体
- 快通路给初始值，慢通路精细化拟合
- 分块频域 = 局部短时傅里叶/小波变换

## 千问整理：慢通路层级结构

| 层级 | 关键组件 | 功能描述 | 数学表达 |
|------|---|---|---|
| **L0** | 基础锚点 | 3D坐标轴内的核心空间锚点（物体不随视角变化的拓扑节点：角点、质心、对称轴端点）| A = {a₁, a₂, ..., aₙ} ∈ R³ |
| **L1** | 中心聚合 | 物体核心中心点（加权或几何约束解算出的本体坐标系原点，频域变换的旋转中心）| C_obj = f(A) |
| **L2** | 原子模块 | 傅里叶基 + 角度变量：每个局部频域块携带独立相位/角度参数，表达局部曲率或纹理走向 | M_i = F⁻¹(S_i · e^(jθ_i)) |
| **L3** | 物体合成 | 所有原子模块按锚点拓扑关系空间拼合，生成高保真3D物体表达 | O_final = ⨁ᵢ T(C_obj, v⃗_i) ∘ M_i |

## 慢通路核心机制

### 锚点驱动而非像素驱动
- 不直接处理原始图像，先提取或从快通路接收"空间锚点"
- 锚点是物体骨架：光照变化、遮挡下，拓扑结构依然稳定

### 分块频域编码的优势
- 复杂物体是非平稳信号 → 不能用一个大的FFT
- 分块 = 局部短时傅里叶变换/小波变换
- 每个小模块只需少量频率分量 → 精确描述局部几何
- 避免全局FFT的高计算量和低频模糊

### 角度变量作为"微调旋钮"
- 不仅是旋转，更是模块间对齐的接口
- 优化边界处的角度差和相位连续性 → 无缝融合
- 同时保留对物体形变（关节弯曲）的表达能力

## 快慢双通路协同闭环

```
[语言/视觉输入]
    ↓              ↓
[快通路]        [慢通路]
  ↓               ↓
语义方向预判   空间锚点估计
+拓扑锁定        ↓
    ↓          核心中心点解算
    ↓              ↓
提供: 初始6-DoF  模块化频域生成
位姿&候选方向   (FT + 角度变量)
    ↓              ↓
    → ← 反馈: 高精度残差 & 置信度
    ↓
 方向先验修正
    ↓
[最终精确物体表达]
```

### 快→慢（初始化）
快通路瞬间锁定的"方向向量"和"第三点位置"
→ 直接作为慢通路空间锚点的初始值
→ 慢通路在"正确邻域"内精细化拟合，不从零搜索
→ 收敛时间缩短数个数量级

### 慢→快（校正）
慢通路拼接完成后 → 计算几何一致性分数
- 分数低 → 快通路的"大概率排除"误杀正确解
- 慢通路将高精度残差反馈 → 触发快通路重定向或先验更新

### 动态资源分配
```
简单/常见物体（桌上的杯子）
  → 快通路结果足够好
  → 慢通路跳过或仅轻量级验证

快通路置信度低 或 任务要求高精度操作
  → 完整启动慢通路模块化重构
```

## 工程落地建议（千问）

| 建议 | 详细内容 |
|---|---|
| **锚点选择策略** | 选择曲率极值点、对称轴交点、语义关键点（对噪声和视角变化最不敏感）|
| **模块大小自适应** | 平坦区域→大模块（低频）；边缘/角点区域→小模块（高频）；快通路轮廓信息指导慢通路模块划分 |
| **可学习 vs 解析分离** | 快通路"语义方向先验"可用神经网络学习；慢通路"傅里叶+角度拼接"保持解析/半解析（保证可解释性和物理一致性）|

## 核心洞见

> **解决了"精度-速度"悖论**：
> - 传统方法：快但粗（纯语义） OR 精但慢（纯几何优化）
> - 双通路：快得足够用，精得刚刚好

> **双通路本质**：
> - 快通路 = System 1（直觉、启发式）
> - 慢通路 = System 2（分析、构建式）
> - 不是独立系统，是相互喂数据、相互校验的闭环
