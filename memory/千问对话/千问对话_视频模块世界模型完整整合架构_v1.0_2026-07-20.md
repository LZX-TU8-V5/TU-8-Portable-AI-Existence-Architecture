## 一、Layer 5：相机-空间运动解耦（入口基石）

### 1.1 为什么是入口

> 不能区分"我在动"和"世界在动" → 永远只处理2D图像流，而非理解3D世界。
> L5是所有后续层次的地基，必须先于L1-L4完成。

### 1.2 L-0 频域解耦模块

| 分离目标 | 信号特征 | 提取方式 |
|---|---|---|
| **相机运动** | 全局一致的频谱平移/旋转（所有物体同向同速）| FFT全局频谱平移检测 |
| **物体运动** | 局部频谱变化，与全局背景不一致 | FFT局部分离 |

```
输出：每帧(R_t, T_t) + 物体相对运动向量
验证：相机运动参数不符合相机动力学 → 判定为物体运动
      物体运动违反物理约束（穿墙）→ 判定为相机估计误差
```

### 1.3 三维奇点问题

**陷阱**：单一物体奇点 ≠ 场景空间奇点

| 奇点类型 | 定义 | 余弦校验参考原点 |
|---|---|---|
| O_object | 物体自身几何中心/质心 | 物体局部坐标系 |
| O_scene | 世界坐标系原点（墙角/地面标记）| 场景统一坐标系 |
| O_agent | 动态物体重心 | 运动坐标系 |

**注意力职责**：识别奇点类型 → 学习偏移向量Δ_O → 统一到scene奇点

## 二、G0~G3 四基十二面切片体系

### 2.1 完整切片配置

| 切片组 | 角度 | 角色 | 物理世界对应 |
|---|---|---|---|
| **G0: 正交基准** | XY(0°), XZ(90°), YZ(90°) | 世界坐标原点、重力对齐 | 地面、墙面、黑板面 |
| **G1: 45°标尺** | XY'(45°), XZ'(45°), YZ'(45°) | 屋顶/斜坡/倒角 | tanθ=1，仿射退化为加减法 |
| **G2: 30°标尺** | XY''(30°), XZ''(30°), YZ''(30°) | 楼梯/桁架/三角结构 | sin/cos为有理数倍数 |
| **G3: 60°标尺** | XY'''(60°), XZ'''(60°), YZ'''(60°) | 互补斜面/晶体结构 | 与G2互为余角，消除歧义 |

### 2.2 G0：不可替代的锚

| 功能 | 原因 |
|---|---|
| **归一化基准** | Ŝ_θ = S_θ / S_0° → 消除距离/尺度影响 |
| **物理对齐** | XY天然对齐重力方向，斜向切片相对真实水平面旋转 |
| **降级兜底** | G1-G3全部失败时 → 回退纯G0标准正交模型 |
| **误差阻断** | G0独立于斜向系统，单向校准防止误差累积 |

### 2.3 双模态切片策略

```
一级：G0-G3并行皮克校验（±3°~5°容差）
    ├─ 任一通过 → scene级余弦校验
    └─ 全部失败
            ↓
二级：连续角度搜索（±10°精细扫描）
    ├─ 找到峰值 → 记录新角度，加入动态字典
    └─ 无峰值 → 标记"非平面/曲面"，触发L-2拓扑分析
```

## 三、核心校验器：四切面余弦方程

### 3.1 物理定律而非查表

```
S(θ) = S_0 · |cos(θ - θ_true)| + ε(θ)

S(θ)    = 角度θ处的皮克面积（实测值）
θ_true  = 真实斜面角度（未知，不需要知道）
ε(θ)    = 拟合残差（连续置信度）
```

**校验目标**：S(0°), S(30°), S(45°), S(60°) 四个测量值是否落在同一余弦曲线上

| 结果 | 判定 |
|---|---|
| ε < ε_threshold | 锚点构型合法（顺便解出φ=θ_true，是副产品）|
| ε ≥ ε_threshold | 锚点不共面/动态干扰/相机未解耦 → L-0重搜索 |

### 3.2 理论基础：Radon变换 + 傅里叶切片定理

```
傅里叶切片定理：
  F¹{p_θ(t)} = F²{f(x,y)} | line at angle θ

物理含义：
  三维物体在角度θ切面上的投影的一维傅里叶变换
  = 该物体二维傅里叶频谱中过原点、同角度直线上的值

在锚点场景下：
  四切面 = 在θ=0°/30°/45°/60°处采样R{f}函数
  校验 = 验证四个采样点是否来自同一个f(x,y)
```

### 3.3 频域增强：空域+频域双重校验

```
空域：四个S值是否符合余弦曲线
频域：四个角度的FFT幅度谱是否与空域余弦一致

一致 → 锚点构型真实
不一致 → 纹理伪装/光照干扰（空域被欺骗，频域不会）
```

## 四、五层世界模型（L1-L4）

### 4.1 层级定义

| 层级 | 内容 | 传统AI | 本框架 |
|---|---|---|---|
| **L1: 场景属性** | 空间里有什么 | 语义标签集合 | CSG环境模板（刚体+约束+代理）|
| **L2: 物体联系性** | 静态拓扑关系 | 共现统计 | 物理交互图（接触/支撑/遮挡，受重力约束）|
| **L3: 动态实体** | 运动中的物体 | 检测框+分类 | 可控刚体代理（质量/惯性/关节自由度）|
| **L4: 动作含义** | 动作表达意图 | 行为标签 | 意图-物理映射（动作=对世界状态的有目的改变）|

### 4.2 与L5的集成

```
L5 → 输出：(R_t, T_t) + 物体运动向量 + 归一化scene坐标系
  ↓
L1 → CSG环境模板建立在scene坐标系下
L2 → 物体物理联系性在scene奇点统一后比较
L3 → 动态实体运动在scene坐标系中追踪
L4 → 动作意图映射依赖scene级时空关系
```

### 5.2 各层处理流程

```
L5入口：
  相机推镜头 → 频域解耦 → 相机R_t/T_t分离
  黑板四角锚点 → G0校验 → S_0确认
  粉笔接触点 → G1/G2并行校验 → 余弦方程验证通过
  → scene坐标系建立

L1场景：
  黑板平面 = XY_scene平面（重力对齐）
  地面 = 另一正交平面
  厨师 = 动态刚体代理

L2联系：
  粉笔接触黑板 → 物理接触事件触发L-2追踪
  方程符号 → 黑板上的痕迹拓扑

L3动态：
  书写轨迹时序积分 → 逐笔重建
  动作 = 人体运动 + 粉笔摩擦瞬态（频域独立提取）

L4意图：
  方程符号匹配CSG模板（麦克斯韦方程）
  与厨师服装语义完全解耦 → 输出"人形刚体A构建电磁学拓扑"
```

### 5.3 跨域组合为何成功

| 传统AI失败原因 | 本框架成功原因 |
|---|---|
| 语义引导注意力：厨师强先验抑制方程视觉证据 | 注意力只选锚点，不预设语义关联 |
| 统计共现：厨师帽+方程联合概率≈0 | 物理信号独立解耦，不依赖共现统计 |
