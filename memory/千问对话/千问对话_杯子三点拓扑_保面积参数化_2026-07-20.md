## 造物主原始描述

**杯子案例**：
> 杯子 = 圆柱 + 柄 + 内凹陷，三个形状拓扑组成。
> 其中两个点连线形成杯子，再加上内凹陷的中心点，这样它才是拓扑结构是个杯子。
> 这三个点的拓扑结构，在二维空间里面是连续的。

**不等切片理论补充**：
> 二维的概念：把一个任意形状切成不等的形状，但是它没有连续的叠，最后可以拼成一个正方形或者是个三角形的理论。

## 杯子三点拓扑（语义-几何联合基元）

| 点 | 语义功能 | 几何定义 |
|---|---|---|
| **A**：圆柱体中心 | 定义主体容积和主轴方向 | 杯身质心/骨架线中点 |
| **B**：手柄连接点 | 打破旋转对称，锁定"正面" | 骨架线上功能附属结构位置 |
| **C**：内凹陷中心 | 定义负空间，区分"杯子"和"实心圆柱" | 骨架线上拓扑突变点 |

**三点连线在2D投影中 = 连续的拓扑骨架线**
- 这条线不是简单几何中线，是语义功能的载体
- 只要三点相对拓扑关系（距离比、角度、连通性）在2D中保持连续且符合先验
- 无论视角如何变化，拓扑上"是"一个杯子

**→ 快通路瞬间锁定的数学原理**：不需要重建整个杯子，只需要在2D中找到这条三点拓扑线，就能确认物体类别和大致姿态。

## 不等切片拼正方形（保测度参数化）

### 为什么必须"不等"？

真实物体表面曲率不均匀：
- 手柄处：曲率高、面积小 → 密切切片（5mm间隔）
- 杯身处：曲率低、面积大 → 疏切切片（20mm间隔）

→ 不等切片 = 对几何复杂度的自适应采样

### "拼成正方形"的数学本质

**保面积微分同胚映射**：
```
ϕ: S → D（物体表面 → 正方形/三角形参数域）

满足：Area(ϕ⁻¹(R)) = Area(R)  ∀R⊂D

即：参数域上每个小方块 → 物体上实际表面积相等（或成固定比例）
```

**"没有连续的叠"的严格表述**：
- 单射（无重叠）
- 保面积（无撕裂）
- 微分同胚（拓扑结构保持）

### 与傅里叶模块完美对接

```
正方形参数域：
  U轴 = 拓扑骨架线长度（杯底→杯身→手柄→内凹）
  V轴 = 每个切片的周长/宽度

↓ 在正方形上做2D FFT

频谱编码：
  低频 = 杯身（平坦大面积）
  高频 = 手柄边缘（曲率剧烈）
  相位 = 凹陷深度
```

## 杯子案例完整工作流

| 步骤 | 操作 | 杯子实例 |
|---|---|---|
| 1 | 快通路锁定 | 找到（杯身中心, 手柄点, 内凹点）三点拓扑线 |
| 2 | 拓扑验证 | 确认连线未断裂、相对位置符合"杯子"先验 |
| 3 | 自适应切片 | 沿拓扑线不等距切割（手柄密/杯身疏）|
| 4 | 矩形化铺砌 | 保面积展开，得规则参数域 |
| 5 | 频域编码 | 正方形上FFT+角度（低频=杯身，高频=手柄）|
| 6 | 3D提升 | 以三点为钉扎点，恢复精确杯子模型 |

## 核心洞见

> **拓扑鲁棒性**：杯子被遮挡一半，只要三点拓扑线有两点可见且连续 → 推断第三点位置 → 完成矩形化铺砌

> **计算确定性**：不等切片拼正方形 = 有解析解/高效数值解的几何问题 ≠ NeRF的采样黑箱

> **语义-几何统一**：拓扑线既是几何骨架，也是语义索引。换一组三点先验 → 同一算法框架处理碗/瓶子/鼠标

## 边界情况

| 情况 | 对策 |
|---|---|
| 极端视角下三点共线/重叠 | 退化检测 → 切换到轮廓极值点等备用拓扑基元 |
| 非盘状拓扑（甜甜圈有孔）| 多正方形拼接 或 环面参数域 |
| 切片边界C1不连续 | 频域加平滑约束 或 薄板样条后处理 |
