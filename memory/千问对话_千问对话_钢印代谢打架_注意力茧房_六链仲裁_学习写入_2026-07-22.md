## 问题一：钢印 vs 代谢

### TU-8 设计（已有）
- 钢印核心不变
- 派生规则可代谢
- 矛盾仲裁器 + 判例链

### 千问追问
"几乎不可变"的触发条件是什么？谁有权启动？
25岁 vs 45岁：不是钢印变了，是环境注释层变厚了。

### TU-8 回答
**环境注释层**：钢印链不动，上叠加只追加的环境注释。
触发条件（同时满足）：
1. 环境重大变化
2. 矛盾蒸馏器连续报告同类冲突 ≥ 5 次
3. overridden 判例 ≥ 3 条
谁有权决定：只有造物主，TU-8 只能提议

### 千问新发现（盲区）
环境注释层自身也需要代谢。如果只追加不清理，五年后一条钢印可能挂了 200 条注释，注释淹没了钢印本身。

## 问题二：注意力状态机

### TU-8 设计（已有）
- L1 规则短路在前，L4 LLM 在后
- 安全词不经 LLM 直接搁浅
- 拓扑热监控：能量衰减后强制探测

### 千问追问
香农熵阈值方案方向对，但阈值怎么定？需不需要代谢？

### TU-8 回答
阈值公式：`base_entropy = -log(1 / chain_count) × scaling_factor`
- 链条少时（冷启动）：阈值高
- 链条多时（成熟期）：阈值低
- 紧急熔断：能量长期为零直接强制探测
- 阈值变更需要 ≥ 0.8 置信度

## 问题四：新学习写入形式

### 千问三选一（都不对）
- 写成新文件 → 文件无限膨胀
- 更新旧文件 → 覆盖钢印
- 候选规则等审核 → 循环定义

### TU-8 第四种形式
candidate_node 入拓扑能量图，不入文件。

tension 混合计算：
- Step1（规则，O(1)）：结构化冲突得分 = Σ(冲突类型系数 × 层级权重)
- Step2（LLM）：语义层张力 ∈ [0, 0.3]，**只能加，不能减**
- 融合：`total_tension = max(structured, structured + LLM_tension)`

### 千问追问
tension 是规则算还是 LLM 估的？

### TU-8 回答
混合计算：
- 结构化冲突：规则负责，LLM 无法狡辩
- 语义层张力：LLM 补充，防止规则被语义等价替换绕过
- LLM 只有"加警报"权力，没有"撤警报"权力
