# 任务归档：L-0 频域相机-空间运动解耦原型

> 日期：2026-07-22 凌晨（续 2026-07-21 深夜 Session 3）
> 指令：用户「开始」→ 续做视觉模块 L5 入口「最优先」项
> 文件：`src/l5_motion_decoupler.py`（新建，11.4KB）

## 目标

L5 入口地基：相机运动（全局同频）与物体运动（局部频变）在频域分离，无需 3D 重建。
- 输出每帧 (R_t, T_t) + 物体相对运动向量
- 校验：相机动力学校验 + 物体物理约束

## 成果

### L5MotionDecoupler
| 组件 | 方法 | 说明 |
|------|------|------|
| 相机平移 T_t | 相位相关 (phase correlation) | 全局 FFT 交叉功率谱峰值 → 帧间平移 |
| 相机旋转 R_t | 对数极坐标相位相关 | FFT 幅度谱 log-polar 重采样 → 旋转角 |
| 物体运动场 | 相机补偿残差 + 前景相位相关 | 补偿后残差=局部运动；亮度阈值分离前景→物体位移 |
| 相机动力学校验 | 单帧平移/旋转上限 + 连续一致性 | 超上限→标记 invalid（相机/物体混淆） |
| 物体物理约束 | 前景局部集中 (<50% 图像) | 局部=刚性物体；全局=误判相机 |

### 关键修复（3 处）
1. **补偿符号**：相位相关返回"内容位移"（=应用相机位移负值）；原代码用负向 roll → 残差爆炸(19.8M)。改正向 roll → 残差 0。
2. **物体位移度量**：原用残差 `|f1-f2|` 掩码 → 只覆盖物体前/后缘窄带(160px) → 相位相关错比边缘返回 -20。改**亮度阈值**分离前景(物体=200/背景=0-60) → 前后帧前景相位相关直接得物体图像空间位移。
3. **刚性一致性**：原 region_ratio 用残差/0.4图像 → 小物体误判不coherent。改前景占比 <0.5 = 局部刚性。

### 自测 11/11 通过
- 纯相机：相机 valid / 平移≈3.6 / 运动平滑 / 物体残差低
- 纯物体：相机≈静止 / 物体位移≈4x / 刚性一致
- 复合：相机 valid / 平移≈2x / 物体位移≈3y
- 异常跳变：第 1 帧相机 invalid（100px 突跳触发上限）

## 物理本质（SFGAP L-0）

```
相机运动 = 全局同频平移/旋转 → FFT 全局相位斜坡（所有频率同移）
物体运动 = 局部频变        → FFT 局部频谱变化（仅物体区域）
两者频域天然可分离 → 无需 3D 重建
```
