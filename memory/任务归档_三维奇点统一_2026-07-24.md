## 目标

统一多物体场景下的奇点基准，使跨物体余弦校验成为可能。

## 核心问题

单一物体余弦校验参考自身几何中心(O_object)，scene级校验参考世界原点(O_scene)。两个奇点不同 → 直接比较S(θ)毫无意义。

## 设计

### 三大组件

**SingularityDetector**：奇点分类（5规则）
- 世界参考物(wall/floor/door/ceiling等) → O_SCENE
- 运动物体 → O_AGENT
- 高大垂直结构(aspect>2.0, h>200px) → O_SCENE
- 大面积低矮物体(area>10000, aspect<0.3) → O_SCENE
- 其他 → O_OBJECT

**OffsetComputer**：像素→世界坐标偏移
- 简化针孔相机模型：`Δworld = (cx - O_x) * depth / focal_length`
- 经验校正系数：`S_scene = S_object × (1 + α·|Δ|)`

**CrossObjectAnalyzer**：scene坐标系下跨物体关系
- 平行度：`parallel_score = max(0, 1 - rel_angle/tolerance_parallel)`
- 共面度：`coplanar_score = min(S_a, S_b) / max(S_a, S_b)`
- 关系类型：parallel(<5°) / perpendicular(≈90°) / oblique

### 场景原点定位策略
1. 最大低矮物体 → 取其左下角
2. 两个高大垂直物体 → 墙角交点
3. 图像左下角 → 降级兜底
