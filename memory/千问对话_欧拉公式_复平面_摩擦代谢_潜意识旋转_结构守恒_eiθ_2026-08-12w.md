## 一、欧拉公式分解

```
e^(iθ) = cosθ + i·sinθ          ← 复平面上的单位圆旋转

|e^(iθ)| = 1                     ← 模长恒为1，结构守恒

e^(iπ) + 1 = 0                  ← 半圈旋转（π）+ 补丁（+1）= 归零
```

## 二、e^(iθ) 的三元素映射

### 三元素

| 欧拉元素 | 数学含义 | 认知架构对应 |
|---------|---------|------------|
| **e^(iθ)** | 复平面旋转（单位圆上的运动） | **摩擦代谢总线**上的张力运动 |
| **cosθ（实部）** | 实轴 = 主意识可见的处理 | **主意识**：逻辑、行动、可见输出 |
| **sinθ（虚部）** | 虚轴 = 不可见的正交方向 | **潜意识**：情绪、隐含、压缩消化 |
| **θ（相位角）** | 旋转位置 = 张力的累积量 | **张力值**：θ越大，张力越强 |
| **模长 = 1** | 单位圆半径，永不变 | **结构守恒**：核心"我-吃-饭"骨架不崩 |

## 三、摩擦代谢总线 = 复平面上的 θ 旋转

### 动力学方程

```
dθ/dt = friction_bus_activity(t)

θ = f(张力值, 代谢进度)
```

### 旋转的物理含义

```
θ = 0：      张力完全释放，事件归档，|e^(i·0)| = 1+0i，系统平静
θ → π/2：    张力积累中，潜意识（虚部）占主导，系统焦虑
θ = π/2：    张力峰值，虚部最大，系统被潜意识情绪主导
θ → π：      接近断裂点，潜意识（虚部）达到极限
θ = π：      e^(iπ) = −1，张力最极端（−1 = 负面积最大值）
```

### 旋转的本质：主×潜的相位关系

```
在摩擦代谢总线上行进时：

  cosθ（实部）↔ sinθ（虚部）不断此消彼长

  当主意识找到补丁（+1）→ cosθ 向 +1 方向收缩
  当潜意识消化情绪（sinθ）→ 虚部向 0 方向衰减

  最终：cosθ + i·sinθ → +1 + i·0 → e^(i·0) = 1
        系统回归平静，总线释放
```
