## 关键推理

### 核心隐喻

> 本地模型 = "刚切下来的肉"
>
> 小龙虾给电信号 → 身体做被动反应
>
> 不需要思考，只需要肌肉记忆

### 三层架构

| 人体部位 | TU-8 对应 | 职责 |
|---------|----------|------|
| 大脑 | 腾讯混元 | 思考、决策、翻译 |
| 脊髓 | Ollama + Qwen-3B | 反射、执行、肌肉记忆 |
| 身体 | 本地数据 | 承载、存储 |

### 硬件配置

- 模型：**Qwen2.5-3B-Instruct**（2GB内存，极快）
- 驱动：Ollama
- 适合：16GB内存 + AMD CPU

### 协同逻辑

```
1. 用户输入自然语言
2. 混元翻译成JSON指令（电信号）
3. 本地3B执行机械动作（正则/替换/提取）
4. 结果返回混元润色
```

### 关键原则

- 禁止给3B自然语言
- 必须给代码级指令
- 提示词模板：`Input: [文本] -> Output: [结果]`
