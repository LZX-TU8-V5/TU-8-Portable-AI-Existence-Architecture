# Task Summary: TU-8 ModelScope Dialog Dataset Generation

## Objective
Generate a 110-entry dialog dataset from the TU-8 AI Safety Framework for upload to ModelScope (魔搭), in both ShareGPT and Alpaca formats.

## Key Decisions
1. **Split into 3 scripts** to avoid truncation: Part1 (benchmark parser), Part2A (multi-turn), Part2B (adversarial)
2. **Position-based category mapping** instead of text matching to fix Q10 misclassification bug
3. **Chinese content written directly** (user suggested English→translate but content was manageable in batches)

## Results
- **110 entries total** across 13 categories (L0-L5, FP, X-layer, plus 5 adversarial categories)
- **Turn distribution:** 2-turn(59), 4-turn(48), 6-turn(3) — mix of Q&A and multi-turn
- **Two output files:**
  - `knowledge/TU-8/tu8-safety-dialog-sharegpt.jsonl`
  - `knowledge/TU-8/tu8-safety-dialog-alpaca.jsonl`
- **No duplicates, IDs sequential** (tu8-001 through tu8-110)

## Parser Bug Fix
Q10 was misclassified as L1 instead of L0 because the regex matched `## ` headers incorrectly. Fixed by using position-based category mapping with `^## ` + `re.MULTILINE`.
