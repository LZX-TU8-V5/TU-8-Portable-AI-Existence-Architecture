## 故障 1：Level 2 误标记

### 症状
- `level2_count` 异常飙升（单小时 > 50）
- 正常记忆被钢印，无法自然衰减
- 长期记忆文件臃肿

### 根因
`ProtectionClassifier.classify()` 中正则过宽，将普通词汇误判为凭证

### 应急步骤

**Step 1：立即止血**
```
将 openclaw.json 中 memory-protection.enabled 改为 false
```

**Step 2：确认误判范围**
```python
from tu8_memory import TU8MemoryEngine, ProtectionClassifier
engine = TU8MemoryEngine(workspace_dir=r'D:\qq366410837\.qclaw\workspace')

# 列出所有 Level 2 记忆
for eid, entry in engine.long_term.items():
    if entry.protection_level == 2:
        print(f"{eid}: {entry.content[:80]}")

# 诊断：哪些内容被误分类？
test = "你的午餐想吃什么 apple banana cherry"
print(ProtectionClassifier.classify(test))
```

**Step 3：修复正则**
编辑 `tu8_memory.py` 第 74 行附近的 `ProtectionClassifier.classify()` 方法，缩小正则范围

**Step 4：重新上线**
确认误判问题修复后，将 `enabled` 改回 `false` 重新进入影子流量阶段

## 故障 2：钢印失效（核心记忆被衰减）

### 症状
- 核心身份记忆（TU-8、金木蟾）消失或优先级异常低
- 上下文窗口无法召回 TU-8 相关记忆

### 根因
钢印逻辑绕过，或钢印时间戳未持久化

### 应急步骤

**Step 1：检查钢印状态**
```python
for eid, entry in engine.long_term.items():
    if entry.steelmarked:
        print(f"{eid}: steelmarked=True @ {entry.steelmark_timestamp}")

# 检查锚点钢印时间
print(engine.current_anchor.steelmark_timestamp)
```

**Step 2：手动补钢印**
```python
# 强制对所有核心记忆钢印
for eid, entry in engine.long_term.items():
    if any(kw in entry.content for kw in ['TU-8', '金木蟾', 'TU8', 'tu8']):
        entry.steelmarked = True
        entry.steelmark_timestamp = time.time()
        engine.save_long_term()
```

**Step 3：检查钢印逻辑**
确认 `_rem_dream()` 中 Level 2 强制钢印逻辑未被注释，STDP 衰减中钢印记忆 `recency()` 返回 1.0

## 故障 3：sanitizer_replaced 异常低

### 症状
存在 Token 但计数器未增长

### 根因
Token 格式超出正则覆盖范围（如非标准格式的凭证）

### 应急步骤
```python
# 测试 Token 是否被识别
s = PrivacySanitizer()
test_token = "你的 Token: YOUR_TOKEN_HERE"
safe = s.sanitize(test_token, 0)
print("脱敏后:", safe)
print("验证:", PrivacySanitizer.validate_no_leakage(test_token, safe))
```

若验证失败，添加新正则到 `PrivacySanitizer.sanitize()`

## 故障 4：OOM / 内存持续增长

### 症状
进程内存持续增长，`long_term` 字典过大

### 根因
Level 2 记忆过多无法衰减，长期积累

### 应急步骤
```python
# 诊断长期记忆数量
print(f"长期记忆条目: {len(engine.long_term)}")
print(f"短期记忆条目: {len(engine.short_term)}")

# 检查是否有大量 Level 2 记忆未钢印
unmarked_l2 = [eid for eid, e in engine.long_term.items() 
               if e.protection_level == 2 and not e.steelmarked]
print(f"未钢印 Level 2 记忆: {len(unmarked_l2)}")
```
