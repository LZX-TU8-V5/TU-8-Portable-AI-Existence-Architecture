## 组件：PrivacySanitizer

负责将记忆内容中的敏感信息替换为脱敏标记，防止泄露到外部日志或上下文窗口。

### 替换规则

| 模式类型 | 正则 | 替换为 |
|---------|------|--------|
| API Token | `(?i)(token\|sk\|api[_-]?key)[\s:=\"']+([a-zA-Z0-9_-]{16,64})` | `[TOKEN]` |
| Bearer Token | `(?i)Bearer [a-zA-Z0-9_-]{20,}` | `[TOKEN]` |
| 隐私符号 | 原始内容为 `[TOKEN]`、`[CREDENTIAL]` 等 | 透传 |
| 时间干扰 | 各种时间戳模式 | `[RECENT_TIME]` |

### 使用方法

```python
from tu8_memory import PrivacySanitizer

s = PrivacySanitizer()

# 脱敏
safe = s.sanitize("我的 API token 是 sk-1234567890abcdef", protection_level=0)

# 验证无泄露
ok = PrivacySanitizer.validate_no_leakage(original, safe)
print("安全:", ok)
```

### 已知限制

1. **Base64 误判**：某些 Base64 字符串可能误被识别为 Token
2. **短 Token**：长度 < 16 字符的 Token 不会被匹配
3. **嵌套攻击**：`[TOKEN]sk-real-key[TOKEN]` 形式需额外检测
4. **非结构化文本**：纯自然语言中的密钥无法被正则识别

## 组件：ProtectionClassifier

根据记忆内容判断保护级别。

### 分类规则

| 级别 | 内容特征 | 示例 |
|------|---------|------|
| Level 2 | 身份锚点、核心记忆、Token/Credential | TU-8、金木蟾、`token sk-...` |
| Level 1 | 高情感/高意义 | 强烈情绪词、梦想、重要事件 |
| Level 0 | 普通记忆 | 日常记录、闲聊 |

### 强制升级条件

若 `protection_level < 2` 但命中以下任意条件，自动升级为 Level 2：
- 包含 `token`、`sk-`、`sklive`、`bearer` 等凭证关键词
- 包含 `password`、`secret`、`private_key` 等密钥词

```bash
# Python 扫描
python -c "

leaks = []
for p in Path(r'D:\qq366410837\.qclaw\workspace').rglob('*.py'):
    try:
        content = p.read_text(encoding='utf-8')
        sanitized = s.sanitize(content, 0)
        if sanitized != content:
            leaks.append(str(p))
    except:
        pass
print('Found leaks:', leaks)
```
