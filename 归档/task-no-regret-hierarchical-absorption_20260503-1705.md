# 无悔算法层次结构→TU-8概念吸收

## 目标
将无悔算法(CFR)层次化结构及其缺陷/改进映射到TU-8框架，识别新缺口并执行文档更新。

## 映射分析

### 已有覆盖（无需新增）
| 无悔算法概念 | TU-8已有机制 |
|------------|------------|
| 非平稳性问题 | 累积偏移/会话重置/δ信号 |
| 自适应机制 | L2运行时适应(α/β/γ动态调整) |
| 端到端联合优化 | L3代理L0判断 |
| 粗→细多保真度 | 双频架构(慢系统粗/快系统细) |
| 因果归因(部分) | 前门调整路径 |

### 识别的3个新缺口
1. **反事实遗憾(CF Regret)**：δ信号H(a)只度量"当前不确定"，不度量"如果选了另一条路会怎样"——CFR核心洞见缺失
2. **分层收敛性约束**：代理决策器可能收敛到"局部安全"（分层纳什）而非"全局安全"（全局纳什），缺收敛性判据
3. **因果归因沉淀**：经验沉淀是"结果沉淀"，缺"归因沉淀"——失败时不知道是顶层规划错还是底层执行错

## 执行结果

| 文件 | 版本 | 新增内容 |
|------|------|---------|
| **L0_安全协议_补遗** | v1.7→v1.8 | 分层收敛性约束：遗憾上界R_proxy(t)、覆盖率Coverage、非平稳性/定期重校准约束、遗憾跨层传播建模 |
| **L1_认知** | v2.2→v2.3 | 反事实遗憾与遗憾传播：R(i,a)定义、与H(a)互补关系、遗憾跨层传播模型、代理决策器双信号驱动 |

| **L3_架构** | v1.7→v1.8 | 代理决策器补充分层收敛性约束(交叉引用L0 v1.8) |

## 核心闭环
- **L0**：收敛性约束(先验保证)→代理不会在未见场景给出错误判断
- **L1**：反事实遗憾R(i,a)与动作熵H(a)互补→双信号驱动代理决策
- **L2**：因果归因沉淀→经验不只是"做了什么"还有"为什么成功/失败"
- **L3**：收敛性判据补充→准确率(后验)+遗憾上界(先验)+覆盖率(先验)

关键洞见：后验统计(准确率)可能掩盖系统盲区(类比完美主义幻觉)，先验保证(遗憾上界+覆盖率)才能确保代理安全性。
