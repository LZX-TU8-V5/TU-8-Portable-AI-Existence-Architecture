### 2. ollama_client.py v2.0 架构（10370字节）

三层防御体系：
```
Python关键词路由（第一道，绝对可信）
    ↓ 隐私内容
本地 Ollama qwen3:4b（格式化/润色）
    ↓ 私密结果
直接返回用户

    非隐私内容
    ↓
云端（腾讯混元）
    ↓ 发送前
sanitize_for_cloud() 脱敏（第三道）
    ↓ 变量乱码化 / 背景虚拟化
返回结果 restore_from_cloud() 本地还原
```

### 3. 关键发现：qwen3:4b 特性

| 特性 | 结果 |
|------|------|
| `/api/chat` 输出位置 | `thinking` 字段，`content` 永远为空 |
| 即使 `num_predict=15` | 模型仍先说"首先，用户的问题是..." |
| `think: False` | 直接关闭所有输出 |
| `/api/generate` vs `/api/chat` | generate 可输出 content |
| JSON 代码块 | 模型从不输出 |
| 格式化任务（"只输出JSON"） | 完全不听，全程思考 |

**结论**：qwen3:4b 是推理模型，不是指令遵循模型。

### 4. 最终架构决策

| 任务类型 | 处理方式 |
|---------|---------|
| 隐私检测 | Python 关键词（绝对可靠） |
| 正则提取（手机号/邮箱等） | Python re（不用 AI） |
| 格式化/润色 | qwen3:4b `/api/generate` |
| 思考型任务（分析/总结） | qwen3:4b `/api/chat` → 读 `thinking` |
| 简单问答 | qwen3:4b `/api/generate` |
