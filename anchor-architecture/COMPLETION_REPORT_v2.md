## 二、核心创新点（已文档化）

### 2.1 三层剥离宪法

**核心命题**：
> "1+1=2" 在硅基上都是晶体管开关，但认知架构中必须被视为**两种完全异构、不可通约、只能交叉验证**的独立系统。

**三层正交**：
- 物理层（因果律 / 确定性连续量）
- 数字层（结构化关系 / 精确中间表征）
- 语义层（统计共现 / 概率性离散符号）

**每一层作为其他两层的"证伪器"**。

---

### 2.2 状态机绑定协议

**解决的问题**：LLM 不会验证"2025年税法"是否已废止。

**解决方案**：
- 状态机持有"当前真实"（时间 / 法规版本 / 物理参数）
- **注入而非生成**：强制约束 LLM 推理
- **拦截与校验**：LLM 输出必须回传状态机硬校验

**关键**：LLM 无需"记住"2026年新规，只需遵守状态机提供的临时规则。

---

### 2.3 安全原则（★★★★★ 核心）

**四条铁律**（系统设计的"第零条"）：
1. LLM 输出永远是"假设"，物理插件输出才是"证据"
2. 任何 LLM 生成的结论，若无法追溯到至少一个物理插件提供的确定性参数，一律视为无效
3. 当 LLM 概率与物理测量冲突时，无条件采信物理测量
4. "找相同"是 LLM 的能力，"找正确"是物理锚点的责任

---

### 2.4 傅里叶+梯度+角度算法

**算法本质**：不是识别静态形状，而是识别形状的**生成过程**。

**三大机制**：
1. **角度扰动作为认知探针**：主动改变视角，观察梯度变化率
2. **傅里叶变换作为"光场解调器"**：将2D梯度图转换为1D径向信号，FFT提取频率签名
3. **排除法语义检索**：位掩码索引（O(1)排除，从10,000候选→<100）

## 三、与传统 AI Agent 框架的区别

| 维度 | LangChain / AutoGPT | Anchor-Cognitive Architecture |
|------|---------------------|------------------------------------------|
| **知识来源** | LLM 权重矩阵（静态快照） | 外部确定性运行时（动态更新） |
| **时间感知** | 无（每次推理独立） | 有（状态机驱动的时间轴） |
| **安全机制** | Prompt 约束（软） | 架构级硬约束（状态机 + 物理锚点） |
| **行业适配** | 微调 / 重新训练 | 状态图配置化切换（零模型改动） |
| **可审计性** | 黑箱 | 确定性状态转移日志（可解释、可归责） |
| **数据注入** | 全量上下文（容易泄露） | 最小完备集（按需加载，权限严格控制） |
